# 조약돌형 스마트폰 반사경 — 끼움 조립 시안

2026-09-22. 사용자가 기존 외형과 조립성을 반려하고, 조약돌형 외형과 **나사 없는 플라스틱 끼움 결합**을 선택했다. 이전 printable.py 출력물은 그대로 보존한다. 현재 시안의 원본은 `pebble.py`다.

## 구조

- 출력 부품: 좌측 케이스, 우측 케이스, 누름판 — 3개. 구매 부품은 거울과 부드러운 PU 스펀지 패드다.
- 외형 약 **49 × 42.4 × 29.6mm**. 거울을 카메라 쪽으로 옮겨 이전 시안보다 앞뒤 길이가 약 7mm 줄었다. 아래쪽은 폰 삽입과 광학 경로를 위해 열린다.
- 정렬 핀 2개와 내부 스냅 걸쇠 2개. 나사·너트·접착제로 케이스를 잠그지 않는다.
- 거울과 누름판 축을 안에서 넣고 우측 케이스를 닫는다. 닫힌 케이스의 거울 홈 양 끝이 막혀 있다.
- 케이스 아래쪽의 2.4mm 해제 구멍으로 걸쇠를 위로 누르면서 양쪽을 벌린다. 손으로 막 잡아당겨 여는 구조가 아니다. 동시 해제의 편의성은 시제품에서 확인한다.
- 누름판은 직선형 강체다. 기존 곡선 판은 끝만 폰에 맞춰 회전시켜도 판 중간이 폰을 침범했다. 탄성은 뒤의 **14×8×5.8mm 부드러운 PU 스펀지**가 담당한다. 뒷벽에 0.6mm 얕은 자리를 파서 패드 위치가 움직이지 않게 하고, 접착면은 뒷벽을 향한다. 가로로 보이던 관통 축은 없애고, 케이스 안쪽 축 받침에 들어가는 좌우 3mm 짧은 핀만 남겼다.
- 폰 쪽 외곽은 아래 가로대와 양쪽 상단 턱이 없는 단순 **ㄷ자 채널**이다. 휴대폰은 분리된 스토퍼에 걸리지 않고 연속된 안쪽 천장까지 들어간다. 휴대폰과 누름판 축은 6.05mm 더 안쪽으로 들어가지만 거울은 기존 높이에 유지한다. 전면 카메라 반경을 2.2mm로 가정해 **카메라 윗선과 거울 윗선을 맞췄고, 휴대폰 윗변은 거울 윗변보다 7.14mm 위에 있다.** 누름판 회전 공간은 외피 안쪽에 별도 확보했다.
- 휴대폰 주변의 날카로운 접촉부를 줄이기 위해 ㄷ자 입구 폭을 36→40mm로 넓히고 입구·카메라 창 모서리에 R2.2, 거울 받침 외곽에 R1.2를 적용했다. 내부 광학 챔버의 R3와 외피의 기존 큰 라운드는 유지한다. 스냅 걸쇠의 걸림턱과 정렬 핀은 체결 기능 때문에 임의로 둥글리지 않았다.
- 거울 앞쪽 아래에 보이던 양쪽 뾰족한 턱은 전용 ㄷ자 여유 공간으로 잘라 완전히 없앴다. 거울 받침 외곽은 40×23mm로 줄였고, 거울은 아래 턱 없이 위쪽과 뒤쪽 테두리로 고정한다.
- 폰 화면과 거울 사이에는 폰 면 기준 **36×14mm 카메라 창**을 파고, 거울의 32×17mm 유효 창까지 넓은 사각 원뿔대로 연결한다. 폰 면 바로 앞 3mm 구간은 36×14mm 그대로 비워 지지벽이나 얇은 다리가 렌즈 앞에 남지 않게 했다. 특정 카메라 좌표를 향한 작은 구멍이 아니므로 전면 카메라가 몇 mm 옮겨져도 지지대가 렌즈를 가리지 않는다.
- 거울 중심은 카메라 면에서 앞뒤 방향으로 **12mm** 떨어진 위치로 옮겼다(이전 19.07mm). 35×20mm 거울의 가까운 모서리는 폰 면에서 약 3.1mm 남고, 계산상 제공 화각은 약 106.3°×61.4°로 기존 최소 요구 76°×41°보다 넓다. 실제 화각은 휴대폰 렌즈 자체의 화각을 넘지 않는다.

## 조립 순서

1. 좌측 케이스를 옆으로 놓고 거울 홈을 위로 향하게 한다.
2. 반사면 방향을 확인하고 거울을 중앙 분할면에서 좌측 홈으로 넣는다.
3. 뒷벽의 얕은 자리에 약 14×8×5.8mm의 부드러운 PU 스펀지 테이프를 붙인다. 폼은 구매 부품이며 출력하지 않는다. 5.8mm는 CAD 시험값이므로 실제로는 6mm 제품을 잘라 쓰고 결합 시험에서 힘을 조정한다.
4. 누름판의 좌측 축을 축 받침에 넣는다. 폼은 이 과정에서 일부 압축된다.
5. 우측 케이스의 거울 홈·축 구멍·정렬 구멍을 맞춰 수평으로 밀고, 두 걸쇠가 모두 잠겼는지 확인한다.
6. 반사경을 폰 화면 쪽에 놓고 폰 윗변을 아래에서 위로 밀어 ㄷ자 채널의 안쪽 천장까지 넣는다. 누름판은 폰 뒷면 쪽으로 회전하며 폼을 누르고, 폼의 복원력이 폰을 화면 쪽 벽에 고정한다. 설계상 폰 두께는 7~11mm이고 실제 기종의 전면 카메라 위치는 별도 확인한다.

## 거울

현재 CAD 기준은 **35×20×1.1mm, 평면 전면 반사경(First Surface Mirror)**이다. 1.1mm는 기존 코드의 기준이며 구매 가능한 상품을 확인한 두께가 아니다. 실물 확보 후 두께와 외곽 공차에 맞춰 홈을 수정한다. 유효 창은 32×17mm, 거울각은 기존 33도를 유지한다.

문의 사양: **가시광용 평면 전면 반사경 / 보호 알루미늄 코팅 / 35×20mm / 두께 약 1mm, 공급 가능한 두께 회신 / 모서리 면취**. 정확히 이 크기의 재고품·가격은 확인하지 않았다.

일반 후면 코팅 거울은 유리 표면과 뒤의 반사막에서 중복 반사가 생길 수 있다. 글자 영상용 시제품에는 전면 반사경을 권한다. 코팅 면이 카메라·보드 사이의 빛을 반사하도록 설치한다. 반사면의 중앙을 접착하거나 누르지 않는다.

근거: [에드몬드 옵틱스 금속 미러 코팅 설명](https://www.edmundoptics.co.kr/knowledge-center/application-notes/optics/metallic-mirror-coatings/) (2026-09-22 확인). 실물의 반사 품질과 글자 인식률은 아직 검증하지 않았다.

## 재생성

저장소 루트에서 CadQuery가 있는 Python을 사용한다.

```powershell
python hardware/periscope/pebble.py
python hardware/periscope/pebble_preview.py
python hardware/periscope/pebble_html.py OUTPUT.html
```

출력은 `out/pebble/`. 첫 명령은 STEP/STL, 결합 시험 부품 `coupon_left/right`, `report.json`을 생성한다. 검사 실패 시 종료 코드 2다. 두 번째 명령은 실제 STL에서 정지 미리보기를 만든다. VTK·Pillow가 필요하다. 세 번째 명령은 실제 STL을 표시용으로 단순화해 회전·분해·폰 삽입·장착 단면을 볼 수 있는 인터랙티브 HTML 조각을 만든다.

## 검증 결과와 한계

- 좌우 케이스·누름판과 시험 부품 모두 단일 유효 솔리드. 출력 STL은 워터타이트, 연결체 1개.
- 완성 위치의 강체 부품 간섭 0mm³. 거울·누름판 삽입과 케이스 닫힘의 **표본 위치 검사**에서 강체 간섭 0mm³.
- 누름판 회전 0~27도의 표본에서 케이스 간섭 0mm³. 7/9/11mm 폰 모형은 각각 8.594/16.954/25.270도에서 판·폰·케이스 간섭 0mm³.
- 스펀지의 형상상 압축률은 휴대폰 미장착 8.62%, 7mm 폰 22.10%, 9mm 폰 35.01%, 11mm 폰 47.36%다. 이는 접촉 위치의 기하 계산이며 실제 누르는 힘·장기 눌림·복원력은 스펀지 재질과 밀도에 따라 달라진다.
- 걸쇠 끝을 0.85mm 올리는 가정으로 삽입 경로 검사 통과. 해제하지 않고 케이스를 0.8mm 벌리면 걸림턱과 겹쳐 빠짐을 막는 형상이다.
- 빔 길이 16mm·두께 1.2mm. 단순 외팔보식의 뿌리 변형률 추정 약 0.60%. 재질·적층·루트 응력 집중·크리프·피로를 해석한 값이 아니다.
- 실제 반사면에서 만든 광학 경로와 별도로, 최종 케이스에 중앙·주변 9개 가는 광선을 검사했다. 둥근 출구로 바꾼 뒤 수치 교차의 최댓값은 0.00198mm³로 통과 기준 0.01mm³ 미만이다. 렌즈 왜곡·전체 센서 화각·폰 위치 오차 검증은 아니다.
- 폰 면의 36×14mm 독립 검사체와 케이스의 겹침은 0mm³다. 중앙 개구부를 바닥 아래까지 연장한 별도 검사에서도 아래 가로대 겹침이 0mm³이며, 7/9/11mm 폰 모형은 양쪽 턱 없이 안쪽 천장까지 들어간다. 이 개구부는 카메라 공간을 확보하지만, 모든 휴대폰의 노치·다이내믹 아일랜드 위치까지 보장하는 규격은 아니다.
- 라운딩 후에도 7/9/11mm 폰 모형, 누름판 회전, 거울 유지와 조립 경로의 강체 간섭은 0mm³다.
- 거울을 여섯 축 방향으로 1mm 이동하면 케이스에 걸린다. 복합 회전으로 빠져나오는 모든 경로까지 증명한 것은 아니다.
- 전체 케이스의 출력 방향·서포트·치수 수축·끼우는 힘·실제 폰 보호와 고정력은 **미검증**. 완제품 출력 전에 작은 결합 시험 부품부터 출력한다.

시험 부품은 실제 결합부를 잘라낸 형상이다. 옆으로 돌려 빔이 휘는 방향이 적층면 안에 오도록 배치했다. 양쪽 STL은 각각 따로 슬라이서에 놓고 실제 사용할 필라멘트/설정으로 시험한다. 꽉 끼면 억지로 누르지 말고 간극을 조정한다. 본체 출력은 같은 적층 방향과 서포트 제거 가능성을 먼저 확인해야 한다.
