# 조약돌형 스마트폰 반사경 — 끼움 조립 시안

2026-09-22. 사용자가 기존 외형과 조립성을 반려하고, 조약돌형 외형과 **나사 없는 플라스틱 끼움 결합**을 선택했다. 이전 printable.py 출력물은 그대로 보존한다. 현재 시안의 원본은 `pebble.py`다.

## 구조

- 출력 부품: 좌측 케이스, 우측 케이스, 누름판 — 3개. 구매 부품은 거울과 부드러운 PU 스펀지 패드다.
- 외형 약 **49 × 49.6 × 33.2mm**. 확보한 40×30mm 거울이 휴대폰 면을 침범하지 않도록 카메라 면과 거울 중심 간격을 15mm로 잡았다. 아래쪽은 폰 삽입과 광학 경로를 위해 열린다.
- 정렬 핀 2개와 내부 스냅 걸쇠 2개. 나사·너트·접착제로 케이스를 잠그지 않는다.
- 폼과 누름판 축을 안에서 넣고 우측 케이스를 닫은 다음, 거울의 스티커 보호지를 벗겨 외부에서 연속된 경사 접착판에 붙인다. 거울 끼움 홈과 유지 턱은 없다.
- 케이스 아래쪽의 2.4mm 해제 구멍으로 걸쇠를 위로 누르면서 양쪽을 벌린다. 손으로 막 잡아당겨 여는 구조가 아니다. 동시 해제의 편의성은 시제품에서 확인한다.
- 누름판은 직선형 강체다. 탄성은 뒤의 **16×10×6mm 부드러운 PU 폼**이 담당한다. 뒷벽과 내부 리브를 마지막 단계에서 다시 잘라 폼 전체가 들어가는 개방형 공간을 확보했고, 뒤쪽 1mm는 위치를 잡는 포켓에 들어간다. 뒤쪽 스냅은 폼 위로 올려 서로 겹치지 않는다. 가로로 보이던 관통 축은 없애고, 케이스 안쪽 축 받침에 들어가는 좌우 3mm 짧은 핀만 남겼다.
- 폰 쪽 외곽은 아래 가로대와 양쪽 상단 턱이 없는 단순 **ㄷ자 채널**이다. 휴대폰은 분리된 스토퍼에 걸리지 않고 연속된 안쪽 천장까지 들어간다. 전면 카메라 반경을 2.2mm로 가정해 **카메라 윗선과 거울 윗선을 맞췄고, 휴대폰 윗변은 거울 윗변보다 4.42mm 위에 있다.** 누름판 회전 공간은 외피 안쪽에 별도 확보했다.
- 휴대폰 주변의 날카로운 접촉부를 줄이기 위해 ㄷ자 입구 폭을 36→40mm로 넓히고 입구·카메라 창 모서리에 R2.2, 거울 받침 외곽에 R1.2를 적용했다. 내부 광학 챔버의 R3와 외피의 기존 큰 라운드는 유지한다. 스냅 걸쇠의 걸림턱과 정렬 핀은 체결 기능 때문에 임의로 둥글리지 않았다.
- 거울 앞쪽 아래의 뾰족한 턱과 양옆의 얇은 고정막은 없다. 40×30mm 거울 뒤에는 좌우 케이스에 걸친 2.4mm 두께의 연속 경사판만 두며, 거울 자체의 스티커 면을 여기에 직접 붙인다. ㄷ자 공간을 먼저 절삭한 뒤 이 판을 합쳐 접착면이 사라지지 않게 한다. 완성 판 체적은 약 3543.2mm³다.
- 폰 화면과 거울 사이에는 폰 면 기준 **36×14mm 카메라 창**을 파고, 거울의 36×26mm 유효 영역까지 넓은 사각 원뿔대로 연결한다. 폰 면 바로 앞은 비워 지지벽이나 얇은 다리가 렌즈 앞에 남지 않게 했다.
- 거울 중심은 카메라 면에서 앞뒤 방향으로 **15mm** 떨어져 있다. 계산상 제공 화각은 약 100.4°×72.0°로 기존 최소 요구 76°×41°보다 넓다. 실제 화각은 휴대폰 렌즈 자체의 화각을 넘지 않는다.

## 조립 순서

1. 좌측 케이스를 옆으로 놓고 16×10×6mm로 자른 부드러운 PU 폼을 뒷벽 포켓에 넣는다. 필요하면 뒷면에 얇은 양면테이프를 사용한다.
2. 누름판의 좌측 축을 축 받침에 넣는다. 폼은 이 과정에서 약 5% 미리 눌린다.
3. 우측 케이스의 축 구멍과 정렬 핀을 맞춰 수평으로 밀고, 두 걸쇠가 모두 잠겼는지 확인한다.
4. 40×30mm 거울의 반사면 방향을 확인한다. 스티커 보호지를 벗기고 경사진 접착판의 외곽에 맞춰 눌러 붙인다. 거울이 좌우 케이스의 중앙 이음선을 덮으므로 케이스를 다시 열려면 거울을 먼저 떼어야 한다.
5. 반사경을 폰 화면 쪽에 놓고 폰 윗변을 아래에서 위로 밀어 ㄷ자 채널의 안쪽 천장까지 넣는다. 누름판은 폰 뒷면 쪽으로 회전하며 폼을 누르고, 폼의 복원력이 폰을 화면 쪽 벽에 고정한다. 설계상 폰 두께는 7~11mm다.

## 거울

확보한 거울의 외곽은 **40×30mm**이고 뒷면 스티커를 경사판에 직접 붙인다. CAD 두께는 실측 전까지 1.1mm로 두었지만 끼움 홈이 없어서 두께 오차가 조립을 막지는 않는다. 유효 반사 영역은 가장자리 2mm씩을 제외한 36×26mm, 거울각은 33도다.

구매한 거울이 전면 반사경인지 일반 후면 반사경인지는 아직 확인하지 않았다. 뒷면 스티커의 접착력과 유리 가장자리 안전성도 실물 조립에서 확인한다.

일반 후면 코팅 거울은 유리 표면과 뒤의 반사막에서 중복 반사가 생길 수 있다. 글자 영상용 시제품에는 전면 반사경을 권한다. 코팅 면이 카메라·보드 사이의 빛을 반사하도록 설치한다. 반사면의 중앙을 접착하거나 누르지 않는다.

근거: [에드몬드 옵틱스 금속 미러 코팅 설명](https://www.edmundoptics.co.kr/knowledge-center/application-notes/optics/metallic-mirror-coatings/) (2026-09-22 확인). 실물의 반사 품질과 글자 인식률은 아직 검증하지 않았다.

## 재생성

저장소 루트에서 CadQuery가 있는 Python을 사용한다.

```powershell
python hardware/periscope/pebble.py
python hardware/periscope/pebble_preview.py
python hardware/periscope/pebble_html.py OUTPUT.html
```

출력은 `out/pebble/`. 첫 명령은 STEP/STL, 결합 시험 부품 `coupon_left/right`, `report.json`과 **한 번에 출력하는 `tango_pebble_print_plate.stl`**을 생성한다. 이 통합 STL에는 좌측 케이스·우측 케이스·누름판만 서로 떨어진 3개 바디로 들어가며 거울·스펀지는 포함하지 않는다. 검사 실패 시 종료 코드 2다. 두 번째 명령은 실제 STL에서 정지 미리보기를 만든다. VTK·Pillow가 필요하다. 세 번째 명령은 실제 STL을 표시용으로 단순화해 회전·분해·폰 삽입·장착 단면을 볼 수 있는 인터랙티브 HTML 조각을 만든다.

`tango_pebble_print_plate.stl`은 형상만 담은 교환 파일이라 서포트 설정이 없다. 슬라이서에서 내부 공중 시작 면까지 받치도록 서포트를 설정해야 한다. 이전 35×20mm 거울 형상의 `tango_pebble_A1_supported.3mf`는 현재 40×30mm 모델과 맞지 않으므로 출력에 사용하지 않는다.

## 검증 결과와 한계

- 좌우 케이스·누름판과 시험 부품 모두 단일 유효 솔리드. 출력 STL은 워터타이트, 연결체 1개.
- 통합 출력 STL은 71.35×67.41×31.08mm 안에 분리된 워터타이트 바디 3개가 있고 서로 겹치지 않는다. 케이스는 평평한 분할면을 바닥으로 배치했지만 형상 내부에 공중에서 시작되는 층이 있어 서포트가 필요하다. 부품 사이 최소 축방향 여유는 7.5mm 이상이다.
- 완성 위치의 강체 부품 간섭 0mm³. 거울·누름판 삽입과 케이스 닫힘의 **표본 위치 검사**에서 강체 간섭 0mm³.
- 누름판 회전 0~27도의 표본에서 케이스 간섭 0mm³. 7/9/11mm 폰 모형은 각각 8.594/16.954/25.270도에서 판·폰·케이스 간섭 0mm³.
- 폼의 형상상 압축률은 휴대폰 미장착 5.00%, 7mm 폰 18.03%, 9mm 폰 30.51%, 11mm 폰 42.45%다. 폼과 하우징의 강체 겹침은 0mm³다. 이는 접촉 위치의 기하 계산이며 실제 누르는 힘·장기 눌림·복원력은 폼 재질과 밀도에 따라 달라진다.
- 걸쇠 끝을 0.85mm 올리는 가정으로 삽입 경로 검사 통과. 해제하지 않고 케이스를 0.8mm 벌리면 걸림턱과 겹쳐 빠짐을 막는 형상이다.
- 빔 길이 16mm·두께 1.2mm. 단순 외팔보식의 뿌리 변형률 추정 약 0.60%. 재질·적층·루트 응력 집중·크리프·피로를 해석한 값이 아니다.
- 실제 반사면에서 만든 광학 경로와 별도로, 최종 케이스에 중앙·주변 9개 가는 광선을 검사했다. 모든 표본 광선과 케이스의 교차는 0mm³다. 렌즈 왜곡·전체 센서 화각·폰 위치 오차 검증은 아니다.
- 폰 면의 36×14mm 독립 검사체와 케이스의 겹침은 0mm³다. 중앙 개구부를 바닥 아래까지 연장한 별도 검사에서도 아래 가로대 겹침이 0mm³이며, 7/9/11mm 폰 모형은 양쪽 턱 없이 안쪽 천장까지 들어간다. 이 개구부는 카메라 공간을 확보하지만, 모든 휴대폰의 노치·다이내믹 아일랜드 위치까지 보장하는 규격은 아니다.
- 라운딩 후에도 7/9/11mm 폰 모형, 누름판 회전, 거울 유지와 조립 경로의 강체 간섭은 0mm³다.
- 40×30mm 거울과 하우징의 계산상 강체 겹침은 좌우 각각 0.005mm³ 미만이며 검사 허용치 안이다. 끼움 유지 구조는 없고 공장 부착 스티커만 사용하므로 실제 접착력과 장기 내구성은 실물 시험이 필요하다.
- 무서포트 실물 출력에서 불량이 발생했다. 0.2mm 층 단면 검사에서 좌측 케이스 z=2.5/6.1mm, 누름판 z=0.7mm, 우측 케이스 z=3.9mm에 이전 층과 이어지지 않는 시작 면을 확인했다. 단순 회전만으로 세 부품의 공중 시작 면을 모두 없앨 수 없었다.
- Bambu Studio에서 A1/0.4mm/PLA Basic/0.20mm Standard와 트리(자동) 서포트 30°로 다시 슬라이스했다. 153층, 높이 30.60mm, 예상 1시간 9분, 모델 16.08g + 서포트 4.03g = 총 20.11g이다. 이는 슬라이서 검증이며 수정 3MF의 실물 재출력 성공을 뜻하지 않는다.
- 치수 수축·끼우는 힘·실제 폰 보호와 고정력은 아직 **미검증**이다. 완제품 재출력 전에 작은 결합 시험 부품부터 출력한다.

시험 부품은 실제 결합부를 잘라낸 형상이다. 옆으로 돌려 빔이 휘는 방향이 적층면 안에 오도록 배치했다. 양쪽 STL은 각각 따로 슬라이서에 놓고 실제 사용할 필라멘트/설정으로 시험한다. 꽉 끼면 억지로 누르지 말고 간극을 조정한다. 본체는 서포트 포함 3MF로 출력하고, 완료 후 ㄷ자 카메라 공간과 누름판 축 주변의 트리 서포트를 먼저 잘게 나눠 제거한다.
