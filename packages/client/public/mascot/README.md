# Mascot Assets

탱고북 마스코트 **호리(Hori)** — 호랑이 캐릭터. 자산은 `hori/` 폴더 아래.

- Lottie (5): `idle.json`, `waving.json`, `cheering.json`, `celebrating.json`, `dancing.json`
- WebP (7): `idle.webp`, `waving.webp`, `thinking.webp`, `reading.webp`, `pointing.webp`, `sleeping.webp`, `sad.webp`
- Fallback: 파일 없으면 state별 이모지 (기본 🐯)

향후 친구 캐릭터 추가 시 `panda/`, `fox/` 등 같은 레벨 폴더로 확장. `<Mascot character="hori" />`가 기본값, `character` prop으로 전환.
