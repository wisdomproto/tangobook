1왜 1차 무료 베타인가

시장 조사·agent 검토·brainstorm 다 *가설*. 진짜 답은 *데이터*. 1차 베타 = paid 압박 없이 순수 콘텐츠 가치만 검증.

🎯 검증 핵심

"우리 동화책으로 아이가 매일 들어오는가? 부모가 학습 가치 느끼는가?"

🚫 일부러 안 함

충전·구독·코스 결제 모델 결정. 2차에서 A/B 테스트로 데이터 기반 결정.

📊 통과 시

2차 부분 유료 (콘텐츠 확장 + 결제 모델 검증) 진행. 미통과 시 콘텐츠·UX 보강 후 재시작.

🌱 핵심 인사이트: Khan Academy Kids·Duolingo ABC = 무료 모델로 1위. 가치 먼저 입증 → 유료 모델은 그 후. 우리도 동일 순서. 추측보다 데이터.

2타겟 오디언스

🇰🇷 한국 4-7세 부모 (1차 베타 핵심)

30대 후반~40대 초반 부모 / 4-7세 자녀. 한글 떼기·영어 시작 시점. 학습지 13~18만 원 부담. 핑크퐁·토도 등에 학습 깊이 의심. 맘카페·카카오·인스타 활동.

모집 채널: 맘카페 (네이버) → 카카오 친구 → 인스타 → 도메인 직접 방문

evangelist 부모: 의견 적극, 자녀 학습 진심, 베타 후기 작성 의향

3메시지 / 슬로건

메인 슬로건
"동화책 읽으면서 초등 입학 전 한글·영어 필수 어휘 뗀다"

핵심 차별 4가지 (시장 검증된 우리만의 것)

1. 이미지 퀄리티

2026 AI SOTA 그림체. 리틀팍스 등 기존 = 10년 전 그림체.

2. 양산 속도

매주 새 책. 무거운 출판사는 연 12권.

3. 명작 원전

그림형제·안데르센·이솝. 자체 IP 아닌 *진짜 원작*.

4. 한·영 한 책

한 동화 = 한·영 동시 학습. 글로벌 어디에도 없는 모델.

1차 베타 강조 톤

"가치 입증 단계" 톤. "광고 0 · 결제 0 · 카드 등록 0 · 500명 한정 베타 사용자 의견으로 정식 런칭".

9추천 무한 lever

1차 베타는 *무료* 라 보상이 *2차 부분 유료에서 적용*:

🔁 추천 보상 구조

  • 친구 1명 OAuth 가입 → 추천인 2차 시작 시 1개월 무료
  • 친구도 가입 즉시 베타 무료 풀체험 + 평생 30% 할인
  • 12명 = 1년 무료 (2차 시작 시 적용)
  • abuse 방지: OAuth + 같은 폰번호·기기 1회

1차 베타 카피로 직접 활용: "친구와 함께 시작하면 평생 30% 할인 + 친구 1명당 1개월 추가"
