바이럴 자석 5종 — 한 클릭 공유 UI 흐름

바이럴 자석은 컨셉만 있고 화면이 잘못 짜이면 안 굴러간다. 5종 자석 각각의 출발 화면 → 자석 카드 미리보기 → 공유 시트 → 친구 도달 4단계 모바일 흐름을 와이어프레임으로 사전 확정. 디자인·개발팀에 그대로 발주 가능한 수준.

📱 모바일 우선 (320px~414px) 🎯 클릭 수 목표 ≤ 2회 🔁 자석 5종 🎨 low-fi 와이어프레임 (회색/박스/단순 컬러)

📐 UI 설계 7원칙

  • 클릭 ≤ 2회 — 출발 화면에서 공유 완료까지 최대 2번 탭. 3번이면 자석 작동 안 함.
  • 자석 카드 자동 생성 — 사용자가 캡션·이미지 안 만들어도 됨. 클릭하면 카드 완성된 상태로 미리보기.
  • 한국은 카톡, 글로벌은 인스타·메시지 — 우선 노출 채널을 지역·언어로 분기.
  • 자녀 이름·이미지는 자동 채움 + 편집 가능 — 프라이버시 우려 부모는 이름 끄기 가능 (디폴트 ON).
  • 출발 위치를 적극적 — "공유" 버튼을 숨기지 말 것. 화면 상단·종료 직후 큰 버튼.
  • 인센티브 가시화 — 자석 4·5는 "지금 공유하면 N개월 무료" 같은 보상 명시.
  • 강제 X, 매력으로 유도 — "공유 안 하면 차단" 같은 강압 어조 절대 금지.

  • POST /api/share/track — {magnet_id, action: clicked|previewed|shared} 이벤트 수집
  • GET /api/invite/status — 현재 초대 수, 다음 보상까지 남은 수
  • POST /api/invite/redeem — 가입 시 초대 코드 적용 + 양방 보상 발급

🎨 이미지 생성 파이프라인

  • node-canvas 또는 @vercel/og 사용 — 서버사이드 SVG → PNG 합성
  • 템플릿 5종 (자석별) × 비율 3종 (정사각 1080×1080 / 스토리 1080×1920 / PDF A4)
  • 자녀 이름·KPI·그림체 스타일은 동적 합성. 폰트는 Pretendard 임베드
  • 생성 응답 시간 < 2초 (사용자가 미리보기 기다리는 시간)

📱 프론트 화면 (5종)

  • /weekly-report — 자석 1 출발점
  • /book/:id/end — 자석 2 출발점 (동화 종료 모달)
  • /book/:id/styles — 자석 3 출발점 (그림체 갤러리)
  • /monthly-report — 자석 4 출발점
  • /my/invite — 자석 5 허브
  • 공통: <ShareCardPreview /> + <ShareSheet /> 재사용 컴포넌트

📊 측정 이벤트 (Mixpanel/Amplitude)

  • share_button_clicked {magnet, user_id}
  • share_card_previewed {magnet, user_id}
  • share_completed {magnet, channel, user_id}
  • invite_link_clicked {referrer_user_id, invite_code}
  • invite_signup {referrer_user_id, new_user_id}
  • 대시보드 KPI: 자석별 클릭→공유 전환율, 자석별 K-factor

⚠️ 프라이버시·법규

  • 자녀 이름 글로벌 토글 + 자석별 오버라이드 (디폴트 ON · OFF 선택 가능)
  • 자녀 사진 업로드 시 본인 동의 명시 (만 14세 미만 보호자 동의)
  • 공유 카드에 자녀 사진 사용 시 별도 동의 (개인정보보호법)
  • 카톡 공유 시 카카오 디벨로퍼스 앱 등록 필요
  • 인스타·페이스북 공유는 표준 Web Share API 사용 (앱 등록 X)

🚦 우선순위 (베타 시작 D-day까지)

  • P0 (베타 D0 필수): 자석 1 (학습 그래프 카톡) + 자석 5 (친구 초대) — 가장 강한 자석 두 개부터
  • P1 (W1-W2): 자석 2 (좋아한 동화 인스타) — 동화 종료 화면 통합
  • P2 (W3-W4): 자석 3 (그림체 4종 캐러셀) — 인스타 캐러셀 이미지 생성
  • P3 (W4-W8): 자석 4 (월말 PDF) — 월말 발송 자동화. 첫 월말 시점에 맞춤 출시

📐 측정 임계 (자석별 합격선)

  • 자석 1 (학습 그래프): 주간 리포트 오픈 가구 중 공유 클릭 ≥ 25%
  • 자석 2 (동화 카드): 동화 완독 직후 공유 클릭 ≥ 15%
  • 자석 3 (그림체 캐러셀): 풀스펙 갤러리 진입 가구 중 공유 클릭 ≥ 10%
  • 자석 4 (월말 PDF): 다운 가구 중 가족 카톡방 공유 ≥ 30%
  • 자석 5 (친구 초대): K-factor ≥ 1.5 (가구당 평균 1.5명 가입 유도)
