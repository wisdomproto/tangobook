01. Market

시장성 — 4-7세 미취학 디지털 학습

한국 → 영어권 → 아시아 7개국. 미취학 가정의 일상에 들어가는 시장.

TAM · GLOBAL

$280B+

글로벌 K-12 EdTech 시장. 미취학 부문 약 $30B, 디지털 동화·리딩 부문 빠른 성장.

SAM · 아시아 7개국

~$8B

한국 + 일본 + 동남아 5 + 인도 일부. 미취학 디지털 학습 시장. 영어 사교육 갈증 공통.

SOM · 한국 정식

~$120M

4-7세 약 130만명 · 디지털 학습 침투 30%+ · ARPU 약 ₩7,500/월 가정.

왜 이 시장인가

  • 아시아 부모의 공통 갈증 = 영어 사교육. 한국 학원·학습지 시장 연 5조+. 동남아 영어 사교육 폭증.
  • 밀레니얼 부모 = 디지털 학습 거부감 ↓. 영상보다 학습 콘텐츠 선호 전환.
  • 4년 LTV. 한 아이가 4세 → 7세 = 평균 4년 구독. 형제 자매 호환 시 더 길어짐.
  • 핑크퐁·BabyBus 가 길 닦음. 한국 키즈 IP 글로벌 가능성 검증됨.
핵심: 시장 규모는 충분. 문제는 "진짜 OTT 모델이 없다" — 다음 섹션에서 설명.
02. Competition — 기존 업체 문제

"수만권 동화"가 OTT 가 아닌 이유

리틀팍스·Reading Eggs·핑크퐁 — 수만권 라이브러리 보유. 하지만 진짜 OTT 가 아니다.

문제 ①

10~20년 된 구식 컨텐츠

리틀팍스 25년·Reading Eggs 25년·핑크퐁 15년 — 라이브러리 대부분이 10~20년 된 자산. 2025 AI 양산 콘텐츠 대비 비주얼 노후. 부모도 "내 어릴 때 본 거 같다" 느낌. Netflix 가 80년대 영화만 갖고 있는 거랑 같음.

문제 ②

신간 속도 느림

새 동화 1권 = 작가·일러스트레이터·성우·편집 = 수개월 + 수백~수천만원. 직원 100명 회사도 신간 = 월 5~10권 한계. 부모가 매주 새 책 만나는 경험 X — OTT 답지 않다.

문제 ③

검수 = 편집자 (시장 평가 X)

어떤 책이 라이브러리에 들어갈지 = 출판사 직원 평가. 소비자 인기 평가 X. 인기작이 부각되지 않음 — 유튜브·웹툰처럼 시장이 컨텐츠를 키우는 구조 부재. 결과: 작가도 노출 못 받고, 소비자도 보석 같은 신인 작품 못 만남.

문제 ④ → 결론

즉, OTT 가 아니다

신간 속도 X · 시장 평가 X · 작가 풀 X = 그냥 "디지털 도서관". 진짜 OTT (Netflix · 카카오웹툰 · 유튜브) 의 ① 매주 신간 ② 소비자 평가 ③ 무한 제작자 풀 — 셋 모두 없음. 키즈 동화 시장에 진짜 OTT 가 없다 — 우리가 만든다.

03. What We Do

우리가 하는 것 — 진짜 키즈 동화 OTT

우리 = 플랫폼 (브랜딩/마케팅/유저 모으기). 실제 컨텐츠 = 외부 작가. 초기 마케팅 미끼 컨텐츠만 우리가 직접 제작.

04. Why Now

왜 지금이 진입 시점인가

AI 가 키즈 동화 UGC 를 처음 가능하게 만든 지 6개월. 우리는 이미 6개월 헤드 — 브랜딩/마케팅에 시간·돈 다 쓸 차례.

① AI DISRUPTION

키즈 일러스트 비용 0

여태 키즈 UGC 가 없던 이유 = 일러스트 1권 수백~수천만원. 2025 AI 가 이 비용을 0 으로 만든 게 6개월 전. 이제 작가가 본인 시간만으로 동화 제작 가능 — 카테고리 자체 새로움.

② 6 개월 헤드

이미 풀 파이프라인

저작도구 v2 · 자동 영상·오디오북 · 마케팅 자동화 · 우리 기초 컨텐츠 (명작·자연관찰·한·영 파닉스) 모두 완성. 곧 런칭 — 따라오는 스타트업은 0 부터 6개월.

③ MOAT

브랜드 × 작가 funnel

AI 자체는 moat 아님 (누구나 씀). 진짜 moat = 브랜딩으로 모은 유저 + 합류한 작가 풀. 먼저 도달 = 작가가 우리 플랫폼 선택. Network effect.

누가 못 따라오나

경쟁군 왜 못 따라오나
100명 회사
(Reading Eggs · 리틀팍스 · 핑크퐁)		 전통 양산 모델 sunk cost — 100명 인건비 구조 못 갈아엎음. UGC 모델 = 자기 매출 cannibalize
출판사 (웅진·창비·비룡소) 1책 1예산 구조. 작가 풀 운영 노하우 X. 디지털 인프라 X. 오히려 우리 파트너 (출판 funnel)
⚠️ 진짜 라이벌 — 스타트업 AI 시대라 따라하기 쉬움. 6개월 안에 5~10개 등장 가능 — 브랜딩·작가 풀 lock-in 으로 차별
카카오웹툰·네이버웹툰 위협 아님 — 브랜딩 mismatch. 성인용 웹툰 브랜드라 부모가 4-7세 자녀 컨텐츠를 거기서 안 찾음. 키즈 진출 시 새 브랜드 필요 = 0 부터 시작 — 우리와 동일 출발선
핵심: AI 자체는 누구나 쓴다. 진짜 moat = ① 6개월 헤드, ② 브랜딩·작가 funnel network effect, ③ 한·영 동시 + 자연관찰 + 명작 (작가 진입 어려운 영역).
05. Business Model

비즈니스 모델 — 3 Layer

① 부모 OTT 구독 (메인 매출) · ② 작가 royalty 분배 (cost = 매출 %) · ③ 인기작 출판 + IP 라이선싱 (장기). 카드 등록 강제 X · 자동결제 함정 X.

LAYER 1 · 메인

🏠 OTT 구독

월 구독 (Freemium) · 7일 풀 무료 · 카드 X · 가격 베타 후 확정 (후보 ~₩7,500/mo). 매출 ~80%.

LAYER 2 · COST

✍️ 작가 royalty

구독 매출의 일정 % 를 작가 풀에 분배 (디지털 업계 표준). Spotify 모델 — 읽힌 시간 기준 가중. 구독 0 = royalty 0, risk 0.

LAYER 3 · 장기

📚 출판 + IP

인기작 = 종이책 출판 (POD · 아마존) + IP 라이선싱 (굿즈·영상). 정식 단계 이후 추가 layer.

moat = 가격 + 플랫폼: 학습지·웅진은 인건비 구조 때문에 우리 가격 못 맞춤. 우리 = 작가 royalty = 매출 % 분배 (직원 양산 X) 라 가능. 영업이익률 25~35% 목표 (royalty 분배 후) — Netflix 8~15% 보다 가벼움.
06. Author Funnel

외부 작가 funnel — 출판사 빠지는 구조

기존 출판 시장에서 작가가 못 가지던 노출·royalty 를 우리가 제공.

📕 기존 출판

출판사 게이트키핑

  1. 작가 응모 → 공모전 (연 1~2회)
  2. 출판사 직원 평가 — 소수만 통과
  3. 종이책 출판 = 등단 조건
  4. 노출 채널 X (서점·도서관)
  5. 그림 작가는 책 1~2권 내고 끝
🐯 탱고북

디지털 등단 + 소비자 평가

  1. 작가 모집 (공모전 + 상시)
  2. 저작도구 + AI 삽화 = 진입 비용 0
  3. 디지털 공개 = 즉시 등단
  4. 소비자 평가 → 인기작 = 출판 funnel
  5. 글로벌 노출 + royalty 분배
  6. 인기작 = 종이책 (POD·아마존) + IP

작가 단계별 진입

① 모집
공모전 + 상시

2차 베타: 1회 공모전 5~10명. 정식: 상시

② 제작
저작도구 + AI

진입 비용 0. 그림 작가는 preset 라이선스

③ 평가
시장 평가 + royalty

편집자 검수 → 공개 → 읽힌 시간 기반

④ 출판·IP
아마존 + 한국 출판

한국·글로벌 — 마케팅 이미 됐으니 자연 진입

출판사 빠지는 가치: 기존 유통 구조에서 출판사 60~70% 마진이 사라지고 우리 플랫폼 매출 + 마케팅·브랜딩 투자 + 작가 디지털 등단·노출 채널로 재분배. 작가는 royalty 자체보다 등단 · 글로벌 노출 · 출판 funnel 가치가 핵심. Netflix vs 영화관 / Spotify vs 음반사 / 유튜브 vs 방송국 — 같은 패턴.

🌍 글로벌 일러스트레이터 풀 — 우리만의 ammunition

전세계 일러스트레이션 상 수상작 풀 = 매년 수천명. 상 받고도 책 1~2권 내고 끝나는 게 현실 — 노출 채널 없고 royalty 적음. 우리가 디지털 등단 + 글로벌 마케팅 + 30% royalty 제공.

10. Global + Publishing

인기작 글로벌 마케팅 + 출판 funnel

인기 작품 = 우리가 더 마케팅 (글로벌). 진짜 인기작 = 출판 (아마존).

① 글로벌 마케팅

인기작 = 더 광고

구독 매출 기준 top 작품 → 글로벌 광고 + 유튜브 자동 영상 + 다국어 자막. 작가는 본인 작품이 글로벌 노출되는 보상 — 더 많은 작가 진입 동기.

자국어 ↔ 영어 매칭

한국어 ↔ 영어 (메인) → 일본어·태국어·인니어·베트남어 ↔ 영어 동일 패턴 확장. 책 1권 = AI 자동 다국어화 (이미지 재사용 + 텍스트만 새).

② 출판 funnel

아마존 + 한국 출판

진짜 인기작 = 종이책 출판. POD (Print on Demand) + 아마존 KDP — 재고 부담 0. 마케팅은 이미 디지털에서 됐으니 자연 진입.

  • 온라인·오프라인 서점
  • IP 라이선싱 (굿즈·영상·교과서)
  • 해외 출판사 라이선스
  • 출판 인세 → 작가 + 우리 공동
왜 자연스러운가: 기존 출판은 작가 → 출판사 → 서점 (3 단계). 우리는 작가 → 플랫폼 → 인기 검증 → 출판 (4단계지만 첫 3단계는 무료/디지털). 작가는 등단 보장 받고, 우리는 인기 검증된 작품만 출판 (실패 risk 0).
