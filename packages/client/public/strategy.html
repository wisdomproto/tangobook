04. Differentiation

핵심 차별점 7가지

경쟁사가 따라하기 어렵거나, 따라하려면 1년 이상 걸리는 구조적 차별점들.

1. 명작 원전 기반 — AI 양산 사이트와 정반대 포지셔닝 ★ 진짜 moat

AI 동화 양산 사이트가 천지인 시대. 우리는 그림형제·안데르센·이솝·페로 등 원전을 새 그림으로 다시 그린다. "AI 가 만든 가짜 동화"가 아니라 "공식 명작을 새 그림으로" 인식.

부모는 결제 결정 시 "이거 진짜인가" 의문을 가짐. 우리는 그 의문에 대한 답을 저작권 만료된 원전 + 명작 카테고리로 명확히 제공. 경쟁사 (Epic·Lingokids·핑크퐁) 가 흉내내려면 *전체 라이브러리 큐레이션* 을 다시 해야 함.

💡 같은 동화 여러 그림체 swap 도 보유 — 다만 부모 결제 lever 가 아니라 제품 내부의 재독성 강화 도구로 포지셔닝 (마케팅에서 강조 X).

2. 3단계 글밥 시스템 — 5세도 7세도 같은 동화를 본다

아이는 매년 자란다. 3세 때 본 동화를 5세에 다시 보고 싶어할 수 있다. 우리는 같은 동화를 짧게(3~4세) / 보통(5~6세) / 자세히(6~7세) 3단계로 제공한다. 한 권을 사면 3년을 본다.

부모 관점에서: 동생이 태어나도 같은 구독을 이어 쓴다. 학습 관점에서: 아이는 자기 수준에 맞는 글밥으로 읽으며 어휘를 자연스럽게 늘린다.

3. 동화 → 어휘 → 파닉스 → 게임 → 리포트 통합 학습 루프

경쟁사는 동화책 앱(Epic), 파닉스 앱(Lingokids ABC), 어휘 앱(Pinkfong)이 다 분리돼 있다. 우리는 하나의 데이터로 모든 기능을 연결한다.

  • The Three Little Pigs 읽음 → "pig·wolf·house·brick" 어휘 노출
  • 같은 단어로 자동 매칭 게임 생성 → 게임 진행
  • "P sound" 파닉스 단계와 자동 연결 → pig·pen·pot 학습
  • 모든 결과가 어휘 마스터리(unknown→seen→practiced→mastered)로 누적
  • 부모 리포트에 "이번주 14단어 익힘 / 파닉스 P 사운드 80%" 표시

이게 우리만의 통합 데이터 모델이다. 경쟁사가 따라하려면 시스템 전체를 다시 짜야 한다.

4. 자국어 ↔ 영어 자동 매칭 — 한 학습으로 두 언어 동시 ★ 핵심 무기

이게 우리 플랫폼의 가장 강력한 차별점이다. 아이가 한국어로 동화 한 권을 읽으면, 그 안의 단어 · 파닉스 사운드 · 예문 · 발음 · 게임이 모두 영어와 자동 매칭되어 학습된다. 한 번의 학습으로 두 언어가 같이 따라온다 — 부모 입장에서 한 구독료로 한국어 학습 + 영어 학습 동시.

📐 매칭 학습 메커니즘 — 학습 요소별 한·영 자동 매핑

학습 요소 🇰🇷 한국어 🇺🇸 영어 (자동 매칭) 학습 효과
핵심 단어 사과 / 거인 / 콩 apple / giant / bean 어휘 두 배 누적
파닉스 사운드 ㅏ (아) → 사과·아빠·아침 a → apple, ant, axe 음운 인식 동시 발달
예문 (Sentence) 사과는 빨갛다. An apple is red. 문장 구조 자연 노출

📖 실제 학습 예시 — "잭과 콩나무" 한 권

🇰🇷 한국어 학습 흐름

  • 단어: 잭, 콩, 거인, 황금알, 거위, 도끼
  • 파닉스: 받침 ㄱ(잭·콩·도끼), ㅁ(콩·금)
  • 예문: "잭은 콩을 심었어요."
  • TTS: 한국어 자연 발음
  • 게임: 매칭·블록·낱말쓰기 (한글)

🇺🇸 영어 자동 매칭

  • Words: Jack, bean, giant, golden egg, goose, axe
  • Phonics: J·B·G sound, CVC (egg)
  • Sentence: "Jack planted the bean."
  • TTS: 영어 원어민 발음
  • Game: 같은 매칭 게임 영어로 자동 재생성

한 권을 읽으면, 위 모든 요소가 한국어 + 영어 두 세트로 학습된다. 아이는 "두 언어 학습 중"이라는 부담 없이, 같은 동화를 다른 언어로 보는 즐거움으로 받아들인다.

💡 부모 관점에서 왜 강력한가

  • 한 결제 = 두 언어 학습 — 한국어 학습지 월 3만원 + 영어 학습지 월 5만원 = 8만원. 우리는 학습지 1/10 수준의 가격으로 둘 다 (정확한 가격은 베타 데이터로 결정).
  • 인지 부담 없음 — 따로 외우는 게 아니라 동화 속 자연스러운 맥락으로 두 언어 노출
  • 한국 부모 영어 갈증 직격 — "영어 유치원 vs 일반 유치원" 고민의 디지털 해법
  • 형제자매 호환 — 5세는 한국어 위주, 7세는 영어 위주 — 같은 동화 한 권으로 둘 다 학습
  • 예문 학습 = 회화의 시작 — 단어만 외우는 학습지와 달리, 자연 문장을 통째로 노출

🌍 글로벌 확장 시 동일 모델

이 매칭 시스템은 영어가 아닌 다른 언어와도 동일하게 작동한다 → 태국어 ↔ 영어, 인도네시아어 ↔ 영어, 일본어 ↔ 영어, 베트남어 ↔ 영어. 아시아 모든 부모의 공통 갈증인 "자국어와 영어 동시 학습"을 우리 시스템이 자동으로 푼다. 경쟁사가 따라하려면 각 언어마다 매핑 데이터·TTS·예문을 처음부터 짜야 한다 — 언어당 6개월~1년 작업.

5. 통합 학습 리포트 — 부모 결제 알리바이 (정직 인정)

부모는 결제하는 사람. 부모는 "내가 이거 결제하는 이유"를 자기한테 설명할 근거가 필요하다. 학습 리포트는 그 알리바이를 제공한다.

  • 어휘 마스터리: 단어 노출·연습·마스터 4단계 (망각 곡선 반영) — 아이 UI 에서는 hide, 부모 리포트에만 노출
  • 한글 파닉스 히트맵: 자음 × 모음 매트릭스, 어디가 약한지 한눈에
  • 영어 파닉스 스킬트리: Book 단계별 진척도
  • 읽은 책 통계: 주제별, 장르별, 주간/월간
  • 자녀별 분리: 한 가구 최대 4명 자녀 각각 추적

정직 인정: 부모는 매주 리포트를 깊이 안 본다. 단 결제 유지 명분으로 *주 1회 이메일* 한 통이 trigger. "민준이 이번 주 4권 28단어" — 이거면 충분. 깊은 분석 X, 가시화 우선.

⚠️ 또래 비교 금지 — "상위 35%" 같은 표현은 학부모 불안 자극 + 데이터 신뢰도 문제. 비교는 *자녀의 과거 자신*과만 (지난주 vs 이번주).

6. 포인트·별 게이미피케이션 (베타에서 hide — 데이터 후 결정)

⚠️ 베타 V0 정책: 게이미피케이션 (별·포인트·호리 꾸미기·연속 보너스) 은 처음에 빼고 데이터로 결정. 이유 — 게임화를 동시에 던지면 진짜 retention 동인이 *콘텐츠* 인지 *게임화* 인지 구분 불가능. 본질 (동화·어휘·파닉스 통합) 만으로 D30 retention 측정 후 결정.

인프라는 보유 (코드·데이터 모델 살아있음) — 베타 D30 25%+ 면 게임화 없이 정식 런칭, 18% 미만이면 콘텐츠 보강 후 게임화 검토.

설계 원칙 (게임화 활성화 시):
① 별로 유료 콘텐츠 잠금해제 X (결제 회피 방지)
② 별로 오프라인 굿즈 교환 X (운영 부담 + 학습 동기 변질 방지)
③ 또래 비교 X — 자녀의 과거 자신과만 비교

7. 유튜브 자동 업로드 — 무료 글로벌 유입 채널

모든 동화 애니메이션을 유튜브에 자동 업로드. 유튜브 = 무료 발견, 웹/PWA = 유료 학습. 자세한 활용은 마케팅 전략 섹션 참조.

  • 풀 애니메이션 (3~5분) → 품질 체험
  • 쇼츠 (30초 동화 핵심) → 글로벌 빠른 테스트
  • 설명란·종료 카드 → 7일 풀 무료 체험 링크 → 가입
  • 다국어 자막 자동 생성 → 영어·일어·태국어 글로벌 SEO

핑크퐁·BabyBus 검증 모델. 차이 — 우리는 학습 통합으로 LTV 더 높음.

8. 카드 콜렉션 + 도감 (베타에서 hide — 데이터 후 결정)

⚠️ 베타 V0 정책: 카드 콜렉션·도감 시스템은 처음에 빼고 본질 검증 후 결정. 포켓몬식 수집 메커니즘은 강력하지만, *콘텐츠 본질로 retention 작동하는지* 먼저 확인해야 진짜 동인이 보임.

설계 핵심 아이디어 (활성화 시):

  • 학습 → 카드 즉시 보상 — 동화 1권 완독 시 수집 카드 1장 (도파민 즉발)
  • 도감 = 학습 인증 — 동화 완독 + 어휘 게임 통과 시 도감 항목 활성 (회색 실루엣 → 풀컬러)
  • 8 카테고리 — 명작·공룡·동물·식물·바다·우주·생활·전래
  • 운영비 0 — 기존 동화 자산으로 자동 카드화 가능 (양산 파이프라인 보유)

💡 활성화 조건: 베타 D30 retention 18% 미만이면 콘텐츠 보강 후 도입 검토. 25%+ 이면 본질로 충분하니 게임화 없이 정식 런칭.

구조적 moat: 1번 (명작 원전) · 2번 (3단계 글밥) · 3번 (통합 학습 루프) 는 시스템·데이터·콘텐츠 자산이 있어야 가능. 4번 (자국어↔영어 매칭) 은 다국어 파닉스 데이터가 필요. 진짜 moat = $4.9 가격 — 무거운 경쟁자가 *콘텐츠 인건비 구조* 때문에 절대 못 따라옴. 학습지·웅진이 따라하면 자기 매출 구조 무너짐.
05. Content Architecture

콘텐츠 아키텍처 — 동화 중심, 어휘로 묶는다

1차 무료 베타는 명작 동화 + 자연관찰이 메인. 아이가 동화를 읽으면 핵심 단어가 한·영 동시 노출되고, 가벼운 게임으로 익힌다. 파닉스는 거든다. 어휘 마스터 화면은 2차 베타에서 붙인다.

🎯 동화 중심 — 한 권 = 한·영 어휘 + 가벼운 게임

아이가 동화 한 권을 읽으면 핵심 단어가 한국어/영어 동시 노출 + 매칭·블록 게임으로 익힌다. "잭" 한 번 = 동화 노출 + 한·영 어휘 카드 + 게임 정답.

단어를 따로 외우는 화면 대신, 동화의 핵심 단어 + 파닉스 사운드 단어가 각각 한·영 카드로 노출되고 게임에서 다시 만난다. 같은 단어가 여러 곳에서 5~7회 반복되며 익숙해진다.

📖 동화 핵심 단어

각 동화의 명사 위주 핵심 단어가 한·영 카드로. 매칭·블록·선긋기 게임에서 다시 만남. 동화당 6~12개 단어가 자연스럽게 어휘로 누적.

🔤 파닉스 사운드 단어

한글 자음·모음·받침 학습 + 영어 알파벳·CVC 학습 중 만나는 단어들. 동화 단어와 자동 중복 검출 — 같은 단어는 마스터리 합산.

★ 베타에서 검증할 것

"동화 + 핵심 단어 + 게임"만으로 아이가 충분히 어휘를 쌓는가? 따로 "필수 어휘 마스터" 화면이 필요한가? — 1차 베타 데이터로 결정. 2차 베타에서 필요하면 별도 마스터 화면 추가.

09. Gamification

게이미피케이션 — 베타 V0 에서 hide, 데이터 후 결정

포인트·별·카드 콜렉션·호리 키우기·주간 미션은 베타에서 모두 빼고 콘텐츠 본질로 retention 검증. 게임화를 동시에 던지면 진짜 retention 동인이 *콘텐츠* 인지 *게임화* 인지 구분 불가능. D30 데이터로 추가 시점 결정.

🚫

왜 베타에서 빼는가

우리 본질 = 동화·어휘·파닉스 통합 학습 + 명작 원전 큐레이션. 게임화·포인트·카드 콜렉션을 동시에 던지면 D30 retention 의 진짜 동인이 무엇인지 측정 불가. 본질로 D30 25%+ 도달하면 게임화 없이 정식 런칭, 18% 미만이면 콘텐츠부터 보강.

📐 베타 게이트 — D30 데이터 기반 의사결정

D30 Retention 의미 게임화 결정

18~25% 보통 본질 보강 후 정식. 게임화는 보조 단계로
