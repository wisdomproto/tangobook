계속 이용할 이유로 구독하게.

무료에서 무엇을 경험하게 하고, 유료에서 무엇을 더 제공할 것인가. 아시아 미취학 아동을 위한 언어 학습 플랫폼의 구독 전략을 함께 검토합니다.

출발점세 가지 안구체적 후보이용 규칙검증과 다음 결정검토 기록
01 / 무엇을 지킬 것인가

아이의 재미가 먼저이고, 부모의 결제는 그다음입니다.

책·파닉스·낱말·놀이를 연결해 어휘력과 문해력을 쌓는 플랫폼입니다. 한국에서 시작해 아시아로 확장합니다. 무료 체험은 아이가 스스로 다시 찾을 만큼 충분해야 하고, 부모는 무엇에 돈을 내는지 한 문장으로 이해할 수 있어야 합니다.

무료 발견검색·영상·공유에서 첫 체험
→
아이의 재이용좋아하는 책과 놀이를 찾음
→
부모의 가치 확인실제 이용과 학습 기록 확인
→
구독과 유지더 자유로운 이용·학습 지원
현재 확정된 것은 ‘계속 검토한다’는 점입니다. 아래 무료 범위, 일일 권수, 유료 혜택은 논의 후보입니다. 현재 제품의 이용권·공개 정책을 변경한 문서가 아닙니다.
02 / 무료와 유료를 나누는 세 가지 방법

어디를 잠그느냐에 따라 결제 이유가 달라집니다.

A · 우선 검토 후보

하루에 고를 책 수를 제한

무료: 하루 일정 권수의 책과 연결된 활동을 함께 이용.

유료: 원하는 책과 놀이를 일일 선택 제한 없이 이용.

결제 이유: “좋아하는 책과 놀이를 언제든 계속 하고 싶다.”

책→어휘→놀이를 무료에서도 경험합니다. 반면 제한이 넉넉하면 무료로 만족하고, 너무 적으면 재미를 발견하기 전에 나갈 수 있습니다.

B · 비교 후보

책 읽기는 무료, 활동은 유료

무료: 전체 동화책 읽기·듣기와 대표 활동 체험.

유료: 모든 독후활동과 파닉스 과정 이용.

결제 이유: “아이가 좋아하는 이야기를 직접 놀며 배우게 하고 싶다.”

읽기 유입에는 유리할 수 있습니다. 활동을 전부 잠그면 플랫폼의 연결 가치를 체험하지 못하므로 대표 책 몇 권은 활동까지 열어야 합니다. 체험 책 수는 미정입니다.

C · 보조 검토 후보

읽기·놀이 무료, 학습 관리 유료

무료: 전체 책과 자유 놀이.

유료: 전체 파닉스·상세 리포트·맞춤 복습 과정.

결제 이유: “부모가 매번 준비하지 않아도 학습이 이어지게 하고 싶다.”

재이용에는 유리할 수 있지만 리포트만으로 결제할 이유는 약합니다. 실제로 다음 학습을 준비해주는 경험과 부모의 지불 의사 확인이 필요합니다.

A를 우선 검토하는 것은 기획자의 현재 제안입니다. 사용자가 A나 하루 3권을 확정한 것은 아닙니다. 세 안을 모두 남겨 비교합니다.

03 / A안을 실제 상품처럼 써보기

무료는 하루 3권의 완결된 경험.
유료는 전체 도서관과 학습 과정.

3권은 실험 후보 ‘하루 3권’을 출발 가설로 두고, 무료와 유료의 차이를 구체화했습니다. 1·2·3권 중 어떤 범위가 발견·재이용·결제를 함께 만드는지 확인해야 합니다.

영역무료 후보구독 후보
동화책+1000권의 목록·표지 탐색. 하루 서로 다른 책 3권을 선택해 본문·나레이션 이용.전체 도서관 읽기·듣기. 일일 책 선택 제한 없음.
반복 읽기당일 선택한 책은 횟수 제한 없이 반복. 다음 날 다시 선택하면 그날 1권으로 계산.즐겨찾는 책과 활동을 날짜에 관계없이 반복.
다국어선택한 책을 제공 중인 모든 언어로 이용. 같은 책의 언어 변경은 추가 차감 없음.모든 책을 제공 중인 모든 언어로 이용.
독후활동당일 선택한 책에 제공되는 활동 전체 이용·반복. 활동 종류마다 추가 제한하지 않음.모든 책에 제공되는 활동을 언제든 이용·반복.
파닉스언어별 대표 단원 1개를 모든 활동까지 이용·반복. 대표 단원은 후속 선정.제공되는 전체 과정. 현재 한글32·영어39단원 기준, 향후 제공되는 언어별 과정의 포함 범위는 후속 결정.
학습 리포트최근 7일의 읽은 책·활동·만난 낱말 요약.전체 기간의 어휘별 노출·연습, 첫 시도·재시도, 파닉스 진도와 기간별 변화 조회.
추천·복습관심 소재에 따른 책 탐색·추천.기록에 따른 다음 단원·복습 낱말·관련 책/활동과 추천 이유.
인쇄 자료무료 선택 책의 기본 도안과 체험 단원 학습지.전체 제공 학습지와 복습 자료. 개인별 자동 묶음 생성은 구현·운영 비용 확인 후 결정.
구독의 첫 번째 이유는 자유로운 책·놀이 이용입니다. 상세 리포트와 맞춤 학습은 부모가 구독을 유지할 이유로 검토합니다. 표는 상품 후보이며 모든 혜택의 구현 완료를 뜻하지 않습니다.

무료 가족의 하루

「거인의 정원」을 선택합니다. 한국어로 듣고 영어로 다시 들어도 1권입니다. 나무 색칠과 연결된 활동을 반복한 뒤 다른 책 2권을 더 고릅니다. 부모는 만난 낱말과 활동 요약을 확인합니다.

구독할 이유가 생기는 순간

아이가 다른 책도 보고 싶거나, 어제 하던 활동을 바로 이어가고 싶습니다. 부모에게 전체 도서관·놀이·파닉스 과정의 이용 범위를 안내합니다. 아이 화면에서 결제를 진행시키지 않습니다.

04 / 제한은 알아보기 쉽게, 놀이 흐름은 끝까지

‘하루 3권’보다 계산 규칙이 더 중요할 수 있습니다.

  • 표지와 소개를 보는 것은 차감하지 않습니다. ‘오늘 읽을 책’ 선택을 확인할 때 1권으로 계산합니다. 잘못 누른 책의 교체·차감 취소 규칙은 후속 결정입니다.
  • 같은 책의 재생·다시 읽기·언어 전환·활동 반복은 추가 차감하지 않습니다. 여러 그림체 판본을 같은 작품으로 묶어 계산할지는 현재 책 그룹 데이터와 대조 후 결정합니다.
  • 시작한 책·게임은 중간에 잠그지 않습니다. 날짜가 바뀌어도 현재 경험은 끝낼 수 있게 합니다. 다음 진입부터 새 날짜의 선택 규칙을 적용하는 안입니다.
  • 일일 제한은 계정 단위로 묶는 안입니다. 프로필을 추가해 무료 한도를 늘리는 구조를 피합니다. 여러 자녀가 있는 가족의 적정 무료 범위는 별도로 확인합니다.
  • 초기화는 계정의 고정된 생활 시간대 기준으로 설계합니다. 기기마다 한도가 달라지지 않도록 서버가 판정하며 해외 시간대·오프라인 처리는 구현 전에 확정합니다.
  • 무료가 끝나도 기록과 작품은 보존합니다. 저장된 그림·즐겨찾기·학습 기록을 지우지 않습니다. 7일 요약 제한은 조회 범위 후보이며 보관 기간과 개인정보 정책은 별도입니다.
  • 공유·검색용 대표 체험은 별도로 검토합니다. 지정된 공개 샘플은 가입 없이 책과 활동을 끝까지 체험하는 안입니다. 일일 권수 포함 여부·추적 방식은 미정이며 지금 무료라고 안내하지 않습니다.

안내 문구 후보: “오늘 고른 책은 계속 즐길 수 있어요. 다른 책은 내일 고르거나, 부모님과 전체 이용을 확인해 주세요.” ‘무제한’은 콘텐츠 접근 범위이며 장시간 이용을 권장하는 뜻으로 쓰지 않습니다.

05 / 먼저 확인하고, 그다음 가격을 정하기

결제율 하나로 무료 범위를 결정하지 않습니다.

  1. A와 B의 구매 이유를 먼저 비교합니다. 같은 대표 콘텐츠로 ‘더 자유롭게 읽고 놀기’와 ‘독후활동 전체 이용’의 안내를 부모에게 보여줍니다. 결제를 받지 않는 조사와 실제 유료 실험을 구분합니다.
  2. A를 실험한다면 1·2·3권을 비교합니다. 동시 실험 또는 모집 조건을 맞춘 순차 실험을 사용합니다. 비교 기간·대상·성공 기준을 사전에 정하고 한도 도달자만으로 결제율을 계산하지 않습니다.
  3. 무료 범위가 잡힌 뒤 가격과 이용권 기간을 검토합니다. 한국은 시작 시장이며 아시아 각국의 지불 의사와 결제 방식·세금·원가를 따로 확인합니다. 월/연 구독·가족 프로필 수는 아직 미정입니다.
  4. 교구 구매 혜택은 별도로 설계합니다. 관련 디지털 과정 제공과 전체 구독 기간 제공 중 무엇인지, 포함 기간·갱신 조건을 명확히 정합니다. 무료 첫 체험의 조건으로 교구 구매를 요구하지 않습니다.
다음 회의에서 결정할 것: A/B 우선순위 → 무료 체험 범위 → 권수·활동 계산 규칙 → 리포트 경계 → 가격·기간·교구 혜택. 현재 문서는 운영 정책이나 출시 확정안으로 사용하지 않습니다.
