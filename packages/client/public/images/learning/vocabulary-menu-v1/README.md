# Vocabulary game object illustrations v1

2026-10-14 사용자 동일 구름 버튼 반증 후 게임 도구 자체를 대형 선택 대상으로 재작화. 로컬 ComfyUI8188 미응답으로 내장 imagegen 사용. 원본 PNG는 Codex generated_images에 보존, 배포용640×480 alpha WebP8종. 무장식 투명 배경·부드러운 클레이/종이 재질·게임별 다른 실루엣.

- matching: 같은 고양이 그림 두 카드
- blocks-ko / blocks-en: ㄱ·ㅏ / A·B 블록 (영어는 한글 원본 glyph만 내장 편집)
- coloring: 어휘 삽화 색칠용 팔레트/붓
- drawing: 점잇기 대체 활동용 점선 꽃/크레용
- writing: 따라쓰기 노트/연필
- hidden: 숨은그림 찾기 돋보기/무당벌레
- scene-coloring: 장면 선화/채색 종이/붓

제목은 DOM 번역이다. 단어/쪽 삽화 또는 실제 게임 데이터로 사용하지 않는다. 파일별 최종 프롬프트, 원본/변환 해시, 용량은 [manifest.json](manifest.json)에 기록한다. 변환은 비율을 유지한 리사이즈/alpha보존 WebP 인코딩만 수행했다.
