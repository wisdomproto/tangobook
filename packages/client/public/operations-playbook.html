1운영 원칙 — 본질 먼저

5가지 원칙

  • 본질 = 큐레이션된 명작 + 그림체 4종 + 어휘 게임 통합 + 부모 학습 측정. AI 양산 사이트가 못 가진 깊이가 우리 차별점.
  • 변수를 동시에 던지지 않는다 — 게이미피케이션을 처음에 넣으면 진짜 리텐션 동인이 콘텐츠인지 게임인지 구분 불가.
  • 주 2개 풀스펙 출시 = 마케팅 이벤트화 — 발행 캘린더가 곧 캠페인 캘린더.
  • 듀얼 동인 검증 — 자녀가 매일 켤 이유 + 부모가 매월 결제 유지할 이유, 둘 다.
  • 데이터 결정 룰을 미리 약속 — D30 25%+면 게임화 보강, 18% 미만이면 콘텐츠 보강. 사후 합리화 금지.

  • + 학습만화 30편 (과학·역사·위인)
  • + 전래동화 30권 (12지신 IP)
  • LTV 12개월+ 도전

왜 이 순서인가

  • 동화 → 파닉스/어휘: 동화는 "재미", 파닉스/어휘는 "학습/투자". 베타에서 동화 만족도 검증되면 파닉스로 결제 명분을 한 단계 강화. 자연관찰도 이미 출시했지만 "학습성"이 강하지 않음.
  • 파닉스/어휘 → 생활동화/학습만화: 유료 가구 확보 후 LTV 늘리기 위해 콘텐츠 다양화. 생활동화 = 비활성 가구 재활성, 학습만화 = 6~8세 신규 유입.
  • 왜 자연관찰을 처음부터 같이 넣나: 어휘 게임 검증을 명작(서사형)·자연관찰(정보형) 둘 다에서 해야 포맷 보편성이 입증됨. 핵심 검증 가설이 콘텐츠 양 늘리는 것이 아님.

10리스크 & 대응

리스크신호대응
주 2개 풀스펙 페이스 못 맞춤 출시 누락 또는 품질 저하 TIER 1 동화 5~6개를 베타 시작 전 미리 완성 대기. 결손 시 즉시 투입
H1 (그림체 4종) 작동 안 함 풀스펙 재독률이 라이트와 차이 작음 (1.3배 이하) 최우선 대응. 그림체 선택 UI 발견성 강화 ("오늘은 어떤 그림체로?"), 그림체 비교 미리보기 추가, 풀스펙 9개 외 그림체 4종 매핑 재검토
H2 (동화+어휘 통합) 작동 안 함 동화→게임 연결률 < 25%, 게임 단독 실행 거의 없음 최우선 대응. 동화 종료 화면에 어휘 게임 자동 진입 동선, 어휘 미리보기 표시("이 동화로 새 단어 8개"), 게임 UI 단순화
라이트 vs 풀스펙 만족도 차이 작음 풀스펙 ROI 약함 풀스펙 차별 요소 강조 (그림체 비교 UI / 어휘 게임 풍부도). 또는 풀스펙 페이스 축소 + 라이트 양 확장
오픈 베타 가입 부진 W0-W2 누적 가입 200 미달 8-Pronged 채널 중 효과 낮은 채널 진단 (분석 도구) → 인플루언서·맘카페 즉시 보강. 유료 광고 W4 → W2로 앞당김. 차별화 메시지 (그림체 4종) 재테스트
바이럴 K-factor 낮음 K < 0.5 — 친구 초대 거의 없음 인센티브 강화 (초대 1명 → 1개월 → 2개월). 학습 그래프 공유 자동 발생 빈도 ↑. 인플루언서에 "친구 초대" 콘텐츠 직접 요청
주간 리포트 오픈율 저조 오픈율 < 30% 이메일 → 카톡 채널 전환. 제목 A/B (수치형 vs 감성형). 자녀 사진 활용 권장
인플루언서·PR 풀 부족 주별 협찬 결손 1명에 동화 4개 풀 협찬 (월 1회 × 4개월 깊은 협업). 출판사·도서관 제휴 병행
D30 25% 미달 (PMF 미검증) 핵심 게이트 실패 정식 런칭 연기. 게임화 즉시 추가 vs 콘텐츠 보강 vs 페이월 위치 변경 — D30 결과 기준으로 결정 (섹션 7 매트릭스)
