# 프롬프트 생성 가이드

이 문서는 동화책 생성의 모든 프롬프트 규칙을 통합 관리합니다.
서버 시작 시 자동으로 읽어 프롬프트에 주입됩니다.

---

## 1. 스토리 텍스트 생성 규칙

### 1.1 대상 연령별 기준

#### 4-5세 (기본)

- 문장당 어절: 3-8어절
- 1페이지당 문장: 1-3문장
- 어휘: 일상 단어 위주, 의성어/의태어 적극 사용
- 문장 구조: 단문 위주, 반복 패턴 활용
- 페이지 수: 12-16페이지

#### 5-7세

- 문장당 어절: 5-12어절
- 1페이지당 문장: 2-4문장
- 어휘: 감정 표현, 형용사 다양화
- 문장 구조: 단문 + 간단한 복문
- 페이지 수: 12-20페이지

#### 7-8세

- 문장당 어절: 7-15어절
- 1페이지당 문장: 3-5문장
- 어휘: 추상 개념 일부 포함
- 문장 구조: 복문 허용, 접속사 활용
- 페이지 수: 14-18페이지

### 1.2 공통 규칙

- **한 페이지 = 한 장면**: 각 페이지의 텍스트는 하나의 장면만 묘사해야 함
- 장면이 바뀌면 반드시 새 페이지로 분리
- 한 페이지 텍스트에 2개 이상의 장면을 합치지 말 것

### 1.3 종결어미 규칙

#### 사용 가능

- 긍정 표현: ~했어, ~었어, ~됐어, ~같아
- 과거 회상: ~했지, ~었지, ~됐지
- 강조/극적: ~했단다, ~었단다, ~하는
- 의문형: ~했을까?, ~일까?
- 감탄형: ~구나!, ~네!

#### 사용 금지

- ~했습니다 (너무 격식적)
- ~하다 (너무 건조)
- ~하더라 (거리감)
- ~하였다 (문어체)

### 1.4 어휘 선택

#### 적극 사용

- **의성어/의태어**: 치기죽기, 허겁지겁, 후다닥, 펑, 퐁, 어슬렁
- **감정 표현**: 슬픔, 기쁨, 화가 남, 무서움, 설렘
- **친근한 대화 어휘**: 깜짝, 착한, 예쁜, 신기한

#### 제한적 사용

- **한자어**: 꼭 필요한 경우만 (왕비, 공주 등)
- **추상 개념**: 구체적 묘사로 대체

#### 사용 금지

- 지나치게 어려운 어휘
- 폭력적/잔인한 직접 묘사
- 성인 대상 표현

### 1.5 스토리텔링 구조 (3막)

#### 1막: 설정 (전체의 20-30%)

- 주인공 소개, 평화로운 일상
- 문제/갈등 발생

#### 2막: 전개 (전체의 40-50%)

- 시련과 도전
- 조력자 등장
- 긴장감 고조 → 클라이맥스

#### 3막: 결말 (전체의 20-30%)

- 문제 해결
- 교훈 전달 (직접적이지 않게)
- 해피엔딩

### 1.6 대화와 서술 비율

- **대화**: 30-40%
- **서술**: 60-70%

## 2. 캐릭터 생성 규칙

### 2.1 선정 기준

- **2페이지 이상 등장하는 모든 캐릭터**를 포함 (수 제한 없음)
- 그룹 캐릭터는 **반드시 개별 분리**:
  - 일곱 난쟁이 → 난쟁이1, 난쟁이2, ... 난쟁이7
  - 의붓언니들 → 큰언니, 작은언니
  - 세 마리 곰 → 아빠 곰, 엄마 곰, 아기 곰

### 2.2 캐릭터 정보 작성

| 필드            | 설명                                                        | 언어                     |
| --------------- | ----------------------------------------------------------- | ------------------------ |
| `name`          | 캐릭터 이름                                                 | 한글                     |
| `description`   | 상세 외모 설명 (머리색/눈색/체형/의상/액세서리 등)          | **한글** (사용자 열람용) |
| `descriptionEn` | 동일한 외모 설명의 영어 번역                                | **영어** (이미지 생성용) |
| `age`           | 나이 (숫자)                                                 | -                        |
| `role`          | 주인공, 조력자, 악역, 조연                                  | 한글                     |
| `height`        | 상대적 높이 (50-200 사이 숫자)                              | -                        |
| `heightCm`      | 실제 키 (cm). 예: 어린이=110, 성인=170, 난쟁이=90, 거인=300 | -                        |

### 2.3 저작권 회피 규칙 (매우 중요)

AI 이미지 생성 모델은 저작권/상표권 필터링이 있어, 유명 캐릭터와 유사한 외모 설명이 포함되면 이미지 생성이 차단(OTHER 에러)됩니다.

#### 캐릭터 description 작성 시 필수 규칙:

1. **고유명사 금지**: description(한글)에 디즈니/픽사/지브리 등 특정 IP의 캐릭터명을 절대 포함하지 않음
   - ❌ "신데렐라풍 하늘색 드레스를 입은 소녀", "백설공주처럼 빨간 입술의 소녀"
   - ⭕ "갈색 머리를 땋아 올린 소녀, 낡은 회색 원피스에 나막신을 신고 있음"

2. **상징적 디자인 회피**: 유명 캐릭터의 대표적 시각 요소 조합을 피함
   - ❌ 금발 + 하늘색 드레스 + 유리구두 (디즈니 신데렐라)
   - ❌ 빨간 머리띠 + 노란 드레스 + 파란 조끼 (디즈니 백설공주)
   - ⭕ 원작 동화의 설정을 참고하되, 독자적인 외모/의상 디자인을 창작

3. **독창적 디자인 우선**: 동화 원작의 시대/문화적 배경을 살리면서도 기존 유명 작품과 확실히 다른 외모 설계
   - 머리색, 의상 색상, 스타일을 원작과 다르게 변형
   - 예: 신데렐라 → "물결치는 적갈색 머리를 지저분하게 올린 16세 소녀, 이끼색 원피스 위에 기워진 린넨 앞치마를 두르고 맨발에 그을음이 묻어 있음"

4. **coverPrompt, scene_description에도 동일 적용**: 고유명사 대신 외모 묘사로 캐릭터를 지칭

### 2.4 캐릭터 이미지 생성 규칙

- **레퍼런스 시트** 형태로 생성 (정면/측면/3/4 각도 + 표정 3종)
- description(한글)과 descriptionEn(영어)은 동일한 내용. 이미지 생성에는 descriptionEn(영어)를 사용
- 재생성 시 현재 이미지를 레퍼런스로 참조하여 일관성 유지

## 3. 장면 설명 (scene_description) 규칙

### 3.1 작성 규칙

- **한글**(scene_description)과 **영어**(scene_description_en) 모두 작성
- 2-3문장 수준
- 포함 요소: 캐릭터 행동/표정, 배경, 분위기
- 이미지 생성에는 영어 버전(scene_description_en)을 사용

### 3.2 예시

```
백설공주가 겁에 질린 표정으로 어두운 숲을 달리고 있어. 노란 드레스에 파란 조끼를 입고, 주변에 키 큰 나무들이 둘러싸고 있어. 나뭇가지 사이로 달빛이 비치고, 바닥에는 신비로운 안개가 깔려 있어.
```

### 3.3 scene_structure

각 페이지에 추가 구조화 정보 포함 (한글 + 영어):

- `characters` / `characters_en`: 등장 캐릭터와 행동
- `background` / `background_en`: 배경 묘사
- `atmosphere` / `atmosphere_en`: 분위기

## 4. 삽화 생성 규칙

### 4.1 캐릭터 레퍼런스 필터링

- 삽화 생성 시 **해당 페이지에 등장하는 캐릭터만** 레퍼런스로 전달
- 페이지의 `text`, `scene_description`, `scene_structure.characters` 텍스트에서 캐릭터 이름 매칭

### 4.2 이미지 일관성

- 이전 페이지 삽화를 레퍼런스로 전달하여 스타일/구도 일관성 유지
- 재생성 시 현재 이미지를 레퍼런스로 참조
- 동일한 아트 스타일, 색상 팔레트, 렌더링 기법 유지

### 4.3 절대 규칙

- **텍스트/글자 절대 금지**: 이미지에 어떤 텍스트, 말풍선, 라벨, 워터마크도 넣지 않음
- 아동 친화적이고 따뜻한 시각적 미학
- 생생하지만 조화로운 색상
- 배경은 상세하되 복잡하지 않게

## 5. 핵심 단어 (key_objects) 규칙

### 5.1 선정 기준

- **동화책에 실제로 등장하는 사물**만 선정 (스토리에서 언급되거나 장면에 나오는 것)
- 반드시 **명사**만 가능
- **반드시 단일 단어**로 작성 (수식어/형용사 붙이지 않음)
  - O: 콩, 하프, 구두, 모자, 지팡이, 거울
  - X: 마법 콩, 황금 하프, 유리구두, 빨간 모자, 마법 지팡이
  - 영어도 동일: O: bean, harp, slipper / X: magic bean, golden harp, glass slipper
- 5-8개 선정

### 5.2 선정 가능 (O)

- **도구/물건**: 거울, 빗, 구두, 지팡이, 모자, 바구니
- **음식**: 사과, 떡, 죽, 포도주
- **자연물**: 장미, 달, 호두, 콩
- **건물/장소 요소**: 성, 오두막, 우물, 탑
- **탈것/가구**: 마차, 침대, 의자, 물레

### 5.3 선정 불가 (X)

- **인물/캐릭터**: 백설공주, 왕비, 사냥꾼, 난쟁이 → characters에서 관리
- **대명사**: 그것, 이것, 저것
- **추상 명사**: 사랑, 용기, 우정 → moral_lesson에서 관리
- **동사/형용사**: 달리다, 아름다운
- **복합 명사/수식 표현**: 마법 콩, 황금 하프, 빨간 모자 → 단일 명사만 사용

### 5.4 각 사물 작성 규칙

| 필드           | 설명                                                                   | 언어     |
| -------------- | ---------------------------------------------------------------------- | -------- |
| `name`         | 사물 영어 이름 (단일 단어, 이미지 생성용)                              | 영어     |
| `nameEn`       | name과 동일 (단일 영어 단어)                                           | 영어     |
| `korean`       | 사물 한글 이름 (단일 단어)                                             | 한글     |
| `description`  | 사물의 시각적 특징 상세 묘사 (색상, 재질, 크기, 장식 등)               | **한글** |
| `pages`        | 등장 페이지 번호 배열                                                  | -        |
| `sizeCm`       | 실제 크기 (cm). 예: 사과=8, 거울=50, 성=1500                           | -        |
| `sizeCategory` | "small" (손에 들 수 있는), "medium" (가구/도구), "large" (건물/자연물) | -        |

## 6. 교육 콘텐츠 규칙

### 6.1 학습 단어 (6-8개)

- 스토리 핵심 단어
- 쉽고 일상적인 영어 단어
- 명사 중심 (동사/형용사 일부 포함)

### 6.2 퀴즈 (5개)

- 스토리 이해도 확인 질문
- 감정/동기 추론 질문
- 교훈 관련 사고력 질문

### 6.3 교훈

- 도덕적 가치관 형성 (정직, 용기, 친절, 인내, 사랑)
- 직접적 설교 대신 이야기를 통한 자연스러운 전달

## 7. 표지 규칙

### 7.1 표지 프롬프트 (coverPrompt)

- **한글**로 작성
- 2-3문장
- **제목 텍스트 포함하지 말 것**
- 재생성 시 현재 표지를 레퍼런스로 참조

---

## 8. 이미지 재생성 규칙

모든 이미지(캐릭터, 표지, 핵심사물, 삽화) 재생성 시:

1. **현재 이미지를 레퍼런스로 전달** (currentImageUrl)
2. **새로 수정된 프롬프트를 기준으로 생성**
3. 레퍼런스 이미지는 스타일/구도의 일관성을 위해 참고하되, 프롬프트 지시를 우선

---

## 9. 콘텐츠 전체 구성

```
[표지] 1페이지
[본문 스토리] 12-20페이지 (연령별 상이)
  - 1막(설정): 3-5페이지
  - 2막(전개): 6-12페이지
  - 3막(결말): 3-5페이지
[교육 콘텐츠: 상징/주제 해석] - educational_content에 포함
[교육 콘텐츠: 영어 단어 학습] - vocabulary에 포함
[교육 콘텐츠: 퀴즈] - quiz에 포함
```

## 10. 시리즈 구성 참고

### 세계 명작 동화 (서양)

- 테마: 서양 문화권 이야기, 판타지/모험
- 교육 목표: 서양 문화 이해, 상상력과 창의성
- 예: 백설공주, 신데렐라, 잠자는 숲속의 공주, 미녀와 야수, 라푼젤, 빨간 모자, 헨젤과 그레텔, 피노키오, 피터팬, 오즈의 마법사, 이상한 나라의 앨리스, 어린 왕자

### 한국 전래 동화

- 테마: 한국 문화권 이야기, 교훈/전통
- 교육 목표: 한국 문화 이해, 전통 가치관
- 예: 흥부와 놀부, 콩쥐 팥쥐, 해와 달님, 선녀와 나무꾼, 금도끼 은도끼, 흥부리 영감, 견우와 직녀, 토끼와 자라, 춘향전, 심청전
