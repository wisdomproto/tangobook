# OG 이미지 생성용 번들 폰트

`generate-og-images.mjs` 가 OG 소셜 이미지의 한글/영문 텍스트를 렌더링하는 데 사용한다.
CDN/시스템 폰트에 의존하지 않고 재현 가능한 빌드를 위해 repo 에 직접 번들한다.

- **Pretendard** (ExtraBold, Regular) — © Kil Hyung-jin
- 라이선스: SIL Open Font License 1.1 (OFL) — 자유 재배포 허용
- 출처: https://github.com/orioncactus/pretendard

브랜드 UI 본문 폰트(`index.css` CDN @import)와 동일 패밀리라 시각적 일관성 유지.
