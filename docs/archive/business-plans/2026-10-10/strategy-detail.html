01. Vision & Mission

"키즈 동화 OTT."

부모·아이에겐 키즈 동화 OTT, 작가에겐 AI 시대 디지털 등단 플랫폼. Reading Eggs 의 양산자 모델 X — Netflix·Steam·유튜브가 각각 영화·게임·영상에서 한 disruption 을 키즈 동화에서 한다.

4~7세 타겟 Web/PWA First 한국 MVP → Global OTT 구독 + 작가 royalty 우리 = 플랫폼, 컨텐츠 = 외부 작가
우리가 기초 컨텐츠로 유저를 모으고,
외부 작가가 컨텐츠를 양산,
소비자가 평가, 인기작은 출판.
🎯

Mission

부모·아이에겐 매주 새 동화책이 쌓이는 OTT, 작가에겐 AI 삽화 + 디지털 공개 + 소비자 평가로 등단 장벽을 넘는 플랫폼. 동화 안에 한·영 단어와 파닉스가 자연스럽게 묻어난다.

🌍

Vision (10년)

한국 → 영어권 → 아시아 7개국으로 확장하는 글로벌 키즈 동화 OTT + 등단 플랫폼. 각국 진출 시 자국어 ↔ 영어 자동 매칭 동일 패턴 적용 — 일본어·태국어·인니어·베트남어 ↔ 영어. 글로벌 phase 에선 권위있는 일러스트레이션상 수상 그림 작가 매칭까지.

💎

Core Belief — 시간 우위

양산자(리틀팍스·Reading Eggs·핑크퐁)는 직원 수가 한계. 플랫폼은 작가 수가 한계. 5년 후 작가 100~1000명이 모이면 컨텐츠 양으로 못 따라잡힌다. Netflix vs Disney 와 같은 게임.

📖 동화 안에 학습이 자연스럽게 묻어난다

매주 새 동화책이 쌓이는 OTT 안에, 한·영 단어 노출, 파닉스 사운드, 가벼운 어휘 게임이 자연스럽게 묻어 있다. 아이는 "동화를 본다" — 따로 외우지 않고, 따로 학습 시간을 내지 않는다. 그 사이 한·영 단어와 파닉스가 누적되고, 부모는 주간 리포트로 진척을 확인한다.

우리 플랫폼: AI 삽화 도구로 진입 장벽 0 · 디지털 공개 = 즉시 등단 · 소비자가 평가 · 인기작은 종이책 출판 funnel + IP 라이선싱. 글로벌 phase 에서는 그림 작가 ↔ 글 작가 매칭 + 그림체 preset 라이선스 ★★ — 그림 작가가 본인 그림체 1번 등록 → 글 작가가 사용 → 자동 royalty 패시브 수익. Adobe Stock·폰트 라이선스의 키즈 동화 버전 — 새 자산 카테고리.

왜 이게 진짜 disruption 인가: 여태 이 모델이 안 나온 이유는 단순 — 키즈 일러스트 1권당 수백~수천만원으로 작가 진입이 불가능했고, 출판사가 게이트키핑 했음. 2025 AI 가 일러스트 비용을 0 으로 만든 순간 처음 가능해진 카테고리. 카카오웹툰이 청소년/성인에서 한 disruption 을 키즈 동화에서 우리가 한다.

여태 키즈 UGC 가 안 나온 이유 = 일러스트 1권당 수백~수천만원. 2025 AI 가 이 비용을 0 으로 만든 게 6개월 전. 이제 작가가 본인 시간만으로 동화 제작 가능 — 카테고리 자체 새로움.

② 6 개월 헤드

이미 풀 파이프라인 가동

저작도구 v2 · 오디오북 렌더 · 롱폼 영상 · 마케팅 자동화 · 우리 기초 컨텐츠 (명작·자연관찰·한·영 파닉스) 모두 완성. 곧 런칭 — 따라오는 스타트업은 0 부터 6개월.

③ MOAT = 브랜드 × FUNNEL

시간이 깊게 만드는 moat

AI 자체는 moat 아님 (누구나 씀). 진짜 moat = 브랜딩/마케팅으로 모은 유저 + 합류한 작가 풀. 먼저 도달 = 작가가 우리 플랫폼 선택, 후발은 빈 플랫폼. Network effect.

핵심: AI 자체는 누구나 쓸 수 있다 — 그래서 진짜 moat 는 ① 6개월 헤드, ② 브랜딩·작가 funnel network effect, ③ 한·영 동시 + 자연관찰 + 명작 원전 (작가 진입 어려운 영역) 의 조합. 이게 6개월 안에 들어올 스타트업과 우리를 가르는 차이.

🛡️ 플랫폼 moat 7가지 (자세히)

1. 플랫폼 모델 — 양산자 vs 플랫폼 시간 우위 ★ 진짜 moat

"동화책 시장의 카카오웹툰". 경쟁사 (리틀팍스·Reading Eggs·핑크퐁) 는 자체 컨텐츠를 직원이 만든다 — 직원 수가 한계. 우리는 외부 작가가 만든다 — 작가 수가 한계. 5년 후 작가 100~1000명 모이면 컨텐츠 양으로 못 따라잡힌다.

모델컨텐츠 출처5년 후
양산자 (경쟁사) 직원·외주 작가 월 5~10권 → 5년 300~600권 정체
플랫폼 (우리) 외부 작가 + AI 삽화 월 50~200권 → 5년 3,000~12,000권 폭발

Netflix vs Disney · Steam vs EA · 유튜브 vs 방송국. 같은 게임의 키즈 동화 버전.

2. AI disruption 시점 첫 진입 — 카테고리 자체 새로움

여태 키즈 동화 UGC 가 안 나온 이유는 단순: 일러스트 1권당 수백~수천만원 → 작가 진입 불가능 → 출판사 게이트키핑.

2025 AI 가 그 비용을 0 으로 만든 순간 처음 가능해진 카테고리. 카카오웹툰이 청소년·성인에서 한 disruption 을 키즈 동화에서 우리가 한다 — 진입 시점 우위.

  • Wattpad·Inkitt — 청소년·성인 소설 UGC (키즈 X)
  • 카카오웹툰·네이버웹툰 — 청소년·성인 만화 (키즈 X)
  • Storybird (학교용 키즈 UGC) — AI 이전, 일러스트 비용으로 실패
  • 키즈 동화 + AI + 등단 모델 = 우리가 첫 진입
3. 명작 원전 + 자연관찰 — 작가 진입 어려운 영역 + 마케팅 미끼 ★

우리 기초 컨텐츠는 두 역할: ① 1차 베타 유저 모집 미끼 (작가 없는 상태에서 D30 검증) ② 작가가 들어와도 못 만들 영역 (자연관찰 = 전문 지식·자료 비용) 채움.

명작 원전 — Grimm·Andersen·Perrault·이솝·와일드 원작 (저작권 만료, 새 그림체로 재해석). "AI 양산 가짜 동화" 가 아니라 "공식 명작" 인식 — 부모 신뢰 확보.

자연관찰 — 공룡·곤충·동물·식물·우주·우리 몸. AI 이전엔 제작 비용 폭주로 아무도 못 한 영역. 작가도 진입 어려움 (생물학 자료 필요). 우리만의 진입장벽.

4. 자국어 ↔ 영어 자동 매칭 — 학습자 측 핵심 무기

학습자 측 가장 강력한 무기. 아이가 한국어로 동화 한 권을 읽으면, 그 안의 단어 · 파닉스 사운드 · 예문 · 발음 · 게임이 모두 영어와 자동 매칭되어 학습된다. 한 권 = 두 언어 동시. 학습지 한국어 월 3만 + 영어 월 5만 = 8만 시장의 1/10 가격에 묶어버림.

5. 글로벌 그림 작가 ↔ 글 작가 매칭 + 그림체 preset 라이선스 ★★

권위있는 일러스트레이션상 수상 그림 작가도 노출 채널이 없어 책 1~2권 내고 끝나는 게 현실. Bologna Illustrators Exhibition·CJ 그림책상·BIB (Biennial of Illustration Bratislava) 수상자조차 그렇다. AI 가 글 양산을 도와주지만 진짜 그림 작가는 AI 가 대체 못 함 — 글로벌 그림 작가 풀이 거대한 무콘텐츠 시장.

두 가지 매칭 방식

방식 설명 그림 작가 cost royalty (default) 적합
A. 직접 매칭 그림 작가와 글 작가가 매칭되어 작품 별로 직접 그림 시간 cost 큼 글 50% / 그림 50% 프리미엄 · 고관여
B. 그림체 preset ★ 그림 작가가 그림체 preset 1번 등록 → 글 작가가 선택해서 AI 삽화 생성 → 자동 royalty 공유 1회 등록 = 패시브 수익 글 60% / 그림 30% / 우리 10% 메인 모델 (5년 후 비중 ↑)

방식 B — 그림체 라이선스 시장 (새 카테고리)

우리가 만드는 새 자산 카테고리. 비교 사례: Adobe Stock·Shutterstock (이미지 1장 라이선스) · Adobe Fonts·Monotype (폰트 라이선스) · Splice (음악 샘플 라이선스). 우리는 "그림체 자체" 라이선스 — 2025 LoRA fine-tune 시대 기술적으로 가능. 그림 작가의 1회 등록 = 무한 새 작품에 사용 = 패시브 수익.

  • 등록 흐름: 그림 작가가 본인 작품 N장 업로드 → 우리 LoRA fine-tune → preset 활성화
  • 사용 흐름: 글 작가가 preset 선택 → 본인 작품 페이지마다 AI 삽화 생성 → 그림 작가에게 자동 royalty
  • 보호: 본인 명시 등록한 모델만 사용 가능 · 작가가 특정 작품 제외권 보유 · 언제든 등록 철회 가능
  • 품질 통제: 편집자 검수 + 그림 작가가 본인 preset 으로 만든 작품 일부 미공개권 행사 가능
  • 법적: AI 학습 스타일 = 현재 법 회색지대 → 우리 플랫폼 내 계약 기반 합의로 해결. 글로벌 법 정비 추적 필수
💡 왜 게임 체인저: ① 수상 그림 작가가 본인 시간 안 들이고 합류 가능 → 글로벌 작가 풀 폭발적 합류 · ② 글 작가 자유도 max (원하는 preset 으로 무한 양산) · ③ "그림체 라이선스" 자체가 새 자산 카테고리 — Adobe Stock 의 키즈 동화 버전 · ④ 경쟁사가 따라하려면 LoRA 파이프라인 + 작가 풀 + royalty 시스템 + 법무 동시 구축 (~2년).

경쟁사가 이 시장을 못 한 이유 — 출판사 = 1책 1예산, 그림 작가 풀 운영 노하우 X, AI 양산 인프라 X. 우리 = 풀 파이프라인 보유 + 디지털 매칭 + 글로벌 풀.

6. 출판 funnel + IP 라이선싱 — 디지털만으로 끝나지 않음

디지털 인기작 → 종이책 출판 → 작가 등단 → 우리 IP 라이선싱. 디지털 플랫폼이 종이책 출판사 역할까지 흡수.

  • 소비자 평가 = 출판 결정 — 출판사 직원 게이트키핑 X. 시장이 직접 인기작 선택
  • 인기작 종이책 — POD (Print on Demand) + 굿즈 + 인쇄 출판 funnel
  • 작가 등단 — 종이책 출판 = 한국 작가들의 진짜 등단 조건. 우리가 그 길 제공
  • IP 라이선싱 — 인기 캐릭터 굿즈·애니메이션·교과서 라이선싱 장기 수익
  • 2차 컨텐츠 — 인기작 → 영상화 (자동 파이프라인 보유) → 유튜브 글로벌 유입

💡 구조: 작가는 등단·노출 동기로 들어옴 → 우리는 컨텐츠 폭발 → 부모/아이는 무한 컨텐츠 → OTT 구독. 세 stakeholder 모두 윈.

7. 통합 학습 리포트 + 유튜브 자동 업로드 — 학습자 측 retention

플랫폼 모델이지만 학습자 측 retention 도구도 보유 — 부모 결제 유지 명분 + 무료 글로벌 유입 채널.

📊 통합 학습 리포트 — 부모 신뢰 + 결제 유지

  • 어휘 마스터리 — unknown → seen → practiced → mastered 4단계
  • 한글 파닉스 히트맵 + 영어 스킬트리
  • 주 1회 이메일 — "민준이 이번 주 4권 28단어" 한 줄. 깊은 분석 X, 가시화 우선
  • 또래 비교 금지 — 자녀 과거 자신과만 비교

📺 유튜브 자동 업로드 — 글로벌 유입

  • 풀 애니메이션 (3~5분) → 품질 체험
  • 쇼츠 (30초) → 글로벌 빠른 테스트
  • 다국어 자막 자동 생성 — 영어·일어·태국어·베트남어
  • 유튜브 = 무료 발견, 웹/PWA = 유료 학습. 핑크퐁·BabyBus 검증 모델
  • 인기작 = 영상화 → 작가 노출 강화 → 더 많은 작가 진입 (선순환)
구조적 moat 정리: 1번 (플랫폼 모델) · 2번 (AI disruption 첫 진입) · 5번 (글로벌 그림 작가 매칭) 은 시간이 갈수록 깊어지는 moat — 작가 풀이 쌓일수록 진입 장벽 ↑. 3번 (명작·자연관찰) · 4번 (자국어↔영어) 은 시작점 무기. 6번 (출판 funnel) · 7번 (리포트+유튜브) 은 retention·확장 도구. 진짜 moat = 작가 풀 — 무거운 경쟁자 (학습지·웅진) 가 따라하려면 사업 모델 갈아엎어야 함.
05. Content Architecture

콘텐츠 아키텍처 — 우리 기초 + 외부 작가 two trough

  2. 14페이지 영어 텍스트 + 영어 TTS
  3. 핵심단어: Snow White, apple, mirror, bed, forest, queen
  4. 같은 매칭 게임이 영어 단어로 재생성

08. User Experience

UX — 아이는 단순하게, 부모는 신뢰감 있게

두 명의 사용자, 두 개의 화면. 아이용은 큰 버튼·적은 메뉴, 부모용은 데이터·통제권.

아이 동선 (Kid Flow)

1 홈 화면 오늘의 추천, 이어보기, 카테고리
2 동화 선택 16:9 큰 표지 카드 (3~4-col)
3 그림체+레벨 큰 버튼, 아이 친화 단어
4 읽기 TTS 자동, 단어 progressive 자막
5 게임 완료 시 호리 칭찬 + 어휘 마스터리 갱신
6 다음 책 매주 새 동화 추천 + 진도 카운터

부모 동선 (Parent Flow)

1 유튜브/검색 무료 애니메이션 시청
2 가입 (이메일/구글) 1~2분, 자녀 1명 프로필
3 7일 무료체험 전체 콘텐츠 오픈 + 첫 리포트
4 주간 리포트 수신 이메일 + 푸시
5 결제 전환 구독 또는 충전 (베타 데이터로 결정)
6 장기 구독 리포트로 유지, 추천으로 신규

  • 버튼은 최소 48×48px (3~7세 손가락 기준)

  • 아이콘 + 큰 단어 동시 표기 (글 모르는 아이도 이해)
  • 다크모드 기본 켜짐 (밤에 부모와 함께 보는 시간)
