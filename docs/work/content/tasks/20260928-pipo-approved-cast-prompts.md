## 사용자 기준

사용자가 현재 본문 캐릭터 네 장을 직접 제공하고 프롬프트 재작성/파일 업데이트를 요청했다. 피포·엄마·양 할아버지·거위 아줌마·말 아저씨 모두 이 본문 외형이 기준이다. [참조 원본](../../../art-direction/references/pipo/README.md)을 저장소에 그대로 보관했다.

## 변경

- `pipo-cast.md` 다섯 규격 재작성: 흰 피포의 긴 검은 귀·돌출 주둥이·목도리, 흰 엄마의 자연스러운 adult dog 비례와 모자, 밝은 곱슬 털과 뚜렷한 회색 양 얼굴, 풍성한 흰 거위 몸과 넓은 날개, 밝은 회색 말의 부드러운 몸과 검은 갈기·몸 밖으로 내려오는 꼬리.
- 6등신/극도로 가는 팔다리·작은 머리 엄마, 넓은 인간형 가슴·어깨 말, 숨긴 짧은 말 꼬리, 무조건 고정 자세/소품 강제를 폐기했다. 양의 한쪽 장화는 해당 장면 소품으로 구분한다.
- `pipo-sheet-style.md`를 추가했다. 개별 시트에는 짧은 공통 매체 지침+해당 인물만 전달한다. 다른 캐스트의 체형·무대·광원·장면 규칙과 외부 수상작 원본 첨부 요구가 시트에 섞이지 않는다. 사용자 본문 이미지를 실제 첨부하도록 안내한다. 배경은 본문과 맞는 크림색이다.
- 빌더는 선택적 `{key}-sheet-style.md`를 읽고 공용 템플릿은 있을 때에만 전용 시트 경로를 쓴다. 없는 시리즈의 기존 시트 경로는 유지한다.
- 장면용 공통 앵커도 다섯 외형으로 맞췄고, 피포에만 있던 흰 털/부드러운 연필 명암 예외를 전체 캐스트의 실제 몸색/질감으로 정리했다. 번진 얼룩 눈을 작은 명확한 눈으로 변경. 설계/앵커 색인도 동기화했다.
- `pipo-core.js`, `pipo-plan.html` 재생성. 빌더가 함께 바꾼 34개 회차 HTML은 기존 원본/생성물 차이였으므로 이번 작업 전 파일로 보존했다. 본문 원고·500컷 SCENE은 수정하지 않았다.

## 검증·한계

- 실제 복사 함수를 VM에서 실행: 5종 시트 모두 해당 규격 전문 포함, 다른 캐릭터 규격/장면용 앵커/마젠타/외부 수상작 참조 문구 없음. 길이 약 13,600~14,800자에서 2,420~2,601자로 감소.
- `node --test packages/client/scripts/pipo-prompts.test.mjs packages/client/scripts/kota-prompts.test.mjs`: 5개 통과. 빌더/core 구문 검사, `sync-anchor-to-core.mjs pipo --check`, `git diff --check` 통과.
- 새 그림을 만들지 않았으므로 실제 렌더 일치까지 검증한 것은 아니다. 저장된 시트와 페이지 이미지는 그대로다. 다음 시트 생성 시 대응하는 본문 이미지 파일을 첨부해야 하며 텍스트 복사가 파일을 첨부해 주지는 않는다.
