## 실행

`D:/ComfyUI-output/mina-series-qwen/source.json`에 현재 HTML 49권의 본문·SCENE 490개를 추출했다. 등장 판정은 core의 감지를 쓰되 명시적 `Name elephant` 토큰이 있으면 그것만 참조해 ‘라주 빵’ 같은 소유자 언급으로 인물이 추가되지 않게 했다. 인물이 없는 배경 컷 18개는 인물 참조를 넣지 않는다.

같은 폴더 `run.py`가 Qwen INT8 기본25스텝/Euler/CFG1/참조768/출력1280×720으로 순차 실행한다. 전체 가족 앵커 대신 장면 우선, 해당 인물 시트와 짧은 규격만 전달한다. 생성 완료는 `state.json`, 쪽별 육안 검수는 `reviews.json`에 분리하며 SHA-256과 실행 API/history를 보관한다. 검수 해시가 현재 이미지 해시와 같을 때만 갤러리에서 통과로 표시한다. 재실행 시 해시가 일치하는 생성본을 건너뛴다. 미검수 결과를 자동 통과하거나 운영 등록하지 않는다.

중단은 폴더에 `STOP` 파일을 만들어 현재 한 장 이후 멈춘다. 중단·타임아웃 재개 전 ComfyUI queue/history를 확인해야 한다. 원본 출력은 `D:/ComfyUI-output/qwen21-mermaid-test/mina-series/`에도 보관한다. 운영 책 본문은 변경하지 않는다.

## 실제 생성·검수에서 확인한 사항

- 한글 장면 직접 전달 시험은 인물 시트 구도를 반복하는 실패가 있어 폐기했다. `rejected-korean-pilot/`에 보존했다. 원문을 읽고 영어 장면 우선 프롬프트 490개를 모두 준비했다(`prepare-en-*.py`, `source.json`). 설정된 Gemini 텍스트 번역 경로는 HTTP 402로 결과 없이 중단했고, 이후 직접 장면을 정리했다.
- 다면 시트가 인물 복제를 유도할 수 있어 ComfyUI `ImageCrop`으로 공식 시트의 첫 전신 자세만 참조한다. 그래도 복제·코 누락·의상 누락·역할 교환이 발생하므로 참조만으로 외형/장면 일치를 보장하지 않는다.
- 전체 재생성으로 새 오류가 생길 수 있다. 구도가 좋은 결과는 해당 PNG를 Qwen 참조 편집에 넣어 손 색·장신구·표정·중복 인물을 수정한다. 수정본도 반드시 다시 육안 확인한다.
- `repairs.json`은 검수자가 넣는 수정 요청이며 원본 해시를 포함한다. 러너는 이미지 사이에 이를 처리하고 `state.json.completed_repairs`에 결과를 기록한다. 수정 전 PNG/API/history는 `versions/<repair-id>/`에 보존한다. 생성 중인 state를 외부에서 직접 수정하지 않는다.
- 02~03권 각 10장, 총20장 개별 육안 검수 통과. 기획의 카메라 각도/정확한 키비율 등 근사 차이는 검수 메모에 남긴다. 03권 P10은 11개 진흙 소로 본문의 ‘열 마리도 넘어요’를 충족하며 SCENE의 12개와는 차이가 있다. 04권 이후 계속 생성·검수 중이며, 전체 49권 완료로 취급하지 않는다.
- 전체 갤러리: `http://127.0.0.1:5190/` (D 폴더 정적 서버). 01권 운영 등록과는 별도이며 02~50 운영 업로드는 아직 하지 않았다.

## 재개

`state.json`의 현재 작업·프로세스와 ComfyUI queue/history부터 확인한다. 실행 중이면 새 러너를 중복 실행하지 않는다(파일 잠금도 있음). 갤러리/개별 PNG를 원문 `source.json`과 대조해 `queue-review.py`의 `record`로 검수와 수정 요청을 기록한다. 최초 스크립트 자체를 다시 실행하면 과거 수정이 재등록될 수 있으므로 재개 시 함수만 불러 현재 결과를 기록한다. `MINA_BOOK_LIMIT=49`로 실행 중이고 490장 모두 영어 지시가 준비되어 있다. 이미지 생성 완료와 전체 검수 완료는 별도다.

`finalize-reviewed.py`는 실제 PNG 디코딩/크기 및 생성·검수 해시를 모두 대조해 한 권 10장이 통과한 경우에만 `mina-XX/selected-manifest.json`을 기록한다. 전체 목록은 `reviewed-books.json`이다. 운영 업로드 기능은 없다.

장시간 제작을 이어가기 위해 현재 대화에 30분 간격 heartbeat `02-50`(미나 02–50 삽화 제작·검수 이어가기)을 ACTIVE로 연결했다. 변화 없는 단순 진행은 조용히 유지하고, 권별 검수 완료·실패·사용자 조치·전체 완료만 알린다. 490장 최종 해시 검수까지 끝난 뒤 후속 실행을 비활성화한다. 자동화가 있다고 미검수 결과를 완료로 취급하지 않는다. 로컬 PC/ComfyUI가 실행되어야 생성이 진행된다.
