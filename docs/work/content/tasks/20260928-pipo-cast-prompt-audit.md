# 피포 캐릭터 시트 이상 검토

2026-09-28. 사용자가 캐스트 카드 5종 스크린샷을 보내 시트 프롬프트대로 만든 캐릭터가 이상하다고 확인을 요청했다. 이미지 생성·제품 프롬프트 수정 없이 첨부 화면과 실제 시트 복사 텍스트를 대조했다.

## 결과

- 엄마: 첨부 화면은 매우 길고 가는 몸, 작은 머리와 긴 팔다리다. `pipo-cast.md`는 `SIX HEADS TALL`, 작은 머리, 목, 좁은 허리, 동일한 가는 폭의 긴 팔다리를 명시한다. 공통 앵커도 반복한다. 모델의 임의 왜곡만이 아니라 문구 자체가 해당 비례를 요구한다.
- 말 아저씨: 화면은 말 머리에 사람 같은 근육질 상체다. 규격은 가장 넓은 어깨, 무거운 판 같은 가슴, 무거운 팔과 손, 두 발 직립을 요구하며 말의 사족 몸통/엉덩이/긴 꼬리를 금지한다. 공통 옷 금지와 결합해 사람 몸에 말 머리를 붙인 형태로 해석될 여지가 크다. 정확한 생성 원인을 확정하는 로그는 없다.
- 양 할아버지: 목 없는 큰 달걀 몸·작은 머리·짧은 팔다리를 요구하므로 화면의 둥근 덩어리 모양과 대응한다. 거위 아줌마도 가장 작은 물방울 몸과 몸 길이만큼 긴 목을 요구한다. 과장된 실루엣 구분에 비해 같은 동화의 친근한 동물 비례라는 제약이 약하다.
- 피포: 9월 21일 사용자가 확정한 현행 기준은 흰 몸·긴 검은 귀다. 화면의 회색·짧은 귀 피포는 현행 규격과 다르다. 스크린샷만으로 해당 시트의 생성 시점이나 실제 입력·첨부를 알 수 없어 새 프롬프트 결과라고 단정하지 않는다.
- 지난 수정은 피포만 변경했으며 나머지 네 캐릭터 규격은 유지했다. 피포에만 흰 털/부드러운 명암/또렷한 눈 예외가 있고 나머지는 명암 금지/경계 없는 숯 얼룩 눈 규칙이 남아 있어 가족·이웃의 질감도 갈릴 수 있다.
- `sheetPrompt`는 무대 조항을 뺀 공통 앵커 전문에 개체 규격을 덧붙인다. 각각 약 13,600~14,800자이며 한 명의 시트에도 다른 네 명의 설계·장면 연기 규칙이 함께 들어간다. 몸 비례의 직접적인 원인은 위 개체 규격이며, 길이 자체를 단일 원인으로 확정하지 않는다.

## 검증·후속

로컬 main `98a1c967`에서 실제 `sheetPrompt`를 VM으로 다섯 번 실행해 개체 규격 전달을 확인했다. 배포된 `/pipo-core.js`를 GET한 결과 개행 정규화 후 로컬과 동일하다. 미배포만의 문제가 아니다.

수정 요청 시 다섯을 같은 동화용 동물 비례·질감으로 맞추되 종별 특징과 사용자 확정 피포 외형을 보존한다. 엄마의 6등신/극단적으로 가는 팔다리, 말의 사람형 가슴·어깨를 유도하는 규격을 재설계하고 시트에는 매체+해당 인물 규격+3방향 배치 중심으로 남긴다. 기존 이미지와 운영 데이터를 임의로 교체하지 않는다.
