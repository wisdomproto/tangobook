## 사용자 결정

전체 인상 검토 후 사용자가 처음부터 다시 그리고 프롬프트를 모두 수정하며 기존 이미지를 모두 지우도록 요청했다. 앞서 제안한 바틱의 남색·크림·주황은 살리고 반복 문양과 기형적인 늘임을 없애는 방향으로 진행했다. 작업 도중 사용자가 만든 캐릭터를 직접 카드에 넣으라고 재확인했다. 새 캐스트 그림은 이번 작업에서 만든 기준이며 별도의 사용자 시안 승인이 있었다고 기록하지 않는다.

## 변경

- `taro-simple-batik`: 넓고 조용한 남색/파랑/크림 색면, 은은한 질감, 몸/배경 장식 문양·크랙 없음. 크림 얼굴과 배, 자연스러운 관절과 체형, 읽히는 눈·눈썹·입.
- 타로: 남색 아기 원숭이, 둥근 귀/짧은 다리/말린 꼬리/주황 허리끈. 무무: 파란 아기 사슴, 긴 귀/자연스럽게 긴 다리/주황 머리끈. 엄마: 파란 성체 원숭이, 감기지 않은 꼬리, 자연스러운 자세/뜬 눈. 할머니: 남색 성체 사슴, 보통 길이 목/넉넉한 체형, 지팡이·가방·무늬 없음.
- 공통 앵커·캐스트·전용 시트 스타일·설계·무대/소품 프롬프트·시리즈 등록부 갱신. 500컷에서 기형적 목/팔/등 길이 지시를 자연스러운 시선/상체 움직임으로 바꿨다. 키 차이, 그림자 길이, 장소와 소품 수는 유지한다.
- 공통 빌더로 core/plan/index와 50권 HTML 생성. 생성된 500쪽 글을 변경 전 HTML과 비교하여 전부 동일함을 확인.
- imagegen으로 새 캐스트 한 장 생성 후 이 파일을 실제 참조로 넣어 개별 3방향 시트 4장 생성. 기준 원본은 `docs/art-direction/references/taro/redesign-cast.png`. 개별 원본은 `output/imagegen/taro-{taro,mumu,taromom,mumugran}-redesign.png`.
- 운영 조사: 기존 캐스트 4장 + 01~27권 270장 = 274장. 28~50권 이미지 없음. 기존 자산 manifest와 50권 책 데이터 백업은 `output/taro-migration/`에 보관(커밋 제외).
- 각 책을 저장 직전에 GET하여 최신 필드를 보존하고, 이전 illustrationUrl 제거/새 scene_description 적용. 기존 자산은 manifest의 doc/key/url과 현재 등록을 대조하여 Mina 등 타 시리즈에 영향 없이 삭제한다.

## 검증

- 빌더: 50권·500컷. 기존 별칭 포함 경고(타로⊂타로 엄마/무무⊂무무 할머니)는 여전히 존재하며 이번 변경으로 새로 생긴 것은 아니다.
- Node VM에서 실제 시트 복사 4종/장면 합성 500컷: 새 스타일·개체 규격 포함, 마젠타 시트 배경/옛 과장 신체 지시 없음.
- 전후 장소 토큰/가족 등장 토큰/수치 비율 및 500쪽 한국어 글 동일 확인. `node --check packages/client/public/taro-core.js` 통과.
- 새 이미지 육안 확인: 네 인물 식별점·2개 눈·넓은 얼굴·무늬 없음·3방향 확보.
- 운영 검증 완료: 기존 274개 자산 삭제, 본문 illustrationUrl 270개 해제. 50권의 500개 scene_description이 새 원본과 일치. updatedAt/scene_description/illustrationUrl 외 모든 필드 및 글 동일.
- 50권 자산 목록이 모두 비었고 taro-plan에는 새 4개 키만 존재. 4장의 공개 PNG를 내려받아 생성 원본 SHA256과 일치 확인. 카드의 data-paste 키도 일치. UI 브라우저 검증은 별도로 수행하지 않았다.
- `git diff --check` 통과. 변경 범위가 미술 데이터/생성 정적 파일이라 전체 앱 테스트는 실행하지 않았다.
