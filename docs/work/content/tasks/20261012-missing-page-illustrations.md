## 사용자 반증과 중단 지점

사용자가 새 생성본의 그림체/영어 말풍선을 지적했고 기존 페이지와 생성 기준 프롬프트를 확인하라고 요청했다. 생성 배치를 중단했으며 운영 업로드/책 저장은 아직 한 번도 하지 않았다. 생성본은 미승인 후보다.

- 잘못: 그림체 라이브러리 원문을 읽기 전에 실제 이미지에서 그림풍을 추론하여 별도 프롬프트를 작성했다. 뼈와 근육 12~16쪽에는 영어 문구를 추가했다. 서버 원래 buildIllustrationPrompt는 `CRITICAL - NO TEXT: No text, speech bubbles, or labels in the image.`이므로 이 생성본들을 등록하지 않는다.
- 사용자 기준: 뼈와 근육 이야기는 실사여야 한다고 명시했다. 현재 책 ID1773618909980의 artStyle=photographic, 운영 art-style-library의 이름=자연관찰 · 실사, 원문=`Photographic realistic illustration`로 확인했다.
- 반증: 같은 운영 책의 등록된 13쪽 이미지(1~11,17~18)를 직접 내려받아 확인하면 모두 손그림 수채화풍이며 영어 문구가 이미지 안에 있다. 이는 이번 작업 전부터 저장돼 있던 자산이다. 사용자에게 실제 내려받은 1/11쪽과 전체 비교판을 보여 주었다. 해당 책의 스타일 설정과 기존 자산이 불일치한다. 기존 13장 교체는 아직 요청받지 않았으며 범위를 임의로 확대하지 않는다.
- 준비 결과: 10권21쪽 현재 데이터/참조 백업, 인어11쪽과 뼈12/14/15/16쪽 후보 PNG 생성. 뼈13쪽은 이미지 도구 출력 검사에서 거절되어 파일 없음. 다른 후보도 등록 미승인.
- 재개 기준: 운영 art-style-library의 실제 그림체 prompt + 페이지 scene_description/scene_structure + 캐릭터 참조 + NO TEXT 원문을 사용하고 실제 앞뒤 그림과 대조한다. 원문이 비어 있는 장면만 본문에서 구성하되 문구를 그림 안에 추가하지 않는다. 설정/자산 불일치는 먼저 분리한다.

## 교체 승인과 재개

사용자가 기존 13장도 잘못됐다고 확인한 뒤, 뼈와 근육 이야기 18쪽 전체를 실사·무문자로 다시 만드는 제안에 `ㅇㅇ`으로 승인했다. 기존 13장 교체 + 원래 빈 5장 생성으로 이 책 18장을 만들고, 나머지 9권의 빈 16쪽을 합쳐 최종 선정 대상은 34장이다. 초기 수채화 후보는 제외한다. 다른 책은 기존 장면/캐릭터 참조를 실제 첨부하고 라이브러리 원문 그림체를 사용한다. 본문·번역·음원·게임 변경은 없다. main push는 이번 작업에 요청받지 않았다.

실사 첫 쪽을 먼저 생성·검수하고 이후 17쪽의 실제 이미지 참조로 사용한다. 뼈와 장기는 외부 교육 모형/초음파로 표현하며 인체 절개 장면은 사용하지 않는다. 생성 결과는 운영 등록 전에 쪽별 육안 검수하고, 운영 원본과 충돌 대조를 수행한다.
