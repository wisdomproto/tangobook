## 작업 중 확인

- 원고와 운영 본문 500쪽을 대조하여 위 135쪽 외에는 운영의 선행 수정을 보존했다. 현재 HTML과 원고 500쪽은 일치하며 HEAD HTML과는 44권 204쪽이 다르다. 이 차이에는 기존 원고/HTML 불일치의 동기화가 포함된다.
- 29·38·39·48·49권의 제목과 해당 요약·기획 표를 갱신했다.
- 새 SCENE에도 기존 `<b>인물</b>` 구획을 유지했다. 현재 본문을 덧붙이는 구획은 `표정 연기` 뒤에 두어 대사 속 화면 밖 인물이 참조 목록에 추가되지 않게 했다. 22장 생성 목록의 참조 캐스트와 HTML의 감지 결과가 일치한다. 인물 없는 기존 18컷 목록은 변경 전후 동일하다.
- 기존 변경 후보 134장 비교판을 전부 보고 문장/그림 대응을 점검했다. 44권 p10의 실제 배가 흙 그림 바로 뒤에 붙은 구도도 바뀐 p8~9와 이어지지 않아 재작화에 추가했다. 재작화 대상은 22장이다.
- 자동 장면 이음매 검사의 남은 7건 중 06/p5는 앞서 수건을 넌 라주, 26/p5·28/p9·38/p9는 화면 밖 화자/청자다. 기존 경고 09/p3·17/p7는 과거 행동의 관형절이고, 21/p3는 느린 소누 몰래 신발을 챙기는 미나 손 클로즈업이다. 검사 수치를 낮추기 위해 불필요한 인물을 그리지 않는다.
- Python의 Windows 기본 CRLF 출력은 기존 `parseBooks`의 페이지 시작 정규식과 맞지 않는다. 원고를 LF로 저장한 뒤 50권 × 10쪽 파싱과 HTML 대조를 확인했다. 빌더/파서 코드는 이번에 수정하지 않았다.

## 생성·검수 결과

로컬 Qwen-Image-2.1 INT8, 25스텝/CFG 1, 1280×720으로 **12권 22장**을 생성했다. 기존 승인된 과슈 시트 네 장의 단일 인물 영역을 잘라 실제 이미지 참조로 전달했다. 기존 시리즈 생성·등록 폴더는 보존했다.

모든 생성 PNG를 한 장씩 직접 열어 본문, 인물, 옷, 손발, 소품, 동선과 대조했다. 1차 22장 중 12장은 추가 편집했다. 바구니 네 개→세 개, 중복 소누/어른 제거, 미나의 회색 코끼리 손발 복구, 소누의 노란 옷 복구, 물가 아래에 남겨 둔 인형, 발찌 중복, 형제 상대 키 등을 수정했다. 12장에 총 14회 Qwen 참조 편집을 적용했고 모든 수정본을 다시 직접 확인했다. 최종 22장 모두 선정 PNG SHA-256 = `state.json` = `reviews.json`, 검수 통과 상태, PNG 규격을 대조했다. 파일·검수 메모·해시는 [선정 manifest](20260930-mina-qwen-selected.json)에 있다.

본문 수정 전후 135쪽은 [교정 목록](20260930-mina-text-changes.json)에 저장했다. 29권 p6의 무대에 없는 식탁 표현, 39권 p8의 손을 잡는 상대, 44권 p10의 부수적인 코 동작도 그림과 자연스럽게 맞췄다. 49권은 미나가 먼저 위로받고 자발적으로 수건을 가져오며, 마지막에는 엄마가 돌봄을 맡는다.
