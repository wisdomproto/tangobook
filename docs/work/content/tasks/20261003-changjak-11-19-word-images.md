사용자는 01~10 완료 후 나머지 11~19도 같은 방식으로 요청했다. GPT 이미지 스킬로 실제 그림체·캐릭터·본문 문맥을 참조하여 단어 카드를 생성, 분할·검수하고 운영 책 DB와 Editor2에 연결한다. 6칸 묶음 생성과 최대 500px WebP를 유지한다. 이미 등록된 단어 이미지와 본문 페이지·삽화·음원·번역은 보존한다. 이번 새 작업 main push는 아직 요청되지 않았다.

기존 01~10 생성·백업은 덮어쓰지 않는다. 같은 작업 폴더에서 새 브랜치와 별도 `generated-images/changjak-words-11-19/`를 사용하고, 스크립트에는 `--scope=11-19`를 명시한다. 11~15는 50권, 16~19는 25권으로 운영 조회한다. 운영 목록 및 실제 참조부터 확인하며, 최근 바뀐 미나·타로 캐릭터/그림체를 낡은 문서로 추정하지 않는다.

## 현황과 생성 기준

운영 백업 350권, 핵심단어 1,594개, 기존 성공 단어 이미지 0개. 뜻 구분 후 초기 manifest는 511종, 90장(3×2칸)이다. 붕이 물 청회색 #7FA6B2, 가족 옷 구분, 딩딩 밝은 얼굴/두 눈, 타로 단순 바틱, 미나 승인 과슈를 유지한다. 운영 본문 실제 이미지가 없는 bung/dingding/taro는 현재 등록된 시트를 실제 첨부한다. 나머지 시리즈는 읽을 수 있는 본문과 캐릭터 시트를 첨부한다. references.json에 실제 원본 URL을 기록한다.

운영 dari-01의 기존 첫 이미지 URL은 404였으므로 읽을 수 있는 후속 본문 삽화를 찾아 참조했다. 잘못된 이미지 링크를 새로 만들거나 본문 연결을 수정하지 않았다. 초기 snapshot 명령은 백업/summary 저장 후 이 참조 오류로 종료했으며, 별도 references 스크립트로 참조만 보완했다. 백업 snapshot을 다시 덮어쓰지 않는다.

본문 문맥에서 ‘한 바퀴’는 한 번 돌아오는 동작, ‘두/세 가지’는 여러 종류, 밤이의 ‘나비’는 고양이 이름, 코타의 ‘가지 마’는 떠나는 상황으로 구분했다. 원래 key_objects 이름은 그대로 둔다. 조각은 수박·도자기·잎·얼음 등, 껍질은 코코넛·밤송이·밤 껍질을 구분한다. `prepare` 후 `finalize`는 생성 전에 한 번만 실행했으며 생성 도중 다시 실행하면 보정 프롬프트/순서를 덮어쓰므로 실행하지 않는다.

생성은 subscription-native image_gen을 최대 4장씩 호출한다. 원본을 보존하고 명시적으로 육안 확인한 job만 review-pass에 기록한다. 생성 상태는 로컬 sheets와 native-batch receipts, 검수는 reviews.json, 운영 등록은 registration.json을 기준으로 재개한다.

추가 문맥 분리: 모야의 꼬리는 멧돼지 툼바와 미어캣 키키, 미나의 꼬리는 염소와 36권 물소로 나눈다. 카드 수는 513종이며 90장·1,594개 링크는 유지된다. 미어캣 꼬리는 moya-006의 빈 4번 칸, 물소 꼬리는 아직 생성 전인 mina-010의 5번 칸에 추가한다. `refine-tails`를 한 번 실행했으므로 재실행하지 않는다.

보정 완료: bami-007은 시계 숫자를 눈금으로 제거하고 가죽을 가방 대신 재료로 변경. moya-002는 얼룩말로 나온 꼬리를 본문의 멧돼지로 교체, moya-006에는 미어캣 꼬리 추가. taro-008은 사슴 꼬리를 타로의 긴 원숭이 꼬리로 교체했다. bung-010의 온전한 꽃은 꽃잎 조각으로 보정했다. 붕이 36권의 기존 key_objects ‘얼음/조각’은 최신 본문에 해당 단어가 없어 추출 데이터가 낡은 상태지만, 이번 요청에서는 원래 단어/페이지를 보존했다. 꽃 문맥에 맞춘 조각 카드만 연결한다.

모야 보충 프롬프트에서 키키/니아 이름이 잘못 연결된 것을 확인해 각각 미어캣/기린으로 바로잡았다. 실물 검수로 원래 생성된 기린·멧돼지 등 종은 올바름을 확인했다. 최종 90장 전수 육안 확인과 hash/pass 기록 완료. 보정 전 파일은 review/*-original.png, 최종 보정 receipt는 native-corrections.json에 보관했다. 첫 보정 호출은 상대 참조 경로 오류로 생성 전에 실패했으며 절대 경로로 수정해 성공했다. 513종 분할 후 70종의 보정/시리즈 표본을 추가 확인하고, 일부 외곽 격자 테두리를 제거하도록 11~19만 inset 12px를 적용했다.

## 완료 결과와 검증

GPT 이미지 90장 묶음 및 5장 부분 보정 후 **513종 WebP, 350권, 1,594개 단어 항목**을 운영 등록했다. 크기 488×488, quality 82, 파일 크기 중앙값 16,396바이트, 합계 9,894,202바이트. [완료 manifest](20261003-changjak-11-19-word-images.json)에 시트 검수/참조 해시, 카드 URL·해시·사용 책, 책별 추가 수·보존 검증 결과를 기록했다.

모든 책을 저장 전후 비교해 keyObjectImages/updatedAt 외 본문·SCENE·기존 삽화·음원·번역·표지·캐릭터 등을 보존했다. 513종을 CDN에서 다시 받아 최종 WebP SHA-256과 전수 일치 확인. 운영 책 DB와 Editor2가 같은 keyObjectImages를 읽는다. 기존 nameEn 빈값을 건너뛰는 전역 어휘 DB 자동 추출은 별개이며, 이 작업에서 영문 이름이나 전역 어휘 DB 코드는 바꾸지 않았다.

운영 Editor2 표본: 밤이 07권 6개, 미나 01권 4개, 타로 30권 5개 카드 naturalWidth/Height 488 및 실제 화면 확인. 타로 30권 꼬리는 보정한 원숭이 카드로 표시됐다. 화면 증거는 review/editor2-bami-07.png, editor2-mina-01.png, editor2-taro-30.png. 브라우저의 생성/저장 버튼은 누르지 않았다. 이미 열어 둔 Editor2는 새로고침해야 최신 연결이 표시된다.

스크립트 MJS 구문, Python AST, Prettier 및 git diff --check 통과. 생성물/운영 데이터/작업 스크립트 변경이므로 제품 전체 build/typecheck/test는 실행하지 않았다. 완료 report는 CDN 검증 진행 중 최초 호출 시 registration incomplete로 차단됐고, 검증 종료 뒤 재실행해 성공했다.

로컬 원본·참조·보정 이전 파일·전체 책 백업·갤러리·등록 receipt는 generated-images/changjak-words-11-19에 보존하고 Git에는 넣지 않는다. 기존 01~10 데이터는 재등록하지 않았다. 코드와 완료 기록은 현재 작업 브랜치에 로컬 커밋한다. 이번 작업 main push는 미요청이며 다음 사용자 승인 시 최신 origin/main과 비교해 관련 변경만 통합한다.
