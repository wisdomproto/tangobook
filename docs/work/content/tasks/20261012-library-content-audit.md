- `packages/client/public/library-content-audit.json`은 제목/ID/완비 수/누락 쪽/게임 종류만 포함한 화면용 자료다.
- 삽화는 모든 페이지, 음원·번역은 한글 본문이 있는 페이지를 대상으로 한다. 의도된 빈 마지막 페이지에는 음원을 요구하지 않는다.

- 게임은 실제 학습 화면의 deriveStorybookUnit/getAvailableGames로 계산한다. 별도 저장 book.games는 상세에서 따로 표시한다.
- 생활동화 45권의 hideVocabulary는 어휘 삽화/단어 색칠 미사용으로 표시하며 누락 필터에서 제외한다.
- 장면 색칠은 Editor2 catalog의 연결 가능한 도안 수다. 단어 색칠 학습 카드와 별도로 표시하며, 실행 검수 완료를 뜻하지 않는다.

## 화면 변경

`/library-master`의 기본 탭을 콘텐츠 현황으로 변경. 9개 집계, 카테고리/게임 종류별 요약, 제목/ID·카테고리·공개·누락 필터, 책별 수량/누락 쪽/실제 게임과 Editor2 링크, 50권씩 페이지, 필터 결과 CSV를 제공한다. 기존 카테고리 편집/정렬/공개/표지 언어 기능은 라이브러리 관리 탭으로 유지한다.

운영 데이터 새로고침은 목록/개별 책을 8개씩 읽어 URL 등록 상태를 다시 계산한다. 진행률과 읽기 실패 ID를 표시하고 새로고침 실패 때 마지막 자료를 유지한다. 브라우저에는 R2 LIST 권한을 넣지 않는다. 따라서 버튼으로 갱신한 결과는 URL 기준이라고 표시하며, 파일 대조는 아래 수집기로 재수행한다. 대형 장면 catalog는 새로고침 시에만 동적으로 불러온다.

## 재수집

```powershell
node packages/server/scripts/collect-library-content.mjs --env=C:/projects/tangobook/packages/server/.env --out=D:/tangobook-inventory/20261012
pnpm --filter @tangobook/server exec tsx --tsconfig ../client/tsconfig.json scripts/build-library-content-audit.ts D:/tangobook-inventory/20261012
```

새 조사에는 새 날짜 폴더를 지정하고 snapshot을 관련 변경으로 커밋한다. 다른 브랜치 `codex/content-inventory`의 기존 마케팅 조사/동기화 작업은 이번 작업에 합치지 않았다.
