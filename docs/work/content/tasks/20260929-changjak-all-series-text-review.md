## 검토 방법과 기록 규칙

공용 `parseBooks`로 권별 10쪽을 읽고, 앞뒤 인과·등장인물과 소품의 이동·대사 화자·말의 자연스러움·결말의 회수·원고와 SCENE의 핵심 일치를 확인한다. **2026-09-29 사용자 보완 기준:** 각 권을 처음부터 읽는 아이를 기준으로 첫 1~3쪽에 인물이 셋 이상 나오면 이름만으로 누가 누구인지 알 수 있는지 확인한다. 두 명만 나오는 도입은 인원수 자체를 문제 삼지 않는다. 동시 등장뿐 아니라 첫 등장이 짧은 간격으로 몰린 경우도 본다. 새 인물은 등장 문장 안의 종·가족 관계·역할 등 한 조각으로 구별되는지 확인하고, 인물 수가 많아도 충분히 구별되면 통과한다. 기존 가이드의 ‘처음 나오는 인물은 한 조각으로 소개’ 원칙과 사용자 기준을 함께 적용하되 기계적 인원 상한으로 대체하지 않는다. 작품 설계상의 의도와 실제 원고 결함을 구분한다. 자동 검사 통과를 사람이 읽은 권으로 세지 않는다. 검토한 권만 아래 표에 추가하며, 발견한 문제는 쪽과 이유·수정 방향을 적는다. 글 검토이므로 그림의 시각 품질은 이번 통과 판정에 포함하지 않는다. 범위 밖 단권 검토는 별도 요청에서 다룬다.

## 인물 소개 기준 보완 — 시리즈 첫 권 도입부 예비 확인

19개 시리즈의 **01권 p1~p3만** 따로 훑었다. 이는 해당 19권의 10쪽 전체 검수가 아니므로 위 10/850에 더하지 않는다.

- `yuki-01` p1: 할머니·유키·모모가 한꺼번에 등장한다. 할머니의 관계는 명확하지만 모모가 개라는 정보는 p1에 없고 p4의 ‘앞발’에 가서야 드러난다. 첫 등장에 ‘작은 개 모모’처럼 종을 넣는 수정 후보.
- `mina-01` p1~p3: 라주→미나·소누→엄마 순으로 네 인물이 빠르게 나온다. p2의 ‘소누는 아직 못 해요. 미나는 가운데예요’는 셋의 형제 관계와 나이 순서를 독자가 추론해야 한다. ‘큰형 라주·둘째 미나·막내 소누’처럼 짧은 관계 단서를 해당 등장 쪽에 녹이는 수정 후보.
- `bami-01` p1~p2: 밤이·‘기차 고양이 나비’·‘식당칸 엄마’ 셋이 나오지만 나비의 종과 엄마 역할이 바로 적혀 있어 구분 가능하다. `pipo-01` p2~p3의 피포·엄마·‘양 할아버지’도 역할이 분리된다. 인원수만으로 문제 삼지 않는 예다.
- 이미 검토한 `pongi-01`~`pongi-10`의 p1~p3에는 이 기준의 세 인물 동시 소개 문제를 새로 찾지 못했다. `pongi-02` p8·`pongi-09` p9의 동생 갑작스런 등장은 기존 권별 기록 그대로 추적한다.
