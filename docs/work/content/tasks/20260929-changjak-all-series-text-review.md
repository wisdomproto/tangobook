## 검토 방법과 기록 규칙

공용 `parseBooks`로 권별 10쪽을 읽는다. **2026-09-29 최신 사용자 우선순위:** 글 읽는 사람 입장에서 ① 앞뒤 사건의 원인·결과와 시간·장소·소품이 논리적으로 이어지는지, ② 설명 없이 튀어나온 인물이나 결말이 없는지, ③ 없어도 이야기가 같은 문장·반복 설명·뜬금없는 문장이 읽기를 끊는지부터 판단한다. 문제를 찾으면 해당 쪽의 원문과 실제 독자가 막히는 이유, 덜거나 고칠 최소 문구를 적는다. 등장인물 소개·대사 화자·결말 회수·SCENE 일치는 본문 판단을 돕는 근거로 확인한다. 안전성·그림 지시·설계 메타만의 문제는 별도 참고로 남기되 본문 논리·군더더기보다 우선하지 않는다. **앞선 사용자 보완 기준:** 각 권을 처음부터 읽는 아이 기준으로 첫 1~3쪽에 인물이 셋 이상 나오면 누가 누구인지 바로 알 수 있는지 확인한다. 두 명만 나오는 도입은 인원수 자체를 문제 삼지 않는다. 새 인물은 등장 문장 안의 종·가족 관계·역할 등 한 조각으로 구별되는지 본다. 기존 가이드의 ‘처음 나오는 인물은 한 조각으로 소개’ 원칙과 함께 적용하되 기계적 인원 상한으로 대체하지 않는다. 자동 검사 통과를 사람이 읽은 권으로 세지 않는다. 검토한 권만 아래 표에 추가한다. 글 검토이므로 그림의 시각 품질은 이번 판정에 포함하지 않는다. 범위 밖 단권 검토는 별도 요청에서 다룬다.

| `pongi-26` p4~p10 | ‘빈 칸이면 힘도 빈다’는 설명을 들은 뒤 동생 시범·엄마 노래·퐁이 노래·저녁 노래·마지막 교훈으로 같은 뜻이 여러 번 반복된다. | 시범 또는 노래 한 번만 남기고 뒤쪽의 같은 설명을 덜어 행동과 결과를 살린다. |
| `pongi-30` p5~p10 | ‘치즈를 많이 먹어 저녁 자리가 없다’는 설명을 p5와 p6에 다시 하고, 한 조각 후렴을 p7~p10 거의 매 쪽 되풀이한다. p7과 p8 사이 날짜도 어긋난다. | p5 또는 p6 설명 하나만 남기고, p7은 다음 날 간식으로 명시하며 후렴은 결말에 한 번 회수한다. |

기존 30권 표는 당시 검토 기록으로 보존한다. 향후 판정은 위 독자 관점 우선순위를 적용한다.

## 인물 소개 기준 보완 — 시리즈 첫 권 도입부 예비 확인

19개 시리즈의 **01권 p1~p3만** 따로 훑었다. 이는 해당 19권의 10쪽 전체 검수가 아니므로 위 10/850에 더하지 않는다.

- `yuki-01` p1: 할머니·유키·모모가 한꺼번에 등장한다. 할머니의 관계는 명확하지만 모모가 개라는 정보는 p1에 없고 p4의 ‘앞발’에 가서야 드러난다. 첫 등장에 ‘작은 개 모모’처럼 종을 넣는 수정 후보.
- `mina-01` p1~p3: 라주→미나·소누→엄마 순으로 네 인물이 빠르게 나온다. p2의 ‘소누는 아직 못 해요. 미나는 가운데예요’는 셋의 형제 관계와 나이 순서를 독자가 추론해야 한다. ‘큰형 라주·둘째 미나·막내 소누’처럼 짧은 관계 단서를 해당 등장 쪽에 녹이는 수정 후보.
- `bami-01` p1~p2: 밤이·‘기차 고양이 나비’·‘식당칸 엄마’ 셋이 나오지만 나비의 종과 엄마 역할이 바로 적혀 있어 구분 가능하다. `pipo-01` p2~p3의 피포·엄마·‘양 할아버지’도 역할이 분리된다. 인원수만으로 문제 삼지 않는 예다.
- 이미 검토한 `pongi-01`~`pongi-10`의 p1~p3에는 이 기준의 세 인물 동시 소개 문제를 새로 찾지 못했다. `pongi-02` p8·`pongi-09` p9의 동생 갑작스런 등장은 기존 권별 기록 그대로 추적한다.
