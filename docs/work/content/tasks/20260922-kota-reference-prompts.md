## 사용자 결정

[진단](20260922-kota-reference-prompt-audit.md) 후 사용자가 “바꿔”, “전체적으로”라고 요청했다. 5권 하마만이 아니라 **코타 시리즈 25권 250컷과 손님 10종 전체**로 범위를 안내하고 반영했다. 사용자는 하마 참조 이미지를 만들어 첨부했으며, 현재 등록 삽화도 대부분 수정본이다. 이미지 미첨부를 원인으로 가정하거나 등록 이미지를 덮어쓰지 않는다.

## 변경

- `kota-anchor.md`: 모든 얼굴에 먹 도형을 추가하고 눈가 띠의 분할/두께 변화로 감정을 표현하던 규칙 폐기. 눈 크기 고정도 제거. 눈꺼풀·시선·입·자세로 감정을 표현한다. 참조의 자연 무늬는 유지하며 다른 인물의 눈가 띠·손·꼬리 특징을 전이하지 않는다.
- 옷색·옷 형태·얼굴은 첨부한 해당 인물의 참조 우선. 코타 OCHRE/아빠 AZURE는 참조가 없는 경우의 기본값이며 승인된 참조 의상을 덮지 않는다. 손님 옷을 매 쪽 팔레트에서 새로 선택하지 않는다. 수건 전달·목욕·맨발은 SCENE에 명시된 행동만 허용한다. 07권은 동일한 분홍 수건이 이동하는 예외로 명시했다.
- `kota-cast.md`와 손님 등록부 10종에서 임의 얼굴 먹 도형/눈 고정 규칙 제거. 손님 시트에 종별 설명과 공통 의상 유지 규격을 함께 전달한다. Guest 절 끝의 편집자 지침이 프롬프트에 유출되던 부분도 제거했다.
- `castLegend`: 코타 시리즈는 110자짜리 BUILD 첫 줄 대신 개체 규격 전문을 페이지/묶음 프롬프트에 전달한다. 공통 템플릿의 다른 시리즈 동작은 유지한다. 전달된 문자 규격보다 실제 참조 외형·의상을 우선한다는 지시를 덧붙였다.
- 250컷에서 얼굴 무늬의 굽힘·분할·굵기 연기를 눈매/눈꺼풀/눈썹/입의 연기로 변환했다. 05 p2의 하마 먹 줄 두 조각은 놀라 커진 눈으로 변경. 각 컷 끝에는 참조/표정 유지 지침을 넣되 `표정 연기` 부록은 등장 판정에서 제외한다.
- 설계 및 `_SERIES-ANCHORS.md` 기준 동기화, 25권 HTML·기획서·core 재생성. 본문 원고·등록 이미지는 변경하지 않았다.

## 검증

- 빌더: 25권 250컷. 이전 Guest 규격 미사용 경고는 실제 손님에 연결되어 해소됐다.
- Node VM에서 250컷 수정 전후 고정/손님 등장 판정 동일, 카메라 구도·장소 문구 동일, 생성 HTML과 SCENE 일치 확인. 단일/묶음 복사 함수에 실제 의상 규격과 참조 우선 지시 포함 확인. 손님 10종 모두 공통 규격+종별 설명 전달 확인.
- `node --test packages/client/scripts/kota-prompts.test.mjs`: 3개 통과. 하마 p2의 잘못된 얼굴 무늬 지시 제거·등장 목록·의상 전문, 손님 시트의 종/공통 규격, 참고 문구로 인한 화면 밖 인물 추가 방지를 검사한다.
- core/config/builder 구문 검사, `sync-anchor-to-core.mjs kota --check`, `git diff --check` 통과.
- 새 이미지를 생성하지 않았으므로 실제 개선 효과는 다음 생성에서 확인한다. 자동 배치 러너의 기존 삽화 한 장 참조 방식은 이번 변경 범위가 아니다. 사용자의 참조 첨부+프롬프트 복사 경로를 수정했다.
