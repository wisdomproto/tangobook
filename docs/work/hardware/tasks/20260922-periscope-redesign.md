## 요청과 완료 조건

사용자: 기존 반사경이 예쁘지 않고 조립을 고려하지 않았다. 외형과 실제 조립 구조를 수정한다. CAD 시안·조립 순서·치수와 간섭 검사 결과를 함께 제공한다. 실물 출력은 별도 검증이다.

## 읽은 기억과 변경 범위

hardware BRIEF/MEMORY, 루트 CLAUDE 반사경 절, 기존 periscope-reflector 메모리, printable.py/plate.py/review.py. 과거 deploy-board3d의 출력물은 보존한다. 최신 main의 printable.py는 35×20×1.1mm 거울이고 과거 메모리의 17×11mm는 구버전이다.

## 결정과 진행

- 현재 거울·33도 광학 배치를 기준으로 한다. 둥근 외피와 좌우 분할 케이스를 시안으로 개발한다.
- 기존 몸체는 채널을 전폭으로 제거한 뒤 핀 구멍만 뚫는다. 독립 축 지지대가 없으며, 거울 삽입구를 막는 구조도 없다.
- 사용자 확정: 둥글고 매끈한 조약돌형. 추가 지시: 나사 없이 프라모델처럼 플라스틱 끼움 결합.
- 나사 설계는 폐기했다. 최종 시안은 정렬 핀 2개와 내부 스냅 2개, 아래쪽 해제 구멍으로 결합한다.
- 좌우 케이스·직선 누름판 3개, 구매 거울·폼. 거울 홈과 축 받침을 케이스 분할면에서 조립한다.
- 기존 곡선 누름판은 롤 끝을 폰 두께에 맞춰 돌려도 몸통이 폰을 침범했다. 폼을 스프링으로 쓰는 현재 구조에 맞게 직선 강체 판으로 수정했다.
- 기존 축 정렬 원뿔은 거울 고정 테두리까지 지웠다. 실제 경사진 반사면의 모서리에서 광선을 반사시켜 광학 통로를 만들고 독립 표본 광선으로 확인했다.
- 사용자가 거울 종류를 질문했다. 전면 반사경·가시광용 보호 알루미늄·35×20mm를 안내했다. 1.1mm는 구매 확정이 아닌 CAD 기준. 정확 규격 재고/가격은 미확인. 근거와 구매 문의 사양은 PEBBLE.md.
- 사용자 피드백: 검은 누름판과 관통 축 때문에 폰 삽입 방향이 이해되지 않음. 폰은 화면 쪽을 거울에 대고 아래에서 위로 넣으며 판이 뒷면으로 회전하는 구조다. 전폭 원통 축을 제거해 케이스 안의 좌우 짧은 축만 남기고, 삽입 전·장착 단면 CAD 뷰를 추가했다.
- 사용자 재지적: 축만 있는 누름판에는 힘이 없고, 오스모는 뒤에 스펀지를 댄다. 설계 의도에 폼이 있었지만 시각화와 현재 형상 검증에서 빠져 기능이 불분명했다. 뒷벽 0.6mm 자리와 14×8×5.8mm PU 스펀지를 명시하고 장착 단면에 표시. 기하 압축은 미장착 8.62%, 7/9/11mm 폰에서 22.10/35.01/47.36%; 힘·피로·크리프는 실물 시험 필요.
- 사용자 요청으로 실제 CAD STL에서 인터랙티브 HTML을 생성하는 `pebble_html.py`를 추가. 완성·분해·폰 끼우기·장착 단면, 7~11mm 두께와 회전 시점 지원. HTML에는 표시용 단순화 메시를 내장하며 제조용 STEP/STL은 바꾸지 않는다.
- 사용자 지적: 거울과 폰 지지부 사이가 파여 있어야 전면 카메라를 가리지 않으며 오스모도 같은 구조다. 기존 입력 광학부가 가정 카메라 중심에서 1.6×1.6mm로 시작해 사실상 핀홀이었다. 폰 면 36×14mm에서 거울 유효창 32×17mm로 이어지는 넓은 공간으로 수정. 독립 폰 면 검사체 겹침 0mm³, HTML에 `카메라 공간` 상태 추가.
- 추가 지시: 거울을 카메라 쪽에 더 가깝게. 중심 거리를 19.07→12mm로 줄이고 몸체 앞뒤 길이를 49.5→42.4mm로 축소. 폰 면 바로 앞 3mm는 36×14mm 직선 창으로 추가 개방. 계산 제공 화각 약 106.3°×61.4°, 최소 요구 76°×41° 이상. 가까워진 거울과 옛 낮은 스냅 리브가 겹쳐 리브 하단을 z 2.5mm로 올리고 간섭 0 재확인.
- 사용자 수정: 카메라 개구부 아래 가로선도 없어야 하며 폰 쪽은 오스모처럼 단순 ㄷ자여야 한다. 폰이 더 안쪽으로 들어가도록 양쪽 상단 턱을 삭제하고, 전폭 채널을 연속된 안쪽 천장까지 열었다. 휴대폰과 누름판 축을 6.05mm 올리고 누름판용 내부 회전 포켓을 추가했다. 거울과 겹치던 뒤쪽 스냅은 폰 뒤 여유 공간으로 옮겼다. 중앙 ㄷ자 개구부의 아래 가로대 겹침 0mm³, 7/9/11mm 폰·누름판·외피 간섭 0을 재확인했다.
- 사용자 반증: 첫 수정은 카메라와 거울도 휴대폰과 함께 올려 휴대폰 윗변과 거울 윗변이 여전히 거의 같았다. 거울을 기존 높이로 되돌리고 전면 카메라 반경을 2.2mm로 가정해 카메라 윗선과 거울 윗선을 일치시켰다. 휴대폰 윗변은 두 윗선보다 7.14mm 더 안쪽에 있으며 HTML에 카메라 링을 표시해 육안 확인이 가능하다.

## 검증

`python hardware/periscope/pebble.py`: 최종 report pass=true. 단일 솔리드, 강체 간섭·표본 조립 경로·처방 변형 스냅 경로·7/9/11mm 폰 모형·9개 광선 검사 통과. 거울 6방향 이동 시 걸림 확인. `trimesh`: 출력 부품과 시험 부품 5개 모두 워터타이트·연결체 1개. py_compile, git diff --check 통과. 실제 출력/착용·피로·고정력 미검증. 상세 수치/검사 한계는 hardware/periscope/PEBBLE.md.

실제 STL 기반 review-board.png를 눈으로 확인했다. 나사 구멍 없음, 조립/분해/하부/내부 4개 뷰. Windows VTK의 성공 렌더 후 인터프리터 종료 시 native teardown 오류가 관찰되어 이미지 저장 완료 후 정상 종료하도록 미리보기 엔트리에서 명시 처리한다. CAD 검사 오류를 감추는 처리는 아니다.
