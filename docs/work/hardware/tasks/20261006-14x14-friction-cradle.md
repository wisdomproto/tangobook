## 요청과 완료 조건

사용자:14×14로 변경, 태블릿 거치부를 인식판에 프라모델처럼 마찰로 끼워 조립. 직전 일체형요구는 새조립형선택으로 대체. 높이20mm·수직뒤15도·2×2블록5.5mm/9홈 유지.

## 읽은 기억과 변경 범위

hardware MEMORY, 인식판/블록/태블릿 task, 기존 생성스크립트. HTML 동일경로와 hardware/studboard 생성·CAD자료만 변경.

## 결정과 진행

15mm피치14×14칸=210×210mm, 사방베젤15mm포함판240×240×20mm. 태블릿거치부240×60×20mm, 조립전체240×300mm. 기존NX격자 내부한칸 메시를14×14반복하여원형유지. 판쉘CAD를재구성하고뒤쪽에2blind소켓 추가. 홈위살2.5mm이상남기도록탭z중심7/높이6mm로낮춤(초기높이8mm안은격자하단침범검수후폐기).

두탭중심x50/160, 폭18×높이6×삽입18mm. 소켓한쪽여유0.08mm, 탭양옆리브돌출0.12mm로리브한쪽0.04mm압입안. 탭진입끝0.6mm모따기. 마찰에의한고정초안이며재료/FDM/사출공차별힘검증은안했다. 얇은탭·연결부전체휨/전도하중은실시험후조정해야함.

태블릿슬롯은거치부너비보다긴커터로양끝열린홈, 폭13/바닥5/깊이약15mm·뒤15도. 판너비240에맞추면서긴태블릿좌우돌출허용, 특정기종호환보장아님. 참고태블릿240×8×170, 블록중심105로옮김. HTML 조립분리보기55mm이격토글/태블릿예시/블록위아래 유지. 홈안쪽깊이표현용음영추가.

## 검증

CAD 판쉘/거치부각각유효단일솔리드. 탭본체간섭부피0, 리브만의의도적교차부피8mm³. 가상태블릿CAD간섭0. 두STL닫힘/정상와인딩확인. 최종탭높이6으로변경후CAD검사재실행·HTML구문·Chrome조립렌더검수(tango14-assembled.png), 분리렌더(tango14-exploded.png)는초기8mm탭시점도형검수이며최종6mm분리는추가재생성확인. 실물맞물림/마찰력/하중검증미실시.

## 자료와 한계

recognition-board-14x14.step/.stl은소켓/베젤/격자함몰부를포함한판쉘CAD이며원본NX돌기·격자미세표면은HTML의별도grid메시다. 판쉘STL에돌기까지포함된제조완성판이라고보고하지않는다. tablet-cradle.step/.stl은마찰탭포함거치부단독. tablet_cradle.py가양쪽CAD/HTML메시재생성, sticker_block_2x2.py는블록중심105로갱신. 직전일체형CAD·높이·각도요구중각도/높이보존·조립방식만대체. 원격push/운영배포없음.
