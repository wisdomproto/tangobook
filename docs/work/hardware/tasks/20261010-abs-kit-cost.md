## 사용자 확정 구성

- **최종 판매 구성은 한글·영어 통합 한 세트**다. 아래 언어별 소계는 비교용이며 별도 상품으로 확정한 것이 아니다.
- 한글: 자음 블록 28개, 모음 블록 10개, 인식판, 반사경.
- 영어: 알파벳 26종 각 2개 = 정사각 블록 52개. 기존 사용자 결정대로 자음용 몸체를 공유한다.
- 재질 ABS, 거울 개당 100원(사용자 제공 가격).
- 후속 사용자 정정: **거치대는 자체 제작하지 않고 기성품 약 1,500원에 구매해 포함**한다. CAD 거치대 체적은 참고값으로만 남기고 모든 최종 세트 중량/사출/프린팅 합계에서 제외한다.
- 제작 방식 확인에 사용자가 **사출과 3D 프린팅 모두 비교** 선택.
- 완성 세트 비교는 영어에도 같은 인식판·기성품 거치대·반사경이 포함된다고 가정한다. 영어 추가 블록만의 중량은 별도 표시한다. 태블릿은 제외한다. 현재 판의 앞 다리 2개는 포함하며 기성품 거치대와 판의 실제 결합 방식은 아직 검증하지 않았다.

## 최종 통합 세트 — 이 표를 사업 원가 기준으로 사용

후속 사업 가정: 사용자는 통합 세트 원가를 약10,000원, **단품 판매가50,000원**으로 두었다. 아래 재료/구매부품 소계는 원가 근거로 보존하고,10,000원을 실제 견적 확정으로 취급하지 않는다. [플랫폼 결합상품 논의](../../strategy/tasks/20261010-platform-block-packages.md).

| 구성 | 수량 |
|---|---:|
| 한글 자음 블록 | 28개 |
| 한글 모음 블록 | 10개 |
| 영어 알파벳 블록 | 26종 × 2 = 52개 |
| **블록 합계** | **90개(정사각80 + 모음10)** |
| 인식판(현재 앞 다리2개 포함) | 1세트 |
| 고정형 반사경·거울 | 1세트, 거울100원 |
| 구매 거치대 | 1개, 약1,500원 |

인식판·반사경·거치대를 언어별로 두 번 넣지 않는다. 기존 거치대 포함 결정은 유지한다. **자체 ABS 고체 환산553.505g, FDM 설정상 소모량369.848g**. 실출력 계량값이 아니다.

| 제조 방식·조건 | 통합 세트 재료·구매부품비 소계 |
|---|---:|
| 사출 원료3,000원/kg 가정 | 3,261원 |
| 사출 원료4,000원/kg 가정 | 3,814원 |
| 사출 원료5,000원/kg 가정 | 4,368원 |
| FDM eSUN ABS+ 18,700원/kg·밀도보정 | 8,649원 |
| FDM Moment ABS 38,500원/kg·품절 표시가 | 15,839원 |

모두 거울100원+기성품 거치대1,500원을 한 번씩 포함. 사출 원료가는 **국내 견적 미확보 상태의 가정**이고 FDM은 아래 명시한 슬라이서 조건·필라멘트 표시가다. 완제품 원가가 아니며 가공/장비/금형/라벨/폼/조립/포장/불량 등을 별도 반영한다. 개별 출력 시간의 수량 합계는 약15.0시간(일괄 배치 시간은 미계산). JSON의 `primary_kit=ko_en`이 최신 기준이다.

## 원본과 산출

[측정 스크립트](../../../../hardware/costing/measure_abs.py), [부피 결과](../../../../hardware/costing/abs-volume-report.json), [슬라이서 스크립트](../../../../hardware/costing/slice_abs.py).

현재 HTML의 board/grid는 각각 닫힌 메시임을 확인하고 Boolean 합집합으로 겹치는 체적을 제거했다. 표시 메시의 block/cradle/frontFoot는 양자화 때문에 열린 부분이 있어 그 부피를 그대로 채택하지 않았다. 블록 2종과 거치대는 STEP의 모든 솔리드 체적을 합산하고 다리는 flat_board.py:foot, 반사경은 compact_fixed의 5개 CAD 부품에서 계산했다. 원본 형상은 수정하지 않았다.

밀도 1.04g/cm³는 LG Chem HI121의 대표값을 사용한 계산 조건이다. 실제 구매 등급 확정 아님. CAD에 표현된 빈 공간은 제외하지만 FDM 내부 채움은 적용하지 않은 고체 환산이다. 사출 양산 설계에서 살빼기/리브/구배/게이트를 바꾸면 중량도 변한다.

참고로 과거 높이 조절식 wrap_cover 버전은 플라스틱 83.481g, 이 버전 사용 시 한글 391.882g/영어 468.751g이다(기성품 거치대 제외). 여러 반사경 버전을 혼용하지 않는다. 10월6일 작업 후반 기록은 compact_fixed로 돌아오므로 wrap_cover를 최신 확정 양산형이라고 부르지 않는다. 초기 탐색에서 기억 요약만 보고 ‘이후 높이 조절형’이라고 설명했으나 전체 작업 기록과 날짜를 대조해 정정했다.

## 사출 재료·구매 부품비 시나리오 — 거울 100원 + 기성품 거치대 1,500원 포함

| ABS 원료 단가 가정 | 한글 세트 | 영어 세트 |
|---:|---:|---:|
| 3,000원/kg | 2,630원 | 2,861원 |
| 4,000원/kg | 2,973원 | 3,281원 |
| 5,000원/kg | 3,317원 | 3,701원 |

식: 자체 제작 CAD ABS 중량(kg) × 원료 단가 + 거울 100원 + 거치대 1,500원. 재료·구매 부품비 소계이며 러너/퍼지/불량·착색·사출 가공·라벨·폼·조립·포장·배송·금형비를 제외한다. [제조사 공정 설명](https://www.rapiddirect.com/blog/injection-molding-quote-cost-breakdown/)에서도 금형/캐비티·성형 주기·러너를 분리한다. 업체 문의/파일 전송/발주를 수행하지 않았다.

## 검증·재현

- 부피 계산: STEP 모든 솔리드 유효성·양수 체적, board/grid 닫힌 메시와 합집합 확인. 반사경5부품/과거비교9부품 합산. 원본 CAD 변경 없음.
- 슬라이싱: 6종 모델 전부 반환코드0, 각1판, warning 빈 문자열. 슬라이싱용 재생성 메시 부피와 CAD 기준 오차0.3% 미만 검사. 기성품 전환 전 계산한 cradle은 참고 parts에 남기고 최종 BOM 수량에서 제거했다.
- 재생성: cadquery/trimesh/numpy/manifold3d 환경에서 `python hardware/costing/measure_abs.py`, `python hardware/costing/slice_abs.py`. 이 PC에는 manifold3d가 없어 `tmp/cost-python`에만 설치했으며 실행 시 `PYTHONPATH=C:/project/tangobook/tmp/cost-python`을 사용했다. 기존 Python 패키지는 변경하지 않았다. VTK/nlopt의 이 PC import 멈춤을 우회한 두 스크립트는 그 기능을 사용하지 않고 명시적 OCCT 연산만 수행한다.
- 파생 STL/3MF/G-code는 로컬 `tmp/abs-slice`에 보존. 프린터 전송/실출력/외부 업로드 없음. 원본 경로·해시, 입력 프로필과 결과 JSON은 Git 기록.
- 사용자 거치대 정정 후 이미 검증된 부품 결과에서 거치대 항목만 빼고 구매비1,500원을 더해 합계를 다시 계산했다. 형상이 바뀌지 않아 동일 슬라이싱을 반복하지 않았다.
- 한글·영어 통합 결정 후 정사각80개/모음10개와 공통 구성1벌로 다시 합산했다. 한글/영어 분리 표는 부품별 비교용으로 보존하고 통합 세트를 최신 기준으로 명시했다.

## 판단과 다음 행동

초기 자체 거치대 포함 한글713g/영어790g 및 거치대 경량화 검토는 사용자 기성품 결정으로 현행 원가 기준에서 제외한다. 기성품은 개당약1,500원으로 기록하고 공급업체·구매량·배송 포함 여부는 아직 미확인이다.

블록의 글자가 라벨이면 자음·영어는 공용 정사각 몸체, 모음은 직사각 몸체여서 글자마다 새 몸체 금형이 필요한 구조가 아니다. 실제 캐비티 수와 다른 부품의 금형 통합 여부는 제작사 견적 대상이다. 영어 추가 블록 52개 자체의 고체 중량은 약210g, 4,000원/kg 가정 순수 수지비는 약841원이다(거울/보드/가공/라벨 제외).

완제품 원가 = 순수 수지비 + 공정 손실 + 가공비 + 구매 거치대/거울/폼/라벨 + 조립/검수/포장 + 금형/초기 비용 ÷ 생산 수량. 구독 이용권의 정상 판매가 59,400원/118,800원을 제조원가에 더하지 않고 실제 서비스 제공 비용을 별도 반영한다. 블록 판매가·초도 수량·금형 견적이 없어 완제품 원가나 이익률을 확정하지 않는다. 사출 견적은 몸체2종·판·다리·반사경5파트의 캐비티/주기/러너 조건과 1천/5천/1만 세트별 금형비 분담을 받아 후속 비교한다.
