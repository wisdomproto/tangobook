# 탱고 블록 국내 생산·판매 전 KC 안전확인 실행 가이드

작성일: 2026-10-12. 국내 판매를 전제로 한 실무 준비안이다. 탱고 블록의 완구 분류와 구성별 시험·신고 범위는 지정 시험기관 상담으로 확정한다. 비용·기간·시료 수량은 아직 견적을 받지 않았다.

현재 구성은 ABS 한글·영어 블록 90개(자음28·모음10·영어52), 인식판1벌, 반사경·거울1벌, 구매 거치대1개다. 태블릿은 포함하지 않으며 사용자가 블록에는 전기가 들어가지 않는다고 확인했다. [제품 기준](../../PLATFORM.md), [구성과 치수](tasks/20261010-abs-kit-cost.md).

**사전 상담 → 생산 사양 확정 → 양산과 같은 샘플 제작 → 시험 → 안전확인 신고 → 표시 완료 → 출고** 순서로 진행한다. 시험 합격 성적서와 안전확인 신고확인증은 구분한다. 아래 사전 상담·공장 관리 항목은 실행 권고이며, 모든 항목을 법정 필수 제출서류라고 뜻하지 않는다.

## 1. 제품 설명 자료부터 준비

사진과 부품 목록을 포함한 1~2쪽 자료를 만든다. 미정 사항은 미정으로 표시한다.

| 항목 | 적을 내용 |
|---|---|
| 품명·모델명 | 탱고 한글·영어 블록 세트 / 내부 모델명 후보 |
| 용도 | 미취학 아동이 글자를 조합하는 비전기 학습 교구 |
| 실제 사용연령 | 시작 연령과 사용방법. 현재 최종 연령은 미정 |
| 판매 구성 | 90블록·판·반사경·거울·거치대·기타 제공 부품 |
| 치수 | 정사각 블록29.6×29.6×5.5mm, 모음14.6×29.6×5.5mm; 최종 생산 치수와 대조 |
| 재료 | ABS 등급·색상, 글자 스티커/인쇄, 접착제·폼, 거울·거치대 재질 |
| 제조 | 국내/해외, 제조공장, 사출/3D 출력 등 실제 방식 |
| 사업자 | 브랜드 판매사·실제 제조사·수입자 관계 및 사업자 정보 |

모음 블록과 판의 분리 가능한 다리는 작은부품 해당 여부를 먼저 문의한다. 반사경은 거울이 유리인지 아크릴 등 합성수지인지, 떨어질 수 있는지를 명시한다. 합격 여부를 CAD 치수만으로 단정하지 않는다. 연령 표시는 실제 대상과 용도에 맞추며 경고문을 붙이는 것만으로 모든 위험이 해결된다고 판단하지 않는다.

## 2. 금형·재료 확정 전에 지정 기관에 상담

[국가기술표준원 지정기관 안내](https://kats.go.kr/content.do?cmsid=499)에 있는 KCL/KTR 등에 자료를 제시한다. 문의 예시는 다음과 같다. 이 문서는 문의 초안이며 실제 전송하지 않았다.

> 안녕하세요. 국내 판매용 비전기 한글·영어 학습 블록 세트의 KC 안전확인 사전 상담을 요청드립니다. ABS 블록90개, 인식판, 반사경·거울, 구매 거치대가 한 세트이고 태블릿은 포함하지 않습니다. 사용연령은 검토 중이며 제품 사진·치수·부품/재질 목록을 첨부할 예정입니다. 다음 사항을 안내 부탁드립니다.
>
> 1. 완구 품목 해당 여부와 구성별 적용 기준
> 2. 블록·판·반사경·거치대를 한 모델로 신고할 수 있는지 및 별도 관리 대상 구성품 여부
> 3. 한글/영어 글자·몸체 형상·재질·색상별 모델 구분과 시험 범위
> 4. 모음 블록의 작은부품 기준, 거울 재질·고정 방식과 적정 사용연령 검토
> 5. 국내 OEM 또는 해외 생산 시 제조업자/수입업자 중 신고 주체와 필요한 서류
> 6. 완성 세트 및 재질·색상별 추가 시료 수량과 접수 방법
> 7. 시험·신고·추가시험 수수료, 부가세, 예상 기간과 재시험 조건
> 8. 포장·제품·설명서 표시사항의 검토 가능 여부

접수·배송 담당자와 주소를 먼저 확인한다. [KCL 절차 안내](https://www.kcl.re.kr/site/homepage/menu/viewMenu.do?menuid=001012006002)는 창구/택배 접수를 안내한다. KCL 대표 고객지원02-2102-2500에서 어린이제품 완구 담당 연결을 요청할 수 있다.

## 3. 제조업체에 재료·공정 자료 요청

공장에는 다음 요청을 전달한다.

> 한국 어린이제품 KC 안전확인 시험을 진행할 제품입니다. ABS 원료의 제조사·등급·신재/재생재 사용 여부, 색상별 착색제, 글자 인쇄 잉크 또는 라벨 원단·접착제, 폼·거울 등 부자재의 공급사와 품번을 정리해 주세요. 보유한 TDS·SDS/MSDS·유해물질 시험자료도 부탁드립니다. 시험용 샘플과 양산품은 동일한 재료·색상·공정·구조를 사용하고, 재료/공정/공급처 변경은 사전에 알려주세요.

재료표와 승인 샘플을 보존한다. TDS·SDS/MSDS 등은 조달 확인용 자료이며 완제품 KC 신고를 대신하지 않는다. 공장의 다른 제품 KC 번호를 우리 제품에 그대로 사용하는 것으로 처리하지 않는다. OEM 신고 주체와 제품·공장 범위는 시험기관에 확인한다.

## 4. 판매품과 같은 샘플을 제작해 시험

기관이 요구한 수량의 완성 세트와 추가 재료 시료를 준비한다. 글자 인쇄/라벨·접착·폼·거울을 실제 제공 상태로 포함한다. 사출 판매품을 검토용 3D 출력물로 시험한 뒤 동일하다고 취급하지 않는다. 시제품 사전 평가와 최종 판매 사양 시험의 적용 범위는 기관과 합의한다.

유해물질, 작은부품·날카로운 부분·파손/분리, 해당되는 가연성·표시사항 등 최종 적용 항목은 기관이 제품과 사용연령에 맞춰 정한다. 부적합이면 원인 부품/재료/구조를 수정하고 필요한 재시험을 받는다. 상세 적용 기준은 [완구 기준 진입점](https://kats.go.kr/content.do?cid=24257&cmsid=530&mode=view&page=)에서 확인한다.

## 5. 시험 후 안전확인 신고까지 완료

지정 기관의 적합 검사결과서가 나온 뒤, 신고 주체가 안전인증기관에 안전확인 신고를 한다. 기본 서류는 안전확인 신고서, 사업자등록증 사본, 사진을 포함한 제품 설명서, 해당 제품의 검사결과서다. 기관 양식과 추가 요구사항을 확인한다. 발급된 신고확인증에서 사업자·제조사·모델·구성 범위가 맞는지 확인한다. [국가기술표준원 신고 절차](https://kats.go.kr/content.do?cmsid=499).

## 6. 제품·포장·설명서 표시를 확정하고 출고

KC 표시·안전확인 신고번호, 품명/모델명, 사용연령, 제조자/수입자·제조국, 재질, 제조시기 표기, 연락처, 사용상 주의/경고 등 적용 표시사항을 기관에 검토받는다. 정확한 필수 항목과 표시 위치·크기는 품목 기준에 맞춘다. 블록이 작다는 이유로 포장에만 표시해도 된다고 임의 판단하지 않는다.

번호를 받은 뒤 최종 포장 인쇄를 확정하면 재인쇄 위험을 줄일 수 있다. 국내 제조는 출고 전, 수입은 통관 전에 필요한 안전확인·표시를 완료한다. 유통사에 신고확인증·검사결과서·최종 표시본·실제 제품 모델 정보를 제공한다. 온라인 상세페이지의 모델/신고번호/연령도 실물과 일치시킨다.

## 7. 판매 후에도 시험한 사양 유지

시험·신고 자료, 승인 샘플, 재료표, 생산 배치와 공급처 기록을 보관한다. 제품 설명서·검사결과서·신고확인증의 법정 보관은 제조일(해당 제조일이 없는 수입품은 수입일)부터5년이다. 제조국·공장·재료·색상·글자 표시 방식·형상·구성이 바뀌면 생산/출고 전에 기관에 변경신고 또는 추가 시험 필요 여부를 문의한다. 모든 변경이 자동으로 별도 신고 대상이라고 단정하지 않는다. [어린이제품 안전 특별법 시행규칙 제29·30·34·39조](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=286387).

## 지금 실행할 세 가지

1. 실제 사용 시작 연령, 생산국/업체, 사출/출력 방식의 후보를 정리한다.
2. 재료·색상·스티커/인쇄·거울·부품 목록과 사진/치수를 한 자료로 만든다.
3. 지정기관에 위 문의문으로 분류·작은부품/거울·시료·견적을 확인한 다음 최종 생산 사양을 확정한다.

전체 비용·기간은 실제 견적 전까지 숫자로 확정하지 않는다. 견적에서 시험과 신고 수수료, 재질/색상 추가 비용, 재시험, 샘플 제작/배송을 구분한다.
