## 현재 상태

[BRIEF](BRIEF.md)에 기존 코드·전문 지침을 연결했다. 공개 `/blocks` 허브와 한글·영어별 플레이 진입면을 추가한 [블록 놀이 작업](tasks/20260921-blocks-analog-digital-hub.md)이 main에 통합됐다.

한글 블록 상단 예시 단어는 [자모 색상 작업](tasks/20260921-hangul-target-jamo-colors.md)에서 초성·받침을 실물 블록 주황색, 모음을 녹색으로 표시한다. 완성형 글자를 사각 영역으로 잘라 색칠하면 `바다`의 ㅂ·ㄷ 오른쪽 획까지 녹색이 되는 것이 배포 화면에서 확인돼 폐기했다. 현재는 자모를 음절 안에 직접 배치하되 칸을 겹치고 크기를 조정해 옆/아래/복합 모음과 받침이 자연스럽게 붙도록 한다.

## 유지할 결정과 이유

검수는 실제 플레이까지 포함한다. 책에서 유래한 독후활동 맥락과 기존 정답·칭찬·보상 흐름을 유지한다.

한글·영어 블록 놀이는 공개 허브가 마케팅과 방식 선택을 담당하고, 실제 게임은 기존 `RandomBlockGamePage`와 언어별 플레이어를 재사용한다. 화면/카메라 차이는 `mode` 쿼리로 전달하는 첫 입력 모드이며, 카메라 인식 엔진을 별도로 복제하지 않는다.

근거 원본은 [BRIEF의 자료](BRIEF.md)와 [공통 기억](../../handoff/MEMORY.md). 상세 원본을 이 파일에 길게 복제하지 않는다.

## 실패·반증과 검증 범위

블록 허브 작업에서 타입 검사·빌드·SEO 테스트와 데스크톱·모바일 브라우저 표시를 확인했다. 로컬 API와 실물 카메라를 함께 띄운 전체 플레이는 배포 후 스모크 테스트가 남아 있다.
