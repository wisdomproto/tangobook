## 유지할 결정과 이유

검수는 실제 플레이까지 포함한다. 책에서 유래한 독후활동 맥락과 기존 정답·칭찬·보상 흐름을 유지한다.

한글·영어 블록 놀이는 공개 허브가 마케팅과 방식 선택을 담당하고, 실제 게임은 기존 `RandomBlockGamePage`와 언어별 플레이어를 재사용한다. 화면/카메라 차이는 `mode` 쿼리로 전달하는 첫 입력 모드이며, 카메라 인식 엔진을 별도로 복제하지 않는다.

근거 원본은 [BRIEF의 자료](BRIEF.md)와 [공통 기억](../../handoff/MEMORY.md). 상세 원본을 이 파일에 길게 복제하지 않는다.
