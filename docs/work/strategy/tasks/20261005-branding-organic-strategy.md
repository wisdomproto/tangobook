## 요청과 완료 조건

사용자가 부모 학습·아이 재미의 균형을 반영해 새 전략 문서를 요청했다. 플레이탱고·교원탱고·플레이노트 인터넷 조사와 오가닉 중심 실행안을 포함하고, 기존 결정과 제안·현재 기능과 예정 연계를 구분한다.

## 읽은 기억과 변경 범위

공통 AGENTS·인수인계·MEMORY·work 절차, strategy/marketing BRIEF와 MEMORY, STRATEGY·brand-brief·CLAUDE·marketing CLAUDE를 확인했다. write-page 스킬의 문서 작성·근거 구분 원칙을 적용하고 기존 저장소 형식을 따른다. 변경은 새 전략, 기존 원본의 갱신 안내, 작업 기록과 기억이다.

## 결정과 진행

- 사용자: 종합 경험 확장에 찬성하되 놀이만으로 부모 구매 이유가 약해지므로 학습·재미의 균형을 핵심 조건으로 확정.
- 파닉스는 학습, 동화는 재미, 색칠·블록·쓰기 및 아날로그는 경계 경험. 모든 동화를 퀴즈화하는 안은 제안하지 않음.
- 플레이탱고 직접 운영·교원 협업의 큰 사업적 반응은 사용자 진술. 교원 공식 2020-10-29 자료로 협업과 상품 구조 확인. 공개 판매량으로 확대하지 않음.
- 팀브레인즈 공식 사이트로 플레이노트 제품 소개 확인. 탱고북 연계는 사용자가 아직 안 했다고 명시, 후속 쓰기 놀이로 계획.
- 오가닉 우선 확정. 슬로건·연령·채널 순위·8주 발행안·BM은 제안/미결.
- 초안: [브랜딩과 오가닉 전략](../../../marketing/branding-organic-strategy-2026-10-05.md).

## HTML 후속 제작

2026-10-05 사용자 요청으로 내부 팀 공유용 [HTML](../../../marketing/branding-organic-strategy-2026-10-05.html)을 추가했다. 기존 랜딩·동화·색칠·캐릭터 이미지 17종을 25개 위치에 포함한 약 4.94MiB 단일 파일이다. 12개 절, 목차, 이미지 확대, 반응형 CSS, 인쇄 CSS를 제공한다. 실제 후기와 홍보 비주얼, 제품 사진과 모티프, 미공개 참조와 실제 서비스 상태를 구분했다. 공식 출처 링크 외에 외부 로딩 자원 없음. public 폴더와 운영 서비스는 수정하지 않았다.

HTML parser로 12개 절·목차 타깃·ID 중복·필수 내용·외부 실행 의존성 없음 확인, 이미지 25개를 PIL로 전부 decode/verify, 추출 JavaScript `node --check` 통과. 브라우저는 file 프로토콜 보안 정책으로 열기를 거부해 화면·반응형·인쇄·상호작용 동작 검증은 미수행. 우회 브라우저/서버 검증 없음. 로컬 문서 탭 열기 요청 완료. 외부 공유·발행·push 없음.

## 다음 검토

2026-10-05 사용자 구조 정정: 동화·파닉스 원본 → 콘텐츠별 독후활동(블록 맞춰보기·써보기·색칠하기). 목적은 아이의 재미. 디지털·아날로그·연계는 구현 방식으로 구분. HTML에 콘텐츠 구조와 활동×구현 방식 표, 원문에 같은 구분과 캠페인 필드 반영. 제품명과 구현 상태 분리, 구조·이미지·JS 정적 검사 재통과.

2026-10-05 사용자 목표 확정: 글로벌, 특히 동남아, K-에듀. 다국어 제작 구조를 이미 갖췄다는 사용자 설명과 shared 책 타입의 언어별 제목·표지·부모 가이드 구조를 확인했다. 한국 검증 후 해외 확장 신념을 HTML 고객 절의 시각 흐름과 전략 원문에 추가. 국가별 성과 보장으로 표현하지 않고 우선 국가·언어·일정은 미결. 오가닉 기조 유지. 이미지·HTML 구조·JS 정적 검사 통과.

2026-10-05 사용자 제품명 확정: 탱고 블록(탱고 한글 블록·탱고 영어 블록), 탱고 노트. 전략 원문과 HTML의 현재 제품 계획에 적용하고, 플레이노트 과거 이력·공식 출처 명칭은 보존했다. 상위 전략·실행 브리프·공유 기억 갱신. 제품명만 확정하며 연동 완료로 바꾸지 않는다. 이미지와 구조·JS 정적 검증 재통과.

2026-10-05 사용자 정정: “아이가 반복 이용 → 자기주도 학습. 놀면서 학습의 핵심.” 재미의 중심 가치를 자발적 시작·선택·지속에 따른 자기주도 학습으로 명확히 했다. HTML 핵심 문구·구매 가치·지표 설명, 전략 원문·STRATEGY·brand-brief에 반영. 재방문만으로 자기주도 학습이 입증되는 것으로 표현하지 않는다. HTML 이미지/구조/JS 검사 재통과, 화면 검증은 앞선 정책 제한으로 미수행.

사용자와 대표 문장·첫 캠페인 3개를 검토한다. 실행 시 공개 상태·체험 주소·측정 구현·기존 예약을 먼저 확인한다. 현재 요청에는 캠페인 발행·교구 구현·광고 집행이 포함되지 않는다.
