# 구독 전략 검토 문서와 editor2 BM 자료실

- 날짜: 2026-10-06
- 브랜치: main
- 사용자 요청: 구독 전략을 계속 고민할 수 있도록 HTML로 만들고 editor2의 BM 자료실 폴더에 보관.
- 문서: [구독 전략 HTML](../../../../packages/client/public/subscription-strategy.html)

## 결정과 제안의 구분

확정된 것은 구독 전략을 계속 검토한다는 점이다. 일일 독서량 제한 또는 읽기 무료/독후활동 유료는 사용자 제시 후보이며 선택·가격·기간·권수는 미확정이다. 이전 응답의 하루3권, 무료 선택 책의 전체 활동, 대표 파닉스1단원, 최근7일 요약은 기획자의 구체안이지 사용자 확정 정책이 아니다.

HTML에 A 일일 권수제한, B 독후활동 유료화, C 학습관리 유료화를 비교했다. A 우선 검토는 현재 기획 제안으로 표시하고 책→어휘→놀이의 완결된 무료 경험, 유료 추가 접근, 날짜/언어/반복/계정 계산 규칙, 다국가 가격·교구혜택 미결, 재이용·전환·유지·원가 검증을 정리했다. 현재 접근 정책·리포트 구현·운영 데이터는 변경하지 않았다.

## 연결 방식

TopBar에 이미 있던 BM 전용 메뉴를 중복 생성하지 않고 ‘BM 자료실’로 표시했다. 기존 마스터/콘텐츠 현황판/낱말 그래프를 보존하고 `/subscription-strategy.html` 새 탭 링크를 추가했다. 기존 정적 HTML 자료실 배포 방식을 따른다. 로컬 코드 연결이며 운영 배포·새 main push는 이번 요청에 포함하지 않는다.

## 검증

HTML 태그 균형·고유ID/목차 앵커, 문서와 메뉴 연결 및 기존 BM 세 항목 보존, diff 공백 검사 통과. TopBar ESLint·Prettier, 클라이언트 typecheck·production build 통과. 빌드의 기존 Browserslist/동적 import/청크 크기 경고는 남아 있다. dist에 HTML 복사 및 원본 동일성 확인. 브라우저 화면·드롭다운 클릭 검증은 미수행. 운영 배포와 main push 미실시.

## 다음 논의

A/B의 실제 구매 이유를 비교한 뒤 권수·무료 활동 범위를 결정한다. 가격/가족 프로필/교구 디지털 이용기간/현재 가입 체험과의 관계는 별도 결정한다. 결제율만 올리고 재이용을 떨어뜨리는 정책을 성공으로 판정하지 않는다.
