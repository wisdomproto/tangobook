## 확정된 전제

### 플랫폼 운영비 추가 — 최신 원가 가정

사용자가 플랫폼 운영비 항목을 만들고 **판매 대당10,000원**을 우선 책정하라고 지시했다. 교구 원가10,000원과 별도로, 메인 상품의12개월 플랫폼 이용분 전체를 신규 판매당 한 번 반영한다. 월마다1만원을 곱하지 않는다.

- 공급가69,500−교구10,000−플랫폼10,000=세트당 예상 매출총이익49,500원.
- 2027년10,500대 기준 플랫폼 운영비105,000,000원, 교구+플랫폼 원가210,000,000원, 예상 매출총이익519,750,000원(약71.22%).
- 1~3월 각24,750,000원,4~12월 각49,500,000원. 이 수치는 사업계획 원가 가정에 따른 관리용 매출총이익이며 모든 비용/세금 차감 후 순이익 아님.

시뮬레이션에 수정 가능한 플랫폼 운영비 입력·월별/지역별/연간 별도 비용 열·예상 매출총이익·이익률을 반영했다. 추가 비용 및 고정비는 매출총이익과 섞지 않고 별도 차감액으로 표시한다. 기존 월 서비스비는 ‘기본 운영비 외 추가 서비스비’로 구분하고, 잔여 이용기간에 기본 플랫폼 비용을 다시 부과하지 않는다. v3 저장값이 없으면 v2의 수량/공급률 등은 보존하며 플랫폼1만원을 추가하고 이전 월서비스비 입력만 중복 방지를 위해 비운다. 원래 v2 저장값은 삭제하지 않는다.

본문8장 비용 구조/9장 예상 매출총이익/팀 최신요약도 동기화했다. 검증: Node 구문·HTML 생성,실제 브라우저의 기본519,750,000원·플랫폼105,000,000원/단가2만원 변경414,750,000원/새로고침 보존/계획복원/음수 입력 거부/추가 서비스비가 매출총이익과 별도 차감됨 확인.1280px 계산표/본문 및390px 가로 넘침 검수. 운영 결제/가격 구현 및 push 없음.

### 2027년 한국 출시 계획 반영

사용자는 사업계획서 본문에 반영하도록 요청했다. **2027년1월 한국에서 판매 개시,1분기 월500대·2분기부터 월1,000대,2027년 해외 판매 없음. 2028년부터 태국·베트남·인도네시아3개국 판매 계획.** 국가별 개시 월·판매량,2028년 국내 판매량은 미정이므로 임의로 매출 목표를 만들지 않았다.

- 한국2027년: 500×3+1,000×9=10,500대.
- 공급액: 10,500×69,500=729,750,000원(약7.30억원).
- 교구 원가 가정: 105,000,000원. 교구 원가 차감액624,750,000원, 순이익 아님.
- 분기 공급액: Q1 104,250,000원/Q2~Q4 각각208,500,000원.
- 서비스 제공 기간: 당월 등록 가정 시2027년61,500 이용권·월, 이후 남은64,500 이용권·월. 합계126,000=10,500대×12개월.

투자자8장에 메인 상품139,000원·공급률50%·69,500원 공급가·디지털 독립 구독/무료 진입을 반영했다.9장은 분기 판매량 도표·연간 목표·2028년3국 진출 계획으로 변경,1·10장과 팀 최신 요약도 일정/가격에 맞췄다. 본편10장은 유지한다.

`business-plan-sales-20261011.cjs`를 본문과 시뮬레이션 초기값의 공통 원본으로 사용한다. 시뮬레이션의 행은2027.01~12,해외0대 기본값이며,‘2027 계획 복원’으로 돌아갈 수 있다. 수정 시나리오는 본문 확정 목표와 구분한다. 기존 v1 브라우저 저장값을 지우지 않고 새로운 v2-2027 저장키를 사용하여 과거 한국/해외 각1,000대 값이 새 계획을 덮지 않도록 했다.

검증: Node 구문 및 재생성,Chromium의 판매량10,500/공급액729,750,000/원가105,000,000/차액624,750,000 확인. 공급률40% 변경·저장/새로고침·계획복원·서비스 월수 합산·본편10장·팀 최신요약·390px 가로 넘침0.1280px8·9장/시뮬레이션 및390px9장 육안 검수. 실제 계약·운영 상품·해외 시장가격을 검증한 것은 아니며 투자금·현지 상세계획은 여전히 추가정보 대기. 로컬 반영, 미푸시.

사용자는 이전 상품 가격을 정가로 확정했다. 디지털 월9,900원, 통합 블록 단품50,000원, 블록+6개월99,000원, **메인 상품 블록+12개월139,000원**. 유통업체 공급가는 정가의50%이며 최종 소비자 할인은 유통업체가 결정한다. 탱고북이 별도로 행사 비용이나 공동구매 수수료를 부담하는 모델을 넣지 않는다. 해외도 동일 가격·공급률의 원화 기준으로 계산하라고 확인했다.

현재 시뮬레이션은 메인 상품 신규 공급만 다룬다. 공급 세트당69,500원, 사용자 교구 원가 가정10,000원, 단순 차액59,500원. 정가139,000원을 당사 공급 매출로 계산하거나 포함된 구독료를 별도 매출로 중복 합산하지 않는다. 한국/해외 수량은 시나리오이며 판매 예측이 아니다.

## 계산 범위

- 월 공급액 = 지역별 신규 공급 수량 ×69,500원. 주문·공급·등록이 같은 달에 발생하고 미수/반품 없음이라는 단순 모델이며 실제 현금 입금 시점과 회계상 수익 인식은 별개다.
- 월 교구 원가 = 신규 공급 수량 ×10,000원. 공급액에서 원가만 뺀 수치를 순이익으로 부르지 않는다.
- 부가세 포함/별도와 해외 세금·통관·배송 부담 조건은 미확정. 계약 표시금액을 그대로 곱한 비교이며 세후/회계상 매출 시뮬레이션이 아니다.
- 선택 비용 입력: 국내/해외 세트당 추가 비용, 이용권1개당 월 서비스비, 월 고정비. 공란은 비용0원 확정이 아니라 미반영이다. 기존 원가1만원에 포함된 항목은 다시 넣지 않는다.
- 동일 신규 판매량을12개월 유지하는 비교. 모든 구매가 즉시 등록되고12개월 권리를 유지한다고 가정해 m월 제공 이용권은 신규 수량×m. 실제 활동률과 구분한다.
- 1년차 서비스 이용권-월은 신규 월수량×78. 12월 말 이후 잔여 제공분은 신규 월수량×66 이용권-월. 선택 서비스비 적용 시 두 금액을 별도로 계산한다. 신규 판매분의 총12개월 비용은 신규 월수량×144×서비스비와 같아야 한다.
- 재구독·디지털 단독 판매·기존 고객·환율 변동·시장별 차등가는 제외한다. 미정 비용에 임의의 업계 평균을 넣지 않는다.

## 산출물·검증

사용자가 후속으로 **사업계획서 별도 탭에서 판매 대수·공급률을 수정하는 표**를 요청했다. 최종 산출물은 단일 원본 `packages/client/public/tangobook-business-plan.html#simulation`의 ‘매출 시뮬레이션’ 탭이다. 대화용으로 먼저 만든 시안은 최종 전달물로 사용하지 않는다.

생성 모듈은 `docs/marketing/drafts/business-plan-simulation-20261011.cjs`, 통합 생성기는 `build-investor-plan-20261010.cjs`. 정가·교구 원가·한국/해외 공급률,12개월 각 월의 지역별 판매 대수 편집을 지원한다. 일괄 수량 적용/기본값 복원,지역별 연간 합계,월별 공급액·원가·차액,선택 비용/서비스 제공 부담을 계산한다. 브라우저 localStorage에 시나리오를 보존하며 실제 상품/결제 정책은 변경하지 않는다. 본편10장/팀 문서는 보존하고3개 탭의 키보드 이동·직접 해시 링크·발표 키보드 분리를 처리했다.

최초 위 계산은 동일 월수량 예시이며, 최종 표에서는 매월 다른 수량도 가능하다. 첫해 서비스 제공분은 월별 신규수량×(13−월차)의 합, 이후 잔여분은 월별 신규수량×(월차−1)의 합이다. 둘의 합은 총 신규수량×12와 같다. 공급률 조정값은 시나리오이며 확정 기본50%를 덮어쓰지 않는다.

검증: Node 구문검사 및 원본 HTML 재생성. 실제 localhost Chromium에서 기본값,한국 공급률40%,첫달 수량 변경,새로고침 복원,서비스 제공 총량 합산,추가 비용/고정비,공급률101% 거부,0판매량,12개월 일괄 적용,초기값 복원 확인. 기존 본편10장/3탭/팀 iframe/발표 모드 키보드 격리/인쇄 미디어의 탭 격리/중복ID 없음 확인.1280px·390px 화면 육안 검수와 페이지 가로 넘침0.
