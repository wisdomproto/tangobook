## 사용자 결정과 범위

사용자는 통합 블록 세트의 사업 계산용 원가를 **약10,000원**, 판매가를 **50,000원**으로 두고 소중한글의 앱·학습지 결합 상품을 조사해 탱고북 상품 구성을 제안하라고 요청했다. 확인 질문에 50,000원은 **블록 세트 단품 가격이며 구독 포함 패키지는 별도 가격**이라고 명시했다. 원가10,000원은 앞선 CAD 재료비 분석을 대체하는 실견적이 아니라 사용자 지정 계획 가정이다.

단품은 한글38개+영어52개=90블록, 인식판·반사경 각1벌, 기성품 거치대1개. [하드웨어 근거](../../hardware/tasks/20261010-abs-kit-cost.md)의 부품 구성·계산은 보존한다. 한국 플랫폼 구독 월9,900원은 유지한다. 패키지 금액·이용권 운영 조건은 아래 에이전트 제안이며 사용자 확정 아님.

## 소중한글 공식 조사 — 2026-10-10

[공식 구매 페이지](https://www.sojunghangeul.com/home/order/choice?prdType=SUBSCRIPTION) 표시 기준. 최종 로그인·쿠폰 적용 결제액 확인이나 구매는 하지 않았다.

| 상품 | 구성 | 표시가 |
|---|---|---:|
| 앱 이용권 | 6개월 / 1년 | 93,000원 / 138,000원 |
| 쓰기 집중 초등 준비 | 앱6개월 + 한글 배움책4권 | 108,000원 |

웹 이용권은 구매 즉시 시작, 추가 구매 시 기간 연장, 만료 시 자동 연장 없음, 자녀2명 등록으로 안내한다. 앱 내 정기구독은 별도다. 같은 페이지의1년59,000원 행사는 ‘~10/9’가 명시되어 확인일10/10의 유효 판매가로 사용하지 않았다. [배움책 소개](https://www.sojunghangeul.com/home/about/books)는156,000원을 쿠폰 적용 가격으로 표현한다. 가격 변경·채널/쿠폰 차이는 있을 수 있다.

## 참고할 설계와 탱고북 적용

[배움책 공식 설명](https://www.sojunghangeul.com/home/about/books)의 학습 순서는 앱 맞춤 학습→종이 쓰기 연습→앱 게임 복습이다. 묶음의 구성품뿐 아니라 각 구성품의 역할과 사용 순서를 설명한다는 점이 핵심 참고다. 학습 성과/판매량에 대한 업체 홍보 문구는 이번 수익성 판단 근거로 쓰지 않았다.

탱고북은 화면 그림·발음 안내→실물 블록 조합→인식에 따른 반응→관련 동화·독후활동으로 설명하는 방향을 제안한다. 이 연결이 경쟁사에 전혀 없다고 단정하지 않는다. 한글/영어를 갈라서 상품 수를 늘리지 않고 동일한90블록과 이용기간만 다르게 한다. 쓰기 하드웨어/종이 교재는 사용자의 상세 정보 제공 후 추가하며 지금 확정 상품에 넣지 않는다.

## 상품 제안 — 아직 미확정

| 상품 역할 | 구성 | 가격 | 개별 단순 합산 대비 |
|---|---|---:|---:|
| 디지털 월 구독 | 교구 없이 프리미엄 이용 | 월9,900원(확정) | — |
| 통합 블록 단품 | 90블록+판+반사경+기성품 거치대 | 50,000원(확정) | — |
| 6개월 시작 패키지 | 통합 블록 + 프리미엄6개월 | **99,000원 제안** | 109,400원 대비10,400원 차이 |
| 12개월 성장 패키지 | 동일 통합 블록 + 프리미엄12개월 | **139,000원 제안·대표 상품** | 168,800원 대비29,800원 차이 |

개별 단순 합산은 사용자 설정 단품50,000원 + 월9,900원×기간이다. 아직 출시/거래 이력이 확인된 ‘종전 정상가’나 실제 할인 행사라고 표시하지 않는다. 무료 진입은 기존 무료 파닉스 및 동화책 전체 읽기를 유지하며, 유료 상품 카드와 별도로 안내한다.

제안 가격의 논리: 6개월은10만원 미만 진입안, 12개월은6개월보다40,000원 추가로6개월을 더 제공하는 안이다. 블록 단품가를 뺀 이용권 대응 금액은6개월49,000원(월환산약8,167원),12개월89,000원(월환산약7,417원)이어서 긴 기간의 결합 혜택이 더 크다. 이는 비교용 분해이며 회계상 매출 배분이 아니다. 패키지를5만원에 상시 판매해 월 구독료의 의미가 흐려지는 구조는 사용자의 단품/패키지 구분과도 다르다.

대표 판매 문구 초안: **“탱고북 한글·영어 블록 학습 패키지 — 90개 블록과 프리미엄12개월,139,000원”**. 이어서 안내→조합→반응→동화/독후활동이라는 사용 경험을 보여준다. 12개월 안에 두 언어를 완성한다는 효과 보장은 하지 않는다.

## 프리미엄 범위와 기간 운영 제안

- 포함 콘텐츠 제안: 무료 단원 이후 한글·영어 파닉스 과정, 동화책 독후활동, 학습 리포팅·맞춤 콘텐츠 추천. 동화책 읽기는 원래 전부 무료라 패키지 유료 혜택으로 재포장하지 않는다. 리포트/추천은 현재 구현 수준과 강화 로드맵을 구분한다.
- 단품 구매자/이용권 만료 후: 무료 콘텐츠는 유지하고, 블록 기본 인식·글자/낱말 읽어주기 기능을 계속 제공하는 안을 제안한다. 고급 과정·독후활동·상세 관리 유료 권한은 만료된다. 과거의 ‘구매 언어 전체 기본 과정 영구 포함’ 제안과 동일한 확정 정책이 아니다. 상세 경계는 사용자 승인 전이다.
- 패키지 기간 시작은 제품 수령 후 첫 등록을 기준으로 검토, 등록 기한은 후속 결정. 만료 시 유료 지속 여부를 선택하게 하고 별도 동의 없이 자동 결제를 시작하는 안은 제안하지 않는다.
- 기존 월 구독자의 패키지 구매 시 기간 중복 차감/중복 청구를 막는 처리가 필요하다. 가족 프로필 수·환불·배송 포함·해외 가격·쓰기 제품은 후속 설계하며 경쟁사 조건을 그대로 확정하지 않는다.

## 손익 판단의 한계

원가10,000원 가정만 빼면 단품40,000원/6개월89,000원/12개월129,000원의 단순 차액이다. 세금·결제/유통·배송·반품/AS·고객획득·6~12개월 서비스비·콘텐츠 운영비 차감 전이므로 순이익/확정 마진율로 제시하지 않는다. 실제 비용별 견적과 이용량을 넣어 판매가를 검증해야 한다. 소중한글 표시가는 시장에서 제안하는 가격대의 참고이며 탱고북의 구매 전환/유지율을 입증하지 않는다.

## 검증과 인계

### 2026-10-11 현재 범위 — 행사 설계 보류

사용자는 할인 행사·인플루언서 공동구매 맥락을 설명한 뒤 **“행사는 고려하지마. 그건 나중에”**라고 명시했다. 따라서 현재는 블록 단품50,000원·월구독9,900원 기준의 일반 판매용 패키지 구성과 가격만 검토한다. 6개월99,000원·12개월139,000원은 기존 제안이며 아직 사용자 확정 아님. 이번에 작성하던 행사가·공동구매 수수료 시나리오는 제안에서 제거했다. 행사 가격/수수료/채널별 할인 정책은 사용자가 다시 요청할 때 다룬다. HTML·결제·가격 구현 변경 없음.

공식 상품·교재 설명을 읽고 기간·구성·표시가·행사 종료일을 대조했다. 공식 홈페이지에는 가정용과 기관용 설명이 따로 있으므로 학교용 LMS 제공 항목을 가정용 패키지 혜택으로 섞지 않았다. 가격 산식/상대 링크/diff 확인 후 전략·메모리와 로컬 커밋. 제안서 HTML, 운영 상품/결제/권한과 원가 계산 원본은 변경하지 않았다. 다음은 제안 가격·기본 교구 기능 유지·이용권 시작 조건 선택이다.
