## 사용자 피드백

홈 상단 로고만 있는 줄의 공간 낭비, 한글·영어 선택 카드와 배경의 유사한 색을 지적했다. 실제 887px 폭에서는 상단 73px에 로고/부모 버튼만 있고 메뉴는 하단에 있었다.

## 결정·변경

- 768px 이상에서는 기존 5개 메뉴를 상단에 표시하고 하단 메뉴·예약 여백을 제거한다. 모바일에서는 상단을 72→56px로 줄여 로고·44px 부모 버튼을 유지한다. 프로필 이름은 좁은 폭에서 말줄임하며 접근성 이름은 전체 이름을 유지한다.
- 과정 페이지의 동적 높이를 같은 탐색 기준에 맞춘다. 홈 상단 여백도 8px 줄인다.
- 홈 한글 카드는 peach-200/peach-300 테두리, 영어는 mint-200/mint-300 테두리로 구분한다. 단순한 가/Aa 표식·실제 학습 경로·CTA 대비와 키보드 초점은 보존한다. 두 과정 선택 외 일반 콘텐츠 카드는 기존 white 기준을 유지한다.
- 새 기능·운영 데이터 쓰기·push/배포는 포함하지 않는다. 기존 미추적 자료·다른 worktree를 보존한다.

## 검증

768·887·1024px 상단 메뉴, 375px 하단 메뉴·44px 부모 버튼, 한글/영어 과정의 높이·메뉴 중복/넘침을 브라우저로 확인한다. 기존 AppShell 회귀·client typecheck/build와 변경 파일 lint를 실행한다.

## 검증 결과

- client typecheck·production build 통과. 기존 빌드 경고는 유지한다. 변경 TS/TSX5파일 ESLint0오류/0경고, AppShell의 탐색·활성 경로·게스트/회원 부모 진입 회귀3테스트 통과. 스타일 변경에 전체 게임·서버 테스트는 반복하지 않았다.
- 실제 production preview의 사용자 화면887×871에서 상단5개 메뉴 표시·하단 메뉴 숨김·가로 넘침0 확인. 한글 peach-200, 영어 mint-200와 각각2px 테두리로 카드 경계가 보인다. 추천3권까지 기존 첫 화면에서 확인할 수 있다. 캡처: 루트 output/ui-v2-20261012/home-header-contrast.jpg.
- 375×812에서 상단 실제56.67px(이전72.67px), 부모 버튼44×44px·하단5개 메뉴만 표시·가로 넘침0 확인. 768×768에서 탐색이 상단으로 전환되고 중복 표시 없음.
- 한글 과정375/768px, 영어 과정768/1024px에서 페이지 가로·세로 넘침0 확인. 과정 내부 스크롤은 유지한다. 테스트용 탭·viewport override는 검수 후 제거/복원한다. 운영 가입/결제·개인 데이터 조작 없음.
- 실제색 대비: 본문 ink-600/peach-200 5.08:1, ink-600/mint-200 4.72:1, CTA white/coral-700 5.29:1. 키보드 초점 윤곽을 유지한다.
