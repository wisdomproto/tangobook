# 학습자 전체 손그림 게임 UI 통일

## 사용자 결정

최종 방향은 유아용 구름 행동 버튼·별도 평평한 수채화 제목 띠·책 상세의 종이 책갈피 메뉴다. 초기 나무 간판 승인 뒤 사용자가 책에 어울리지 않는다고 반증했다. 한영·홈·책·독후활동·게임의 학습자 공통 sprite/제목/바탕/행동을 적용하며 저작/부모 도구는 구분한다.

## 진행 범위

한영 경로 v1두꺼운 atlas와 자유모드 흰 패널, 텍스트/emoji 헤더가 혼재한다. 손그림 stage4/CTA2/책2 atlas와 도구12 atlas를 내장 imagegen으로 제작하고 기존리본/집/조용한 풍경을 재사용한다. 그림 글자·쓰기/색칠 마스크·캔버스좌표·음원·게임평가·읽기본문/표지·기록·권한/순서는 보존한다. 학습자 AppShell main, 독립 게임root/결과/로딩·헤더, 책 찾기/상세/독후활동 메뉴·학습홈, 한영 자유모드/전체경로/ActivityShell에 연결한다. 읽기 도구는 손그림 조작기만 적용한다.

atlas crop은 원본내용을 수정하지 않는 표시 메타데이터다. 분리된 열린 잠금 고리도 보이도록 여러 큰 alpha component union으로 보완했다. 학습/콘텐츠 데이터 및 운영 R2는 이번 디자인 요청으로 수정하지 않는다.

## 검증

구현·검증 완료, 로컬 main 통합 준비. 사용자 탭 대신 localhost 점검 탭에서 확인했다. 새 원격 push 요청 없음.

## 후속 사용자 반증: 나무 간판 중단

2026-10-13 페이지별 검수 중 사용자는 책에 나무 재질이 어울리지 않고 전체적으로 느려 보인다고 반증했다. 새 자산은 모두 alpha WebP 총501,234B이나 체감 지연의 원인으로 단정하지 않는다. 이후 나무 판 대신 유아적인 구름 모양을 제안·요청했다. 기존 간판 자산은 비교 근거로 보존하며 최종 테마는 얇은 보송한 구름/파스텔 종이 삽화로 바꾼다. 이전 puffy 찐빵 반증을 유지해 두꺼운 베벨/쿠션/광택을 피한다. 책 본문/표지는 중심을 유지하고 책/독후활동 메뉴의 장식 밀도를 줄인다. 기능/진도/평가/음원 흐름은 유지한다.

구름 윗면과 흰 배경 경계·모든 요소가 구름이면 역할 혼동을 사용자 반증으로 추가했다. 큰 행동만 구름, 제목/설명은 그림자/입체 받침 없는 별도 수채화 띠, 표지/학습본문은 원본으로 유지한다. 책은 다른 디자인을 허용한다. 사용자 직접 페이지별 시각 검수·레이아웃/제목/버튼 위치 확인을 요청했다.

## 2026-10-14 최종 레이아웃·검증

제목 앞의 중복 가/Aa 제거. 언어 모드 입구는520px 제목·440px 동등한 선택2개를 화면 높이의 남은 영역 가운데 둔다. 1280×720에서 버튼 bbox는 같은 y314~552, 제목 중심x640. 568×320에서 두 버튼 y124~231, 하단 탐색 시작y247, 문서 scroll320으로 겹침/누출 없음. 그림의 눌리는 바닥·색 테두리는 유지하며 제목 띠에는 입체 받침이 없다. 상단 탐색에 홈이 있는 입구의 별도 홈 제거, 전체화면 게임/독서의 홈·뒤로가기는 보존한다.

홈의 언어 진입/이어하기는 한 카드로 통합, 설명은 제목에 맞춰 가운데 정렬. 작은 가로에서는 두 언어 카드와 활동 허브3개가 함께 보이며 중복 모드 링크·긴 소개를 줄인다. 자유모드는 작은 화면에서 단원 제목/주요 행동/진행을 나란히 배치하고 반복 글자 미리보기만 숨긴다. 독후활동 두 그룹은 아이콘·제목의 시작 높이를 맞췄다. 책의3메뉴는 종이 책갈피, 표지·본문은 원본. 전체화면 독서의 남은 emoji 홈/뒤로/닫기를 그림/벡터 아이콘으로 교체했다. 작은 결과 화면은 두 열로 조정해 다시 하기/확인이 모두 화면 안에 있다.
