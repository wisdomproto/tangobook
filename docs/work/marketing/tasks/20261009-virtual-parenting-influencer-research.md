사용자는 시우맘을 포함해 교육 중심 인플루언서 10명을 선정하고 이미지·영상·피드·댓글·대댓글을 수집해 계정별 교육관·콘텐츠·반응을 깊게 분석한 뒤 가상 인플루언서 페르소나를 만들도록 요청했다. 이미 로그인된 인앱 Instagram을 사용한다. 1차 표본 확보와 전체 수집 완료를 구분한다.

## 결정과 진행

- Apify는 무료 크레딧과 유료 대댓글 옵션을 확인했으나 가입·결제·수집 실행하지 않았다. 사용자가 Instaloader를 선택하여 별도 venv에 4.15.3 설치. 사용자가 직접 로그인한 뒤 로컬 세션 저장됐으나 게시물 GraphQL은 execution error, 라이브러리 대체 조회는 403/login_required로 거절됐다. 반복 재로그인·대량 재시도하지 않았다.
- 사용자가 브라우저 수집을 진행하도록 지시했다. CUA로 인앱 Instagram UI만 조작하고 DOM에서 현재 로딩된 공개 원문을 저장했다. DM·좋아요·팔로우·댓글 게시·외부 전송은 하지 않았다.
- 확정 후보: __siu.mom(시우맘), my__chaechae(채채맘), __ririmom(리리맘), _hyunee_mom(현이맘), momglish__(맘글리쉬), woooooori_mommy(우리맘), ggumi_geonhu(건후맘), taeoh_mom_(태오맘), bloom_with_play(블룸쌤), _jinsun.kang(써니나라).
- 플맘(playwith_mommy)은 쉬어간다는 게시물 및 오래된 표본을 확인해 주 후보에서 제외. 보조 3개 게시물만 별도 보존. 써니나라는 고정 일상 글뿐 아니라 최근 문해력 신문·기업 탐구·어린이과학동아 게시물을 확인했다. 블룸쌤은 교육 정보 구성 참고용이며 상단 오래된 표본으로 현재 운영 빈도를 단정하지 않는다.
- 후보 10곳의 첫 페이지 게시물 URL 120개, 직접 읽은 본문 42개(추가 보조 3개), 고유 댓글·대댓글 470개(확인한 대댓글 8개 포함), 대표 JPEG 10장을 확보했다. 첫 페이지에는 고정 글이 섞여 있다. 댓글은 로딩된 표본, 이미지는 각 캐러셀 대표 한 장이며 전체 데이터가 아니다. 릴스는 재생 가능하지만 파일 다운로드 시간 초과로 전체 영상 0개다.
- 대댓글 부모 추출을 실제 DOM과 대조했다. 작은 댓글 목록에서 공통 조상을 부모로 잘못 잡는 사례를 발견해 우리맘 댓글 관계를 답글 UL 조상 기준으로 교정했다. 다음 배치에는 이 엄격한 방식을 사용한다.
- 표본에서 공구/자료 키워드 댓글과 진짜 교육 질문을 분리해야 함을 확인했다. 교육 효과·자녀 성장·경력은 계정의 자기 설명이며 별도 사실 검증하지 않았다. 원본 인물의 개인 이력은 가상 엄마 사실로 복제하지 않는다.
- 로컬 `http://127.0.0.1:5191/research/index.html`에 10계정 출처·이미지·게시물 링크·범위와 가상 엄마 페르소나 초안을 정리했다. 초안은 고정 집에서 4세 가상 아이와 책→손놀이→짧은 대화를 기록하는 방향이며 완성 페르소나가 아니다.

## 검증

브라우저에서 후보 프로필과 게시물 본문, 댓글/대댓글 펼침을 확인. JSON 중복 제거 결과를 재계산했고 이미지 저장 도구는 10건 image/jpeg 성공. 저장된 세션/비밀번호/사용자 터미널 로그는 수집 데이터와 Git에서 제외. 제품 테스트는 문서/로컬 조사 산출물 범위여서 실행하지 않는다.

## 다음 행동

최근 3개월/비공구 교육 글을 추가 수집해 교육·일상·판매 비중을 코드화한다. 캐러셀 전체, 집/공부방 사진, 원본 영상의 안정적인 저장 경로와 댓글 완전성을 검증한다. 현재 42개 표본은 10계정 전체 분석을 완료한 근거가 아니다. 충분한 근거가 쌓인 뒤 페르소나·콘텐츠 구성·공간 소품을 확정한다. 모든 후속 브라우저 조작은 CUA로 하고 인증 파일을 임의 추출/전송하지 않는다.
