## 요청과 완료 조건

사용자가 전체 오가닉 채널·콘텐츠·언어권 전략과 타깃 키워드를 요청하고 기존 조사 활용을 지시했다. 제안한 키워드–자료–채널–도착 페이지 표 제작을 승인했다.

## 읽은 기억과 변경 범위

공통 인수인계, marketing/strategy BRIEF와 MEMORY, 기존 브랜딩 전략 task, STRATEGY와 brand-brief, marketing/blog CLAUDE 및 마케팅 도메인 지침을 참고했다. 5월 통합 키워드/노이즈 감사와 9월 네이버 4축 조사를 활용했다. 제품 코드와 기존 전략 HTML은 수정하지 않았다.

- P1은 자산과 체험 연결 가능성에 따른 제안이며 검색량 순위나 확정 캠페인이 아니다. 한글 ㅂ·영어 cat·거인의 정원을 첫 묶음으로 제안하고 6주 순서·채널 역할·측정을 담았다.
- 실제 URL 6개는 기존 10월5일 체험 증거 기록에서 연결했다. 이번 요청에서 운영 접근/게임 완료 재검증은 하지 않았다. 다른 항목은 URL 선정 필요로 남겼다.
- 영어 후보와 베트남·태국·인도네시아·말레이시아 시드 후보는 현지 검색량·원어민 검증 필요. 미국 영어 조사값으로 현지 수요를 대체하지 않는다.
- 인쇄/PDF/무료 조건과 온라인 활동을 구분하고, 신규 공개 범위·가격·발행·예약·API 유료 조사·DB 변경은 실행하지 않았다.
