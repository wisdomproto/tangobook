## 후속: 다각도 이미지와 카메라 비교 HTML

사용자가 왼쪽 생성 이미지/오른쪽 3D 카메라 위치를 보여주는 HTML과 여러 각도/장소의 이미지를 요청했다. 특히 가구 유지 여부를 확인하고 각 가구를 고정된3D 모델로 보관하는 방향을 확인했다. 중간 질문은 진행 취소가 아니며 이후 “암튼 이미지들 더 만들어봐”로 제작 계속을 요청했다.

같은 BLEND의 독서 정면/독서 창가 측면/거실 대각선/주방4카메라를 정의했다. Blender 실제 view_frame과 matrix_world로 위치·방향·프러스텀·세로화각을 glTF 좌표(x,z,-y)로 내보낸다. 864×1080 기준. Qwen은 각 촬영 원본을 LoadImage로 입력해 재질만 실사화하도록 요청한다. 가구 비교를 우선해 새4장에는 인물 미등장으로 제작한다(작업자 선택).

cutaway 집의 천장 없는 구조가 실내 guide에서 검게 보이는 반증을 발견해 촬영용 ceiling을 추가했다. 가구 원본/배치 변경 없음. 최초 ceiling 없는 Qwen1개 제출 후 caller를 종료해 후속3개 제출을 막았고, Comfy의 이미 제출한1개는 정상 완료를 기다려 다른 작업의 큐를 건드리지 않았다. ceiling 없는guide/API/prompt는 shots/v1-open-ceiling에 보존. 새 촬영 모델·guide로4장 재생성 중.
