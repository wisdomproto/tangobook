`build-library-content-audit.ts`는 실제 클라이언트의 어휘·게임·색칠 빌더와 객체 키를 사용했다. `tsx --tsconfig ../client/tsconfig.json`으로 경로 별칭을 지정해야 한다. 초기 tsconfig 없는 실행은 @/features import 오류로 실패했고 위 명령으로 해결했다. Library Master의 로컬 snapshot도 갱신했고 기존 행 순서를 유지했다.

## 별도 연결 및 기능 범위

실제 게임 장면 함수로 검사한 연결은 한글127/128(오이1개 미연결), 영어304/388(84사용·78고유단어 미연결)이다. 이는 정답을 맞힌 뒤 이어 보여줄 동화 장면이 없다는 뜻이며 단어 그림/TTS 누락과 다른 수치다. 다른 동화 장면이 준비된 정답은 한글90/영어304, 창작 장면은 한글37/영어107이다. 기존 fork/watch 동음이의어 검토 문제는 이 조사로 수정하지 않았다. 로컬 연결 코드 기준이며 미푸시 코드와 운영 코드의 같음을 단정하지 않는다.
