### 수정한 문제

1. 모드 이름만으로 두 선택의 차이를 알기 어려웠다. 기존 두 입구를 유지하고 `순서대로 하나씩` / `원하는 활동 고르기` 한 줄만 추가했다. UI 5개 언어에 같은 키를 추가했다.
2. 지도/사이드바의 주요 활동명이13px, 권/진행 정보가10~11px였다. 활동16px·챕터22px·보조13px, 권 이름16px/짧은 화면14px, 범례14px/짧은 화면12px로 조정했다. 완료/현재/잠금 색·체크·재생은 그대로다. 짧은 화면의 장식 권 아이콘/작은 원형 진행 그림은 빼고 권 이름·실제 퍼센트를 남겨 `복잡한 모음`이 한 줄로 보이게 했다.
3. 지도는 낱말 하위 활동을 펼쳐 번호를 매기지만 셸의 `활동 1/4`는 원래 묶음 기준이라 숫자가 어긋났다. 셸의 별도 묶음 카운터를 없앴다. 실제 문제/쓰기 반복 진행도와 활동 목록 번호는 유지한다.
4. 팝잇·따라쓰기 화면의 큰 행동 안내와 작은 최초 안내가 중복됐다. `ownInstruction`으로 해당 화면은 자체 안내만 표시한다. 다른 활동의 최초 안내는 유지하며 짧은 화면11px→14px로 올렸다.
5. 자유모드에서 낱말 만나기만 선택해도 상단에 블록/쓰기/색칠까지 이어질 것처럼 표시됐다. 단독 활동은 그 단계만, 순차 학습은 실제 전체 단계를 표시한다. 단계 글씨14→16px(짧은 화면12→14px), 비활성 단계 대비도 보완했다.
6. 낱말 색칠에서는 공통 제목을 가린 뒤 대상 낱말도 사라져 그림만 남았다. 실제 현재 낱말을 상단에22px(짧은 화면18px)로 표시해 그림↔낱말 맥락을 유지한다.
7. CVC 학습은 첫 화면에 같은 소리 줄3개와 약한 테두리만 있었다. 기존 번역 안내 `소리 조각을 눌러 들어봐!`를 재사용하고, 현재 누를 셀에 손 모양 표시를 CVC/WordFamily 공통으로 적용했다. 새 래스터/추가 로딩 없이 기존 lucide `Pointer`를 쓴다. 검수 중 `HandPointer` 미지원 export 오류를 발견해 `Pointer`로 수정하고 다시 로드해 확인했다.
8. 짧은 지도에서 목록의 sticky `익히기` 제목이 스크롤된 첫 활동 위를 덮어 첫 활동 클릭이 제목 접기로 동작했다. 제목의 sticky를 제거하고 같은 가로폰에서 `bl- 배우기` 직접 진입을 재검증했다.
9. **실제 진행 막힘**: WordListenChoose가 독자적인 한 번짜리 ref로 안내를 재생했다. StrictMode cleanup이 첫 오디오를 취소해도 두 번째 setup에서 재생하지 않아 `starting=true`·모든 선택지 잠금이 계속됐다. 다른 활동과 같은 `useEntryGuide`의 세대 보호를 재사용했다. 최신 안내 종료 후에만 열리고 이전 종료 콜백은 잠금을 풀지 않는 회귀를 추가했다. 실제 재로드에서 `다시 듣기`/선택지 활성화 및 아기 정답 체크를 확인했다.
