## 요청과 결정

사용자는 활동 완료를 분명하게 알려주고 자연스럽게 다음 활동으로 자동 연결하라고 지시했다. 챕터 마지막은 지도 복귀/다음 챕터 잠금 해제라는 기존 계약을 다시 확인했다. 개별 복습은 같은 챕터/활동 복귀를 유지한다. 완료 안내에 추가 클릭을 요구하지 않는다.

이어하기 입구가 명시적으로 필요하며 현재 학습 시작이 복잡하다는 반증도 받았다. 한영 모드 선택 화면에서 현재 활동으로 바로 진입하는 버튼을 추천하고 홈/지도 상단과 함께 위치 선택 질문을 보냈다. 답변 전에는 기존 홈 판/지도 한 CTA 정책을 임의 변경하지 않는다. 완료 전환 구현은 독립적으로 진행한다.

## 읽은 기록·범위

공통 인수인계/기억·작업 지도, 파닉스 BRIEF/MEMORY, 커리큘럼 활동 선택 task, PLATFORM/디자인 시스템, root/기능 CLAUDE를 읽었다. 기존 실제 완료/음원·칭찬 종료 콜백/자녀 진도/미래 잠금 계약을 재사용한다.

## 진행

첫 챕터로 이끄는 튜토리얼도 사용자 요청으로 추가했다. 처음 지도 시작 버튼 안내, 실제 첫 챕터 누르기/소리 선택/쓰기 방법과 기존 음성/획순 안내를 연결한다. 별도 설명 화면/추가 시작 버튼 없이 실제 학습을 하면서 익히고, 완료한 활동을 다시 하는 경우에는 초기 안내를 반복하지 않는다.

사용자가 이어하기 위치를 **한글·영어 모드 선택 화면**으로 확정했다. 실제 시작/완료 기록이 있고 미완료 활동이 있을 때만 이어하기를 제공한다. 현재 활동 URL로 바로 진입하며 전체 학습 완료/학습 시작 전에는 가짜 이어하기를 만들지 않는다. 홈 언어 판/지도 단일 실행 버튼은 유지한다.

현재 GuidedRun은 실제 완료를 확인하면 즉시 다음 라우트로 이동한다. 한영 누르기/쓰기/소리 게임은 음원·칭찬 종료 후 호스트 완료 콜백을 주므로, 이 지점에 짧은 공통 완료 안내를 넣는다. 별도 결과 화면/다음 버튼/폭죽을 추가하지 않는다.

## 검증

구현 후 한영 완료 안내→자동 다음, 챕터 끝→실제 unlock, 개별 복습→같은 선택 복귀, 중복 콜백·전환 중 이탈/자녀 변경 timer 취소·reduced-motion을 검증한다. 실제 학습 완료를 운영에 추가하지 않는 브라우저 QA와 완료 콜백 회귀를 구분한다.
