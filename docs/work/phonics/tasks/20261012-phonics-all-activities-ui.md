## 요청과 완료 조건

사용자 공통 풍경·모음3카드 승인 뒤 한글 전체와 영어까지 개편 요청. 기존 완료는 공통 틀/모음3카드이며 모든 내부 활동 개편 완료로 해석하지 않는다. 한글 자음·합성/받침/쌍자음/복잡모음·쓰기·복습, 영어 알파벳/CVC/장모음/자음군/모음패턴·쓰기·복습의 실제 활동판에 승인한 표현을 연결한다.

## 읽은 기억과 범위

handoff/phonics/games 지침과 기억, PLATFORM/design-system, phonics-learner CLAUDE 및 앞선 모음/그림자모/UI task. 기존 그림자모·음원·SVG 풍경을 재사용하며 대형 배경/신규 엔진/자산 의존성을 늘리지 않는다. 기존 학습 순서·음원 체인·ID·완료/리포트·게임 게이트·쓰기 폰트/99%는 유지한다. 같은 모음3카드와 자음3카드×3탭은 서로 다른 기존 활동이다.

## 결정과 진행

- 한글 전체 요청에 영어 포함 후속 지시 반영. 남은 화면을 누르기/합성/쓰기/듣기/기억/찾기 역할별로 구분해 다듬는다.
- 기존 worktree를 최신 로컬 main으로 fast-forward해 별도 영상 Rive+Remotion 산출물/의존성과 기억을 보존했다. ReviewWriteActivity.test.tsx의 hunk 없는 기존 M 표시는 수정/스테이지하지 않는다.

진행 중. 대표 실제 한영 활동과 모바일/태블릿 시각 검수, 기존 활동 회귀·타입/빌드/변경 lint를 수행한다. 실물 교구/iPad 스피커/모든 책 음원의 전수 청취는 별도 증거다.

## 구현 결과

- 공용 ActivityShell에 콘텐츠 언어/활동 역할 메타데이터와 독립 CSS를 연결해 16개 한영 활동 컴포넌트에 적용했다. 자음3카드×3탭/그림 보상, 자모·받침·복잡모음 합성 무대, 모음 선택, 영어 대소문자 탐색/종이 쓰기, CVC/장모음/자음군/모음패턴 소리 조각, 낱말 듣기, 뒤집기/글자 사냥/복습 쓰기까지 연결한다. 과정 목록의 모음 외 자음/받침/쌍자음/복잡모음에도 기존 그림 자모를 사용한다.
- 자음 살구/모음 민트 그림과 정확한 폰트 쓰기를 유지. 게임/Activity의 LetterFill·WordFill은 프레임만 변경하며 canvas 픽셀 크기·마스크·획·99%는 변경하지 않았다. 영어 대소문자는 살구/민트로 분리하며 활성 탭/과정 행동은 영어 민트 테마를 따른다.
- 합성 중 다른 음절로 이동할 수 있던 경로를 잠근다. 차례 아닌 글자도 실제 disabled로 표현. 완료/새 음절의 판단·읽기/쉼 순서는 유지하고 받침이 세로로 만나는 공간만 조정. 두 회귀 테스트로 차례·합성 잠금·소리 체인 후 다음 짝·받침 음절 기록/최종 완료를 확인했다.
- 영어 소리 조각의 반복 프레임 애니메이션을 제거하고 현재 대상의 윤곽/누른 상태로 표시. 새 반복 JS/타이머/대형 비트맵/엔진/의존성 없이 기존 SVG/그림/WebP/CSS 재사용. reduced-motion 대응. 효과 엔진은 기존 lazy chunk 유지.
- 새 패널 패딩까지 포함해 카드 격자 폭을 계산한다. 375px 영어 자음군의 첫 열 x=-37.54px 잘림을 실제 발견·수정, 열 정렬과 그림 슬롯 유지. ee 앞/뒤 조각 및 CVC도 가변 열, 복습 4열/사냥6열은 컨테이너 너비에 맞춘다. 812×375 Magic e 마지막 행 bottom409.67px을 발견·수정, 카드44px과 제목/간격을 조정해 마지막 행350px 안쪽 표시. 더 긴 목록은 맨 위가 잘리지 않게 스크롤 가능.
- 공용 GamePlayerLayout뿐 아니라 별도 전체화면인 한/영 블록 플레이어·로딩 게이트·게임 결과에도 파닉스일 때만 같은 풍경을 적용. 카메라/인식·블록 판/드래그·정답·보상은 수정하지 않는다. 한영 복습 그림짝은 빠져 있던 기존 VocabSourceProvider를 연결해 배경과 리포트 source=phonics를 일치시킨다. 단원/진척 키와 완료 조건은 유지한다.
