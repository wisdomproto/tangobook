## 사용자 반증과 실제 원인

동일한 `/library/phonics/korean?mode=curriculum` 주소에서 두 커리큘럼 화면이 보인다. `PhonicsCurriculumPath`의 `parentOpen` 로컬 state가 오른쪽 위 학습 정보 버튼으로 `PhonicsJourneyMap`을 렌더한다. 서버 두 개나 무작위 라우트 분기가 아니라, 아이용 전체 화면 경로와 부모용 예전 상세 지도 사이의 전환이다. 실제 코드로 확인했으며 동일 주소가 역할을 숨긴다.

사용자는 예전 지도가 전체를 대략 한눈에 보여준다는 장점을 인정했다. 예전 지도를 삭제하자는 제안은 **확정하지 않았다**. 이어하기에서 바로 활동에 들어가 현재 챕터에 어떤 활동이 있는지 알기 어렵다고 반증했다. 2026-10-14 마지막 요청은 실제 변경이 아니라 **함께 구성을 고민하기**다. 따라서 이 반증에 대한 화면/라우트 삭제·교체는 아직 하지 않는다.

## 논의할 구성

2026-10-14 사용자 구현 승인: **예전 지도 유지 + 현재 챕터 활동 순서 + 시작 버튼 하나**. 이어서 상단을 최대한 줄이고 열자마자 지도가 보여야 한다고 지시했다. 이 결정은 위 논의 단계에서 확정됐으며 예전 지도를 삭제하지 않는다. 한영 모드의 기본 화면을 JourneyMap으로 연결하고 상단은 작은 뒤로/언어 제목/자유모드 아이콘 및 작은 권 선택만 둔다. 큰 세계관 제목/설명/꽃 집계/집 그림/전체 진도 상자는 제거한다. 완료/현재 노드는 학습 직행 대신 챕터 미리보기를 선택하고 한 개 CTA에서 실행한다. 미래 단계는 잠금, 활동/진도/자동 전환은 기존 계약을 따른다.

한 권의 경로를 한눈에 보여주는 보드와 현재 챕터의 실제 필수 활동 미리보기를 한 화면에 배치한다. 활동 미리보기는 완료/현재/다음 상태의 작은 그림 순서이며 여러 시작 버튼을 만들지 않는다. 시작/이어하기는 하나, 활동 중에는 순서와 현재 위치만 보여주고 자동 다음 활동·챕터 끝 경로 복귀/잠금 해제를 유지하는 안이다. 지도에서 완료 챕터를 선택하면 해당 챕터 구성을 볼 수 있고 재학습 동작은 실제 현재 진도와 구분해야 한다.

기본 모음 첫 챕터 듣기/쓰기, 두 번째부터 소리 게임이 있는 기존 실제 `journeyActivities`를 재사용해야 한다. 모든 챕터에 같은 개수의 활동을 강제로 보여주거나 자유모드 추가 놀이를 필수로 바꾸지 않는다. 이 내용은 제안이며 사용자 합의 전 플랫폼 확정 규칙으로 옮기지 않는다.
