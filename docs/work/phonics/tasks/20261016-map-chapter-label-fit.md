상태: 로컬 수정·검수 완료. 새 push 요청 없음.

- 운영45e4a8fb7, 로컬 main b3983a143에서 시작. 사용자 기존 탭/산출물 보존.

## 발견

- 영어 Book3 `_ake _ape`가82×74px 버튼 안에서32px 글꼴/overflow-wrap:anywhere에 의해4줄128px(텍스트 range135px)로 분리돼 위아래로 넘친다. 다른 권의2줄도 글자 높이/테두리 여백이 부족하다.
- 영어5권 일반 챕터39개 측정. 한글 전 권 및 수정 후 검수는 진행 중이다.

## 방침

- 소리 묶음을 한 줄로 유지하고 두 묶음은 두 줄 중앙 정렬. 버튼 크기에 맞춰 글꼴 크기 조절, 숨김/말줄임/소리 일부 삭제로 해결하지 않는다.
- 접근권·활동 순서·진도는 변경하지 않는다. 운영 검수와 로컬 수정 증거를 구분한다.

## 구현·검수

- StageLetter의 영어 소리 최대2개를 독립된 줄로 표시해 `_ake` 중간 줄바꿈 방지. 실제 버튼 내부 크기(cqw/cqh)와 가장 긴 소리 길이에 맞춰 글꼴 크기를 정하고, 한 소리만 있는 버튼은 더 크게 유지. 공용 지도이므로 커리큘럼/자유모드 모두 사용하며 기존 소리 표기/선택·진도는 보존.
- 실제 운영 한글5권 일반 챕터41개는 넘침 없음. 영어5권 일반 챕터39개는 수정 후 로컬 전부 넘침 없음. 복습 그림을 포함한 지도 버튼 수는 **한글48개+영어58개=106개**다(과거99자유모드 단원 집계와 다른 실제 커리큘럼 렌더 수).
- 브라우저 viewport 설정 반영이 늦는 문제 때문에 별도 로컬 HTML의844×390/1024×768 iframe에서 실제 콘텐츠 innerWidth/innerHeight를 확인해 전수 측정했다. 두 크기에서106개씩 모두 글자/복습 그림이 테두리 안(3px 여백)에 들어옴. 실기기 손 입력 검증과 구분한다. PC는1280×720 설정 후 실제 크기를 재확인한다.
- 지도/공유 학습 공간45회귀·타입 검사·변경 TSX lint·client build22.09초 통과. 기존 Browserslist/Lottie eval/청크 크기 경고 유지.
- 증거는 기존 영어 첫 활동 완주 검수와 함께 `C:/project/tangobook/output/production-english-book3-first-20261016/`에 before/after JSON·이미지를 저장. 운영 완료 검수는 기존 배포45e4a8fb7에서, 넘침 수정은 로컬이다. 새 push/배포 없음.
