## 요청과 완료 조건

한영 모두 지도와 같은 공통 학습 틀 유지, 왼쪽 현재 챕터 활동 내비게이션 접고 펴기, 활동 시작 기본 접힘, 오른쪽에서 학습/게임 실행. 학습 중 목록을 펼쳐도 판/글자 크기·중앙이 바뀌지 않는 overlay. 최초 순차/완료 복습·자유 선택의 기존 권한은 보존. 실제 챕터 완료 후 지도 복귀와 다음 챕터 잠금 해제. 화면 직접 검수.

## 읽은 기억과 범위

공유 인계·MEMORY/작업 지도·phonics BRIEF/MEMORY, PLATFORM/디자인 시스템/기능 CLAUDE, 기존 커리큘럼 보드·순차/완료 전환·자유모드 계약을 확인했다. 현재 map/study는 AppShell 안, activity는 바깥 route로 갈라지고 각 player가 fixed 전체 화면을 소유한다. 공통 route/layout에서 같은 지도 인스턴스와 실행 영역을 유지하며 재사용을 우선한다. 낱말 연결·실물 인식은 의미/규칙을 바꾸지 않는다.

## 다음 행동

### 전체 활동 트리·현재 위치 후속

사용자가 열린 사이드바에서 현재 활동을 알 수 없다고 지적했다. 이어 전체 챕터를 스크롤하고 기본 현재 챕터만 펼침으로 확정했으며, 낱말 배우기와 다른 묶음도 실제 활동 단위의 접고 펴는 트리로 표시하라고 요청했다.

- 한영 공통 WorkspaceTreeBranch로 권→챕터→익히기/놀며 익히기→실제 활동을 각각 접고 편다. 현재 권/챕터만 기본 펼침, 수동으로 다른 가지를 열 수 있다. 전체 내부 스크롤, 열 때 실행 중인 잎에 정렬한다.
- 실제 route의 activity를 ‘학습 중’·테두리/배경·aria-current로 표시한다. 전역 다음 미완료 단계와 개별 복습 중인 활동을 혼동하지 않는다. 같은 현재 항목 클릭은 닫기만 하며 게임을 재시작하지 않는다. 다른 챕터에서 같은 key를 가진 활동도 정확히 이동한다.
- 공유 틀의 자유모드 메뉴는 기존 배우기/쓰기 결합을 실제 key별 잎으로 펼쳐 보인다. 기존 배우기 완료→쓰기 자동 연결은 유지한다. 낱말 배우기 아래는 공통 wordLearningStages의 만나기/블록/쓰기/색칠, 실제 컴포넌트가 현재 낱말과 stage를 workspace context로 전달한다. 영어 Book1은 블록이 없고 글자 쓰기다.
- 자유모드 하위 항목은 검증한 part query로 현재 낱말의 해당 단계만 연습한다. 전체 순차 run의 위치/입력 방식을 덮어쓰거나 부모 활동을 완료 마킹하지 않고, 실제 단계 연습 이벤트만 남긴 후 돌아온다. 커리큘럼 미완료 묶음의 part 점프는 무시하고 원래 단계로 이어가며, 실제 완료한 묶음만 개별 단계 재연습을 허용한다.
- 단위/통합 회귀: 전체48파일427검사 통과(maxWorkers4), 최종 관련2파일16검사 재통과. 개별 단계 연습은 별도 run ID로 기록한다. 첫 병렬 실행의 기존4.6초 완료 연출 테스트1개는5초 한도에 걸렸고, 단독11검사·제한 병렬 전체 재실행에서 기대값/시간 한도 변경 없이 통과했다. 타입·변경 TS/TSX lint·client build 확인.
- 실제 UI: 한글 자음 찾기 현재 표시, 전체 챕터 접기/스크롤, 아기 블록→개별 쓰기→원래 블록 이어하기 보존, 영어 Book1 cup 만나기3개 하위 활동을 확인했다. 실제 사용자 완료 기록은 초기화/대리 완주하지 않았다. 개별 하위 연습 완료가 부모를 완료하지 않는 것은 mock source/player 콜백 회귀로 확인했다.

### 활동 목록 단순화·연속 번호 후속

사용자가 낱말 이름(아기)까지 펼친 트리가 복잡하다고 반증했다. 현재 분류만 기본 펼침·다른 챕터 접힘을 승인했고, 이후 **낱말 만나기/낱말 블록 놀이/낱말 쓰기/낱말 색칠하기를 익히기 바로 아래 같은 깊이에 표시**하라고 정정했다. 앞선 ‘낱말 배우기만 접어두기’ 제안은 이 평탄한 목록으로 대체한다. 한영 공통 적용, 익히기에 연속 번호를 붙인다.

- 권/챕터/분류의 접고 펴기는 보존한다. 현재 실행 분류만 기본 펼침, 지도는 첫 미완료 활동 분류를 연다. 이전의 모든 분류 기본 펼침을 대체한다.
- 활동 그림 대신 작은 번호를 사용하고, 실제 완료 체크와 실행 강조를 별도 유지한다. 낱말 묶음 부모/하위 번호/단어 이름은 빼고 실제 단계 네 개를 같은 목록의 연속 번호로 보여준다. 영어 Book1은 블록 없음·글자 쓰기 예외를 유지한다.
- 목록만 평탄화하며 학습 run·진도/숙달 의미·자산·누적 글자 범위는 변경하지 않는다. 자유모드/이미 완료한 묶음의 단계 연습, 실행 중인 항목 재클릭 시 닫기, 미완료 커리큘럼의 미래 단계 잠금도 보존한다.
- 순서 검토: 낱자 소리/모양→낱자 쓰기→음절 조합/쓰기→낱말 만나기→블록→쓰기→색칠을 유지한다. 같은 타깃마다 네 단계를 이어가고 다음 타깃으로 진행한다. 색칠을 뒤에 둔 것은 맥락 재노출/호흡을 위한 제품 판단이며 고정 순서의 학습효과 우월성이 입증됐다는 뜻이 아니다. 근거와 분량 한계는 [학습 설계 검토](20261015-learning-practice-design-review.md)에 있다.
- 초기 평탄화 검증: 전체 파닉스427검사·타입/lint/build 통과. 이어진 현재 챕터 전용 탐색 정정의 최종 검증은 아래를 따른다. 이번 원격 push 미요청.


#### 현재 챕터만 노출·전체 커리큘럼 별도 선택 — 최신 사용자 정정

사용자가 전체 권/챕터를 한꺼번에 보이지 말고 현재 ㄱ 배우기만 보여주며, 위 ‘전체 커리큘럼’ 버튼에서 챕터를 선택하자고 요청했다. 기본 전체 트리 설명은 이 후속으로 대체한다.

- 기본 사이드바는 선택한 한 챕터 제목·익히기/놀며 익히기·번호 활동만 표시한다. 위 ‘전체 커리큘럼’을 누를 때만 권별 접기 목록+챕터 선택 행이 보이고 활동은 그 화면에서 반복하지 않는다.
- 챕터 선택은 활동 미리보기로 돌아오며 게임을 즉시 교체/완료하지 않는다. 자유모드는 선택 활동 직접 실행, 커리큘럼 미래 활동은 잠금 보존. 활동 중 drawer를 다시 열면 실제 실행 챕터로 정렬한다. 같은 게임/지도 인스턴스는 유지한다.
- 낱말4개 직속 행/연속 번호/단어 비노출과 같은 타깃 순차 run은 앞선 결정을 유지한다. 이 정정으로 별도 낱말 부모/단계 fold 컴포넌트와 사용하지 않는 스타일을 제거했다.

#### 학습 기록 농도 구분 후속

사용자가 학습한/하지 않은 항목을 농도로 구분하자고 제안해 한영 공통 적용했다. 챕터 선택 배경은 해당 모드의 실제 완료 활동 비율0~100%에 따라 연한 바탕→진한 초록으로 바뀌고 완료율을 함께 표시한다. 개별 활동은 실제 완료 진한 초록/체크, 현재 실행은 과정색 테두리/학습 중, 완료 기록 없음은 옅은 바탕이다. 색을 흐리게 하려고 전체 opacity를 낮추거나 터치 가능성을 없애지는 않는다. 단순 클릭 횟수·머문 시간·따라하기를 숙달 점수로 바꾸지 않는다. 기존 진도/부모 활동 완료 기준·권한은 그대로다.
