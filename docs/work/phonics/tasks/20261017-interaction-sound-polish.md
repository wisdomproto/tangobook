## 발견·수정

- 그리기 소리는 입력이 없어도 자체 꼬리 시간이 남았다. StrokeTraceCanvas/WordFillCanvas/LetterFillCanvas에서 손 뗌·완성·이탈 시 즉시 `stopDrawLoop`, 공통 LearningEffectsHost에서 pointerup/cancel·탭 숨김·언마운트도 정리한다. 미완 잉크 유지/90% 판정은 보존한다.
- 획 쓰기 마지막 획의 `playUi('success')`가 상위 활동의 발음/완료 효과와 중복될 수 있었다. 중간 획만 선택음, 마지막 성공 소리는 상위 활동이 소유한다.
- SceneReveal은 그림이 로딩되기 전에 노출 시간/읽기가 시작되고 별도 speech Audio를 만들었다. 그림 load/error 후 시작, 공용 해금 speech 요소 재사용, 실제 ended+최소2.5초(무음3초) 뒤 다음으로 이동한다. 탭 스킵·늦은 ended·타이머는 한 번만 전환하고 이탈 시 예약을 취소한다. BGM은 기존 별도 요소·볼륨0.16 유지한다.
- 작은 가로 화면에서 장면이 높이보다 커지고 영어 긴 문장24px가 그림을 크게 가렸다. 패널 폭을 높이에도 맞추고 자막16~24px/여백을 뷰포트 높이에 맞췄다. PC는 넓게 유지한다. SceneReveal 진입180ms fade, reduced-motion에서 장면/그림·guided 진입 애니메이션을 끈다.
- 새 이미지/음원 생성, 교육 순서·잠금·성취 데이터 변경은 없다.
