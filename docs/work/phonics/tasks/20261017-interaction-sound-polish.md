# 한영 디자인·사운드·전환 점검

## 요청·범위

사용자가 한글·영어 전체의 디자인, 누르는 반응, 사운드 효과와 화면 전환을 직접 점검하고 자연스럽게 다듬도록 요청했다. 현재 교육 순서·같은 타깃 낱말 흐름·기록 정책은 유지하며, 발견한 공통 문제를 수정한다. 새 main push/운영 자산 일괄 수정 요청은 아니다.

## 발견·수정

- 그리기 소리는 입력이 없어도 자체 꼬리 시간이 남았다. StrokeTraceCanvas/WordFillCanvas/LetterFillCanvas에서 손 뗌·완성·이탈 시 즉시 `stopDrawLoop`, 공통 LearningEffectsHost에서 pointerup/cancel·탭 숨김·언마운트도 정리한다. 미완 잉크 유지/90% 판정은 보존한다.
- 획 쓰기 마지막 획의 `playUi('success')`가 상위 활동의 발음/완료 효과와 중복될 수 있었다. 중간 획만 선택음, 마지막 성공 소리는 상위 활동이 소유한다.
- SceneReveal은 그림이 로딩되기 전에 노출 시간/읽기가 시작되고 별도 speech Audio를 만들었다. 그림 load/error 후 시작, 공용 해금 speech 요소 재사용, 실제 ended+최소2.5초(무음3초) 뒤 다음으로 이동한다. 탭 스킵·늦은 ended·타이머는 한 번만 전환하고 이탈 시 예약을 취소한다. BGM은 기존 별도 요소·볼륨0.16 유지한다.
- 작은 가로 화면에서 장면이 높이보다 커지고 영어 긴 문장24px가 그림을 크게 가렸다. 패널 폭을 높이에도 맞추고 자막16~24px/여백을 뷰포트 높이에 맞췄다. PC는 넓게 유지한다. SceneReveal 진입180ms fade, reduced-motion에서 장면/그림·guided 진입 애니메이션을 끈다.
- 새 이미지/음원 생성, 교육 순서·잠금·성취 데이터 변경은 없다.

## 검증·증거

- 변경 및 인접10파일 **206검사 통과**: SceneReveal3, 세 쓰기 캔버스, LearningEffectsHost, useGameAudio, GuidedPhonicsActivity, WordMeetingActivity, HangulPopitActivity. 클라이언트 타입·변경 ESLint·빌드 통과(기존 chunk/i18n mixed import/lottie eval 경고).
- PC1280×720 실제 ㄱ5회 팝잇·ㄱ쓰기3회, A팝잇, G/g 각2획, 그림짝4/4. G/g는 여러 native 직선 드래그로 곡선 중단/재개까지 입력했으며 마우스 입력 검증이다.
- 한글 아기/야구 및 영어 cape/wave/bake 합성, 발음 중 버튼 잠금→다음 단계 확인. 실제 장면은 아기/야구/cape와 한글 그림짝 소파에서 확인. 연결 장면 없는 wave/bake는 다음 낱말로 바로 이동한다. 단어를 잘못 연결하는 새 회귀로 보지 않는다.
- 812×375 가로 화면 실제 영어 낱말/지도, 로컬 iframe812×375 한글 낱말·장면, iframe1024×768 영어 낱말 개요 확인. 브라우저 viewport/iframe 검수이며 실기기 검수와 다르다. 영어 cape 긴 자막을 가로 화면에서 발견 후 CSS 보완했으나 같은 cape의 수정 후 재생 화면은 재확보하지 못했다(공용 CSS 적용·빌드 확인).
- root output `interaction-sound-polish-20261017`에 `en-writing-g-finish.png`, `ko-scene-phone.png`, `en-meet-tablet.png` 저장. `en-scene-phone.png`/`en-scene-after.png`는 자동 전환 뒤 낱말 개요가 찍혔으므로 장면 증거로 쓰지 않는다. root/작업 폴더 output은 미추적·커밋 제외.

- 이전 [자유4종40타깃 운영 완주](20261017-adaptive-free-play.md#전체-완주재시작-적응-검수-진행)와 이번 대표 동작·공통 회귀의 증거를 구분한다. 새 버전 운영 배포/실기기/모든 단원 전수 검증은 하지 않았다.
