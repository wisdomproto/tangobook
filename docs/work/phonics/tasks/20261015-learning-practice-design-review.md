## 요청과 사용자 결정

전체 한영 활동의 배우기/놀며 익히기 분류, 어휘·장면 색칠, 숨은그림 찾기, 난이도와 홈 복습, 부모가 납득할 학습 흐름을 점검한다. 현재는 학습 설계 논의이며 새 적응형 시스템 구현 승인이 아니다.

- 사용자의 ‘틀린그림 찾기’는 **숨은그림 찾기**로 정정됐다.
- 난이도·랜덤 복습 제안은 숨은그림만이 아니라 모든 게임 대상이다. 홈 진입에서 배운 내용에 맞는 랜덤 문제를 만나는 방향을 검토한다.
- 일반 블록·낱말 쓰기는 정답을 보고 연습하는 **배우기**다. 색칠도 배우기에 포함하자는 사용자 방향이다.
- 챕터 핵심은 해당 글자/음절을 눌러 소리를 듣고 조합한 뒤, 타깃 낱말의 글자·소리·뜻(그림)을 연결하는 것이다. 타깃 낱말을 블록으로 만들고 써보는 경험을 중요하게 본다.
- **챕터 안 타깃 낱말의 무작위 추출은 허용된다.** 무작위 추출 자체가 문제라는 앞선 설명을 정정한다. 중복 추출로 특정 낱말을 계속 놓치는 문제와 출제 순서 랜덤은 별개다.
- 한 번 따라 했다고 ‘다 배움/숙달’로 체크하지 않는다. 활동 수행·도움받은 연습과 독립 해결의 근거를 구분한다.
- 아이는 선택 고민 없이 안내를 순서대로 따른다. 부모에게는 왜 이 순서인지, 무엇을 연습했고 무엇을 혼자 해냈는지 설명돼야 한다.

## 숨은그림과 난이도 점검

공개 일반 동화11권 표본은 모두 숨은그림1장, 고유 타깃2~6개였다(신데렐라5개). 전체 동화가 전부1장이라고 전수 확인한 것은 아니다. 각 표본의 장면 색칠2장은 다른 자산이다.

`hidden-object-data.ts`는 여러 적격 장면을 지원하되 진입마다1장만 뽑는다. 다시 하기는 같은 장면을 초기화한다. 같은 그림의 타깃/순서만 바꿔도 위치 기억은 남는다. 재방문이 많은 책·타깃2개뿐인 책부터 검수된 추가 장면을 검토할 수 있으나, 모든 동화2~3장 외부 배치 생성은 미승인·미실행이다.

`GameDifficulty` 타입만으로는 실제 난이도가 바뀌지 않는다. 활성 블록·쓰기·색칠·숨은그림 플레이어 다수는 값을 사용하지 않는다. 실제 문제 생성 변수를 구현해야 한다.

- 소리/그림 선택: 보기 수, 비슷한 소리/뜻, 힌트·본 제공 여부.
- 블록: 배운 조각 범위, 낱말 복잡도/길이, 지원 수준. 배우기에는 본을 제공한다.
- 숨은그림: 고유 타깃 수와 검수된 장면 풀. 타깃2개 장면을 수량만으로3난이도라고 부르지 않는다.
- 색칠: 조작 지원/영역 구성의 차이이며 문해력 점수로 환산하지 않는다. 기존99%채움을 설계 논의만으로 낮추지 않는다.
- 재시도 클릭만으로 자동 어려움 전환하지 않는다. 독립 성공/힌트·오답과 피로를 보고 유지·지원·다음 도전을 제안한다. 숫자 기준은 미확정이다.

## 제안하는 챕터 흐름 — 아직 구현·최종 순서 확정 전

**낱자·소리 → 해당 음절 눌러 듣기/조합 → 타깃 낱말의 뜻·소리·글자 만나기 → 본을 보며 블록 → 본을 보며 쓰기 → 관련 색칠 → 독립 놀이 → 나중 복습**.

- 타깃 낱말을 처음 소개할 때 그림과 발음·짧은 뜻을 함께 주어 무엇을 만드는지 알고 시작한다. 뜻 설명을 색칠까지 미루지 않는다.
- 처음엔 소리에 맞춰 글자/음절이 강조되고, 합치면 정상 폰트 낱말과 그림이 연결된다. 그림이 정답을 알려주는 배우기와 글자만 보고 뜻을 고르는 확인을 구분한다.
- 블록 전부→쓰기 전부를 무조건 긴 과제로 묶기보다 소수 타깃 묶음 안에서 같은 낱말의 블록→쓰기를 연결하는 안을 검토한다. 색칠은 관련 낱말을 다시 만나는 배우기/호흡 조절 역할이다. 모든 낱말의 긴 완전 색칠을 진도 잠금에 넣으면 과제 길이가 지배할 수 있어 분량은 검증해야 한다.
- 챕터 내 랜덤 순서는 유지 가능하다. 배우기 전체 경험을 보장하려면 무작위 **비복원 덱+대상별 수행 기록+이어하기**로 미경험 타깃이 먼저 나오도록 한다. 이미 한 낱말만 반복하고 다른 낱말은 빠지는 상황을 막는다. 자산/배운 조각 조건에 맞지 않는 타깃은 숨기기보다 저작 품질 문제로 확인한다.
- 독립 놀이에는 정답 글자를 숨기고 듣고 블록, 글자→그림/소리→글자 등 서로 다른 연결을 확인한다. 그림/정답 발음이 노출됐으면 해당 문항을 읽기 독립 근거로 취급하지 않는다. 힌트 후 정답/재시도를 별도로 둔다.
- 한글 모음 입문·영어 Book1에는 일반 낱말 블록을 임의로 강제하지 않는다. 음절 정방형 구성과 영어 소리-철자/블렌딩 차이를 보존한다. 이미 정한 누적 자음·기본 회전 모음 정책도 유지한다.
- 챕터 완료/다음 잠금 해제는 그 학습 묶음 수행의 표시다. 한 번 성공을 숙달로 선언하거나 장기 기억 확인까지 다음 진도를 막지 않는다. 새 필수 활동/과거 진도 호환은 구현 전 따로 설계한다.

## 아이 UX와 부모 설득

아이는 한 시작/이어하기와 자동 다음으로 진행한다. 상단은 짧은 활동 순서와 현재 위치만, 긴 학습 이론/난이도 선택/낱말 목록은 요구하지 않는다. 오류는 도움을 주며 다시 해보게 하고 쉬었다 오면 정확한 대상으로 이어간다.

부모에게는 ‘게임4개/완료100%’보다 다음을 보여주는 안이다.

- 오늘 목표: 이번 글자로 어떤 음절/낱말을 만나고 무엇을 해볼지.
- 수행: 직접 눌러 들음·블록 조합·본 보고 쓰기·색칠, 타깃별 누락 여부.
- 독립 관찰: 어느 연결을 힌트 없이 해결했는지, 첫 시도/힌트/재시도 구분.
- 다음 행동: 헷갈린 낱말을 다른 문제/다음 방문에 다시 만나도록 안내.

부모 문구 예시: ‘오늘 이 글자의 소리와 조합을 익히고, 낱말을 직접 만들고 써봤어요. 혼자 해결한 문제와 도움이 필요했던 문제는 따로 기록했어요.’ 예시 문구이며 실제 수치·성취 기록을 만들어내지 않는다. 부모가 매번 활동/순서를 편성할 필요가 없고, 원할 때 완료 활동을 골라 반복하는 기존 역할은 보존한다.

## 홈 복습·기록 후속 제안

홈에는 하나의 ‘오늘의 놀이’를 배운/준비된 후보에서 뽑아 명확한 실행 행동을 제공한다. 모든 게임 유형을 풀에 검토하되 한영/자녀/단원 맥락과 자산 준비를 유지한다. 진입 때 후보를 정하고 활동 시작 뒤에는 렌더마다 답이 바뀌지 않는다. 색칠/숨은그림 수행을 읽기 능력과 섞어 단일 점수로 만들지 않는다.

V2 학습 기록은 노출·참여·시도·근거를 이미 구분한다. 이 원칙을 재사용하고, 문제ID/타깃·지원 수준·첫 시도·힌트·연습 대상 범위를 일관되게 남기는 후속이 필요하다. 기존 관련 단원 추천은 실제 문항 난이도 자동조절 시스템이 아니다. 빠른 클릭·정답 위치 기억·부모 도움을 독립 읽기로 단정하지 않는다.
