## 구현·검증

- 현재 획이 dot일 때만44×44 CSS px 원형 버튼/점·맥동·톡!을 표시한다. 번호/짧은 화살표와 중복되지 않는다. body 성공 전에는 버튼이 없고, click 성공 뒤 사라져 중복 완료되지 않는다. 취소에는 click이 발생하지 않으며 컴포넌트 회귀에서도 pointer cancel 후 미완료를 확인했다. 기본 canvas20px 점 판정도 보존한다.
