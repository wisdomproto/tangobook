## 수정과 최종 경계

근본 원인은 느린 입력의 이동량을 체크포인트 증가분과 매번 min해서 버린 것이었다. 허용 경로 안의 실제 손 이동량을 누적하고 끝점16px 이내/짧은 획 길이28% 이내 여유를 둔다. 모든 획의 실제 이동거리62%와 끝점 근접·경로 이탈 제한을 유지하고, 아주 짧은 직선 획은 순방향 이동45%를 추가해 역방향/문지르기로 완료되지 않게 했다.

보완 후 한글40자는 정확한 경로와8px 흔들림 모의 입력 모두 성공, 각 획 픽셀 소유권 있음. 영어52자의 기존 system-ui 경로/픽셀 소유권·정확한 경로 모의 입력은 모두 성공. 기존 영어 paint UI를 새 추적기로 바꾼 것은 아니다. 미래 추적 방식으로 전환하면 i/j의 점을 swipe와 구분하는 처리가 필요하며, 특히1px i점에8px 흔들림을 준 실험은 실패다. 따라서 ‘92자 실제 새 쓰기 완주’로 보고하지 않는다.

실제 localhost:5187의ㅓ에서 약간 기울고 끝점에 못 미친 짧은 첫 획을 native drag로 입력해 다음 획1/2 표시·전체 첫 획 채움을 확인. 영어 en-b1-u01/letters-write의 A/a 두 캔버스·가이드·기존 면 채움 구조를 직접 확인했다. 기존127.0.0.1 learner 기록은 수정하지 않았다. 다른 모든 자모의 손 입력/실기기 검증은 미수행이며 글꼴·경로 전수 검사와 대표 UI 검수를 구분한다.
