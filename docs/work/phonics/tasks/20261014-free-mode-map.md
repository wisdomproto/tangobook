## 사용자 요청·현재 범위

커리큘럼 지도 적용 중 사용자가 자유모드가 시각적으로 동떨어져 있다고 반증했다. 비슷한 디자인 또는 같은 디자인의 열린 상태를 제안하고 다른 플랫폼 사례를 질문했다. 현재 요청에 답하기 위해 공식 안내를 조사했으며 자유모드 UI/잠금/활동 구성은 아직 변경하지 않았다.

## 공식 사례와 제안

- [Khan Kids Learning Path](https://khankids.zendesk.com/hc/en-us/articles/360048828572-Learn-more-about-the-Learning-Path): 큰 재생 버튼으로 안내 경로, 활동 수준/순서 자동 연결.
- [Khan Kids Library](https://khankids.zendesk.com/hc/en-us/articles/4403657703821-Find-books-and-lessons-in-the-Khan-Kids-Library): 글자/읽기 등 탭·활동 삽화에서 직접 선택, 수준 탐색.
- [Lingokids Sections](https://help.lingokids.com/hc/en-us/articles/23532720590610-What-Are-the-Sections): Play는 놀이 선택/즐겨찾기, Lessons는 구조화된 학습 경로. 공식 문서 확인이며 로그인 앱 직접 플레이 검증은 아니다.

탱고북 제안은 같은 세계관·배경·권 선택·글자 버튼 재질을 공유하고, 커리큘럼은 실제 현재·미래 잠금/한 CTA/자동 다음, 자유모드는 준비된 글자를 열린 상태로 탐색하고 개별 활동을 선택하는 것이다. 시각과 학습 규칙을 구분한다. 유료/데이터 미준비/게임 첫선택 관찰 등의 접근 조건까지 제거하는 뜻은 아니다. 자유모드의 기존 모음4·4·2 묶음/저작 링크와 커리큘럼 개별10챕터의 표시 차이는 실제 구현 전 결정해야 한다. 자유모드 완료를 현재처럼 공유하며 방문을 완료로 기록하지 않는다.

## 다음 행동

사용자 방향 합의 후 실제 자유모드 입구/단원 선택/활동 선택을 같은 테마로 재구성하고 PC·태블릿·가로폰에서 검수한다. 이번 커리큘럼 task와 구분하며 아직 구현 완료로 보고하지 않는다.
