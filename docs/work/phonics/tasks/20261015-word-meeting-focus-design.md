## 사용자 반증과 현재 결정

- 작은 왼쪽 그림 아래 낱말과 떨어진 아/기 조각은 맥락이 약하고 글자 그림 크기가 불균일하다. 구름 모양 다음 버튼도 철회한다.
- 전체 '아기'를 계속 보여주고 그 안에서 아→기를 강조해 배운다. 분리된 아/기 결과/작은 배지로 따로 보여주지 않는다.
- 후속: 그림을 위로 올린다. 한글은 위의 그림→큰 전체 낱말→현재 음절 강조/한 개 행동 버튼 순서로 중앙 정렬한다.
- 전체 낱말은 같은 글꼴/기준 크기/글자 칸을 사용한다. 합치기는 현재 자리에서 잉크가 차오르는 움직임과 부드러운 탄성·빛 궤적으로 표현한다. 단어가 사라지거나 멀리 날아갔다 다시 나타나게 하지 않는다.
- 기존 수동 누르기·실제 발음 종료·오류 재시도·엄격한 한글 누적/동일 낱말 블록-쓰기-색칠 연결은 보존한다. 영어는 rime-first/전체 발음 예외를 유지하며 공유 행동 버튼만 같은 형태를 쓴다.
- 새 그림 파일이 필요한 작업이 아니라 기존 삽화와 코드 기반 글자·동작·버튼 구성을 다듬는다. 원격 push는 이번 후속에 아직 요청되지 않았다.

- 1280×720/1024×768/812×375/568×320의 그림→전체 낱말→행동 버튼 배치와 뷰포트 내 경계 확인. 영어 cat의 PC/가로폰 배치도 확인했다. 물리 기기 검증은 아니다.
- 한글은 위치 인덱스로 음절을 강조해 반복 음절/받침의 같은 칸을 유지한다. 기본 glyph는 계속 표시하며 활성 글자 위 잉크·작은 빛·전체 낱말 호만 움직인다. reduced-motion은 글자를 유지하고 움직임만 끈다.
- 카메라 실물 인식/장치 권한 승인은 실행하지 않았다. 인식 코드/카메라 제약/형판을 변경하지 않았다. 빌드 결과는 아래 후속 기록 참조.

## 블록 진입 후속 — 사용자 최신 결정

선택 화면 없이 화면 블록으로 즉시 진입하고, 한영 공용 GameHeader 오른쪽에서 실물 블록↔화면 블록으로 전환한다. 명시적으로 선택한 launcher/동일 낱말 연결 run의 입력 방식은 유지한다. 기본 미지정 값은 screen이며 카메라는 enabled=false, 실제 전환 시만 enabled=true가 된다. Gate의 context로 헤더에 버튼을 전달해 떠 있는 별도 겹침 버튼을 만들지 않는다. 자식 player를 key로 재마운트하지 않아 진행 순서를 보존하며, 연결 run도 선택을 저장한다. 기존 문서의 게임 진입 전 선택/게임 안 전환 제외 결정을 이 요청으로 대체한다.

## 전체 낱말 + 자모 합성 복원 — 사용자 후속

사용자는 전체 아기를 계속 보여주면서 별도로 ㅇ+ㅏ→아, ㄱ+ㅣ→기의 자모 합성도 보여달라고 했다. 앞선 '분리 음절 결과 제외'를 '자모 조합까지 제외'로 확대한 해석을 바로잡는다. 전체 낱말/활성 음절은 고정한 채 아래 작은 합성 무대에서 기존 자모 WebP들이 모이고 동일 글꼴의 완성 음절로 이어진다. 실제 합성 결과 음원 종료 후 다음 활성 음절/조합으로 이동하며 매번 수동 누름은 유지한다. 강 등 받침은 가+ㅇ→강으로 합성 결과와 소리가 일치한다. 영어·진도·학습 기록·카메라 입력은 수정하지 않는다. 이번 후속 원격 push 미요청.

검증 진행: 아기 1/2단계의 full heading 동일 DOM/활성 음절/현재 조합 그룹/실제 오디오 종료 순서, 받침 조합/소리 일치, 영어 회귀와 연결 소유자 총20테스트 통과. client 타입 검사·변경 코드 lint 통과. 실제 5187 미리보기에서 전체 아기와 각 조합/버튼 표시·눌림 확인. 1024×768·888×870·568×320의 조합/버튼 경계를 확인했고 최종 client build도29.00초 성공했다. 빌드 뒤 Vite 재연결 문제는 이 작업의5187 프로세스만 재시작해 복구했다.

## 첫 진입에서 과제 이해 돕기 — 사용자 승인 후속

- 요청: 아이가 아무것도 누르기 전부터 무엇을 해야 하는지 이해하게 적용, 전체 아기는 계속 유지.
- 현재 첫 화면의 그림/전체 낱말→자모→버튼 나열만으로 관계와 행동을 추측해야 한다는 리뷰를 승인했다.
- 한글 낱말을 실제 녹음으로 소개한 뒤, 해당 첫 음절 소리와 기존 UI 언어별 `tap-sparkle` 안내를 연결한다. 전체 낱말은 고정하며 처음에는 모두 같은 색, 낱말 소개 종료 후 첫 음절을 강조하고 자모가 펼쳐진다. 실제 합성은 자동 실행하지 않는다.
- 안내는 새 음성을 대량 생성하거나 문장을 음절 concat하지 않는다. 실제 낱말/음절 음원과 이미 준비된 '반짝이는 곳을 눌러봐!' 안내를 재사용한다. 화면 문구는 '먼저 아를 만들어 볼까?'이며 오디오는 첫 음절명 뒤 공용 행동 안내다.
- 같은 한 버튼은 자동재생 거절 시 낱말 듣기로 재시도, 소개 후에는 합쳐보기/합성 아이콘/손가락·밝기 강조로 바뀐다. 자모는 조금 다가갔다 돌아오는 예고만 한다. 안내 중 아이가 합치기를 누르면 안내를 취소하고 바로 수행한다.
- 과제 의미/전체 낱말은 항상 유지하고 영어 기존 rime-first/수동 합성 및 저장 진도/연습 근거는 보존한다. 광고 embedded는 음성 소개를 생략한다. 원격 push/배포 미요청.
- 검증: 첫 진입/전체 낱말 동일 DOM/자동 합성 없음/자동재생 실패/동일 버튼 재시도/안내 중 조작/이탈 취소·한영 기존 음원/연결 소유자 총3파일23테스트, client 타입 검사·수정 코드 lint 통과. 실제 5187에서 자동재생 거절→낱말 듣기→아 강조/자모→합쳐보기→기 안내를 확인했다. 1024×768/568×320에서 문구·버튼·손가락이 뷰포트 안에 있음을 측정했다. 물리 아이 사용성 검증은 아니다. 최종 빌드/재연결은 아래 후속 기록 참조.
