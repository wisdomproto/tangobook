## 이전 설계 — 아래 사용자 최종 정정으로 대체

- 작은 왼쪽 그림 아래 낱말과 떨어진 아/기 조각은 맥락이 약하고 글자 그림 크기가 불균일하다. 구름 모양 다음 버튼도 철회한다.
- 전체 '아기'를 계속 보여주고 그 안에서 아→기를 강조해 배운다. 분리된 아/기 결과/작은 배지로 따로 보여주지 않는다.
- 후속: 그림을 위로 올린다. 한글은 위의 그림→큰 전체 낱말→현재 음절 강조/한 개 행동 버튼 순서로 중앙 정렬한다.
- 전체 낱말은 같은 글꼴/기준 크기/글자 칸을 사용한다. 합치기는 현재 자리에서 잉크가 차오르는 움직임과 부드러운 탄성·빛 궤적으로 표현한다. 단어가 사라지거나 멀리 날아갔다 다시 나타나게 하지 않는다.
- 기존 수동 누르기·실제 발음 종료·오류 재시도·엄격한 한글 누적/동일 낱말 블록-쓰기-색칠 연결은 보존한다. 영어는 rime-first/전체 발음 예외를 유지하며 공유 행동 버튼만 같은 형태를 쓴다.
- 새 그림 파일이 필요한 작업이 아니라 기존 삽화와 코드 기반 글자·동작·버튼 구성을 다듬는다. 원격 push는 이번 후속에 아직 요청되지 않았다.

## 끝까지 플레이한 아이 관점 후속 점검

사용자가 '다 해보고 검토까지'를 요청해 실제 처음→아→기→전체 낱말→동화 장면까지 진행했다. 다음을 추가 보완한다.

- 전체 낱말 단계에서 비워진 자모 무대 때문에 행동 버튼만 아래에 멀리 남았다. 글자/그림 위치는 유지하고 마지막 듣기/다음/진행점만 단어 가까이 올린다. 문구는 '이제 아기, 함께 읽어볼까?'로 바꾼다.
- 사람 아기 삽화 뒤에 큰 뱀이 등장하는 아기 까치 장면이 무작위로 나왔다. 아기라는 첫 뜻 연결에는 적합하지 않다. 이 낱말 만나기는 의미가 다른 아기 동물 문맥을 제외하고, 아기는 우선 해당 단원에서 실제 같은 아기 그림이 나오는 쪽으로 연결한다. kr-h1-u02의4쪽 삽화를 직접 보아 니들펠트 사람 아기/아기 글자/따뜻한 상황을 확인했다. 공용 다른 게임의 장면 정책·운영 책 데이터는 변경하지 않는다.
- 문맥 맞지 않는 외부 장면/음원 없음은 같은 단원의 유효한 본문·삽화·동일 언어 음원 쪽을 찾고, 없으면 완료로 넘어간다. 아기 동물→사람 뜻 불일치와 장면 종료 전 완료 금지를 회귀에 추가했다.
- 원문 음원/그림을 재사용하고 최종25회귀·client 타입/lint 통과. 최종빌드 후 다시 처음부터 플레이·장면/실제 블록 진입을 확인하고 마무리한다. 미리보기는 기록을 쓰지 않고 완료 후 처음으로 돌아오는 검수 화면이며 실제 연결 진도와 구분한다.

최종 실제 완주 재검수: 최종 production build23.68초/타입/lint 성공 뒤5187만 재시작했다. 새 미리보기에서 자동재생 차단→동일 버튼으로 낱말 소개→첫 안내 종료→ㅇ+ㅏ→아→ㄱ+ㅣ→기→전체 아기 발음→니들펠트 사람 아기/아기 글자 장면을 실제 확인했다. 장면 음원 완료 뒤 미리보기 첫 화면으로 돌아오는 것도 확인했다. 실제 학습 URL은 저장된 동일 아기의 화면 블록/ㄱ·ㅇ·고정 모음/실물 전환 버튼을 확인했으며, 연결 소유자의 실제 onComplete 전후 같은 낱말 단계 기록은25회귀가 검증한다. 블록 쓰기·색칠의 모든 입력을 새로 완주하거나 실제 유아 대상으로 시험한 것은 아니다.

## 사용자 최종 정정 — 위 낱말/중복 무대/음성 안내 제거

- 미리보기에서 공용 헤더가 없다는 반증을 확인했다. 기존 ActivityShell에 선택적 header 대체 슬롯을 추가하고 한영 WordMeeting에서 블록과 같은 GameHeader를 사용한다. 기본 뒤로가기와 이중 표시하지 않으며 다른 파닉스 셸은 기존 그대로다.
- 실제 연결 소유자와 개발 미리보기 모두 WordLearningProgress를 재사용한다. 뒤로가기/현재 단계/다시 해보기/홈의 위치·아이콘·44px 터치 기준을 맞춘다. 미리보기 뒤로는 빈 브라우저 history 대신 해당 챕터로 이동한다.
- 사용자 선택은 '챕터 낱말 목록 → 현재 낱말 강조'. 현재 run의 엄격 누적 타깃 목록/그림을 보여주고 지금 배울 낱말에 테두리/색/태그를 준다. 한 시작 버튼 후 조합을 시작하며, 아직 모르는 전체 낱말을 갑자기 읽거나 별도 상단 낱말을 중복하지 않는다. 영어8타깃은2행 축소로 현재 단어가 아래 잘리지 않게 보정했다.
- 다시 해보기는 현재 WordMeeting을 재마운트하고 같은 타깃 소개로 돌아간다. 이미 저장된 챕터/블록·쓰기·색칠 단계나 연습/독립 성취는 초기화하지 않는다. 이전 재생·타이머는 이탈 시 취소한다.
