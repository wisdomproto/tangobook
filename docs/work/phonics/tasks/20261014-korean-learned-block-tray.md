## 사용자 결정·범위

후속 사용자 정정: 모음은10개 독립 선택지가 아니라 **ㅣ·ㅏ·ㅑ 세 물리 조각만 표시하고 회전 가능**해야 한다. 아래 최초 구현/검수는 수정 전 기록이다. 기본10모음은 문제 필터의 사용 가능 범위로 유지하며, 자음 누적 선택지만 고정한다.

ㄱ 블록게임 자음 선택지는 ㄱ만, ㄴ은 ㄱ/ㄴ 등 현재 기본 자음 단원까지의 학습 순서를 누적한다. 기본 모음10개는 모두 표시한다. 모음 단원에 블록게임을 새로 넣지 않는다. 커리큘럼/자유모드 모두 단원 순서 기준이며 프로필 완료 이력에 종속시키지 않는다. 영어/동화/받침/쌍자음/복합모음 기존 구성을 이번 요청으로 바꾸지 않는다.

## 구현

- 기존 물리 조각16개는 ㄴ을 ㄱ의180도, 기본모음10개를3개 조각의 회전으로 만든다. 단순 base ID 필터로 ㄴ/모음10개를 표시할 수 없어, 학습 트레이만 정확한 글자·회전 대응을 명시적으로 전달한다. 동일 ID의 ㄱ/ㄴ·모음이 모두 선택되거나 표정/선택 글자가 같이 바뀌지 않게 학습 선택지는 각 orientation을 유지한다. 판 위 조각의 기존 회전/합성·인식 치수는 보존한다.
- ㄱ 단원 운영 타겟 고기/가구/아기/야구 중 뒤 둘은 아직 안 배운ㅇ이 필요하다. 선택지가 없는 문제를 내지 않도록 이 블록게임에만 배운 자음/기본 모음으로 만들 수 있는 낱말을 sample 전에 거른다. 낱말 듣기/쓰기/짝 등 다른 활동과 운영 책/R2는 수정하지 않는다. ㄴ은 나/너/누나를 유지하고 누구야는 이후 범위다.
- 기본14단원 순서·기본모음10개·실제 piece rotation 매핑, 제한 없는 기존 caller 보존·불가능 문제 제외 회귀와 실제 ㄱ/ㄴ/마지막/동화 트레이를 검증한다. 기존 쓰기 테스트 줄바꿈·미추적 출력/자산은 보존한다.
