## 요청과 완료 조건

한글·영어를 선택한 안에서 커리큘럼/자유모드를 실제로 연결한다. 공통 홈의 구조와 기존 버튼 디자인을 유지하며 순서대로 진행·다음 활동·이어하기가 실제 완료 기록으로 작동해야 한다.

## 범위와 판단

- 공통 홈은 유지한다. 한글/영어 진입에서 커리큘럼과 자유모드를 선택한다.
- 커리큘럼은 기존 완료 기록의 첫 미완료 활동부터 시작하며 단원·복습을 순서대로 연결한다. 미래 단계 잠금은 커리큘럼에만 적용한다.
- 자유모드와 커리큘럼은 아이·언어별 기존 완료 기록을 공유한다. 기존 URL과 모음 4·4·2 그룹을 보존한다.
- 모음은 익히기 다음 소리 고르기 게임을 커리큘럼 단계에 포함한다. 기존 필수 활동/부모 리포트 정의는 변경하지 않는다.
- 미준비 이미지에 의존하는 선택 게임을 강제로 필수화하지 않는다. 기존 정오답 게임·복습을 활용한다.
- 게임 첫 선택과 재시도를 구분해서 기록한다. 시안의 임의 통과 점수로 숙달을 판정하지 않는다.
- 영어 여러 글자 익히기는 모든 대상 글자를 실제로 익혀야 완료한다.
- 운영 데이터 배치 수정, 새 이미지 생성, 원격 main push는 이번 요청 범위에 없다.

## 결정과 진행

- 최초 CTA는 경로 화면을 한 번 더 거치지 않고 현재 활동으로 직접 이동한다. 경로 보기 링크를 별도로 둔다.
- 안내 학습 시작은 자녀·언어별 별도 표식으로 저장한다. 첫 활동을 중단해도 이어하기를 표시하며 시작/방문을 활동 완료로 세지 않는다.
- 과정 지도는 현재 권만 먼저 펼치며 완료한 단계는 다시 학습하고 미래 미완료 단계는 잠근다. 자유모드에는 이 잠금을 적용하지 않는다.
- 영어 알파벳의 기존 한 글자/탭 완료를 전체 대상 글자 완료로 수정했다. 음원 누락/실패 시 완료하지 않고 재시도를 안내한다. 글자 전환 시 직전 그림의 완료 칸 수가 새 글자로 이어지는 현상도 제거했다.
- 결과 화면이 있는 활동은 컴포넌트를 바로 닫지 않는다. 완료 기록 뒤 공통 셸의 다음 버튼으로 이동하므로 마지막 소리/연출을 유지한다.
- 관찰 기록은 활동별 최신 소리 고르기 게임의 첫 선택과 재시도를 저장하며 자녀/언어가 분리된다. 모음 소리 게임과 기존 한영 단원 judge 이벤트에 firstAttempt를 추가한다. 모든 게임의 독립 선택/힌트 측정이 완성됐다고 보고하지 않는다.
