## 사용자 반증과 요청

사용자는 여행1~5를 모두 한 화면에 노출하고 설명/진도를 여기저기 배치한 구성이 첫 한글을 배우는 아이에게 복잡하다고 반증했다. 아이에게 지금 할 활동 정도만 보여주는 단순한 구성을 요청했다. 이어 다른 플랫폼의 구성을 물었다. 기존 세계관 자산 제작 요청을 취소한 것이 아니라 기본 화면의 정보량/역할을 교정한 것이다.

## 공식 사례 재확인 — 2026-10-13

- [토도영어 공식 소개](https://www.todoclassroom.com/todoenglish/intro): 정해진 하루 학습 분량의 데일리 코스와 활동 종류를 선택하는 프리초이스가 분리된다.

## 적용 판단

후속 사용자가 ‘오늘 할 학습은 한 챕터 정도만 노출, 모두 마치면 다음 챕터 잠금 해제 애니메이션 후 넘어감’, ‘ㅏ·ㅑ·ㅓ·ㅕ는 각각 따로’로 구체화했다. 한영 기본 화면에는 현재 챕터의 글자와 짧은 활동 순서만 노출한다. 전체 여행/전체 진도/게임 기록과 재학습 지도는 별도 학습 정보에서 연다.

한글 커리큘럼 Book1은 기존 `kr-v1-u01~u10`의 모음 하나당 한 챕터다. 자유모드의4·4·2는 탐색 묶음/옛 링크 호환으로 보존하고 커리큘럼은 열 글자를 하나씩 연결한다. 듣기→쓰기, 두 번째 모음부터 이전 실제로 들은 모음과 소리 고르기 놀이를 넣는다. 놀이 풀은 이전+현재의 실제 듣기 완료만 사용하며 최대4개다. 묶음 진도의 정확한 글자별 듣기/쓰기만 양방향으로 읽고 새 개별 퀴즈 완료/성적을 만들어내지 않는다. 저작/R2 source는 기존 kr-h1-u01 유지.

챕터 마지막 실제 완료 뒤 인접한 다음 챕터가 처음 열릴 때만 짧은 잠금 해제 연출을 한다. 재학습/뒤로가기/방문만으로 연출/완료를 만들지 않는다. 연출 뒤 다음 챕터 화면을 보여주며 활동 자동 재생은 하지 않는다. reduced-motion을 존중하고 완료 query를 소비해서 새로고침으로 연출을 반복하지 않는다. 기존 세계관 자산을 재사용한다.
