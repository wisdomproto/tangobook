## 우선 수정할 문제

### 1. 자유 낱말 활동이 한 낱말에서 반복됨

**실제 재현**

1. 한글 자유 지도 → 2권 ㄱ → 낱말 만나기. 아기/야구/가구/고기 목록과 `1/4`가 보인다.
2. 아기 시작 → 첫 음절 시연 → ㄱ+ㅣ 직접 합치기 → 다음으로 → 장면 연결 종료 후 지도 복귀.
3. 낱말 만나기 재진입 → 다시 아기 `1/4`. 다음 낱말 선택 UI도 없다.
4. 영어 자유 지도 → Book 3 첫 챕터 → 낱말 만나기. tape `1/8` 시작 → a+p, ap+e, t+ape를 실제 눌러 완성 → 다음으로 → 지도 복귀 → 재진입해도 tape `1/8`.

**원인**: ConnectedWordLearningActivity의 practiceStage는 본 순차 run의 index를 그대로 사용한다. 단독 활동 성공 시 완료 ledger만 기록하고 onBack으로 나가며 다음 index를 저장하지 않는다. 본 run이 정지해 있으면 재진입도 같은 낱말이다. 공통 구현이라 블록·쓰기·색칠에도 같은 구조가 적용되지만, 이번에 그 세 가지를 끝까지 입력해 재현한 것은 아니다.

**권고**: 자유 단독 활동은 선택한 종류를 유지한 채 챕터 낱말을 차례로 연습하도록 별도 진행을 제공한다. 단독 낱말 순서/이어하기와 본 커리큘럼 순차 cursor를 분리하고, 본 활동 완료/잠금 해제를 만들어내지 않는다. 모두 마친 뒤 지도 복귀, 도중 지도 나가기 보존. `1/N`의 의미와 실제 동작을 일치시키는 것이 우선이다. 아직 구현·승인된 새 동작으로 간주하지 않는다.

### 2. 연습한 잠금 활동이 초록색으로 표시됨

위 한글 자유 아기 만나기 완료 뒤 커리큘럼 → 2권 ㄱ 미리보기에서 `낱말 만나기 1/4` 행이 초록색인데 자물쇠가 있고 비활성이다. 앞 ㄱ 배우기 등은 아직 미완료다. 개별 연습 근거를 보존하는 데이터 처리는 타당하지만, 사용자는 초록색을 완료/재생 가능으로 읽기 쉽다.

**권고**: 행의 바탕·재생/잠금은 커리큘럼 접근 상태를 우선해 완료 초록 / 현재 과정색 / 잠금 회색으로 유지한다. 별도 연습 근거는 `연습 1/4` 같은 작은 보조 표시로만 구분한다. 연습을 했다는 이유로 미래 활동을 열거나 완료 체크로 바꾸지 않는다. 실제 허용 상태를 바꾸지 않는 표시 보완이 필요하다.

## 디자인·명칭 후속 판단

- 모드 선택은 제목·한 줄 안내·한 카드 전체 클릭으로 정리되어 성인이 이해하기 쉽다. 다만 두 그림이 모두 비슷한 빈 숲이라 비문해 아동에게 선택 의미를 설명하지 못한다. 커리큘럼은 글자 단계가 이어진 길, 자유모드는 블록/연필/그림 놀이를 담는 식으로 기존 세계관 안에서 구별하는 편이 낫다. 이번에 새 그림을 생성하거나 확정하지 않았다.
- 영어 Book 1 목록의 `ABC 써보기`와 `글자 쓰기`는 역할 차이가 이름만으로 약하다. 전자는 단원 알파벳 대소문자 쓰기, 후자는 타깃 낱말의 첫 소문자 쓰기(traceWord)다. Book 1에 전체 낱말 받아쓰기를 도입하거나 기존 교육 예외를 바꾸지 말고 명칭/맥락을 구별할 후속 대상으로 둔다.

## 유지할 구조·실제 확인

- 홈의 한글/영어 큰 카드와 각 언어 이어하기가 별도 목적을 갖는다. 자유 활동을 여러 번 방문·완료해도 홈 한글 이어하기는 실제 커리큘럼 ㅑ, 영어는 미완료 ABC 학습을 가리켰다.
- 모드 선택 → 커리큘럼/자유 지도의 진입은 정상. 다른 권 미리보기 후 `지금 배울 곳으로` 실제 클릭 시 1권 현재 ㅑ/해당 활동 목록으로 복귀했다. 지도 탐색이 실제 이어할 권을 바꾸지 않았다.
- 낱말 만나기의 한글 같은 줄 합성, 영어 단계별 수동 합성/다음 행동은 이번 실제 입력에서 진행됐다. 한국어 장면의 다음 버튼이 관찰 사이 자동 종료되어 클릭 대상이 사라졌는데, 새 상태에서 정상 지도 복귀를 확인했다. 클릭 실패를 학습 실패로 오인하지 않았다.
- PC 1280×720의 홈/모드/지도/한영 낱말을 확인했다. 영어 낱말 시작/활동 목록은 가로 휴대폰 viewport 844×390에서도 확인했으며, 현재 활동 강조·목록 내부 스크롤·학습 본문을 덮는 목록 표시가 유지됐다. 이 두 번째 검토에서 태블릿이나 물리 기기 검수를 다시 수행한 것은 아니다.
- 이전 검토의 전체 230회귀·타입·빌드 결과를 이번 새 실행 결과로 재사용해 보고하지 않는다. 이번은 제품 코드 무변경이라 새 테스트/빌드는 실행하지 않았다. 문서 경로·diff를 확인했다.
