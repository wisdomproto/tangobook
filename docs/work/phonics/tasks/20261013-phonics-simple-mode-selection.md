# 한영 모드 입구 단순화

## 사용자 결정

한글 모드 선택 화면의 긴 설명·현재 활동·이어하기·별도 학습 경로 링크를 제거하고 커리큘럼 모드 / 자유모드 두 버튼만 남긴다. 한글·영어 공유 입구에 적용한다. 언어 내부 분기는 유지하고 학습 홈은 변경하지 않는다.

## 구현

- 과정 제목·홈 이동·동일 크기의 전체 클릭 가능한 생성 이미지 버튼 두 링크만 표시한다. 커리큘럼은 학습 경로로, 자유모드는 기존 최근 단원/첫 단원 활동 선택으로 이동한다.
- 두 모드 이름은5 UI 언어 번역을 사용하며 한글 코랄·영어 민트 토큰을 유지한다.
- 높이500px 이하 가로 화면에서는 제목과 홈 이동을 한 줄에 두고 버튼을 축소한다. 모바일 하단 메뉴 위에서 전체 그림이 보이도록 별도로192px 너비를 적용한다. 새 게임 엔진은 없다.
- 완료 기록·잠금 해제·학습 경로의 현재 챕터 이어하기는 변경하지 않는다. 입구를 방문하는 것만으로 진도를 기록하지 않는다.

## 검증

15개 기존 회귀·client 타입·범위 ESLint·5언어 키 파리티·최종 Vite build 통과. 기존 Browserslist/locale import/lottie eval/큰 chunk warning 유지. 실제 한영 경로/자유모드 클릭과568×320·812×375 가로 화면, 최종 데스크톱 캡처를 검수했다. 자녀 진도는 수정하지 않았다. 기존 자유모드의 첫 링크는 kr-v1-u01이며 과정 화면에서 호환 처리된다. 테스트 작성 시 g01로 가정했던 기대값을 실제 기존 링크로 바로잡았다.

## 사용자 후속 정정: 버튼도 생성 이미지

사각형 CSS 버튼은 다시 거절됐으며 실제 이미지 제작을 요청했다. imagegen 스킬을 적용하고 로컬 Qwen8188/8190 연결 실패를 확인한 뒤 내장 image_gen 전환을 알렸다. 징검다리/책 코랄 버튼과 블록/별/연필 민트 버튼2개를 제작했다. 이름은 DOM이며 두 색은 모드 구분, 과정 제목/메뉴는 기존 언어색이다. 투명 WebP2장114360bytes, hover/누름 transform·reduced-motion 지원. [자산·정확한 프롬프트](../../../../packages/client/public/images/phonics/mode-buttons-v1/README.md). 이미지 원본/인코딩 SHA와 alpha를 확인했으며 생성 자산2개와 실제 배치도 육안 검수했다.
