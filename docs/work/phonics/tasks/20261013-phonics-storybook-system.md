# 한영 파닉스 손그림 디자인 통일

사용자는 모드 입구 v2의 얇은 손그림 간판·종이 리본·집 홈 아이콘을 승인하고 전체적으로 같은 분위기로 가며 영어와 다른 페이지도 확인하도록 요청했다. 한영 학습 경로·자유모드·실제 활동·파닉스 게임의 공통 화면을 점검하고 적용한다. 공용 홈/동화 탐색의 어울림도 살핀다. 저작/부모 운영 도구에는 일괄 적용하지 않는다.

## 확인한 불일치

- 한영 모드 입구는 이미 v2공유다.
- 실제 전체 경로에는 둥근 두꺼운 v1 stage/CTA/아이콘이 남아 있다.
- 자유모드 헤더/단원 hero/활동 카드는 일반 패널과 텍스트 버튼이다.
- ActivityShell·파닉스 GamePlayerLayout의 뒤로가기도 텍스트/흰 알약이 혼재한다.
- 귀여운 자모 그림/정확한 쓰기 폰트·캔버스·오디오·진도/잠금·부모 관찰은 기존 계약을 보존한다.

## 진행

기존 v2리본·간판과 공유 컴포넌트부터 재사용한다. 전체 경로용 얇은 프레임/CTA·손그림 도구 아이콘을 제작해 공통 atlas metadata로 연결한다. 학습 대상은 DOM/기존 그림이며 장식은 투명 WebP·CSS만 사용한다. 새 엔진과 상시 애니메이션은 추가하지 않는다.

사용자 후속 승인으로 동화책 페이지·모든 독후활동/게임까지 범위를 확장했다. 공통 원본은 [플랫폼 작업](../../platform/tasks/20261013-storybook-learning-ui.md)으로 연결한다.

## 최종 상태 (2026-10-14)

나무 간판은 후속 사용자 반증으로 제외하고 구름 행동/별도 제목 띠로 전환했다. 제목 앞 중복 가/Aa 제거·모드 중앙 정렬·짧은 가로 자유모드/활동·홈 보완까지 완료. 검증과 실제 화면 범위의 원본은 위 플랫폼 task다. 그림자모/음원/획순/쓰기마스크/진도/잠금은 유지한다. 로컬 main 통합 준비, 이번 push 미요청.
