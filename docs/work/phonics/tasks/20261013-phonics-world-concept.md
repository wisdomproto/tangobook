## 요청과 완료 조건

한글·영어 플랫폼의 게임 스테이지형 커리큘럼을 조사하고, 탱고북 전체 학습 UI/UX를 유아 친화적으로 구성한다. 후속 사용자는 디자인 컨셉을 잡기 전에 세계관을 먼저 만들어야 한다고 지시했다. 세계관과 진행 정책의 최종 승인은 아직 없다.

## 읽은 기억과 변경 범위

PLATFORM.md, 디자인 시스템, 파닉스 BRIEF/MEMORY, 모음 묶음 task, 과정 화면 시각 개편 task, 실제 한영 StudyPage/CurriculumNavigation을 확인했다. 조사·방향 검토이며 코드·진도·잠금 정책은 수정하지 않았다.

## 사용자 반증·진행

- 기존 모음 화면 캡처에 대해 사용자는 “익히기와 게임으로 나누었던 콘텐츠 구조를 모음에도 적용할까”가 원래 질문이었다고 설명했다. 현재 네 모음 선택과 개별 듣기·쓰기 중심 화면은 익히기를 묶은 것으로 느껴지고, 아래 잠긴 놀이 영역은 같은 단원의 게임 축으로 충분히 드러나지 않는다. 이는 기능 미구현 주장과 구분하는 UI 구성 반증이다.
- 사용자는 전체 유아 친화적 UI/UX 구성을 요청한 뒤 세계관이 있어야 디자인 컨셉이 정해진다고 지시했다. 화면 시안 제작보다 세계관·시각 규칙 검토를 먼저 진행한다.
- 추가 ㄱ단원 캡처에 대해 사용자는 “첫눈에 이상하다”, “아이가 본다고 생각해봐. 물론 엄마가 눌러주겠지만”, “엄마가 봐도 이상하다”고 반증했다. 귀여운 자산 유무보다 첫눈에 배우는 내용·활동 의미·시작 순서가 전달되는지가 기준이다. 캡처에서는 배우기/합성/낱말연습에 비슷한 ㄱ 이미지가 반복되고, 한글 블록게임에 영어 블록이 섞이며, 9개 카드의 비슷한 비중과 작은 학습 대상이 구분을 어렵게 한다. 실제 게임 콘텐츠 오류로 단정한 것이 아니라 카드 미리보기의 의미 불일치 관찰이다.
- 다음 시안은 아이의 큰 학습 대상·현재 할 행동·짧은 완료 흐름과 부모의 학습 순서 이해를 함께 다룬다. 세계관은 이 활동의 역할을 설명하는 공통 배경으로 쓰며, 장소 이름만 바꾸거나 배경 장식만 더하는 개편으로 끝내지 않는다.
- 제안 후보는 글자 학습에서 이야기 읽기까지 연결되는 ‘탱고북 이야기 마을’. 글자를 익히고 블록으로 조합하고 종이에 쓰면 마을의 작은 이야기가 채워진다는 방향이다. 한영은 같은 세계 안에서 코랄/민트 표지를 유지하며, 교육용 실제 글자·쓰기는 명료하게 보존한다. 이 후보는 사용자 승인 전 제안이며 PLATFORM 정책으로 확정하지 않는다.
- 과정 지도/단원 익히기·놀이/완료 후 다음 길 열림을 같은 세계 안의 행동으로 연결할 필요가 있다. 잠금 해제의 필수 활동 범위, 쓰기 준비가 다른 아이의 진입, 부모의 단원 선택과 기존 완료 기록은 별도 설계 사항이다.

## 후속 검토 — 따라가기와 자유 선택

사용자 추가 요청: “순서대로 시키는대로 하는 모드랑 자유모드를 좀 나눠볼까”, 순차 모드에서는 익히기를 하나씩 끝내면 다음 익히기 활동을 제시하여 선택에 고민하지 않게 한다. 이번 기회에 전체 구조를 검토한다. 모드 분리는 검토 요청이며 필수 완료·잠금·세계관의 세부 정책 확정은 아니다.

### 확인한 현재 동작

- 한영 StudyPage는 단원 목록과 활동 선택을 기본으로 제공한다. 영어 `handleComplete`는 기록 뒤 단원으로 돌아간다. 한글 모음은 `onNext`로 인접 익히기 활동을 연결하지만 전체 한영 과정에 걸친 순차 여정은 없다.
- 기존 활동 완료 기록은 자녀별 활동 ID로 보존된다. 자유 선택과 순차 진행을 서로 다른 진도나 별도 콘텐츠 사본으로 만들 이유는 없다. 방문한 마지막 단원과 실제 완료한 다음 활동은 구분해야 한다.

### 설계 초안 — 사용자 승인 전

1. **진입 — 후속 정정 반영**: 학습 홈에서 한글/영어를 선택한 뒤 **각 언어 안에서** 커리큘럼과 자유모드로 나눈다. `/library` 첫 화면을 두 모드로 나누는 안은 사용자가 명시적으로 정정했다. 각 언어의 커리큘럼 입구는 처음에는 ‘학습 시작하기’, 기록이 생기면 ‘이어서 학습하기’로 안내한다. 재방문은 마지막 방문 단원보다 실제 진행 중인 활동을 복구한다.
2. **따라가기**: 커리큘럼의 활동 순서에서 현재 활동 하나를 크게 제시한다. 부모가 시작을 누른 뒤 아이는 화면 안내를 따라간다. 완료 피드백 뒤 ‘다음으로’ 하나로 이어지고 매 활동마다 단원 선택 화면으로 돌아가지 않는다. 자동 재생은 오디오 잠금·사용자 제스처 조건과 함께 검토하며 강제로 넘겨 다시 듣기를 막지 않는다.
3. **짧은 종료 지점**: Book 전체를 끝없이 재생하지 않고 소수의 익히기와 배운 내용의 놀이로 작은 여정을 마친다. 모음 예시는 ㅏ 익히기/쓰기 → ㅑ 익히기/쓰기 → ㅏ·ㅑ 놀이 → 마무리. 이후 ㅓ·ㅕ로 이어지는 구성이 가능하다. 정확한 활동 수·쓰기 필수 여부·게임 종류와 완료 기준은 후속 검토한다.
4. **익히기·놀이의 관계**: 단계별 소개와 복습 놀이가 하나의 여정 안에서 교차한다. 익히기 카드를 묶은 뒤 별도 아래 영역에 모든 게임을 모으는 방식만으로 끝내지 않는다. 익힌 글자만 사용하는 현재 모음 놀이 원칙은 새 합의 전 유지한다.
5. **자유 선택**: 준비된 제공 범위 안에서 단원/익히기/놀이/동화를 고르고 이미 한 활동도 반복한다. 선택한 단원에서는 ‘익히기’와 ‘놀이’를 선명하게 구분하고, 그림은 실제 할 행동을 보여준다. 완료 기록은 따라가기와 공유하며 자유 선택으로 완료한 활동을 순차 모드에서 불필요하게 강제 반복하지 않는다. 신규 단계 잠금을 자유 선택 전체에 일괄 적용하지 않는다.
6. **과정 지도**: 지도는 현재 위치와 다음 목표·완료 구간을 알려준다. 스테이지의 기본 단위는 아이가 한 번에 할 짧은 활동/여정으로 검토한다. 권/단원은 부모가 전체 교육 구성을 읽을 수 있는 보조 구조다. 지도 전체를 매 활동 사이에 보여주지 않고 짧은 여정 종료에 변화가 드러나게 한다. 모바일 세로/태블릿 가로는 동일한 진행 의미를 다른 배치로 표현한다.
7. **세계관**: 이야기 마을은 후보 상태다. 따라가기는 마을의 길을 따라 글자를 만나고 낱말·이야기를 만드는 모험, 자유 선택은 그 마을을 둘러보는 경험으로 연결할 수 있다. 장소나 캐릭터를 읽을 줄 알아야만 탐색 가능한 설계는 피한다. 한영은 같은 시각 규칙과 코랄/민트 표지를 공유하고 교육 순서는 각각 유지한다.
8. **동화·교구**: 자유 독서는 계속 접근 가능하게 두고, 순차 여정에서는 실제 배운 수준에 맞는 짧은 이야기로 연결하는 방식을 별도 검토한다. 모든 책을 스테이지로 잠그거나 교구가 없는 아이에게 실물 활동을 강제하지 않는다. 이용 가능한 블록/종이 활동의 위치와 대체 흐름을 부모 설정에서 다룬다.
9. **부모 역할**: 과정/시작 위치·아이별 진도·교구 준비·중단 복구를 간결하게 제공한다. 쓰기 보류/단원 건너뛰기가 필요하면 실제 완료와 보류를 분리하여 기록한다. 활동을 끝낸 사실을 습득 인증으로 표시하지 않는다. 기존 진도를 리셋하거나 모드를 바꿀 때 잃지 않는다.
10. **디자인 기준**: 한 화면의 주 행동 하나, 큰 학습 대상, 그림+짧은 음성 안내, 행동과 일치하는 미리보기, 짧은 완료 연출·안정된 조작 위치. 따라가기에서는 활동 목록·전체 사이드바가 학습판을 차지하지 않게 한다. 세계관 미술 자산과 상시 연출 규모는 웹 속도·오디오 명료함을 기준으로 정한다.

### 후속 검토 순서

모드의 역할·짧은 학습 흐름 → 여정 완료/다음 단계 정책·부모 선택 → 세계관과 미술/사운드 규칙 → 홈/지도/활동/종료/자유 선택의 연결 시안 → 한영 대표 과정·중단/재방문·기존 진도 검증 순으로 진행한다. 이번 기록에서는 제품 코드를 변경하지 않았다.

## 연결 시안과 사용자 결정 — 2026-10-13

사용자가 시안 제작을 지시한 뒤 다음 기준을 추가했다.

- 안내를 따라 하기만 해도 한글·영어 파닉스 전 과정을 배우도록 설계한다. 단원 선택·매번 활동 목록으로 복귀하는 부담을 줄인다. 실제 습득이나 학습 효과를 보장하는 문구로 바꾸지 않는다.
- 실력 확인은 게임으로 한다. 활동 완료 여부, 처음 독립적으로 고른 답, 힌트/재시도 이후의 성공을 구분한다. 반복 클릭·클릭 속도·게임 끝내기를 실력 점수로 삼지 않는다. 배운 소리 구별 → 글자 조합 → 낱말 적용의 결과를 교육 단계에 맞게 기록하고, 어려운 내용은 다시 만나는 방향이다.
- 커리큘럼/자유모드의 분기 위치는 **한글 내부와 영어 내부**다. 사용자의 “처음부터”를 플랫폼 첫 화면으로 해석했던 것은 잘못이며 “아예 첫 화면을 얘기한 건 아니고”라는 최종 정정을 따른다. 공통 홈·동화책 입구를 모드 선택 화면으로 대체하지 않는다.
- ‘이어서 학습하기’는 각 언어의 커리큘럼 진도가 있으므로 자연스럽다. 언어별 이어 할 위치는 독립, 두 모드의 같은 활동 기록은 공유한다.

### 시안 범위

저장소 재개 원본: [story-journey.html](../previews/story-journey.html). HTML fragment이며 visualize의 `scripts/render.py`로 감싸 브라우저 검수한다. 대화 표시용 사본은 `C:/Users/kil21/.codex/visualizations/2026/10/11/01a12b90-4491-7c02-b97d-b867f6ec4b02/tangobook-story-journey.html`이다. 제품 라우트에 연결하지 않았다.

- 한글 ㅏ·ㅑ 다음 ㅓ·ㅕ, 영어 A·B 다음 C·D의 두 짧은 산책만 구현한 흐름 예시다. 기존 Book1의 4·4·2 교육 묶음을 두 개씩인 새 단원으로 변경한 것이 아니다. 영어 실제 발음 수업이나 전체 한영 교육과정 구현도 아니다.
- 승인한 그림 모음을 재사용하고 세 친구를 순서대로 눌러 듣는 익히기를 유지한다. 쓰기에는 폰트/종이 칸을 사용한다. 새 이미지 생성 없이 정적 배경과 클릭 시 짧은 탄성으로 구성했다.
- 시안 전용 상태만 저장한다. 실제 자녀 데이터·기존 완료 ID·음원·채점·접근 권한·서버에 연결하지 않는다. 쓰기 넣기/보류는 부모 설정 위치 검토용이며 실제 쓰기 필수 정책을 변경하지 않았다.
- 놀이의 3문항과 첫 선택 2개 정답 기준은 다음 길/다시 만나기 두 분기를 보여주기 위한 예시 값이다. 교육적 통과 기준으로 채택하지 않는다. 실서비스에서는 단원별 확인할 능력·충분한 문항과 우연 정답·힌트·누적 결과·복습 정책을 따로 설계해야 한다.
- 브라우저 합성 음성은 임시 안내다. 누른 횟수로 다음 버튼을 보여주며 실제 재생 ended 검증을 대체하지 않는다. 캔버스는 흐름 확인용 자유 선 그리기이고 실서비스의 쓰기 채점과 다르다.

사용자의 최종 언어 내부 분기를 기준으로 시안의 진입·중단/재방문·놀이/복습 흐름을 검토한다. 다음에는 실제 한영 커리큘럼의 활동 ID를 짧은 여정에 매핑하고 기존 진도를 보존하는 진행 모델, 게임 문항별 평가 기록, 부모의 시작 위치/보류 정책을 설계한다. 세계관 미술 상세·통과 기준은 아직 미합의다. 전체 과정을 새로 제작했다거나 실제 앱에 적용했다고 보고하지 않는다.

### 시안 검증 결과

- JavaScript 구문 검사와 fragment 크기/형식 확인. 이미지 포함 약140KB, 허용 CDN 폰트 외 API 호출 없음.
- 브라우저에서 한글 ㅏ 완료→이어서 학습하기→ㅑ, 첫 선택 1개 오답을 재시도 후 성공해도 기록2/3 유지→다음 산책ㅓ 해제·진입을 확인했다. 최종 세 그림 순차 누르기에서도 ㅓ 완료→ㅕ를 확인했다.
- 영어 첫 선택이 세 번 모두 오답이면 수정 후 게임을 마쳐도0/3 유지, 다음 산책이 잠기고 다시 놀이로 진입한다. 지도는 게임 수행 완료와 다음 길 기준 충족을 구분해 현재 복습할 노드를 표시한다.
- 자유모드의 영어 C 듣기 완료가 같은 언어 활동에 재방문 기록으로 나타나고, 커리큘럼 이어 하기는 미통과한 A·B 놀이로 돌아간다. 앞 산책 재방문·한영 독립 진도·부모의 쓰기 설정/기록도 확인했다.
- 1024px 입구·지도와375px 입구/듣기 화면을 육안 확인했다.320px에서 세 듣기 버튼, 게임 선택지와 부모 화면의 가로 맞춤을 DOM 경계로 확인했고 모드 카드 그림/라벨 겹침을 수정했다. 마지막 브라우저 콘솔 오류 없음.
- 실제 음원 청취·캔버스 채점·전체 교육과정·실제 자녀 저장·실기기 FPS·교육적 평가 정확도는 검증하지 않았다. 문서/시안 변경이므로 제품 전체 테스트·빌드는 실행하지 않았다.
