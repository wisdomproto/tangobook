## 발견·우선순위

- **P1 짧은 가로 복습 쓰기**: 영어 en-b1-r1/review-write,812×375에서 종이 하단이 화면 밖으로 내려가고 세로 scrollbar가 생긴다. 제목/진행·그림/캔버스를 가로 높이에 맞게 재배치해야 한다. 회색 글자·쓰기 마스크/99% 판정은 디자인 수정과 구분한다. 다른 쓰기 전체가 같은 문제라고 아직 단정하지 않는다.
- **P1 영어 그림짝 가로 내부 넘침**: en-b1-u01/game-line-matching,812×375의 Aa/Bb/Cc 아래 낱말 캡션이 카드 하단에 걸리고 cap은 화면 아래에 걸친다. 그림은 과도하게 작고 글자/캡션이 공간을 차지한다. 한글 일반1280화면도 큰 폰트 대 작은 삽화로 비율이 약하다.
- **P2 행동 버튼·도구 일관성**: 한영 블록 `다음`은 일반 코랄 Button이며 영어 과정 민트와 다르다. 긴 하단 안내/이모지 실물 블록/되돌리기·초기화가 여전히 앱 도구 형태다. 블록 자음·모음/ABC의 실제 조작 기호를 생성 장식으로 바꾸라는 뜻은 아니다.
- **P2 듣기·쓰기 역할 표현**: 듣기 제목은 이모지 헤드폰+코랄 글자라 영어 mint 보기와 섞인다. 일반 낱말 쓰기는 작은 그림·큰 안내·큰 빈 간격, 그리기는 흐린 원본·목표99% 텍스트만으로 어디를 칠하는지 직관성이 약하다. 영어 복습 쓰기의 ❓는 `ReviewWriteActivity`의 소리 문제 fallback이며 새 누락 삽화로 단정하지 않는다. 더 적합한 듣기 도구 표현이 필요하다.
- **유지할 표현**: 뒤집기 카드의 씨앗/입체 종이 느낌·누르면 그림으로 바뀌는 반응, 글자 사냥의 구분된 민트/코랄 목표·선택 카드, 학습자의 정확한 글자 폰트는 현재 역할이 잘 맞는다. 전부 같은 구름으로 덮지 않는다.
