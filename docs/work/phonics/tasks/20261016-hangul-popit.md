## 요청과 완료 조건

사용자가 공유한 슈퍼파닉스한글 ㅈ 팝잇 영상의 누르는 감각을 참고해 ㅏ·ㄱ·ㅇ 먼저 실제 누르기 활동에 적용한다. 방울마다 즉시 눌림/뽁 소리, 획을 따르는 다음 방울 안내, 전체 완성/발음→기존 쓰기 흐름을 직접 검수한다. 다른 자모/영어 및 숙달 판정은 확대하지 않는다.

## 결정과 진행

- 기존 단일 글자5회 음원 종료 충전과 쓰기3회 기록을 확인했다. 새 표본은 서로 다른 방울 모두 누르기로 대체하고, 음원을 기다리는 동안 매번 터치가 막히지 않게 한다. 같은 방울 연타는 진도를 늘리지 않는다.
- 정확한 자모 형태와 반응형 터치 영역을 위해 SVG 글자 바탕+실제 HTML 버튼/CSS 입체 방울을 사용한다. 고정 bitmap/새 게임 엔진 없이 기존 풍경·탐색 셸을 공유한다. 첫/최종 발음은 겹치지 않고 최종 발음 성공 전에는 완료하지 않는다.
- ㅏ·ㄱ5방울, ㅇ8방울. 모음 민트/자음 살구를 보존하고 다음 방울만 탄성 안내한다. ㅇ은 기존 쓰기 경로와 같은 위→왼쪽 반시계 방향이다. 순서 강요/오답은 없으며 전체 서로 다른 방울 조작만 센다.
- 방울을 누르면 즉시 오목한 홈/작은 반짝임으로 바뀐다. 자체 합성95ms mono WAV4,232byte의 뽁 소리는 기존 playUi 음소거/풀을 공유하며 첫/최종 발음과 분리한다. 전체 완성 때 방울이 매끈한 글자로 바뀌고 체크/칭찬 종료 뒤 기존 완료 콜백을 한 번만 호출한다. 쓰기 키·3회 쓰기·숙달 판정은 바꾸지 않는다.
- 새로 귀여운 그림을 굽는 것보다 SVG로 정확한 형태/사이즈를 유지하는 표본이다. 상시 새 엔진·대형 이미지·외부 생성 호출을 추가하지 않는다. 기존 다른 자모/영어5회 충전과 묶음 모음 퀴즈는 보존한다.

## 검증

- 실제 localhost5187 자유모드에서 ㅏ5/ㄱ5/ㅇ8방울을 native 클릭으로 모두 완료하고 발음/칭찬 종료 후 각각 write-1/letter-write로 자동 연결됨을 확인했다. 기존127.0.0.1 사용자 탭/진도를 초기화하거나 완료 콜백을 주입하지 않았다. 현재 ㅏ는 다시 열어2방울 눌린 상태로 제공한다.
- 실제 앱 iframe 콘텐츠의 innerWidth/innerHeight를 확인하며 PC1280×720/태블릿1024×768/가로폰844×390/작은568×320 ×3자모=12배치 검사. 화면 밖/방울 hitbox 겹침/가로 넘침0, 최종 최소 hitbox47.86px. 실기기 손가락/FPS 측정과 구분한다.
