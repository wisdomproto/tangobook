## 사용자 결정

일반 블록 놀이와 낱말 쓰기는 한글·영어 모두 익히기(사용자 표현 배우기)에 둔다. 듣기 연습은 기존 놀며 익히기 묶음에 추가한다. 처음 제안한 듣고 낱말 쓰기/글자 선택 따라쓰기는 사용자 최종 반증으로 취소했다. 윤곽을 따라 쓰는 방식은 받아쓰기 평가가 아니므로 **듣고 블록 놀이만** 제공한다. 힌트는 첫 글자 하나다.

## 구현 경계

- 기존 block 활동이 있는 단원에만 별도 -listen key의 선택 활동을 파생한다. 영어 Book1 알파벳/현재 모음 단원에 블록을 새로 넣지 않는다. 원본 source plan·기존 key/order/required/진도는 보존, 추가 활동 required=false다. 필수 커리큘럼에 새 평가를 강제하지 않는다.
- 한영 기존 player/tray/회전/화면·실물 입력 선택을 재사용한다. 블록 인식기/카메라 알고리즘은 변경하지 않는다. 일반 모드는 기존 자동 정답/판 소리 읽기/다음 동작 그대로다.
- 듣기 모드는 정답 글자와 그림/alt를 숨긴다. 소리 듣기 음성이 성공적으로 끝난 뒤 판을 활성화하고 직접 확인으로 채점한다. 틀려도 전체 정답을 보여주지 않으며 재시도한다. 맞추기 전 다음/결과 건너뛰기를 막고, 정답 후 기존 소리·칭찬·다음 문제 흐름을 사용한다.
- 힌트는 첫 한글 음절 또는 영어 알파벳 1개만 표시한다. 새 문제(같은 낱말 반복 포함)에서 초기화한다. 늦게 끝난 음원 조회/재생 callback은 세대 토큰으로 무효화하고 재생 실패는 듣기 완료로 취급하지 않는다.
- 첫 시도·오답 재시도·힌트 사용을 관찰 기록과 선택 event metadata로 구분한다. 일반 game logger는 듣기 모드에서 중복 송신하지 않는다. 부모 관찰은 힌트 없이 첫 시도/힌트 문항 수로 표시하며 활동 완료와 숙달 판정을 동일시하지 않는다. 기존 힌트 없는 기록과 호환된다. 힌트만 누르고 제출하지 않은 경우 관찰은 저장하지 않는다.
- 기존 TTS URL이 있으면 즉시 재생하고 없을 때 기존 resolver를 사용한다. 신규 이미지/게임 엔진/패키지는 추가하지 않는다. 지원5 UI 언어 번역을 포함한다.
