## 결정과 진행

노출·직접 연습·능력별 근거·관련 파닉스 이력을 구분한다. 독후활동에서 타깃 어휘의 미학습 여부를 확인해 선택 안내하고 원래 활동으로 복귀한다. 읽기 도중 파닉스로 이동시키는 주 흐름은 채택하지 않는다. 부모 조회 대상과 활동 중인 아이는 분리한다.

현재 기록의 누락·중복·잘림·조회 실패와 단원 방문≠완료를 먼저 해결한다. 원장 보존, V1 adapter, eventId outbox/ACK, profile 귀속, 능력별 투영과 수치 일치, 보상 중복 방지 후 모바일 리포트와 활동 안내를 붙인다.

게스트 최근7일 기기 보관+가입 후 남은 기록 누적은 권장 검토안이다. 사용자가 확정한 보관 기간은 아직 없다. 첫 이용7일 후 전부 삭제와 콘텐츠 체험 만료를 구분한다. TTL 이후 ‘미학습’ 단정도 금지. 알림은 화면 안내 설계이며 실제 푸시·메일·자동화 생성 없음.

기존 .html 브랜딩 파일은 수정하지 않았다. 별도 시안은 기획 검토용 가상 아이·기록을 명시한다. 실제 기능 주소 대신 후속 연결 자리임을 알려준다.

## 검증

운영 /parent/reports는 로그인으로 이동해 실제 자녀 리포트 육안 검수 불가. 기존 화면은 코드 분석으로 판단했다. Browser 스킬을 사용해 새 시안을 localhost의 정적 파일 서버로 열었다. 이 시안은 이전 file URL에서 거부된 브랜딩 문서를 우회해 연 것이 아니다.

320/360/390/430/768/1280px iframe viewport와 실제 콘텐츠 가로 넘침 없음을 확인했다. 모바일 기본과 상세 패널 screenshot 확인 후 제목 줄바꿈/숫자 크기를 수정했다. 검색·언어·조회 대상·필터·상세 열기/닫기·조회 실패/재시도·기록 없음 확인. 이미지 decode·ID·링크·node --check 통과.

실제 DB 현재 schema/trigger, 게스트 업로드/이벤트 중복/학습 상태/보상 기능 검증은 미수행. 제품 테스트를 실행했다거나 실제 리포트 기능이 완성됐다고 보고하지 않는다.

### 유지할 방향

- 목표는 아이의 첫 언어 떼기. 부모는 학습의 근거, 아이는 재미를 경험한다. 아이가 먼저 찾고 반복하는 이용이 자기주도 학습으로 이어지는 것이 핵심이다.
- 설명은 첫 언어 학습의 필요 → 한글·영어 파닉스와 동화 구성 → 공통 어휘 연결 → 독후활동 기획과 각 활동 → 아날로그 제품 → 글로벌 플랫폼 순서다. 콘텐츠 설명 앞부분에는 수익 얘기를 넣지 않는다.
- 독후활동은 블록 맞춰보기·써보기·색칠하기 등이다. 디지털/아날로그/연계는 활동의 구현 방식이다. 제품명은 탱고 한글 블록·탱고 영어 블록·탱고 노트.
- 역방향 연결은 동화 → 독후활동 → 관심 어휘의 관련 파닉스 → 원래 활동 복귀다. 읽기 중 파닉스 이동을 주 경로로 삼지 않는다.
- 아이×학습 언어×어휘 기준으로 노출·직접 연습·능력별 근거·파닉스 이력을 구분한다. 처음 만난 타깃 어휘 안내도 기록 범위/조회 실패를 고려한다. 노출이나 색칠 완료를 읽기 습득으로 단정하지 않는다.
- 학습 리포트는 핵심 마케팅 가치다. 요약 → 어휘별 근거 → 다음 놀이로 읽기 쉽게 구성하고 모바일을 우선한다.
- 브랜드는 이야기와 놀이로 스스로 배우는 글로벌 K-에듀 플랫폼으로 넓게, 첫 유입 메시지는 좁게 검증한다. 동남아를 우선 고려한다. 한국에서 검증한 모델의 확장은 목표이며 모든 나라에서 성공한다는 보장으로 표현하지 않는다.
- 지금은 온라인 무료 체험 유입·체류·재방문이 우선이다. 플레이탱고/교원탱고 당시 영상 성공은 사용자 운영 경험이며 탱고북의 현재 성과와 구분한다.

### 다음 세션에서 함께 결정할 것

- 학습 상태 문구·능력별 판정 기준·데이터 부족 표시와 파일럿 검증. 객관적 근거 없는 전체 학습도 %나 습득 보장은 피한다.
