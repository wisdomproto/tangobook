## 진행과 검증

핵심 수집·어휘 근거·모바일 리포트 구현 및 로컬 검증 완료. main에 통합하고 사용자 요청으로 원격 main에 푸시했다. 운영 schema/실데이터 검증은 별도이며 운영 배포 결과는 아래 전달 기록을 따른다.

### 구현한 동작

- 로그인 기록도 전송 전 로컬 outbox에 보관. 이벤트 UUID를 재시도에 유지하고 upsert ignoreDuplicates 사용. 서버 ACK 이후 해당 묶음 ID만 삭제하고 업로드 중 들어온 새 기록은 보존한다. 지원 브라우저에서는 Web Locks로 탭 간 읽기/쓰기 충돌을 조정한다. 서버 저장 확인과 조회 갱신 사이에도 최근 ACK 기록을 메모리에서 유지한다.
- 게스트 묶음 기록 누락 해결. 이관 전 ID·대상 아이를 고정하고 100개 단위로 ACK 후 삭제. 형제가 여러 명이면 부모 리포트에서 실제 이용한 아이를 골라 가져온다. 저장 공간을 못 쓰면 메모리 임시 기록과 부모 안내를 사용한다. 기존 2,000건 상한은 유지하며 7일 TTL은 적용하지 않는다.
- 서버 기록은 500개씩 timestamp+ID cursor로 조회. 50,000건 안전 상한에서 부분 이력 안내. 조회 실패를 빈 배열/정확한 0으로 바꾸지 않는다.
- 어휘별 노출/직접 연습/활동 근거/날짜/파닉스 직접 연습을 별도 집계. 단어 이벤트와 보조 음절 이벤트를 중복 시도로 세지 않고 영어 대소문자와 NFC를 정규화한다. 과거 첫 시도 조건이 없으면 이전 방식의 기록으로 표시한다. 언어를 알 수 없는 과거 이력은 제외 안내한다.
- 한글·영어 블록과 따라쓰기는 낱말별 결과를 기록하여 게임 전체 중도 종료 전 완료한 낱말도 남긴다. 받침을 보존하고 쓰기 완료를 읽기 성공으로 평가하지 않는다. 공통 게임 컨텍스트에서 동화/어휘/파닉스 출처를 구분한다.
- 한글·영어 파닉스의 실제 필수 활동 완료 기록으로 단원 완료 판단. 단원 방문만으로 완료 표시하지 않는다. 활동 완료 ID는 아이/단원/활동 기준의 실행 중 반복 호출에 유지한다. 기기 진척·최근 단원을 활동 중인 아이별 저장 키로 분리하고 이전 공용 진척을 임의로 자녀에게 배분하지 않는다.
- 뷰어 기록은 아이/책/언어/페이지로 중복 진입을 판단. 베트남어·중국어·태국어를 한글로 기록하지 않으며 번역 없는 낱말을 다른 언어로 치환하지 않는다. 마지막 낱말 보기의 표시 언어·낱말과 기록을 맞춘다.
- `/parent/reports` 기본은 학습 한눈에: 기간 요약 → 다음 놀이 → 누적 낱말 검색/필터 → 어휘 상세. 조회 대상 아이 변경은 활동 프로필을 변경하지 않는다. 서버 오류/로딩/부분 기록/빈 결과/기기 저장 한계/미전송 기록을 구분한다. 상세는 native dialog, 배경 스크롤 잠금·닫기·포커스 복귀·safe-area 지원.
- 독후활동 게임을 마친 뒤 실제 연습한 관련 타깃 낱말을 제안. 로그인 이력 조회가 완료되지 않으면 부정 판정을 하지 않는다. 선택 시 같은 활동 화면 위에서 기존 파닉스 활동을 실행하고 활동 완료/나가기 시 독후활동 목록으로 복귀한다. 읽기 중 이동이나 진행 중인 게임의 정확한 라운드 재개 기능은 아니다. 접근 게이트를 유지하고 잠김/조회 실패 때 플레이어 실행을 차단한다.
- 새 UI 문구 한국어/영어/베트남어/중국어/태국어 추가. `VITE_LEARNING_REPORT_V2=false`로 새 요약/추천 진입을 끌 수 있다. 수집 정확성 개선은 유지된다.

### 남은 확장과 운영 검증

1. 운영 Supabase 실제 RLS/trigger와 event ID 재전송 시 보상/집계 멱등성을 별도 검증한다. 이번 작업은 저장 SQL 읽기·mock API·로컬 UI 검증이며 운영 테이블/원장 변경 없음.
2. 지금은 원장을 읽는 클라이언트 집계다. 대량 lifetime 서버 projection/RPC, 전체 활동 계측 registry, 평가 기준/파일럿은 후속이다. 50,000건 초과를 정확한 전체 이력으로 표현하지 않는다.
3. 현재 연결은 커리큘럼 sampleWords 기반이다. 실제 발행 단원 targetWords 인덱스/운영 데이터와의 전수 일치, 짧은 낱말 지정 놀이, 진행 중 게임 라운드 복귀를 확장할 수 있다.
4. 게스트 기간/알림과 리포트 상태 판정 기준은 사용자와 별도 확정한다. 기존 누락/공용 기기 진척의 자녀 귀속을 추정 backfill하지 않는다.
5. 전체 게임이 낱말별 계측을 마쳤다고 보고하지 않는다. 색칠 등 기록이 없는 활동의 참여를 읽기/음가 성취로 생성하지 않는다. 다음 계측 범위는 실제 표시/행동을 확인하여 추가한다.
