## 결정과 진행

사용자 확정: 신데렐라 소재, 쇼츠 형식, 기획부터 진행. 선택형 질문에 “자정·유리 구두 중심의 긴장감 있는 예고편”이라고 답변했다.
미확정: 세부 컷 구성, 길이, 언어, 타깃, 사용할 책/그림체, 후속 제작 방식.
사용자 답변에 따라 아래 후보 중 “자정의 약속” 방향으로 상세 기획을 제시한다. 다른 후보는 답변 전 검토한 대안이며 추가 선택을 요구하지 않는다.

아래 후보와 초수는 검토안이며, 선택한 방향 이외의 세부사항은 확정된 제작 브리프가 아니다.

| 후보 | 표현 방식 | 첫 장면/훅 |
|---|---|---|
| 자정의 약속 | 경고 → 마법과 무도회 → 종소리 → 남겨진 구두. 사건 중심 예고편 | “밤 열두 시가 되면 모든 마법이 풀린단다.” |
| 나도 가고 싶어 | 혼자 남은 소녀의 얼굴에서 시작해 황금빛 무도회로 확장 | “나도 무도회에 가고 싶어…” |
| 마법을 찾아봐 | 아이가 그림 속 호박·옷·구두의 변화를 찾도록 유도 | “호박이 무엇으로 변했을까요?” |
| 남겨진 한 짝 | 구두를 단서로 계단 → 무도회 → 변신을 거슬러 가는 역순 구성 | “이 구두의 주인은 어디로 갔을까요?” |
| 마법의 사용 설명서 | 준비물(호박)·변신·주의사항(자정)을 짧은 카드로 구성 | “이 마법에는 사용 시간이 있습니다.” |

추천 초안: 자정의 약속. 원문 8·10·11쪽의 경고, 종소리, 구두가 짧은 영상의 사건을 만든다. 교훈 설명보다 장면과 감정으로 책을 경험하게 한다. 성과 우위를 검증했다는 의미는 아니다.

한 줄 목적(제안): 아이와 볼 동화를 찾는 보호자에게 / 짧게 콘텐츠를 둘러보는 순간 / 신데렐라의 마법과 자정의 긴장감을 보여주고 / 탱고북에서 해당 책을 읽게 한다.

## 추천안의 임시 구성

한국어, 세로 9:16, 약 30초 제안. 시간은 실제 기존 TTS 길이에 맞춰 조정한다.

| 시간 | 장면 | 자막·음성 방향 |
|---|---|---|
| 0–3초 | 8쪽 경고 장면. 시계는 실제 삽화에 있으면 활용 | “밤 열두 시가 되면…” / 화면 안에 신데렐라 제목 식별 |
| 3–7초 | 4쪽 외로운 모습 → 5쪽 요정 등장 | “난 입고 갈 드레스도 없는걸.” 기존 대사 발췌 후보 |
| 7–13초 | 6쪽 마차 → 7쪽 드레스/구두 | “와아! 정말 꿈만 같아요!” 기존 음성 후보. 2–3초마다 시점 변화 |
| 13–18초 | 9쪽 무도회 → 10쪽 종소리 | 음악을 잠시 줄이고 종소리로 전환 |
| 18–24초 | 10–11쪽 서둘러 떠나는 장면과 구두 | “앗, 저는 이만 가야 해요, 왕자님!” 기존 대사 발췌 후보 |
| 24–27초 | 11쪽 구두에 시선 고정 | “남겨진 유리 구두 한 짝.” 화면용 편집 문구 |
| 27–30초 | 동일 그림체 표지 + 탱고북 | “신데렐라, 탱고북에서 함께 읽어요.” 화면 CTA 한 번 |

한 권·한 그림체를 유지한다. 기존 페이지 삽화를 카메라 이동·부분 확대·빛으로 연출하는 안이며, 인물의 실제 걷기/춤추기 애니메이션이 준비됐다고 가정하지 않는다. 본문 삽화가 미확인이라 구두 클로즈업 등 구체적 크롭의 가능성은 제작 전 검증한다. 음성은 기존 TTS 우선이며 새 내레이션을 전제하지 않는다.

## 다음 행동

선택한 자정·유리 구두 예고편의 세부 기획에 대한 사용자 반응을 반영한다. 제작 단계에서는 실제 책의 동일 그림체 페이지와 기존 음성을 대조해 컷별 이미지·대사·초수를 확정한다. 과거 쇼츠 중단 기록과 별개로 이번 요청은 단일 영상의 기획이며 자동 발행 재개로 해석하지 않는다.
