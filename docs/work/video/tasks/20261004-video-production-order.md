# 영상 제작 순서 확정

- delivery: 제작 순서·한영 범위·작품별 컨펌·명작 그림체 변형 규칙 기록

사용자 “이거 영상만들 컨텐츠 순서를 만들자. 일단 한글/영어만 하면 됨. 하나씩 만들고 나한테 컨펌 받으면 됨.” 순서는 명작동화 → 전래동화 → 자연관찰 → 호리 생활동화 → 호리 탈것 → 호리 유치원. 명작은 각 책 한 그림체로 먼저 모두 만든 뒤 나레이션 등 다른 구성은 같게 유지하고 그림체만 변경한 추가 버전을 만든다.

원본 정책은 [PRODUCTION-QUEUE](../PRODUCTION-QUEUE.md). 현재 라푼젤 제작을 이어가되 다음 책 착수는 라푼젤 완성본 컨펌 뒤에 한다. 기존 승인 신데렐라/백설공주/인어공주는 진행 위치에 포함했다. 세부 남은 제목/권수는 확인되지 않은 값을 추정하지 않았다. 운영 등록/외부 게시/새 main push 권한을 확대하지 않았다.

문서 링크·경로·diff 검증 후 관련 문서만 로컬 커밋. 영상 제작은 이 계획 작성과 별도이며 라푼젤 task는 active를 유지한다.
