## 언어와 확인 단위

당분간 한국어·영어만 제작한다. 한 책 × 한 그림체를 한 작업 단위로 두고 한국어 롱폼·숏폼, 영어 롱폼·숏폼 네 편을 검수해 사용자에게 보여준다. 현재 기준은 가로16:9 롱폼2~3분, 세로9:16 숏폼, 큰 overlay 자막과 별도 SRT/나레이션/언어별 clean master다. 작품의 실제 내용에 맞는 길이로 구성한다.

진행 상태는 대기 → 제작 중 → 자체 검수 → 사용자 컨펌 대기 → 수정 또는 승인이다. 현재 작품에 대한 사용자 승인 뒤 다음 작품을 시작한다. 여러 작품을 동시에 생성하거나 전체를 무인 배치로 제작하지 않는다. 컨펌 전 다음 작품을 시작하지 않는다. 완성본을 실제로 보여준 뒤 확인을 요청하고, 착수 전에 매번 승인 질문을 반복하지 않는다.

작품 승인과 운영 등록·main push·외부 채널 발행은 각각 기록한다. 영상 컨펌만으로 외부 채널 게시를 수행하지 않는다. 이미 받은 해당 작품의 등록/push 요청은 다시 묻지 않는다.

## 명작동화의 그림체 추가 규칙

먼저 책마다 대표 그림체 하나로 기본 버전을 완성한다. 한 작품의 모든 그림체를 연달아 만들며 다른 명작을 뒤로 미루지 않는다. 기본 버전의 범위가 끝난 뒤 그림체 추가 제작으로 넘어간다.

추가 버전은 승인된 KO/EN 대본, 실제 나레이션 음원, 자막 텍스트·타이밍·크기, 음악·효과음과 믹스, 장면 순서·컷 시점, 화면 비율·해상도·전체 길이를 고정한다. 바뀌는 것은 그림체에 해당하는 이미지·영상 표현뿐이다. 나레이션을 새로 생성하거나 이야기·음악·편집을 바꾸지 않는다. 각 언어의 독립 타임라인을 그대로 재사용하며 KO 길이로 EN을 덮지 않는다.

승인 기준본의 음원/SRT/음악·편집 manifest SHA를 버전 기준으로 기록한다. 새 그림체는 기존 등장인물의 정체성과 행동·구도를 유지하고 해당 그림체 참조로 새 이미지/동작을 만든다. 필요한 길이를 원속도로 생성하고 기준 컷 길이에 맞게 자른다. 반복·감속·시간 보간·끝 정지로 길이를 맞추지 않는다. 스타일 변형도 인원·손·팔다리·그림체/자막 가독성을 별도로 검수해 컨펌받는다.

Editor2의 책 모델은 한 책=한 그림체·한 레벨을 유지한다. 그림체 추가는 해당 책 레코드의 영상 자료로 관리하고 기존 승인 나레이션/자막 URL을 재사용할 수 있다. 과거 styleAssets/레벨 사본 모델을 재도입하지 않는다.
