# 유료 변신 D-day 시나리오 (Monetization D-day)

> 무료 획득 → 유료 전환 단계 설계. "동화 무료 뿌리기로 초기 유저+입소문 → 콘텐츠(학습) 완성 시점에 유료 전환".
> 실제 콘텐츠 인벤토리에 근거 (출처: `phase0-asset-cleanup-design.md`, `phase1-learning-system-design.md`, `한글숲친구들_영어_컨셉.md`).
> 전제: **목표 시장 = 동남아. 한국 = 브랜드 원산지 + proof lab** (수익 센터 X).

---

## 0. 핵심 원칙 (이전 논의에서 확정)

1. **학습은 MVP가 안 된다** — 반쪽 파닉스 = "엄마들이 안 산다". 유료 전환 시점엔 **완결된 학습 루프**여야 함.
2. **가격표가 곧 포지셔닝** — Day 1부터 $4.9 부착. "공짜 동화 앱"이 아니라 "프리미엄 학습 플랫폼을 공짜로 쓰는 중"으로 인식 → 천장 열어둠.
3. **분리·순차화** — 동화(약한 수익화/강한 획득) = 공짜 미끼. 학습(강한 수익화/완결 필수) = 완성 후 유료.
4. **공짜 날짜는 락인 0** — 아이 진도·별·호리·어휘 히스토리로 스위칭코스트를 쌓아야 전환 때 안 증발.
5. **목표는 "유저"가 아니라 "나중에 살 유저"** — vanity metric 경계.

## 1. 콘텐츠 준비도 = "언제 팔 수 있나"의 기준

| Tier | 내용 | 상태 | 역할 |
|------|------|------|------|
| **T0 — 획득용** | 동화 노출 트랙(명작·생활·자연·전래 ~80권) + 핵심단어 보기(8개) + 어휘 match 게임 | ✅ **지금 가능** | 무료 미끼. "재미 + 가벼운 어휘 노출" |
| **T1 — D-day 게이트** | 파닉스 **1개 언어 완결**(영어 5권 = 게임까지) + 어휘 트랙 풀(trace/block/write ON) + 부모 진도 리포트 + 파닉스 어휘를 덮는 동화 커버리지 | 🟡 **제작 필요** (설계 완료) | **유료 전환의 명분.** 완결된 학습 = $4.9 값 |
| **T2 — 확장** | 자연관찰 정확성 검증 완료 + 전래(각국) + 2번째 언어 파닉스 + 레벨 추가 | 🔴 후순위 | 리텐션 심화 + SEA 현지화 |

**임계경로(critical path) to D-day = T1**:
1. 영어 파닉스 5권 **제작 + 게임 메커니즘** (현재 보류 → 해제·완성)
2. 어휘 게임 trace/block/write **enable** (코드 존재, flag만)
3. 부모 진도 리포트 (파닉스/어휘 탭 — 일부 존재, 완성)
4. 파닉스 단어 ↔ 동화 **커버리지 80%** (T0 동화로 상당수 충족, 갭만 보강)

> ⚠️ "300권 다 만들기"는 D-day 게이트가 **아님**. 게이트는 "1개 완결 학습 루프가 진짜 팔리는가". 300권은 T2 목적지.

## 2. 단계별 타임라인

### Phase A — 획득 (한국, NOW → D-day)
- **오퍼**: T0(동화 + 핵심단어 + 어휘 match). 학습은 "오픈 예정"으로 명시.
- **가격/메커니즘**: $4.9/월 가격표 노출 · 7일 무료 체험 · **친구 초대 = +7일** (단 **상한/taper** — 아래 §3).
- **포지셔닝**: "한국에서 만든 프리미엄 동화·학습 플랫폼 (파닉스·어휘 곧)". *동화관 아님.*
- **목표**: ① 한국 proof(유저·후기·"K-플랫폼" 크레딧) ② 모델 검증(레퍼럴 k-factor·리텐션·지불의사 신호) ③ 입소문.
- **병행 제작**: T1 임계경로 (파닉스 5권+게임, 어휘 풀, 리포트, 커버리지).
- **락인 적립**: 별·호리·진도·어휘 히스토리 = 떠날 때 잃는 "파일".
- **유통 엔진**: SEO(about 페이지) · OG 초대 이미지(`og-invite.png`) · 맘카페/카톡 레퍼럴. *(이 인프라는 이미 구축됨)*

### D-day — 유료 변신 (T1 완성 시점)
- **콘텐츠 게이트**: ✅ 파닉스 1언어 완결(게임 포함) + ✅ 어휘 트랙 풀 + ✅ 진도 리포트 + ✅ 커버리지 80%.
- **시장 게이트**: 레퍼럴 k-factor·리텐션이 루프 작동 입증 + 인용 가능한 한국 proof 베이스.
- **액션**: 무한/관대 레퍼럴 종료 → 표준 7일 체험 + $4.9 유료. **기존 무료 유저 = 그랜드파더링**(§4).
- **동시 착수**: 검증된 모델 + K-브랜드를 **SEA 비치헤드**로 현지화 시작.

### Phase B — SEA 확장 (post-D-day)
- 검증된 T1을 SEA 비치헤드 언어로 현지화 (콘텐츠 번역 — vi 152권 이미 선행).
- **포지셔닝**: K-브랜드 = 영어 outcome 정면승부 회피 → **한국어/K-퀄리티 프리미엄/전인발달** 각도.
- **가격**: 시장별 적응 (구독 vs 평생 — 베트남=평생앵커, 태국=구독OK).

## 3. 레퍼럴 경제 (Dropbox 보정)

Dropbox는 **무한이 아니라 캡**이었음(500MB×최대 16GB). 무한은 고래를 영구 공짜에 가두고 D-day를 절벽으로 만듦.

- 1 초대 = +7일. **상한**: 레퍼럴 공짜 누적 **최대 N개월**(예: 6) 또는 **taper**(초대 3건 이후 보상 체감).
- **양면 보상**: 초대자 +7일, 피초대자도 7일 체험 (바이럴 계수 ↑).
- **어뷰징 방지**: 실사용(아이 활동) 기반 인정 — 가짜 계정 파밍 차단.
- **proof 기간 동안만 관대**, D-day에 표준화.

## 4. 무료 베이스 안 잃기 (그랜드파더링)

D-day = **최고 위험 이벤트**(손실회피 → 이탈 절벽). 완성된 학습이 전환을 끌어야 함.

- **창립 멤버 지위**: 가격 락($4.9 평생 고정) + 보너스 무료 개월 + 누적 별·호리·진도 **그대로 유지**.
- **프레이밍**: "무료 종료"가 아니라 "업그레이드/보상". 잃는 게 아니라 더 받는 것.
- **락인 활용**: 아이의 성장기록·별 컬렉션이 탱고북에 살아있어 떠나기 아까움.

## 5. 리스크

| 리스크 | 대응 |
|--------|------|
| D-day 이탈 절벽 | 학습 완성도가 유일한 안전장치 → **T1 미완성이면 절대 flip 금지** |
| 레퍼럴 어뷰징/고래 영구공짜 | 캡·taper·실사용 기반 인정 |
| "유저 많은데 살 사람 없음" | 무료에도 어휘·지식 노출 → 돈 낼 페르소나 자기선택 |
| 한국 proof 부실 → "K-플랫폼" 공허 | respectable 베이스+후기 필요 (단 쇠퇴시장 과투자 X) |
| K-브랜드가 영어권위 못 줌 | SEA는 한국어/프리미엄 각도로 진입 (영어 정면승부 회피) |

## 6. 한 줄 요약

> **Phase A(한국)**: $4.9 가격표 + 7일체험 + (상한 둔) 레퍼럴로 동화 무료 뿌려 proof·입소문·베이스. 병행해 **파닉스 5권+게임 = T1 완성**.
> **D-day**: T1 완결되면(반쪽 금지) 무한 레퍼럴 종료 → 유료. 기존 무료 = 창립멤버 그랜드파더링.
> **Phase B(SEA)**: 검증된 모델 + K-브랜드를 비치헤드로, 한국어/프리미엄 각도로 현지화.
> **D-day 게이트는 "300권"이 아니라 "1개 완결 학습 루프".**
