### p1 · 뜰에서 마주치다
판짜기 3컷 · 위 가로로 넓게 1 / 아래 좌우 2

#### c1 · 마주친 두 사람
나레이션 어느 날 여포가 동탁의 집 뜰에서 초선과 마주쳤어요.
```scene
컷 중형, 아이레벨 — 뜰에서 두어 걸음 떨어져 마주 선 둘.
장소·시간 동탁의 집 뜰, 낮.
인물 Lvbu(여포)와 Diaochan(초선)이 두어 걸음 떨어져 마주 섰다 — 둘 다 손을 뻗지 않았다.
배경·소품 뜰의 나무 한 그루.
톤 밝은 낮.
```

#### c2 · 아무 말도 못 하다
나레이션 두 사람은 아무 말도 나누지 못했지요.
```scene

장소·시간 같은 뜰, 같은 순간.
인물 Lvbu(여포)와 Diaochan(초선)이 서로 눈만 마주친다 — 입은 다물렸다.
배경·소품 비운다.
톤 밝은 낮.
```

#### c3 · 창 안에서 보다
생각 동탁 「저것들이…… 무슨 사이지?」
```scene
컷 중형, 어깨너머 구도 — 화면 앞쪽 뜰의 두 사람, 뒤쪽 창 안에 얼굴 하나.
장소·시간 같은 뜰, 같은 순간.
인물 화면 뒤쪽 창틀 안에 Dongzhuo(동탁)의 얼굴 절반이 걸린다 — 실눈이 이쪽을 본다. 앞쪽에 Lvbu(여포)와 Diaochan(초선)의 뒷모습.
배경·소품 창 하나.
톤 밝은 낮 — 🔴 아무 일도 안 벌어지는데 셋 다 알고 있는 쪽.
```
