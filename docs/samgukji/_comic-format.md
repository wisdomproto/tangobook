# 삼국지 만화판 · 원고 형식

> 그림책판(한 쪽 = 한 그림 + 산문)을 **만화판**(한 쪽 = 여러 컷 + 나레이션 상자 + 말풍선)으로 옮길 때의 형식.
> 🔴 **권·장·쪽의 뼈대와 순서는 그대로 둔다.** 24권 96장 552쪽은 건드리지 않고, 쪽 «안»만 컷으로 나눈다.

## 트리

```
권    #   1권 · 복사꽃 동산의 맹세
장    ##  1장 · 어지러운 세상
쪽    ### p4 · 병을 고쳐 준다는 사람
컷    #### c1 · 지팡이를 든 사람
```

쪽 = 종이 한 장. 컷 = 그 종이 위의 칸 하나. **컷 번호는 쪽마다 c1 부터 다시 시작한다.**

## 쪽 머리

```
### p4 · 병을 고쳐 준다는 사람
판짜기 4컷 · 위 가로로 넓게 1 / 가운데 좌우 2 / 아래 가로로 넓게 1
```

`판짜기` 는 그 쪽의 칸 나눔이다. 합성기가 이 줄을 읽어 마스크를 만든다.
🔴 **칸은 직사각형일 필요가 없다** — 재단 물림·비스듬한 분할·원형 인서트가 전부 생성 비용 0이다.

## 컷 하나

```
#### c1 · 지팡이를 든 사람
나레이션 그때 '장각'이라는 사람이 나타났어요.
대사 장각 「이 물을 마시면 병이 씻은 듯 나을 것이오.」
```scene
컷 ...
장소·시간 ...
인물 ...
배경·소품 ...
톤 ...
```
```

### 글 라벨 넷

| 라벨 | 화면에서 | 쓰는 법 |
|---|---|---|
| `나레이션` | 모서리의 네모 상자 | 화자 없음. 동화체 존댓말 그대로. |
| `대사` | 말풍선 | `대사 <화자> 「…」` — 화자는 SCENE 의 인물 이름과 같은 말로. |
| `생각` | 구름 풍선 | `생각 <화자> 「…」` |
| `효과음` | 글자 그대로 그림 위에 | `효과음 우르르` |

### 컷 안의 규칙

- 🔴 **나레이션과 대사가 같은 말을 두 번 하지 않는다.** 그림책을 만화로 옮길 때 가장 흔한 실수 —
  나레이션이 「장각이 물을 주며 병을 고쳐 준다고 했어요」 하고 말풍선이 「병을 고쳐 주겠소」 하면
  독자는 같은 문장을 두 번 읽는다. **하나가 말하면 다른 하나는 그 다음을 말한다.**
- 나레이션은 컷당 **하나까지**, 없어도 된다. 말풍선은 컷당 **둘까지**(셋이면 저학년이 순서를 놓친다).
- 컷 하나의 글자 총량 **45자 이내**. 🔴 세는 것은 «화면에 실제로 찍히는 글자»뿐이다 —
  나레이션 본문 + 「」 «안»의 말. 화자 이름(`대사 장각`의 「장각」)은 라벨이지 화면 글자가 아니다.
- 🔴 **말풍선이 그림을 설명하면 지운다** — 보이는 것은 그리고, 안 보이는 것만 쓴다.
- 쪽의 첫 컷에 나레이션, 마지막 컷에 다음 쪽으로 넘길 한 마디.

### 쪽의 규칙

- 컷 수 **3~5**. 저학년이라 6컷부터는 칸이 작아져 인물이 안 읽힌다.
- 🔴 **한 쪽 = 한 사건.** 그림책판의 쪽 하나가 이미 한 사건이므로, 컷은 그 사건을 «쪼개는» 것이지
  새 사건을 «더하는» 것이 아니다. 연출(클로즈업·반응 컷·시간차)은 얼마든지 발명해도 되지만
  **사실은 발명하지 않는다.**

`packages/client/scripts/build-samgukji.mjs` 가 이 형식을 읽는다.
검사 = 컷 번호 1..N 연속 · 컷마다 SCENE 있음 · 라벨 없는 글줄 없음 · 컷당 글자수 상한 · 화자가 그 컷 SCENE 의 인물에 있음.
