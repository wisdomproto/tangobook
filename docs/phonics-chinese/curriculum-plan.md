# 중국어 병음(拼音) 파닉스 — 정식 커리큘럼 기획서

> 2026-08-06 · **상위 기획 문서**(확정판). 근거·조사 원본은 [feasibility.md](feasibility.md)·[curriculum-draft.md](curriculum-draft.md).
> 코드 미변경 — 기획만. 유닛 표는 사람이 검토·수정하기 쉬운 마크다운 표.

## 🔴 관통 원칙 — 소리 먼저, 한자는 낱말에서만

**병음(声母·韵母·声调)을 순수하게 소리로 먼저 익힌 뒤, 단어 연습 단계에서만 한자를 병기한다.**

- **글자·소리·블렌딩·성조 학습 구간 = 병음만**(+그림). 한자 노출 없음.
- **낱말 활동(단어 카드·낱말 연습·낱말 게임) = 병음 + 한자 병기** — 표기 규격 **위 병음 / 아래 한자**
  (拼音 위, 汉字 아래). "이 소리가 이런 낱말이 된다"를 보여주는 자리에서만 한자가 등장.
- 이 원칙이 아래 모든 유닛·활동·자산을 관통한다. 유닛 표에 **소리 유닛(한자 X) vs 낱말 활동(한자 병기)**을
  열로 명시한다.
- (이것이 feasibility 결정표 "한자 노출 여부"의 확정 답 = **소리는 A(병음만), 낱말만 B(병음+한자 병기)**.)

## 1. 개요 / 포지셔닝

**영어(ABC)·한글·(일본어) 파닉스와 나란한 라인.** 사이드바 파닉스 랜딩에 카드 하나 추가.

- **타겟 = 글로벌 아이(한국 아이 포함), 안내는 각자 UI 언어를 따라간다** — 영어 파닉스와 완전히 같은
  포지션(i18n 은 영어 파닉스 baseline 그대로, 병음 전용 하드코딩 없음). L2 한국 아이 힌트로 xlsx 한글
  발음 표기(마·파·짜…)를 옵션 노출 검토.
- **설계 전제: 병음 = 성모(声母)+운모(韵母) 블렌딩 → 영어 CVC·한글 자음+모음 합치기와 동형.** 가나(모라)와
  달리 **blend 가 있다** → **blend 활동을 뺄 게 아니라 그대로 물린다**(영어 CVC 활동 세트가 원형).
- **유일한 새 축 = 성조(声调).** mā má mǎ mà 처럼 같은 음절이 성조로 뜻이 갈린다. 이것만 신규 설계.
- **인프라 3종이 이미 있다** — `zh`(中文简体) 등록됨 · Noto SC/ZCOOL 폰트 있음 · 성조 정확한
  `cmn-CN-Chirp3-HD-Leda` TTS 검증됨(낱단어 0.83~0.98). 신규 언어 중 재사용률 최고.

과 같은 형태. plan 은 `lib/chinese-phonics-units.ts`(영어 fork)가 커리큘럼에서 파생(유닛 목록 이중 기재 X).

// 낱말은 별도 단어카드 데이터에서 { pinyin:'māma', hanzi:'妈妈', gloss:'엄마', imageUrl } 로 병기.

🔴 **병음은 zh 한자 유닛과 다른 표시 축** — `splitUnits('zh')` 는 한자 1자=1유닛이라 병음 라틴 문자열엔
안 맞는다. 병음 타일은 코드포인트(NFC 성조 글자 유지, vi 선례)로 쪼갠다. 착수 시 작은 분기(§6).

## 4. 활동 매핑 (기존 phonics-learner 재사용)

병음 유닛 = **영어 CVC(Book2+) 활동 세트와 동형**(블렌딩 유지). 성조만 신규.

| 활동(kind) | 병음에서 | 한자 노출 | 근거 |
| --- | --- | --- | --- |
| `cvc-pattern-learn` (배우기: 성모+운모 블렌딩) | ✅ **재사용** — 성모+운모→음절(병음만) | ❌ 소리 구간 | 영어 CVC 동형. b+à→bà |
| `consonant-tap` / `consonant-blend-listen` (자음 누르고 합치기) | ✅ **재사용** — 성모 소리·블렌딩 | ❌ | 한글 합치기 동형 |

| `word-listen-choose` (낱말 연습·듣고 고르기) | ✅ **재사용** — 낱말 소리→[그림+병음+한자] 고르기 | ✅ **병기** | 🔴 보기 카드 = 병음 위/한자 아래 |
| 게임 `game-connect-dots`(낱말 그리기)·`game-word-writing`(낱말 쓰기)·`game-line-matching`(그림 짝) | ✅ **재사용** — 낱말 단위 | ✅ **병기** | 카드에 병음+한자. splitUnits 병음 타일 |

| **성조 듣고 고르기** (신규-개조) | 🆕 **`word-listen-choose` 개조** — 소리(mā)→성조 4종 보기 | ❌ | 병음만의 축. §3 u03·u05-u03 |

| `review-*` 6종 | ✅ **재사용** — 복습 유닛(게임만) | 낱말 게임만 병기 | 한글 복습 규칙 그대로 |

**소리 학습 구간(Level 1~5 익히기)엔 한자가 한 글자도 안 나온다.** 한자는 낱말 연습·단어카드·낱말
게임에서만, 병음 위·한자 아래로.

**유닛 활동 흐름(초안, 영어 CVC 미러):** 배우기(성모+운모 블렌딩, 병음만) → 성조 듣고 고르기 →
따라쓰기 → 글자 사냥 → [낱말 놀이: 낱말 연습·낱말 그리기·낱말 쓰기·그림 짝 — 여기부터 한자 병기].

## 6. 남은 결정 · 리스크

**빌드 착수 전 확정:**
- ✅ **성조 순서 = 1→2→3→4 (숫자 순, 결정 잠금 2026-08-06).** 기존 유아 병음 콘텐츠 대부분이 순서대로
  가르친다(사용자 결정). 이전 권장(1·4→2·3, 변별 난이도순)을 뒤집음. 경성은 뒤 레벨. 범위(4성 전부)는
  MVP 확정. ⚠️ 2성↔3성 변별 난이도는 파일럿에서 UX 로 완화 검토(순서는 유지).
- **정체/간체** — **간체**(zh=中文简体). 한자 병기 규격(낱말 활동)에만 실효.
- **현지 낱말 1차 확인 — 순서는 해소, 개별 낱말은 남음.** ✅ **레벨·유닛 순서는 YouTube 벤치마크로 이중
  확인 완료**(2026-08-06, curriculum-draft §벤치마크 — 单韵母→성조→声母 bpmf/dtnl→整体认读 수렴). 🔴 **남은
