> 출처: `D:\탱고 데이터\컨텐츠\` (탱고 물리 기기용으로 2020~2022 제작한 병음 콘텐츠).
> 목적: 앱 병음 파닉스(`docs/phonics-chinese/curriculum-plan.md`)의 **미해결 항목 = 음원**을 이 자료로 대체.

## 1. 음원 (★ 핵심 — 기획서 블로커 해소)

`12. 중국 판매용 콘텐츠 개발/2. 중국어 콘텐츠/1. 음원/`

### 1.1 음절 라이브러리 — `mod_cn(최종07.04)` 2,625개 · `tangoch/put` 1,305개
- 성모 23 × 운모(단운모·복운모·전비운모·후비운모·삼병음절) 전 조합 × 4성 + 경성. 원어민 녹음.
- **파일명 규칙 = 声韵母表 SSOT** (`0.dump/0.중국어 병음_병음음절표_0704yh최종검수.xlsx`):
  - 성조 숫자를 **핵 모음 뒤에** 삽입: `ba-1`=bā · `ba-2i`=bái · `ba-1ng`=bāng · `ba-1n`=bān · `jia-1o`=jiāo
  - 단운모: `a-1`~`a-4`, `-1.mp3`~`-4.mp3`(성조 카드용)
  - 특수 성조: **`-5`=반3성**(3+3 사틴디 앞 음절) · **`-6`=변조 2성**. 사틴디까지 녹음돼 있음.
  - `×`=존재하지 않는 음절 / 빈칸=결합 불가 (음절표에 전부 표기).
- 🔴 이 규칙표가 곧 **커리큘럼 음절 목록 + 앱 오디오 키 매핑**이다. 병음 음절 → 파일명은 음절표 조회.

### 1.2 拼读(블렌딩) 음원 — 영어 `c→a→cat` 블렌드와 동형
- `tangoch/py`(283) 성모+단운모: `py_blending_ba-1.mp3` = **"bō → ā → bā"**(성모 소리→운모 소리→합친 음절)
- `4. 블렌딩 음원/fy`·`by`, `tangoch/fy`(100)·`by`(103): 복운모·비운모 블렌딩 + 예시 낱말
- 블렌딩 대본 = `2. 전체 음원 리스트.../…최종0913.xlsx` 시트 「2. 블랜딩 음원 리스트」 (bō→ā→bā 형태 311행)

### 1.3 성조 교습 — `tangoch/sd`
- 4성 카드 + 성조 제스처 멘트: 1성 "앞으로 쭉 ā", 2성 "언덕 올라 á", 3성 "내려갔다 올라 ǎ", 4성 "내려가 à"

### 1.4 성모/운모 카드 + 예시단어 — `sm`(45)·`ym`(52)·`word1`(85)·`word2`(174)
- 운모 성조별 그림단어 페어링: ā 阿姨 / á 爬山 / ǎ 河马 / à 爸爸 · ō 波浪 · ē 车 · ī 衣服 …
- 단어카드: 한자 + 유아용 예문("章鱼有八条腿" 문어 다리 8개). 대본 = 리스트 xlsx 「3. 단어 리스트」 243행

### 1.5 챈트/노래
- 성조·단어 챈트, 운모 챈트, 성모 챈트, 병음조합 챈트, 복운모/비운모 챈트 (mp3 + 악보 + MR)

### 1.6 앱 적용 (기획서 §5 자산 대체)
- **기획서의 "Google TTS cmn-CN 로 ~120클립 생성" → native `mod_cn` 업로드로 교체.**
  기존 `pinyin-audio.ts`의 "cmn-CN이 한자를 읽는다" 블로커가 **사라진다**(사전녹음 병음이라 성조 정확).
- R2 `mod_chinese`(신규 카테고리)에 필요 음절 업로드 → `getChineseSyllableUrl`(한/영 `getKoreanSyllableUrl`
  대칭)로 직행. L1 파일럿 = 단운모 6 × 4성 + 성조 유닛 = 소량.
- 블렌딩(py/fy/by)은 배우기 「성모+운모」 합치기 소리로 직행 재사용.

## 2. 교안 (교습 설계·페다고지)

`21. 중국용 탱고 컨텐츠 교안개발/3. 병음 교안/1. 원본/중국_병음_교안_초안_sh_231214.pdf` (8p, 물리 기기용)

- 구조: Unit N / Class N · 课程(목표)·学习目标·준비물(놀이판·블록·학습카드)·Warm-up(노래·예시단어)·활동 과정·퀴즈
- **Class 흐름 = 앱 파닉스와 동형**: 카드 놓기 → 순서대로 성모/운모 짚으며 소리 듣기(배우기) → 블록 올리고
  플레이(합치기) → 정답 음원 → 다음 → **퀴즈**(듣고 맞추기). 성모 Class = "学习声母", 운모/성조/拼读 Class 반복.
- 즉 기획서의 활동 매핑(배우기→성조 듣고 고르기→따라쓰기→글자사냥→낱말 놀이)과 교습 순서가 일치.
- (전체 교안 라인 스케줄 = `21/(교안_파닉스) 업무 스케줄…xlsx` · 중국 검수본 = `21/0. 교안 샘플 3종(중국검수용)/`)
