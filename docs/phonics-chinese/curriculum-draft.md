# 중국어 병음(拼音) 파닉스 커리큘럼 초안

> 2026-08-06 · **초안**(빌드 아님). 착수 전 결정표(feasibility.md §6) 합의 후 확정.
> 배열 근거 = 部编版(人教版) 一年级上册 汉语拼音 13과 표준 순서. 음절 실재·한글 근사음 근거 =
> `중국어발음표.xlsx`(발음표 + 한글표기 시트). 낱말은 유아 상용 어휘 초안(현지 교재로 재확인 필요).
> 🔴 성조·한자 노출 범위는 미확정 — 아래는 **기본 권장(성조 1·4→2·3, 한자=병기 옵션)** 기준 초안.

## 0. 설계 원칙

- **음절 = 성모(声母) + 운모(韵母) + 성조(声调)**. 영어 CVC·한글 자음+모음 합치기와 같은 **블렌딩**
  구조라 기존 blend 활동을 라벨만 바꿔 씀(feasibility §5.1).
- **레벨 뼈대 = 부편판 순서**: 단운모 → 성모(4묶음) → 복운모 → 비운모 → 整体认读音节.
  근거: 部编版 一년급상 汉语拼음 1~13과.
- **성조는 Level 1(단운모)에서 먼저**, 이후 유닛은 배운 성모×운모로 실제 낱말을 블렌딩하며 성조를 얹는다.
- **낱말은 병음 + 그림**(한자 병기는 옵션). 유닛당 타겟 3~5음절 + 대표 낱말 2~4개.

## Level 1 — 단운모 + 성조 (단모음과 4성)

> 병음의 모음 6개와 성조 4개. **여기서 성조 개념을 심는다.** 낱말보다 소리·성조 변별 중심.
> 근거(순서): 部编版 1~2과(a o e / i u ü). 근거(한글 근사음): xlsx 한글표기 시트.

## 성조 통합 방식 (전 레벨 공통)

- **표기**: 타겟 음절·낱말은 성조 부호가 붙은 NFC 병음(`mā má mǎ mà`)으로 저장 → `splitUnits('zh')`
  가 타일 하나로 유지(vi 성조 글자 선례). 붙일 수 없는 조합은 성조번호 폴백(`nu:3`).
- **음원 키**: `{무성조음절}{성조 1-4}`(zip 명명 `ma3` 과 동일) → Google TTS 로 구워 `mod_chinese` 직행.
- **활동**:
  - Level 1 u03 = 성조 개념 도입(성조 전용).
  - Level 2~4 = 낱말 블렌딩에 성조를 **자연히 얹음**(妈mā vs 马mǎ 를 낱말로 만나며 구별).
  - Level 5 u03 = 성조 종합 복습.
  - 신규 활동 2종: **듣고 성조 고르기**(`WordListenChooseActivity` 개조, 보기=4성) · **성조 곡선 트레이스**
    (1성 평·2성↗·3성∨·4성↘, 가벼운 신규 컴포넌트).

## 🔴 착수 전 확정 필요 (feasibility §6 결정표 참조)

1. **한자 노출**(#2) — 위 표의 "한자" 열을 병기할지/뺄지. A(병음만)면 한자 열 삭제.
2. **성조 범위·순서**(#3) — 4성 전부 vs 1·4→2·3, 경성 포함 여부.
3. **낱말 확정** — 위 낱말은 유아 상용어 초안. 🔴 현지 유아 교재/拼音儿歌(BabyBus 중국어판 등)로
   유닛별 대표 낱말을 재확인해 "근거: [출처]"를 실 낱말마다 붙일 것(조사 시 중국어 페이지 Jina 차단으로
   순서는 국가표준·음절은 xlsx 로 확정했으나, 개별 낱말 선정은 현지 소스 1차 확인이 남았다).
4. **타겟 학습자**(#1) — B(한국 아이 L2)면 한글 근사음 열(xlsx 시트2)을 힌트로 노출 검토.
