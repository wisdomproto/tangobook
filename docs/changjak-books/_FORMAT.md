본보기 원고를 통째로 읽을 필요 없다 — 형식은 이 한 장이 전부다.

## 지켜야 할 것

| | |
|---|---|
| frontmatter | `---` 로 감싼다. 위 키를 다 채운다(`refrain`·`plant` 는 없으면 생략) |
| 따옴표 | 값에 `"` 가 들어가면 홑따옴표로 감싼다 — `refrain: '"붕붕—" …'` |
| 쪽 제목 | **`## p1`** 형식. `## p1 — 제목` 처럼 뒤에 뭘 붙이면 안 파싱된다 |
| SCENE | 쪽마다 **`### SCENE`** 한 번. 5라벨(`**컷**` `**장소·시간**` `**인물**` `**배경·소품**` `**톤**`)을 굵게 |
| note | `## note`. 여러 개면 첫 번째가 머리, 나머지는 꼬리로 간다 |
| 본문 | 마크다운 안 쓴다(그대로 렌더된다). SCENE 라벨만 `**굵게**` |

🔴 **`### SCENE` 의 `배경·소품` 은 목록이 아니라 예산이다.** 거기 적은 것이 다 그려진다.
