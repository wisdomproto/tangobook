# 시리즈 03 — 코코네 빵집 골목

> 창작동화 **시리즈 03** (25권 · 250쪽). 명단 = [_series-slate.md](../_series-slate.md).
> **페파형** · 그림체 = **활판 하나(전권)** — 한 시리즈 = 한 그림체.

| 축 | 값 |
|---|---|
| 형 | 페파형 — 웃음으로 착지, 아무도 안 고쳐진다 |
| 캐스트 구성 | **아이 + 엄마 일터** — 가게에 드나드는 단골 어른들이 틀린다 |
| 주인공 | 아기 생쥐 코코 · 결점 없음 |
| 무대 | 파리 뒷골목 빵집 + 그 골목 |
| 그림체 | 활판(letterpress) — 눌러 찍은 판, 반복 마크, 종이가 빛 |

🔴 01(퐁이)과 같은 페파형이지만 **틀리는 어른이 다르다** — 01은 집 안의 아빠 하나, 03은 **가게에 드나드는
단골들**이다. 그래서 사건이 가족 밖에서 오고, 매 권 다른 어른이 틀릴 수 있다.

---

## §1. 캐스트 다섯

| | | 늘 같은 것 | 틀리는 방식 |
|---|---|---|---|
| **코코** | 아기 생쥐 | 🔴 빨간 머릿수건 — 화면의 유일한 붉은 것 | 결점 없음 (페파형 주인공) |
| **엄마** | 생쥐 · 빵집 주인 | 앞치마, 팔에 밀가루 | 거의 안 틀린다 — 판을 깔고 마무리를 받는 쪽 |
| **두더지 할아버지** | 첫 단골 | 아침마다 같은 빵 | 🔴 길눈이 어둡다 — 안내한다며 앞장서면 헤맨다 |
| **까치 아줌마** | 골목 이웃 | 높은 데서 다 본다 | 🔴 참견 — 다 아는 척 콕콕 고쳐 준다 |
| **돼지 아저씨** | 짐꾼 단골 | 몸이 크다 | 🔴 힘자랑 — 힘으로 하다 일을 키운다 |

🔴 **단골 셋이 페파형의 「틀리는 어른」 풀이다.** 권마다 하나(가끔 둘셋)가 끼어들어 틀리고,
코코는 제 방식대로 해서 원하던 것을 얻는다. 어른들은 안 고쳐진 채 다음 권에 또 나온다 —
그게 페파형이다(01의 아빠가 25권 내내 그대로인 것과 같다).

**시그니처** — 코코의 빨간 머릿수건. 활판의 붉은 판 하나가 이것에만 닿는다(01 퐁이 목끈의 전통).

## §2. 뼈대 — 10쪽 고정 (페파형)

```
p1~p2   판을 깐다 + 원함          (🔴 p1 은 대사로 열지 않는다)
p3~p5   단골 어른이 끼어든다 — 돕는다며 제 방식대로
p6~p7   어른이 틀린다 — 일이 우스워진다
p8      코코가 제 방식을 찾는다
p9      그 방식이 먹힌다
p10     원함이 이뤄져 있고, 웃음이 남는다  (🔴 교훈·사과·반성으로 닫지 않는다)
```

🔴 **원함과 착지가 같은 것을 가리킨다** — 대발이형과 같은 판정축. 다른 건 **결점을 고치는 단계가 없다**는 것뿐이다.
🔴 **어른은 코코가 하는 그 일 안에서 틀린다.** 별도 용무를 주면 겹이 둘이 된다(01 검수에서 확립).
🔴 **한 권 = 규칙 하나.**

## §4. 앵커 — 활판 하나 (전권)

`pongi-anchor.md` §3 보류분 `pongi-presshome`(활판)을 가져와 **캐스트·무대만 갈아 끼운다**.
슬러그 = `coco-pressalley`. 팔레트·무대 조항·시그니처는 앵커 문서에서 확정한다(본문 승인 뒤 — 01·02와 같은 순서).

```
종이       CREAM — 찍지 않은 자리가 빛 · 창으로 드는 아침 해 · 밀가루
잉크 1·2   빵 갈색 + 골목 청회 (앵커 집필 때 확정)
겹침       가장 어두운 색 — 생쥐 등·화덕 속·골목 그늘
악센트     RED — 🔴 코코의 머릿수건에만
```

활판의 성질(같은 판의 반복)이 이 무대와 맞는다 — **선반의 빵, 병, 골목의 창**이 전부 반복 마크다.
찾는 물건만 제 판으로 따로 파는 규칙이 「배달할 집 찾기」「단추 찾기」 같은 권에서 그대로 그림이 된다.
