# 시리즈 08 — 피포네 돌담 목장

> 창작동화 **시리즈 08** (25권 · 250쪽). 명단 = [_series-slate.md](../_series-slate.md).
> **페파형** · 그림체 = **숯 + 한 색(전권)** — 한 시리즈 = 한 그림체.

| 축 | 값 |
|---|---|
| 형 | 페파형 — 웃음으로 착지, 아무도 안 고쳐진다 |
| 캐스트 구성 | **아이 하나 + 이웃 어른 여럿** — 목장 주변 어른 셋이 저마다 제 축으로 틀린다 |
| 주인공 | 강아지 피포 · 결점 없음 |

| 그림체 | 숯(charcoal) — 무채 화면에 **노랑 한 색**(mei-anchor 보류분 숯 문안을 가져온다) |

🔴 03(코코)과 같은 「틀리는 어른 여럿」 구조지만 **어른이 가게 단골이 아니라 목장 이웃**이다 —
가게로 찾아오는 게 아니라 **언덕·돌담·길에서 마주친다.** 사건이 늘 바깥(날씨·양 떼·길)에서 온다.

## §1. 캐스트 다섯

| | 영문 토큰 | 늘 같은 것 | 틀리는 방식 |
|---|---|---|---|
| **피포** | `Pipo puppy` | 🔴 노란 목도리 — 화면의 유일한 노란 것 | 결점 없음 (페파형 주인공) |
| **엄마** | `Mom dog` | 목장 주인 · 챙 넓은 모자 | 거의 안 틀린다 — 판을 깔고 마무리를 받는 쪽 |
| **양 할아버지** | `Sheep grandpa` | 굽은 지팡이, 복슬한 털 | 🔴 옛날 방식 고집 — 「옛날엔 이랬지」로 앞장서다 어긋난다 |
| **거위 아줌마** | `Goose auntie` | 목을 길게 빼고 다 본다 | 🔴 수다·소문 — 봤다는 말이 번번이 딴 곳을 가리킨다 |
| **말 아저씨** | `Horse uncle` | 몸이 크고 걸음이 빠르다 | 🔴 서두름 — 빨리 하다가 일을 키운다 |

🔴 **이웃 셋이 페파형의 「틀리는 어른」 풀이다.** 권마다 하나(가끔 셋)가 피포가 하는 그 일에
끼어들어 틀리고, 피포는 제 방식대로 해서 원하던 것을 얻는다. 어른들은 안 고쳐진 채
다음 권에 또 나온다. 양 떼·아기 양·아기 거위는 이름 없는 소품/단역이다(캐스트를 늘리지 않는다).

**시그니처** — 피포의 노란 목도리. 숯 화면의 노란 판 하나가 이것에만 닿는다.
🔴 어른(조연)은 노란 것을 절대 지니지 않는다. 13권이 이 목도리를 소재로 쓴다.

## §2. 뼈대 — 10쪽 고정 (페파형)

```
p1~p2   판을 깐다 + 원함          (🔴 p1 은 대사로 열지 않는다 · 원함은 p1~p2 안에 문장으로)
p3~p5   이웃 어른이 끼어든다 — 돕는다며 제 방식대로
p6~p7   어른이 틀린다 — 일이 우스워진다
p8      피포가 제 방식을 찾는다
p9      그 방식이 먹힌다
p10     원함이 이뤄져 있고, 웃음이 남는다  (🔴 교훈·사과·반성으로 닫지 않는다)
```

🔴 **원함과 착지가 같은 것을 가리킨다.** 🔴 **어른은 피포가 하는 그 일 안에서 틀린다** — 별도 용무 금지.
🔴 **틀리는 어른은 제 축으로만**(할아버지=옛날 방식 · 아줌마=소문 · 아저씨=서두름). 🔴 **한 권 = 규칙 하나.**
🔴 단서로 해결하는 권(03 방울 · 04 돌담 · 05 파란 지붕 · 07 홀쭉/복슬 · 10 등불 · 19 줄기)은
**그 단서의 근거를 p1~p2 에 심는다.**

## §4. 앵커 — 숯 + 한 색 (전권)

`mei-anchor.md` 보류분 **숯(charcoal)** 문안을 가져와 **캐스트·무대만 갈아 끼운다.**
슬러그 = `pipo-stonewall`. 팔레트·무대 조항·시그니처는 앵커 문서에서 확정한다(본문 승인 뒤 — 01·02·03 과 같은 순서).

```
종이       흐린 크림 — 안개·하늘·양털이 칠하지 않은 종이로 남는다
숯         돌담의 켜켜 · 젖은 언덕 · 비구름 · 개들의 털 — 문지른 면과 그은 선
악센트     YELLOW — 🔴 피포의 목도리에만 (10권의 등불 불빛은 앵커 무대 조항에서 예외를 정한다)
```

숯의 성질(문지르면 안개, 그으면 돌)이 이 무대와 맞는다 — **안개 낀 언덕, 돌담의 결, 비 오는 하늘**이
전부 숯 한 자루에서 나온다. 무채 화면이라 노란 목도리 하나가 어디서든 피포를 찾게 한다.
