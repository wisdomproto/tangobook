# 창작동화 1000 — 검수 체크리스트 (고정)

🔴 **검수는 이 파일로 한다.** 검수 프롬프트에 축을 손으로 옮겨 적지 않는다 — 그러다 축이 빠졌고, 첫 10권의 검수 두 번이 **연령·문체·한 순간·페이지 넘김을 전부 통과시켰다.** 규격이 늘면 이 파일에 축을 추가하고, 검수는 이 파일을 읽고 시작한다.

⚠️ **1차 검수가 결함을 칭찬한 전례가 있다.** a01 의 「반전을 주인공이 스스로 본다, 아무도 설명하지 않는다」를 배치 최고로 꼽았는데, 사용자 판정은 「어른이 봐도 뭔 말인지 모르겠다」였다. **축이 틀리면 검수가 결함을 승인한다.** 아래 A축(읽히는가)을 B축(라인 정책)보다 먼저 본다.

---

## A. 읽히는가 — 이걸 먼저 본다

### A1. 문체 (규격 ⑫)
- [ ] **「~았다/었다/였다」로 끝나는 문장이 0인가.** 자사 검수 통과 105편 중 「했다」체를 쓴 편이 하나도 없다. 해요체 현재형이다.
- [ ] **대사가 10개 이상인가.** 대사 0개인 편은 105편 중 없다. 사건을 대사가 끌고 가는가.
- [ ] **느낌표가 10개 이상, 의성어·의태어가 쪽마다 있는가.**
- [ ] 문장당 24~30자인가. 한 문장에 종속절이 둘 이상인 데가 없는가.
- [ ] **4~6세가 쓰지 않는 낱말**을 집어라(전례: 운하·산비탈·멀찍이·훤히·골짜기·또렷하다·무언가).

### A2. 뜻이 통하는가 (규격 ⑫)
- [ ] **감정을 말해 주는가.** 「부끄러워요」 「화가 났어요」가 있는가. 행동만으로 감정을 추론시키면 이 나이엔 안 읽힌다. ⚠️ 단 「부끄러워하지 않아도 돼요」류 교훈은 여전히 금지.
- [ ] **인과가 말해지는가.** 「A라서 B가 됐다」를 그림·추론에 맡긴 데가 없는가. (a01 은 「빨간 앞발이 안개 속 표지가 됐다」를 한 번도 말하지 않았다.)
- [ ] **전제를 심은 쪽과 회수하는 쪽이 몇 쪽 떨어져 있는가.** 그 쪽 안이나 바로 다음 쪽이어야 한다. (a01 은 p3 → p9 로 여섯 쪽을 건넜다.)
- [ ] **은유가 없는가.** 문자 그대로 작동해야 한다.
- [ ] **에둘러 부른 데가 없는가.** 안개는 「안개」다. (전례: 「하얀 것 말고는 아무것도 없었다」 → 담이 없어진 것으로 읽혔다.)
- [ ] **여백으로 끝나지 않는가.** 4~6세는 닫힘을 원한다. (전례: 「누가 놓았는지는 아무도 말하지 않았다」)

### A3. 한 쪽 = 한 그림 = 한 순간 (규격 ⑭)
🔴 **쪽마다 「이 쪽 그림 한 장은 무슨 순간인가」를 한 문장으로 써라.** 두 문장이 필요하면 그 쪽은 두 쪽이다. **이 목록을 검수 보고에 그대로 낸다** — 이 절차 없이는 매번 통과한다(작성자도, 검수자도, 사용자 지적 뒤 고치던 나도 어겼다).
- [ ] 순차 동작을 쌓은 쪽이 없는가. 「달려가요 → 밀어 놓아요 → 봐요」는 삽화가가 **마지막만** 그리고 앞은 사라진다.
- [ ] **습관 문장이 없는가.** 「이제 ~할 때마다」 「그때부터 ~해요」는 여러 날이라 그림 한 장에 안 담긴다.
- [ ] 순차 동작이 **상태**로 바뀌어 있는가. 「돌을 밀어 놓아요」(동작) → 「큰 돌이 꼭 막고 있어요」(상태 = 이미 그림 안).
- [ ] ⚠️ **동시에 벌어지는 것은 한 쪽에 둘 이상 와도 된다.** 「염소가 흔들고 여우가 숨는다」는 한 프레임이다. 문제는 시간 순서다.

### A4. 페이지 넘김 (규격 ⑮)
- [ ] **답을 안 준 채 끝나는 쪽이 최소 3개 있는가.** (a01 첫 판은 12쪽 전부 문장을 닫아 넘길 이유가 없었다.)
- [ ] 물음으로 끝내는 쪽이 **한 권에 한두 번**인가(매 쪽이면 안 궁금해진다).
- [ ] 닫히는 쪽도 있는가. 전부 열면 넘기는 쪽이 안 산다.

### A5. 자기 규칙 일관성 (규격 ⑬)
- [ ] **1~2쪽에 정한 것이 마지막 쪽까지 그대로인가.** (a01 은 「온몸이 빨개진다」로 정하고 p9 에서 「앞발만」으로 바꿨다.)
- [ ] 인물의 행동에 **그 권 안의 이유**가 있는가. (a01 p8 은 일곱 쪽 내내 피한 이웃을 갑자기 걱정했다.)

### A6. 분량 (규격 ⑯ · 한글 자수)
- [ ] `age: 4~6` → **700~1,000자** / `age: 6~8` → **1,000~1,400자**.
- [ ] 🔴 **영어 단어수를 자수로 쓰지 마라.** 옛 기준(규칙 깨기 200자 등)이 그 오류였고 자사 3~5세 라인의 1/4 이었다.
- [ ] 쪽수는 8~20 자유. 이야기와 연령이 정한다.

### A7. 해결이 전제를 실제로 해결하는가 (규격 ⑰) — 🔴 **이 축이 통과 못 하면 나머지를 볼 필요가 없다**
🔴 **두 줄을 써라. 그리고 둘이 같은 것에 대한 말인지 물어라.**
- **전제**: 주인공이 무엇에 걸려 있나(한 줄).
- **해결**: 무엇이 그걸 풀어 주나(한 줄).

같은 것이 아니면 결함이다. **겉면의 사물이 같은 건 연결이 아니다.**

전례(a01) — 전제 「화난 모습을 남이 보는 게 부끄럽다」 / 해결 「빨강이 이웃을 찾는 데 쓸모가 있었다」. 둘이 **「빨강」이라는 사물로만** 이어져 있고 뜻으로는 안 이어진다. 그래서 결말이 「네 화가 유용했다」가 되어 **화를 서비스로** 만든다. 🔴 **이 결함은 원고가 아니라 §5 요약문 한 줄에서 태어났고, 쪽 단위 수정 열다섯 번으로 안 붙었다.**

같이 볼 것:
- [ ] **부제·제목이 약속한 것**이 본문에서 실제로 벌어지는가. (a01 부제는 「온 마을을 찾아 줘요」인데 이웃들이 한 자리에 **모였을** 뿐이고 집을 찾은 건 아니다.)
- [ ] 주인공이 남을 돕기 위해 **부정적 상태에 들어가야** 하는 구조가 아닌가. (a01 은 도우려면 **화를 내야** 한다.)
- [ ] 해결이 **유용함**으로 오는가 **관계·받아들임**으로 오는가. 전제가 부끄러움이면 유용함은 답이 아니다.

### A8. 물러나서 책 전체를 본다 (규격 ⑳) — 🔴 쪽 단위로는 절대 안 잡히는 셋
쪽마다 검사하면 다 통과하는데 **책을 덮고 보면** 걸리는 것들이다. a01 은 스무 번 고치고 A1~A7 을 다 통과한 뒤에 이 셋이 나왔다.

**① 아이가 들고 갈 수 있는 정보량인가**
- [ ] **장소가 몇 개인가.** 4~6세는 지도식 공간 이해가 약하다. 🔴 a01 은 「집에 가는 길이 두 개(원래 길 / 좁은 산길)」였고, 아이가 쪽을 넘기며 그 둘을 들고 가야 했다. → **길을 하나로** 만들고 바뀌는 것을 「거기 누가 있는지」로 옮겼다.
- [ ] 이름 있는 인물이 넷을 넘는가. 매 쪽 등장하는 인물이 몇인가.
- [ ] 시간이 몇 번 건너뛰는가.
- 판정법: **삽화가가 같은 장소를 매번 같게 그릴 수 있는가.** 못 그리면 아이도 못 붙인다.

**② 기존 유명작과 겹치지 않는가**
- [ ] 이 이야기의 **뼈대 한 문장**을 쓰고, 그게 아이들이 아는 유명작과 같은지 보라.
- 🔴 a01 전례 — 「남들과 다른 신체 특징이 부끄러웠는데 결국 인정받는다」 = **루돌프**. 첫 판은 「그게 쓸모 있었다」까지 얹어 사실상 루돌프였다.
- ⚠️ 「옛이야기 비틀기」 엔진은 겹치는 게 목적이므로 이 항목 면제.

**③ 한 장치가 책을 지배하지 않는가**
- [ ] 쪽마다 같은 소재가 반복되는가. 🔴 a01 은 12쪽 전부가 **색 변화 하나**에 걸려 있었다.
- [ ] 🔴 **그 장치가 다른 규격과 싸우지 않는가.** a01 의 빨강은 규격 ②(톤에 색 이름 금지)와 부딪히고, 앵커의 2~4색 제한 팔레트를 빨강으로 묶어 **그림체 선택까지 제약**했다.
- [ ] 그 장치를 빼도 이야기가 서는가. **서면 빼는 쪽이 낫다** — a01 은 색을 빼자 p1 의 사건(우유 쏟음)이 p9·p11 까지 회수됐다(전엔 빨강을 켜는 스위치로 쓰고 버렸다).

## B. 라인 정책 — A 를 통과한 뒤에 본다

- [ ] **착지 유형**(규격 ⑤): 거울 / 문턱 / 목록 / 증거만 남기기 / 시점 이동 / 거리 이동. **한 배치에 같은 유형 2권 초과 금지**(후렴이 놓인 쪽의 거울은 면제, 최종 쪽은 별도 유형). 🔴 배치 전체를 세라 — 첫 배치가 8권 중 7권 거울이었다.
- [ ] **후렴 ↔ 엔진**: 누적·반복 / 소원의 대가 / 여정과 귀환 / 규칙 깨기 = 있음. **오해와 반전 · 교환·연쇄 = 없음**(반복이 반전을 미리 알린다).
- [ ] **후렴 화자**(규격 ①): 후렴 앞에 새 인물을 두면 어른이 그 인물 목소리로 읽는다.
- [ ] **엔진의 저항**(규격 ④): 규칙 깨기=규칙 편의 마찰 / 누적=매 비트의 반증 / 교환·연쇄=사물의 손해 / 소원=대가 / 여정=돌아올 이유.
- [ ] **SCENE 톤에 색 이름 금지**(규격 ②). 명암·대비·시선·정서만. 한 권 안에서 톤 문구 완전중복 금지(규격 ⑩).
- [ ] **종에 없는 신체부위 금지**(규격 ⑨). 고정 캐스트가 없어 종이 매번 바뀌는데 문장이 재사용된다.
- [ ] **무대 원장**(규격 ⑥): 같은 무대 재사용 시 주인공 종·핵심 소품·조연 중 최소 둘이 달라야.
- [ ] **무텍스트 쪽 해법**(규격 ⑧): 관통선 / 반복 격자 / 한 사물 확대 / 시간 경과 분할 / 완전 여백. 배치에 같은 카드 몰림 금지.
- [ ] **교훈 착지 금지 · 어른이 가르쳐 해결 금지 · 사람 주인공 금지.**
- [ ] **`grows:`**(규격 ⑪): 관찰과 성장 엔진은 자라는 주체를 프론트매터에 적었는가.
- [ ] **`bodyColors:`**: 본문이 색을 말하면 적었는가(앵커 팔레트와 싸울 자리).
- [ ] **정답지 소급**(규격 ⑦): 새 규격이 확정되면 `a01`(문체 정답지)·`a04`(최소 분량)·`a11`(최대 분량)부터 고쳤는가. **정답지는 규격 위반이 0이어야 정답지다.**

## 보고 형식
- **판정** 한 줄: 통과 / 재수정 필요.
- **A3 의 쪽별 한 순간 목록**을 반드시 포함(빠지면 검수 무효).
- **P0**(라인 정책·연령 위반 — 992권에 번진다) / **P1**(그 권의 완성도) / **P2**(취향).
- 각 건에 **파일·쪽·무엇이 문제인지·어떻게 고치는지**를 한 줄씩. 막연한 인상 금지.
- 🔴 파일은 고치지 않는다. 보고만 한다.
