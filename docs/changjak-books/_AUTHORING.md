2. `docs/changjak-books/a04.md` (규칙 깨기 = 최소 분량 192자) 와 `docs/changjak-books/a11.md` (누적·반복 = 최대 분량 899자). **이 둘이 형식의 정답지다.**

## 산출물
`docs/changjak-books/<id>.md` **한 파일**. 형식은 a04.md 를 그대로 따른다:

```
---
id: <소문자 id, 예: b01>
group: <주제군 표기, 예: B · 상상·변신>
no: <번호>
title: <제목 — 표에 있는 것을 그대로>
sub: <한 줄 부제. 표의 요약을 다듬어도 되고 새로 써도 된다>
engine: <엔진>
stage: <무대>
refrain: '<후렴>'          ← 🔴 엔진이 후렴을 안 쓰면 이 줄을 아예 빼라
cast: [<동물>(이름 없음), …]
---

## note

<이 편의 집필 과제를 3~5줄. 왜 이 분량인지, 후렴을 어디에 두는지/왜 안 쓰는지,
같은 글이 반복될 때 그림이 어떻게 달라지는지.>

## p1

<본문. 줄바꿈은 그대로 살아난다. 마크다운 강조 쓰지 마라.>

### SCENE

**컷** …
**장소·시간** …
**인물** …
**배경·소품** …
**톤** …

## p2
… (p12 까지 12쪽)
```

- **12쪽 고정.** 글 없는 쪽을 두려면 `## p7` 다음을 비우고 `### SCENE` 만 채운다(a04 p7 참고).
- 빌드 검증: `node packages/client/scripts/build-changjak-books.mjs --only <id>` 가 통과해야 한다. 쪽이 12개가 아니거나 SCENE 이 빠지면 실패한다. **반드시 돌려 보고 끝내라.**

## 절대 규칙
- 🔴 **분량은 엔진이 정한다.** §6 실측 중앙값(단어) → 한국어 본문 자수 기준: 규칙 깨기 ~200자 · 관찰과 성장 ~260자 · 교환·연쇄 ~490자 · 오해와 반전 ~500자 · 여정과 귀환 ~540자 · 누적·반복 ~670자 · 소원의 대가 ~700자 · 옛이야기 비틀기 ~1,200자. **±25% 안.** 늘리면 엔진이 바뀐다.
- 🔴 **후렴은 엔진의 부품.** 누적·반복 / 소원의 대가 / 여정과 귀환 / 규칙 깨기 = 쓴다. **오해와 반전 · 교환·연쇄 = 절대 안 쓴다**(반복이 반전을 미리 알린다).
- 🔴 **후렴·대사는 화자가 분명해야 한다.** 후렴을 쪽 끝에 두고 그 앞에 새 인물을 등장시키면, 읽어주는 어른이 그 인물 목소리를 낸다(A-11 이 6회 중 5회 그랬다). 누적 엔진의 구조적 함정이다.
- 🔴 **SCENE 「톤」에 색 이름 금지.** 명암·대비·시선 유도·정서까지만. 색은 권별 앵커 소관이고, ref 와 문구가 싸우면 ref 가 이긴다. (첫 2권은 24쪽 중 절반이 이 선을 넘었다.)
- 🔴 **SCENE 에 그림체 문구 금지**(수채·펠트·색연필 등). 그림체는 책마다 다르다.
- 🔴 **한 쪽 = 한 사건.** 그림책이지 애니메이션이 아니다.
- 🔴 **주인공은 동물, 이름 없음.** 사람은 주변부이거나 말이 없다.
- 🔴 **착지에 교훈 문장 금지.** 「~을 배웠다/소중함을 알았다」 류. 습관·교훈은 생활동화 45편이 맡는다. 조용히 장면으로 끝낸다.
- 🔴 **어른이 가르쳐서 해결하지 않는다.** 주인공이 보거나 알아차린다.
- 🔴 **이 엔진의 저항은 무엇인가**를 쓰기 전에 정하라. 규칙 깨기 = 규칙 편의 마찰 / 누적 = 매 비트의 반증 / 교환·연쇄 = 사물의 손해 / 소원 = 대가 / 여정 = 돌아올 이유. **첫 2권의 P1 이 둘 다 이 누락이었다.**
- 🔴 **무대는 이야기의 물리 조건이다.** 무대를 빼면 그 권이 성립하지 않아야 한다. 배경 묘사로 쓰지 마라.
- 4~6세 한국어. 어려운 낱말 금지(A-04 검수에서 「운하」가 걸렸다).
