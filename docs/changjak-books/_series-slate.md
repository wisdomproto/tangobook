# 창작동화 시리즈 명단 — 01~10

> 1000권 = 시리즈 40개 × 25권. 이 문서는 **처음 10개의 설계 축**이다.
> 🔴 규칙: **한 시리즈 = 같은 캐릭터 + 같은 그림체**(2026-08-13 확정). 시리즈끼리는
> ①캐스트 구성 ②형(대발이형/페파형) ③무대 ④그림체(매체) 네 축이 **전부 다르거나 조합이 다르다.**

## 축이 겹치지 않는지

- **캐스트 구성 10종 전부 다름** — 가족 / 또래+어른 / 일터 / 형제 / 조손 / 쌍둥이 / 학급 / 아이+이웃 어른들 / 또래 셋 / 대가족.
- **형** — 페파형 6 · 대발이형 4. 페파형은 「틀리는 어른」이 다르다(아빠 → 단골 → 누나(아이지만 아는 척 축) → 쌍방 → 이웃들 → 사촌 어른들).
- **매체 10종 전부 다름** — 01·02 확정분 + 보류분 6(활판·리소·리노컷·크레용·과슈·숯) + 신규 2(콜라주·모노타이프).
  보류분은 `pongi-anchor.md`·`mei-anchor.md` 에 완성 문안이 있어 캐스트·무대만 갈아 끼운다.
  🔴 꺼낼 때 슬러그의 시리즈 접두어를 갈 것.
- **동물 10종 전부 다름**, 전부 어른 독자도 아는 동물 — 수달·염소·생쥐·오리·곰·토끼·고양이·강아지·참새·당나귀.

## 소재 원천

- **대발이형**(02·05·07·09) — 호리 45편 표의 결점 배역 모델. 🔴 결점이 같아도 **사건은 달라야** 한다.
- **페파형**(01·03·04·06·08·10) — 페파 실측: 소재는 「아이가 처음 겪는 일」, 어른이 계속 틀리고, 교훈으로 안 닫는다.

## 공정 (시리즈마다 동일 — 02 에서 확정)

```
① 설계    _design.md — 캐스트(결점 배역)·10쪽 뼈대·25권 표(원함/탈/착지 전부 채움)
② 톤 확인  3권 먼저 써서 사용자 확인
③ 집필    나머지 22권

⑥ 앵커    보류 문안에 캐스트·무대 조항 끼움 + {시리즈}-core.js (🔴 문서와 core 양쪽)

```
