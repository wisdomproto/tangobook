# 시리즈 06 — 쌍둥이네 바닷가

> 창작동화 **시리즈 06** (25권 · 250쪽). 명단 = [_series-slate.md](../_series-slate.md).
> **페파형 변형** · 그림체 = **리소 하나(전권)** — 한 시리즈 = 한 그림체.

| 축 | 값 |
|---|---|
| 형 | 페파형 — 웃음으로 착지, 아무도 안 고쳐진다 |
| 캐스트 구성 | **쌍둥이 둘** — 🔴 틀리는 쪽 = **서로**. 어른(어부 아빠·엄마)은 배경 |
| 주인공 | 토끼 쌍둥이 리리·롤로 — 정반대 성격 둘, 결점 아닌 「축」 |
| 무대 | 포르투갈 어촌 — 바닷가·통통배·그물·등대·모래밭·시장 |
| 그림체 | 리소(risograph) — 겹쳐 찍는 판, 살짝 어긋나는 두 색 |

🔴 01(퐁이)·03(코코)과 같은 페파형이지만 **틀리는 어른이 없다** — 이 시리즈는 쌍둥이가
**서로에게 틀리는 어른 노릇**을 한다. 각자 제 방식이 맞다고 우기다 둘 다 우습게 틀리고,
둘의 방식이 반씩 합쳐지거나 뜻밖의 것이 해결한다. 아무도 안 고쳐지고 다음 권에 또 정반대로 군다.

## §1. 캐스트

| | 토큰 | 늘 같은 것 | 축 (제 축으로만 틀린다) |
|---|---|---|---|
| **리리** | `Riri rabbit` | 🔴 **노란 모자** | 돌다리도 두드리는 쪽 — 재고·세고·고르고·기다리다 **때를 놓친다** |
| **롤로** | `Lolo rabbit` | 🔴 **노란 장화** | 일단 뛰어드는 쪽 — 덥석·와락·촤악 하다 **일을 키운다** |
| **아빠** | `Dad rabbit` | 어부 · 통통배 · 생선 냄새 나는 검정 장화 | 배경 — 판을 깔고 마무리를 받는 쪽 |
| **엄마** | `Mom rabbit` | 시장 생선 가게 · 파란 앞치마 | 배경 — 심부름을 내주고 단서를 심는 쪽 |

**시그니처 = 노랑 둘.** 생각하는 머리에 노란 모자(리리), 달리는 발에 노란 장화(롤로) —
시그니처가 성격을 가리킨다. 🔴 **어른과 배경에는 노랑을 절대 쓰지 않는다**(어촌은 노란 우비·어구가
흔한 무대라 특히 주의 — 본문에 색을 적을 때도 연·물감·종이꽃 등에 노랑 금지).
15권에서 문어가 리리 모자를 써 보고, 8권에서 소라게가 롤로 장화를 새집으로 넘본다 —
시그니처를 소품으로 굴리는 권들이다.

## §2. 뼈대 — 10쪽 고정 (페파형 · 쌍둥이 변형)

```
p1~p2   판을 깐다 + 원함(둘이 함께)     (🔴 p1 은 대사로 열지 않는다)
p3      갈라짐 — 서로 제 방식을 우긴다
p4~p5   한쪽 방식 → 우습게 틀린다
p6~p7   다른 쪽 방식 → 우습게 틀린다    (순서는 권마다 바꾼다)
p8      실마리 — 반쪽이 만나거나, 뜻밖의 것이 나타난다
p9      먹힌다
p10     원함이 이뤄져 있고, 웃음이 남는다 (🔴 교훈·사과·반성으로 닫지 않는다)
```

- 🔴 **원함과 착지가 같은 것을 가리킨다.** 원함은 p1~p2 안에 문장으로.
- 🔴 **둘 다 그 일 안에서 틀린다** — 별도 용무 없음. 표준 페파형의 「어른이 끼어든다」 자리를
  「서로 우긴다」가 대신한다. **책 머리 메타 줄도 그래서 `**틀리는 어른**` 대신 `**우기는 둘**`**:
  `**원함** … · **우기는 둘** 리리 "…" / 롤로 "…" · **어긋남** … · **착지** …`
- 🔴 **각자 제 축으로만 틀린다.** 리리는 꼼꼼이 지나쳐서, 롤로는 성급이 지나쳐서. 축 이탈 금지.
- 🔴 **「협동」을 말로 하지 않는다.** 반씩 합쳐지는 권에서도 합쳐진 것은 그림과 사건뿐 —
  「둘이 힘을 합치니」류 문장 금지.
- **웃음 착지 구문을 매권 바꾼다** — 「까르르」 상투 방지(전 25권에 6회 이하로 배급했다).

## §4. 앵커 — 리소 하나 (전권)

보류 문안(리소)을 가져와 **캐스트·무대만 갈아 끼운다.** 슬러그 = `twins-risoshore`.
팔레트·무대 조항·시그니처는 앵커 문서에서 확정한다(본문 승인 뒤 — 01·02·03 과 같은 순서).

```
종이       CREAM — 찍지 않은 자리가 빛 · 모래밭 · 하얀 벽 · 물거품
잉크 1·2   바다 파랑 + 그물 갈색 (앵커 집필 때 확정)
겹침       두 판이 겹치는 자리가 가장 어둡다 — 바위 그늘 · 배 밑 · 저녁 바다
악센트     YELLOW — 🔴 리리의 모자와 롤로의 장화에만
```

리소의 성질이 이 시리즈와 맞는다 — **두 색 판이 살짝 어긋난 채 겹쳐 한 그림이 되는 것**이
정반대 둘이 반씩 합쳐지는 쌍둥이 축 그대로다. 파도·그물코·생선 비늘·시장 좌판이 전부
반복 마크고, 안개(12)·소나기(19)는 옅게 찍은 한 판으로 그린다.
