# 동화 낭독 채널 조사 (2026-08-12)

우리 원고가 「4~6세에게 어렵다」는 지적을 외부 표본으로 재려고 유튜브 동화 낭독 채널의
나레이션을 모았다. **결론은 `_AUTHORING` 규격과 memory `changjak-sentence-length-2026-08-12` 에 있고,
여기에는 다시 돌릴 때 필요한 것만 둔다.**

| 파일 | 내용 |
|---|---|
| `storytime-videos.json` | 102편 — id · 제목 · 채널 · 조회수 · 길이 · 검색어 (ko 28 / en 74) |
| `storytime-ids-en.txt` | 영어 74편 id (자막 미수집분) |
| `storytime-stats-ko.json` | 한국어 단편 10편의 **통계만** (분량 · 문장수 · 어절 · TTR) |

🔴 **자막 원문은 저장소에 두지 않는다.** 출판 그림책의 나레이션이라 복제가 된다. 통계와 구조 요약만
남기고 원문이 필요하면 그때 다시 받는다.

## 다시 받는 법

```bash
python ~/.claude/skills/youtube-transcript/scripts/yt_transcripts.py \
  --ids-file docs/changjak-books/_research/storytime-ids-en.txt \
  --out <임시폴더> --lang en --delay 8
```

🔴 **레이트리밋이 이 작업의 전부다.** 한국어 28편을 받은 직후 영어 74편이 **네 번 연속 전부 실패**했다
(delay 를 2 → 6 → 8 로 올리고 15분을 쉬어도 안 풀렸다). 반복 시도가 차단을 늘리는 것으로 보이므로,
**하루쯤 두었다가 한 언어씩** 받는다. `--resume` 이 기본이라 이미 받은 파일은 건너뛴다.

## 이미 나온 것 (다시 재지 말 것)

- **한국어 단편 10편** 수집·분석 완료. 냠냠동화(창작 유아 3~5세) 5편이 우리와 같은 장르라 가장 값졌다.
- 🔴 **문장 길이 지표는 폐기됐다.** 「서술문 4어절」을 세웠다가 같은 날 되돌렸다 — 쪼개니 뜻이 바뀌었다.
  **다시 재서 같은 결론에 도달하지 마라.** 경위 = `_AUTHORING` 규격 절.
- 🔴 **자동자막의 한계** — ko 28편 중 11편에 구두점이 없어 문장 통계에서 빼야 하고(안 빼면 한 편이
  통째로 한 문장이 된다), ASR 이 같은 구절을 매번 다르게 옮겨 **반복 구조는 못 잰다**.
- 🔴 **조회수는 채널 크기를 잰다.** 쓰려면 **채널 내 상대 순위**로만. 영어는 38채널 중 29채널이 1편씩이라
  채널 내 비교가 되는 곳은 9개뿐이다(Vooks 7 · Buddy Son 6 · Storytime Read Alouds 6 · Reading is 5 …).

## 남은 쓸모

영어 자막을 받으면 **논리 구성**만 확인하면 된다 — 한국어 5편이 공유한 틀(①결핍·실수로 열기
②문제는 하나뿐 ③시도하다 나빠짐 ④어른·상대가 풀어줌 ⑤교훈을 주인공 입으로 ⑥독자에게 직접 묻기)이
영어권에서도 같은지. **어절 지표는 영어로 옮길 수 없다.**
