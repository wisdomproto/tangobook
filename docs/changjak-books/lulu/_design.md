# 시리즈 10 — 룰루네 올리브 언덕

> 창작동화 **시리즈 10** (25권 · 250쪽). 명단 = [_series-slate.md](../_series-slate.md).
> **페파형** · 그림체 = **모노타이프 하나(전권)** — 한 시리즈 = 한 그림체.

| 축 | 값 |
|---|---|
| 형 | 페파형 — 웃음으로 착지, 아무도 안 고쳐진다 |
| 캐스트 구성 | **대가족** — 사촌이 많다. 틀리는 쪽 = **어른 친척 셋**(각자 축 하나) |
| 주인공 | 아기 당나귀 룰루 · 결점 없음 |
| 무대 | 이탈리아 올리브 언덕의 큰 농가 — 올리브밭·포도 시렁·큰 식탁·헛간·언덕길·마을 축제 |
| 그림체 | 모노타이프(monotype) — 한 번 찍고 걷어 낸 판, 닦은 자리가 햇빛 |

🔴 같은 페파형이라도 틀리는 어른이 다르다 — 01은 집 안의 아빠 하나, 03은 가게 단골들,
**10은 대가족의 친척 어른 셋**이다. 어른마다 틀리는 축이 하나씩이라(허풍·수선·옛날 방식)
매 권 다른 어른이 다른 모양으로 틀리고, **밥상·잔치·다 같이 하는 일**이 사건의 마당이 된다.

## §1. 캐스트 — 고정 다섯 + 사촌들

| | | 늘 같은 것 | 틀리는 방식 |
|---|---|---|---|
| **룰루** `Lulu donkey` | 아기 당나귀 | 🔴 파란 방울 목끈 — 화면의 유일한 파랑 | 결점 없음 (페파형 주인공) |
| **엄마** `Mama donkey` | 당나귀 · 농가 부엌의 중심 | 앞치마 · 판을 깔고 마무리를 받는 쪽 | 거의 안 틀린다 |
| **니노 삼촌** `Nino donkey` | 당나귀 · 허풍 담당 | "왕년엔 내가 최고지" | 🔴 **허풍** — 큰소리로 시범 보이다 제가 우스워진다 |
| **로사 이모** `Rosa donkey` | 당나귀 · 수선 담당 | 뭐든 더 크게, 더 많이, 더 예쁘게 | 🔴 **수선** — 일을 키우다 정작 못 끝낸다 |
| **베포 큰아버지** `Beppo donkey` | 당나귀 · 옛날 방식 담당 | "우리 땐 이렇게 했지" + 옛 물건 | 🔴 **옛 도구·옛 길 고집**이 지금은 안 먹힌다 |
| **사촌들** `cousins donkeys` | 🔴 **사촌 셋 + 아기 사촌 하나** (전권 고정) | 룰루와 함께 노는 또래 · 아기는 늘 안기거나 누워 있다 | 틀리지 않는다 — 개별 결점 없음, 규격 하나 |

🔴 **어른 셋이 페파형의 「틀리는 어른」 풀이다.** 권마다 하나(셋 다 권만 셋)가 룰루가 하는
그 일 안에서 제 축대로 틀리고, 룰루는 제 방식으로 해서 원하던 것을 얻는다. 어른들은 안
고쳐진 채 다음 권에 또 나온다.
🔴 **한 권의 인물 규격** — 틀리는 어른 하나 + (필요하면) 엄마 + 사촌들 묶음. 대가족이라고
인물을 늘리지 않는다. 사촌들은 언제나 「사촌들」 한 규격이고, 아기 사촌도 그 안이다.

🔴 **사촌 수는 못박혀 있다 — 걸어 다니는 사촌 셋 + 아기 사촌 하나.** 권마다 무리 크기가
달라 보이면 같은 집으로 안 읽힌다. 이 수가 본문 셈과 맞물린 자리 둘 = **21권**(그물 귀퉁이
넷 = 룰루 + 사촌 셋) · **16권**(숨는 사촌 셋 = 포도나무 밑 둘 + 제일 꼬마 하나, 아기는 안 논다).
그림에서도 아이는 늘 **룰루 포함 넷 + 아기 하나**다.

🔴 **의인화 등급** — **이족보행 · 소박한 농가 옷(앞치마·모자·조끼·치마·소매) · 신발 없음.**
🔴 **앞발 = 팔 + 뭉툭한 손.** SCENE 250쪽 실측에서 **앞발 212회 · 손 79회**로 섞여 있었다(당나귀라 어느 쪽으로도
읽힌다). 팔 끝이 뭉툭한 손으로 끝나는 한 규격으로 고정하고, **셀 때만 손가락을 셋까지** 보인다(다섯 금지 —
16권 p10 이 손가락으로 세는 몸짓이다). 계약서 §5-b 가 말한 자리이고, **설계서에 등급이 있어도 SCENE 을
세어 보지 않으면 어긋난 걸 모른다**는 실례다.
맨발이라 24권의 포도 밟기와 보라색 발이 그대로 성립한다. 등급은 쪽별 프롬프트마다 반복한다.

**시그니처** — 룰루의 **파란 방울 목끈**(목에 건 끈에 방울 하나, 끈도 방울도 파랑).
화면의 유일한 파랑이며 어른·사촌은 파란 것을 절대 지니지 않는다.
🔴 **24권 조항**(앵커 민팅 때) — 포도 즙의 **보랏빛은 흙갈색 잉크의 짙은 자국**으로 그린다.
파랑은 그 권에서도 방울에만. 「보라색 엉덩이·보라색 발」은 색이 아니라 **얼룩의 진하기**다.

## §2. 뼈대 — 10쪽 고정 (페파형)

```
p1~p2   판을 깐다 + 원함          (🔴 p1 은 대사로 열지 않는다 · 원함은 문장으로)
p3~p5   친척 어른이 끼어든다 — 돕는다며 제 축대로
p6~p7   어른이 틀린다 — 일이 우스워진다
p8      룰루가 제 방식을 찾는다
p9      그 방식이 먹힌다
p10     원함이 이뤄져 있고, 웃음이 남는다  (🔴 교훈·사과·반성으로 닫지 않는다)
```

🔴 **원함과 착지가 같은 것을 가리킨다.**
🔴 **어른은 룰루가 하는 그 일 안에서 틀린다.** 별도 용무를 주면 겹이 둘이 된다.
🔴 **틀리는 어른은 제 축으로만 틀린다** — 니노=허풍, 로사=수선, 베포=옛날 방식.
🔴 **한 권 = 규칙 하나.**

🔴 **작가에게 빈칸을 주지 않는다** — 네 칸이 다 차 있어야 집필로 넘어간다.
🔴 **틀리는 어른 배분** = 니노 7(01·04·07·11·14·19·23) · 로사 8(02·05·10·13·15·17·20·22) ·
베포 7(03·06·08·12·16·18·24) · 셋 다 3(09·21·25). 같은 어른이 연속 두 권 틀리지 않는다.
🔴 **공치사 착지 = 3권(13 로사 · 18 베포 · 23 니노)** — 6권 이하 · 비연속 충족.
(초고엔 12권도 「이 방법도 옛날에 있었지」로 공치사여서 **4권 · 12~13 연속**이었다. 12를
**무언 착지**(말없이 옆에 앉아 한 알씩 집는다)로 바꿔 연속을 끊었다. 남은 대안 유형 =
따라하기(05·12) · 나란히(06) · 마지못한 인정(02·15) · 콜백(01·09·14·17·20·22·24·25).)

🔴 **베포의 실패 대사는 「옛날엔 ~였는데」 두 권만**(03·08). 18·24 는 같은 문형이 넷이 되어
**몸짓으로 바꿨다**(18 = 손바닥을 털고 돌을 빤히 본다 · 24 = 보라색 엉덩이를 내려다보고 "어험").

🔴 **로사의 수선은 표면을 갈라 쓴다** — 꾸미기(02 꽃) · 크게(05 자장가) · 높이(10) · 많이
넣기(15 재료 · 17 리본) · 옮기기(20) · 자리 정하기(22) · 서두르기(13). 02와 17이 둘 다
「예쁘게 꾸민다」였던 것을 17을 **「리본을 자꾸 더 단다」**(많이 넣기)로 갈랐다.

🔴 **착지 해법도 겹치지 않게** — 「구호 붙여 여럿이 동시에」는 **21권 하나**다(그 권의 핵이라
「하나, 둘!」이 거기 있어야 한다). 18은 같은 해법이었어서 **룰루가 앞에서 끌고 뒤에서 미는**
모양으로 갈랐다. 05(따라 하기)와 19(숨죽여 기다리기)도 같은 이유로 갈라 둔 짝이다.
🔴 **글자 금지 주의** — 축제·시장이 나올 무대지만 간판·차림표를 읽는 사건을 만들지 않는다.
🔴 **「작게 차근차근 vs 크게 한 방」은 이 시리즈의 엔진**이라 여러 권에 흐르되, 동작 표면은

## §4. 앵커 — 모노타이프 하나 (전권)

명단(_series-slate.md)의 신규 매체 2종 중 **모노타이프**. 보류 문안이 없는 신규라 앵커는
본문 승인 뒤 art-director 가 민팅한다(01·02와 같은 순서). 슬러그 = `lulu-monohill`.

```
종이       WARM WHITE — 닦아 낸 자리가 지중해 햇빛 · 마른 흙길 · 식탁보
잉크       올리브 잎의 초록회 + 마른 흙 갈색 (앵커 집필 때 확정)
자국       한 번 찍고 걷어 낸 판 특유의 얼룩·롤러 결 — 언덕 능선·나무 덩어리·군중
악센트     BLUE — 🔴 룰루의 방울 목끈에만
```

모노타이프의 성질(한 판에서 한 장, 넓은 얼룩과 닦아 낸 빛)이 이 무대와 맞는다 —
**언덕의 볕, 큰 식탁 위 흰 보, 잔치의 군중**이 전부 넓은 자국 하나로 앉고, 대가족의
북적임은 세필이 아니라 덩어리로 그려진다. 룰루의 파란 방울만 화면에서 또렷하다.
