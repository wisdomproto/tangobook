# 붕이(11) 편집장 검수 — 수리 지시

> P0 1 + P1 13 + P2 9. **폐기할 권 없음.** 전부 국소 수정이고 쪽 구조·원함·착지는 안 건드린다.
> 🔴 P0 는 **SCENE 전에** 막아야 한다 — 그림까지 가면 「물 위에 아기 혼자」가 그대로 그려지고 컷을 버려야 한다.

## P0

**06 p5~p8 — 두 살이 물 위 흔들다리 한가운데 혼자 남고 그 위로 어른들이 건너온다.**
p1 이 「한 사람씩만 지나갈 수 있어요」라고 못박은 좁은 길이다. 밟힘·밀려 떨어짐이 그림으로 바로 읽힌다.
게다가 p8 에서 할아버지가 **위험한 또리가 아니라 붕이를 먼저** 데려간다 — 어른의 대응 순서가 틀렸다.
→ p5 에서 또리가 주저앉는 자리를 **출발한 배 위**로 물린다(「둘이 갈라진다」는 그대로 성립).
   p8 은 할아버지가 **또리 쪽으로 먼저 배를 댄다.** 손님 줄은 「나무 길이 사람으로 꽉 차 붕이가 도로 못
   건넌다」로 남기면 탈이 안 죽는다.

## P1

**1. 안전 — 아기가 어른 없이 물 가장자리에 있는 쪽 다섯**
`02 p2`(강풍+두 살+뱃머리) · `25 p7`(해 질 녘 혼자 뱃머리) · `01 p5`(배 가장자리에서 물 건너로 몸을 뻗는다) ·
`09 p10`(배 위에서 뛰는 것을 기쁨으로 그린다) · `23 p7`(잠긴 나무 길의 물건을 아이가 건진다)
→ 앞 넷은 **같은 쪽 화면에 엄마나 할아버지를 한 명 넣으면** 끝난다(정서 안 죽는다 — 25 p7 은 엄마가
   국수 배에서 또리 쪽을 보고 있으면 「형을 기다리는 아기」가 오히려 선다). 23 p7 만 **할아버지가 긴 막대로
   건져 준다**(11권이 이미 그 처리를 쓴다).

**2. 13 p6 「배와 배 사이는 전부 물이에요.」** — 「동생이 빠졌을지 모른다」를 네 살에게 문장으로 못박는다.
→ 「배가 너무 많아서 어디가 어딘지 모르겠어요.」 (방울 단서가 p1 에 있으니 긴장은 그대로)

**3. 🔴 02 와 07 이 같은 이야기다 — 거절 문장까지 같다.** 둘 다 「세 번 내밀고 세 번 거절당하고 소진된다」
(02 p6 줄 게 없다 / 07 p6 동전이 없다). 02 p3 과 07 p4 는 **「또리가 고개를 홱 돌려요」로 글자까지 같다.**
→ 07 을 **한 번에 크게 잘못 사는 것**으로. 동전 세 개를 한 배에서 노란 것 한 아름에 다 쓰고, 또리는 그 뒤에서
   오리를 보고 있다 — **붕이 팔에 가려 못 보는 그림이 곧 탈이다.**

**4. 04 p3 과 09 p3 이 글자까지 같다**(「또리가 …를 두 손으로 쥐었어요 / 붕이가 그것을 가져갔어요」).
→ 09 를 「뺏는다」가 아니라 **「또리가 뜨기 전에 붕이가 먼저 다 퍼 버린다」**로. 뺏는 손이 아니라 앞지르는 손.

**5. 04 와 12 가 같은 밥상·같은 그릇·같은 거절 동작**(입을 다문다 + 그릇을 민다).
→ 12 의 거절을 **붕이 그릇으로 손을 뻗는 것**으로. 그러면 p9 의 「또리 눈은 붕이 그릇의 초록 파를 보고
   있어요」가 p5 부터 그림으로 깔린다(단서를 앞에 심는 규칙에도 맞는다).

**6. 03·08·21 착지가 같다** — 「물결을 한 번 더 보내서 이번엔 안 흔들린다」가 세 권의 마지막 장.
→ 21 은 「손님 배들이 다가와요」라는 원함 착지가 따로 있으니 **물결 재현을 뺀다.** 08 은 **엄마가 수박을
   쩍 가르는 소리**로만 닫는다(그 문장이 이미 있다).

**7. p9 가 「다음 날 ~자마자」인 권이 9권**(05·10·11·15·18·20·22·23·25). 축⑤ 다섯은 전부 그렇다.
→ 두 권을 **같은 날 안**으로. 15 는 오후에 고기잡이 배가 한 번 더 온다. 20 은 물 배가 옆 골목에서 아직
   물을 붓고 있고 **붕이가 노 저어 쫓아간다** — 이 무대의 「뛰어갈 수 없다」를 처음으로 착지에 쓴다.

**8. p2 원함이 25/25 「붕이는 ~고 싶어요」 한 문형.** 원함을 **행동으로** 세운 권이 0이다.
→ 여덟 권쯤을 몸으로. 05 p2 「붕이가 바구니를 벌써 뱃머리에 갖다 놨어요.」 · 21 p2 「붕이가 과일 상자
   뚜껑을 열고 소매를 걷었어요.」 원함은 남고 문형만 흩어진다.

**9. 24 — 원함이 곧 결점이라 착지에서 돌아올 것이 없다**(원함 「내가 골라 준다」 → 착지 「또리가 스스로 집는다」).
→ p2 를 **「붕이는 또리 손에 과일이 들리는 걸 보고 싶어요」**로. 결점(대신 대답)은 두고 **목표물만** 갈아 끼운다.
   같은 이유로 **07** p2 는 「또리가 갖고 싶은 게 뭔지 알아내고 싶어요」, **19** 는 원함이 「혼자 갠다」인데
   착지가 「또리 도움으로 갠다」라 반쯤만 돌아온다.

**10. 09·19 — p9 에서 붕이가 한 동작도 안 바꾼다.** 어른이 해결하고 붕이는 그대로다(축④의 나머지 셋은
붕이가 직접 고친다).
→ p8 을 어른이 **물건을 밀어 놓고 물러나는** 동작으로 바꾸고, 건네는 손은 **p9 의 붕이 손**으로 옮긴다.

**11. 10 — p1 이 스스로를 뒤집고, 얼음 출처가 없다.** p1 「늦게까지 녹지 않아요」인데 정오에 다 녹고,
붕이는 얼음을 안 샀는데 p7 에서 또리 손에 얼음이 있다.
→ p1 뒷줄 「그래도 해가 오르면 조금씩 녹아요.」 · p7 은 **얼음 배 아저씨가 통 바닥의 마지막 조각을 또리
   손에 얹어 준다**(주는 사람이 화면에 있으면 출처가 생긴다).

**12. 16 — p1 이 깔아 놓은 물리를 안 쓴다.** p1 은 「밤새 자리를 옮겨요」인데 탈은 「노란 천막 배가 둘이다」다.
→ p1 을 「시장에는 노란 천막을 친 배가 여기저기 떠 있어요.」로(탈의 근거를 첫 쪽에 심는다).

**13. 한 쪽 = 두 순간 9쪽** — `01 p9` `03 p8` `04 p10` `07 p10` `08 p9` `15 p9` `16 p10` `22 p7` `06 p8`.
→ 전부 **앞 동작을 흔적으로 흡수**하면 한 장이 된다. 01 p9 「엄마가 또리를 안아 배에 태워 줘요」 ·
   04 p10 「빈 그릇 두 개 옆으로 둘이 뱃머리에 나가 있어요」 · 08 p9 「배 한가운데 자리에 수박을 꼭 안아
   내려놓아요」 · 16 p10 「엄마가 초록 채소를 국수 위에 얹어요. 붕이 팔에는 아직 오리 배 냄새가 나요」.

## P2

- **또리가 수동인 권이 축①에 몰렸다**(01·06·11·16·21 은 따라오다 뒤처지고 기다리고 운다만 한다).
  축①에 한 권만이라도 **또리가 먼저 가고 싶어 하는 쪽**을 넣으면 시리즈가 오래 간다.
- **13 p9** 또리가 그물에 왜 갔는지가 없어 「잃어버린 물건」처럼 읽힌다 → p3~p4 에 그물 더미 쪽으로
  아기 오리나 고양이를 두어 또리에게 제 이유를 준다.
- **12 p5~p6** 국물을 덜면 오히려 덜 붇는다 → 「국수가 딱딱하게 굳었어요」.
- **24 p4** 아주머니가 제 규칙(「아이가 직접 골라야 해요」)을 스스로 안 지킨다 → 「아주머니가 손을 거두어요」.
- **07 p4 「노란 참외」** → 메콩에는 **노란 망고**.
- **어휘** 「뱃전」(11 p5 · 18 p3) → 「배 가장자리」. 「노」는 01 p3 에서만 붙여 줬는데 05 p8 에 설명 없이
  다시 나온다 — **시리즈는 순서대로 안 읽힌다.** 05 에서도 한 번 더 붙일 것.
- **16 p2 「이번엔」** — 앞 권을 가리키는 말인데 단권 완결이라 근거가 없다 → 「오늘은」.
- **18 「노란 담요」** — 노랑은 이 무대 기본색(천막)이라 주인공 소품이 배경에 묻힌다 → 색을 빼고 「또리 담요」.
