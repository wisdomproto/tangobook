# 호리 34 · 34 💬 고운 말 — 고운 말 하면, 고운 말 와요

**p1**
"야, 저리 비켜!" 토토가 툭 하고 소리쳤어요. 오늘도 토토는 말이 뾰족뾰족해요. 친구들이랑 블록 놀이를 하러 모였는데, 토토는 자꾸 툭툭 막말을 해요.

**p2**
보리가 쌓은 블록탑을 보고 토토가 말했어요. "그거 완전 이상해, 못 만들었네!" 보리는 눈물이 그렁그렁. 두부도 옆에서 귀를 축 늘어뜨렸어요.

**p3**
뾰족한 말을 들은 친구들이 하나둘 자리를 떴어요. "토토랑은 속상해서 못 놀겠어…" 어느새 토토 혼자만 남았어요. "어라, 왜 다 가 버렸지?"

**p4**
그때 호리가 다가와 토토 옆에 앉았어요. "토토야, 누가 너한테 '못 만들었네' 하면 기분이 어떨까?" 토토는 곰곰 생각했어요. "음… 나도 되게 속상할 것 같아…"

**p5**
호리가 방긋 웃으며 말했어요. "말은 거울 같아. 고운 말 하면 고운 말이 오고, 뾰족한 말 하면 속상함이 돌아와." 토토는 눈이 반짝. "아, 그래서 다들 속상했구나!"

**p6**
토토는 친구들에게 조르르 달려갔어요. "하나, 먼저 생각해요! 둘, 고운 말로 바꿔요!" '이상해' 대신 '멋지다', '비켜' 대신 '같이 하자'. 토토가 입을 오물오물 연습해요.

**p7**
토토가 보리에게 다가가 웃으며 말했어요. "보리야, 아까 미안해. 네 블록탑 진짜 멋지다!" 보리 얼굴이 활짝 폈어요. "정말? 고마워, 토토야!" 고운 말 하면, 고운 말 와요!

**p8**
친구들이 방긋방긋 다시 모여들었어요. "셋, 고마워·미안해!" 고운 말이 오가니 놀이방이 다시 웃음으로 가득해요. 그 순간 토토의 빨간 손수건이 무지개색으로 반짝— 팟!

**p9**
이제 토토는 규칙을 알아요. 하나, 먼저 생각해요! 둘, 고운 말로 바꿔요! 셋, 고마워·미안해를 잊지 않아요! 콩이가 도토리를 나눠 주자 토토가 먼저 말했어요. "우와, 고마워!"

**p10**
호리가 토토를 폭 안아 주었어요. "토토야, 고운 말 하니까 다들 방긋방긋하지?" 이제 토토는 알아요. 고운 말은 고운 말로, 웃음은 웃음으로 돌아온다는 걸. 고운 말 하면, 고운 말 와요!
