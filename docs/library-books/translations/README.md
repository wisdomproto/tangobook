# 누락 나레이션용 영어 번역

2026-10-12 운영 조사에서 영어 번역과 TTS가 함께 비었던 36권·368쪽의 원문 대조 번역이다. `en/<운영 bookId>.json`에 제목, 쪽 번호, 검토 여부와 원문 source SHA를 보관한다. 판다 18쪽, 호리 유치원동화 20권·200쪽, 호리 세상 탐험 15권·150쪽이 대상이다.

본문·제목·캐릭터·장면이 바뀌면 기존 source SHA로 생성하거나 등록하지 않는다. 한글 본문과 기존 음원은 보존한다. 번역 파일의 존재는 TTS 생성·운영 등록 완료를 뜻하지 않는다. 진행과 재현 명령은 [TTS 작업 기록](../../work/content/tasks/20261012-library-missing-tts.md)을 따른다.
