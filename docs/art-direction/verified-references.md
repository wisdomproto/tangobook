# 검증된 시각 레퍼런스 라이브러리

> **art-director 에이전트의 기억 저장소.** 시장에서 검증된(상 수상 · 바이럴 · 베스트셀러 · 시장 지배) 시각 레퍼런스와 **왜 통했는지**의 해부를 누적한다.
> 🔴 새로 조사·분석한 건 반드시 여기 append 할 것. 세션이 끝나면 대화는 사라지고 이 파일만 남는다.

---

## 0. 이 라이브러리의 사용법

1. 새 콘텐츠의 그림체를 정할 때 → §2 원칙 + §3 사례에서 **콘텐츠 성격에 맞는 것**을 고른다. 🔴 기본값 없음(귀여움도 기본값 아님). 콘텐츠가 그림체를 정한다.
2. 새 레퍼런스를 조사하면 → §3에 사례 추가, 새 원칙이 보이면 §2에 추가.
3. 반증이 나오면 → 원칙을 고친다. 이 파일은 확정된 교리가 아니라 **계속 갱신되는 관찰 기록**이다.

## 1. 조사 레시피 (재사용)

### World Illustration Awards (AOI) — WordPress REST API
사이트의 프로젝트 페이지(`worldillustrationawards.com/projects/?award-year=...`)는 **JS lazy-load라 스크레이핑이 안 된다.** 대신 REST API를 직접 친다.

```bash
# 포스트 타입 = award / 택소노미 = award-category, award-list, award-year
curl -s "https://worldillustrationawards.com/wp-json/wp/v2/award?award-category=908&award-list=839&per_page=14&_embed=wp:featuredmedia"
```
| 택소노미 | 값 (term id) |
|---|---|
| `award-category` | childrens-publishing=**908** · editorial=474 · book-covers=905 · animation=1083 · advertising=470 · exploration=910 |
| `award-list` (수상 등급) | **category-winner=839** · highly-commended=885 · judges=498 |
| `award-year` | 2020=904 · 2021=1015 · 2022=1040 · 2023=1082 · 2024=1125 · 2025=1367 · 2026=1408 |
| `award-type` | professional=479 · new-talent=481 (수상 등급 아님 — 프로/신인 구분) |

- 이미지: `_embed=wp:featuredmedia` → `_embedded['wp:featuredmedia'][0]['source_url']` (theaoi.com/wp-content/uploads/…)
- 목록 썸네일은 `imagedelivery.net/.../<file>/<variant>` 형식 — 🔴 **variant 는 `public` 또는 `250` 만 열림**(500·800 = 403 "doesn't have variant with this name").
- 🔴 **분석은 반드시 이미지를 직접 받아서 Read 로 볼 것.** 제목·설명만 읽고 스타일을 논하지 말 것.

**🔴 보정 (2026-07-29 실측) — theaoi.com 원본은 죽고 imagedelivery 로 옮겨갔다:**
- `_embed=wp:featuredmedia` 가 주는 `source_url`(`theaoi.com/wp-content/uploads/...`)이 **2023년 이전 자산은 404** 다(2026-07 세션엔 살아 있었다 — 사이트가 옮긴 것). 41점 중 20점이 이렇게 죽었다.
- **경로가 1:1로 매핑된다** → 죽으면 아래로 바꿔라. 재다운로드 성공률 20/20.
```
theaoi.com/wp-content/uploads/<PATH>
  → https://imagedelivery.net/02vYSQfLRblc9N7aAcvddQ/<PATH>/original
```
- 🔴 **`original` variant 가 열린다**(위 표의 "public·250 만 열림"은 **폐기**). 프로젝트 페이지(`worldillustrationawards.com/projects/<slug>/`)의 `<a href>` 가 전부 `/original` 이다.
- 🔴 **2020년 이전은 API 로 못 캔다.** `award-category=childrens-publishing(908)` 은 2020~2026 만, `publishing(1084)` 은 2023+ 만 존재한다. 2002~2019 항목은 카테고리 태그 자체가 없어(`award-list` 만 붙음) 어린이책만 골라낼 방법이 없다. **20년치가 필요하면 WIA 말고 아래 3개 상을 써라.**

|---|---|
| 연도 인덱스 "All the {year} Winners" | **10903** |

```bash
# ① 그 해 인덱스의 스냅샷 찾기 (CDX)
curl -s "http://web.archive.org/cdx/search/cdx?url=bolognachildrensbookfair.com*&filter=urlkey:.*winner.*&collapse=urlkey&fl=timestamp,original,statuscode&limit=200&output=text" | grep -i ragazzi
# ② 인덱스를 raw 로 받아 부문 링크를 긁는다 (id_ = 원본, 래퍼 없음)
```

### 🇩🇪 Deutscher Jugendliteraturpreis 그림책 부문 — 위키피디아 wikitext (2026-07-29)

```bash
curl -s "https://de.wikipedia.org/w/api.php?action=parse&page=Deutscher%20Jugendliteraturpreis&prop=wikitext&format=json"
```

### 2.3 🔴 말로는 모델의 기본 렌더를 못 이긴다 → 스타일 레퍼런스 이미지가 답 (2026-07-17, 전래동화 A3 실패에서 확립)
**관찰**: 전래동화 A3(민화 + MEDIUM 물성 문구 + RESTRAINT 절제 문구)가 "아직도 AI가 만든 것 같다"로 실패.
문구를 아무리 정교하게 써도 —
- `visible brush strokes` → 모델이 **질감 오버레이 필터**로 처리한다(획의 방향·압력·번짐이 없음).
- `2~4색으로 제한` → 무시하고 5색+ 씀.
- 얼굴은 **모델이 아는 가장 예쁜 방식**(매끈한 CG 에어브러시)으로 그린다.

**결론**: 스타일은 **문구가 아니라 이미지로** 전달해야 한다. `@image` 스타일 레퍼런스 첨부 > 형용사 100개.
문구의 역할은 스타일을 "정의"하는 게 아니라 **레퍼런스가 못 담는 것(캔버스·캡션 여백·연령·금지)을 보충**하는 것으로 축소된다.
- 🔴 **문구가 레퍼런스와 싸우면 진다.** 레퍼런스를 붙였으면 문구는 그 레퍼런스를 **재기술**해야지, 다른 걸 요구하면 안 된다.
- 🔴 **매체를 정확히 알고 쓸 것.** A3는 민화에 "visible brush strokes(붓자국)"를 요구했는데 — **민화는 임파스토 붓그림이 아니다.** 실물은 *가는 먹선 윤곽 → 안쪽을 불투명 안료로 평칠*이고, 질감은 **가는 선을 반복해 그은 것**(털·솔잎)이지 붓터치가 아니다. **레퍼런스에 없는 물성을 문구로 요구한 것 자체가 오류**였다. 매체 문구를 쓰기 전에 실물 레퍼런스를 먼저 봐라.

### 2.4 🔴 캐릭터 시트의 렌더링 톤이 최종 그림을 지배한다 (2026-07-17)
**A3 렌더의 최대 범인**: 배경엔 민화 처리가 먹었는데(줄무늬 산·양식화 구름·한지 결) **인물만 매끈한 CG 에어브러시**로 나왔다. 배경은 "그렸고" 인물은 "렌더했다".
**원인**: 캐릭터 시트가 **수채 톤으로 만들어진 것**이라, @image 로 첨부되는 순간 인물이 예전 렌더를 그대로 물려받았다. 장면 프롬프트의 스타일 문구는 캐릭터 시트를 못 이긴다.

> **원칙: 스타일을 바꾸면 캐릭터 시트를 먼저 다시 만들어야 한다.**
> 배경 스타일만 바꾸면 인물은 절대 안 따라온다. 시트 = 그 라인의 진짜 스타일 SSOT.
> **파이프라인은 2단계다** — ① 스타일 ref 로 **시트**를 새로 굽는다 → ② 그 시트를 @image 로 장면에 붙인다. 순서를 어기면 인물/배경이 따로 논다.

**응용**: "얼굴이 매끈하다/애기 같다/평범하다"는 진단이 나오면 → 장면 프롬프트가 아니라 **시트를 의심**하라.

### 2.6 🔴 캐릭터 디자인은 그림체와 독립된 축이다 — 매력(appeal)은 디자인에 산다 (2026-07-17, 사용자 확립)
**관찰**: 전래동화 그림체를 4번 갈았는데(수채→민화→목판→수상작 이식) 인물이 계속 "뻔한 아저씨"였다. 원인 — 캐릭터 스펙이 "성인 비율·아몬드 눈·작은 코·온화한 미소·상투·짚신" = **의상 목록 + 몽타주 평균값**이었지 디자인이 아니었다.
- **그림체(렌더링) = 세계를 어떻게 그리나. 캐릭터 디자인 = 누구를 보고 있나. 별개의 축이다.** 렌더링을 아무리 바꿔도 디자인 없는 인물은 행인1이다.
- 매력의 실체 = **실루엣·비율 체계·얼굴 문법·시그니처 디테일**의 설계. (Yunyun Ai 거인 = 납작 흰 얼굴+점눈 2+실선 입+한 덩어리 머리+웅크린 둥근 몸. 목탄이라서가 아니라 이 설계라서 매력.)
- 🔴 **스타일 ref 는 렌더링만이 아니라 캐릭터 디자인 언어까지 세트로 상속시켜라.** 프롬프트에 사실주의 몽타주 스펙("아몬드 눈, 1/5~1/6")을 박으면 ref 의 디자인 언어 상속이 차단되고 모델 기본 얼굴이 나온다.
- "어른"은 비율로 강제하지 말고 **문화 기호·역할·자세**로 읽혀라 — 상투(조선 기혼 성인 표지)·수염 점 2~3개·웅크린 자세면 점눈 대두 비율(1/4~1/3)에서도 어른이다. (전례: 비율 강제 → "애 아빠가 아기" ↔ 비율 완화+사실주의 → "뻔한 아저씨". 정답은 디자인.)
- 검증: 점눈 언어 이식 렌더가 즉시 "ㅋㅋㅋ"(보자마자 웃음) 반응 — 매력 판정은 이 즉발 반응이 기준.
- 응용 순서: **① 캐릭터 디자인 언어 확정(탐색 시트/ref 상속) → ② 그 언어로 캐스트 시트 → ③ 장면.** 그림체부터 정하고 인물을 끼워 넣으면 반드시 행인이 나온다.

### 2.7 🔴 마감 밀도도 스타일 변수다 — 균일 완성 = AI 티, 획의 절약 = 사람 티 (2026-07-17, 점눈이(Dot-Eye) 확정에서 확립)
- 화면 전체를 균일한 완성도로 채우면(기와 한 장까지 다 그림) "공들인 AI" 느낌이 난다 — A3 실패 5항의 일반화. 반대로 **획을 아끼면**(배경=몇 획, 마당=거의 백지, 먼 것=종이로 소멸) "거장의 스케치북 한 장" — 의도된 미완성이 사람 손 티가 된다.
- **밀도는 캐릭터에만 몬다.** 배경까지 같은 밀도로 그리는 순간 위계가 죽고 AI 티가 난다.
- **종이 자체를 광원으로 쓸 수 있다**(밝은 크림 종이 = 햇빛). §2.1-2 여백 원칙의 확장 — 빈 종이가 구성 요소를 넘어 조명 역할까지 한다. 별도 라이팅 문구가 불필요해짐.
- 프롬프트에 밀도 배분을 명시하라: "Spend density ONLY on the characters; backgrounds hinted with a few strokes" + "edges left open, hatching never fully fills a shape".

**🔴 보정 (2026-07-18, 점눈이 회차 실측) — "흐리게(faded)" ≠ "미완성 스케치(unfinished sketch)":**
- **관찰**: 위 문구("backgrounds hinted / airy / a few strokes")를 넣어도 배경(항아리·담·베틀·지붕)이 인물만큼 **다 그려져** 나왔다. 원인 = 모델은 "hinted / looser / hazy" 를 **저채도·안개·연한 색**으로 오해할 뿐 여전히 형태를 완성한다. 이건 **채도가 아니라 완성도(finish)의 문제**인데 문구가 그걸 구분해 주지 못했다.
- **교정**: 밀도 배분을 "hinted/airy" 같은 애매어로 쓰지 말고 **완성도 위계(finish hierarchy)** 를 명시하라 — characters = finished(line+color) / their handled props = half-finished / **everything else = a LOOSE UNFINISHED PENCIL SKETCH: a few open contour lines and direction strokes, barely any color, bare paper showing through, deliberately not filled in, like the rough underdrawing on a sketchbook page.** 질감을 "unfinished pencil sketch / rough underdrawing" 로 못 박아야 한다.
- 🔴 **오해 차단 문구 필수**: "this is about how FINISHED each area is, NOT about opacity — the background is not faded, hazy, blurry or low-saturation, it is simply left as rough sketch lines, not drawn to completion." NOT 리스트에도 `NOT a fully rendered background / NOT every jar·roof-tile·leaf drawn to completion / NOT a uniform finish / NOT a hazy·blurry·faded background(그건 흐림이지 스케치가 아님)` 을 넣는다.

### 2.15 🔴 「표정이 없다」는 결함이 아니라 배정 조건이다 — 두 방향 (2026-07-30, 창작동화 B-09 · F-02 에서 확립)
§2.8 이 「형태 언어는 감정을 못 쓴다」로 C4 를 A·G 에 금지했는데, 두 권에서 **표정 부재가 오히려 엔진이 되는 두 경우**가 나왔다. 배정 판정에 그대로 쓸 것.
1. 🔴 **읽을 얼굴이 없는 것이 오해의 원인일 때**(b09). 손님은 **깎아 만든 나무 새**라 얼굴 모양이 열한 쪽 내내 안 바뀐다 → 다람쥐는 **몸의 방향**을 읽어야 하고 그걸 계속 틀리게 읽는다. 반전도 표정 변화가 아니라 **머리를 처음 정면으로 돌리는 것**이다. **「오해와 반전 + 말 못 하는 상대」 권 전체에 재사용**: 상대의 얼굴을 고정하면 오해가 억지가 아니라 구조가 된다. 부수 — 이 규칙이 **점눈이 충돌도 막는다**(점눈은 표정을 만드는 희극 장치인데 이쪽은 절대 안 움직이는 홈이다).
2. 🔴 **얼굴을 그려선 안 되는 조연이 있을 때**(f02). 어른이 입을 열면 그 책은 어른이 가르치는 책이 된다 → 어른은 손·무릎·등·소매로만 존재해야 하고, 그건 C4 가 가장 잘하는 일이다. **한계가 비용이 아니라 정책과 일치하는 경우**이므로 C4 를 F 에 열 수 있었다.
- 🔴 **거꾸로 판정 규칙**: **얼굴이 연기해야 하는 권에는 C4 를 주지 않는다.** b09 는 다람쥐가 「부끄러운가 보네!」·「숨바꼭질이지?」를 **즐겁게 틀리는 얼굴**로 열한 쪽을 끌어야 해서 C4 를 탈락시켰다. 같은 클러스터가 한 권에선 정답이고 다른 권에선 탈락인 이유가 **바로 이 한 줄**이다.
- 🔴 **표정이 없는 쪽에는 대신 「가장 정확한 도형」을 하나 준다**(f02). 아기는 눈썹도 표정도 없고 **흰 원반 안 눈동자 하나의 위치**만 있는데, 음영이 0 인 매체에서는 그것이 화면에서 가장 정밀한 것이 되어 열두 쪽을 혼자 진다. **정밀도를 한 곳에 몰아주는 것**이 표정 부재의 대가다.

### 2.5 🔴 NOT 문구 운용 규칙 (사고 2건에서 확립)
- **NOT 은 렌더링 기법에만 쓴다** (에어브러시·그라데이션·CG 광택·셀셰이딩·사진풍…).
- 🔴 **인체·연령·비율에는 NOT 을 쓰지 마라.** `NOT realistic adult proportions` → 어른이 아기가 된 사고. 모델은 부정어의 *대상*만 집고 방향은 제 맘대로 정한다.
  → 비율·연령은 **항상 긍정문 + 수치**로: "머리는 키의 1/5~1/6, 다 큰 어른의 키와 체격".
- **NOT 은 의도한 실패 모드만 정확히** 막는다. 넓게 던지면 엉뚱한 걸 지운다.

### 2.3 스타일 선택 원칙
- **콘텐츠가 그림체를 정한다.** 귀여움·수채·3D 어느 것도 기본값이 아니다. 연령·서사 톤·소비 맥락(잠자리 그림책 vs 릴스 썸네일)에서 역산한다.
- **내용과 형식의 필연성.** 한국 옛이야기에 범용 서양 수채 = 조합에 필연성 없음 → 평범. 형식 자체가 그 내용일 수밖에 없는 이유를 만들어라.
- **형식이 곧 무기.** 세계가 주목한 한국 그림책은 형식이 무기였다(백희나=입체 디오라마 → 린드그렌상 / 서우경=천 콜라주 → WIA).

### 6.1 🔴 글자가 든 아이콘은 언어에 묶인다 (2026-07-25, `word-writing-ko` 건에서 확립)
- **관찰**: `word-writing.webp`(연필이 알파벳 **A** 를 씀)를 한글 파닉스 단원과 영어 단원이 **공유**하고 있어, ㄱ 단원 카드에 알파벳이 떴다. 아이콘 안의 글자 = §4 "그림 안에 글자 금지"(다국어) 규칙이 **UI 아이콘에도 적용**된다는 뜻.
- **규칙**: 아이콘에 글자를 넣는 순간 그 아이콘은 언어 자산이다 → 언어별 변형(`-ko` / `-en`)을 세트로 만들거나, 글자를 빼고 도구·행위만 그린다. 형제 아이콘 중 `korean-block.webp` 는 A·B·ㄱ·ㄴ 을 **한 화면에 섞어** 이 문제를 우회한 사례(단, 단일 언어 표시 정책과는 어긋나므로 신규엔 권장 안 함).
- **선택 기준(같은 카드에 형제가 있을 때)**: 아이콘은 **활동 간 차이**를 그려야 한다. `ㄱ 쓰기`(자모 1개)와 `낱말 쓰기`(단어)가 같은 화면에 있으므로 낱말 쪽은 **음절 블록 2개**로 그린다 — 한 글자를 크게 그리면 두 카드가 같은 그림이 된다.

### 6.2 🔴 모델에 한글을 그리게 할 때 — 자소 기하를 영어로 분해해 못 박는다
- 모델은 한글을 **가짜 한글/한자스러운 획**으로 뭉갠다. `"write 나무"` 만으론 실패한다. 통하는 서술 = **네모칸 → 자소 위치(좌우/상하) → 획 하나하나의 방향**:
  - 나 = `left half: ㄴ = one vertical line then a 90° turn right at the bottom, like L` + `right half: ㅏ = one tall vertical line with ONE short horizontal tick attached at its middle pointing RIGHT`
  - 무 = `top half: ㅁ = a closed square, four straight sides` + `bottom half: ㅜ = one horizontal line with ONE short vertical line dropping from its middle`
- **글자 선택이 곧 성공률**: 획이 전부 직선이고 받침(3단 구성)이 없는 글자를 골라라. 곡선(ㅇ·ㅎ)·사선(ㅅ·ㅈ)·받침은 뭉개짐 1순위. → **나무** 채택(직선만·받침 없음·좌우 조합 + 상하 조합을 한 단어에서 둘 다 보여줌).
- **개수 상한 명시** — "exactly two syllable blocks, nothing else is written anywhere" + `NOT any other Latin/Chinese/Japanese/invented characters`. 안 쓰면 여백에 가짜 글자를 채워 넣는다.
- **재시도 규칙**: 자소가 틀리면 문구를 늘리지 말고(§5.1 교훈) ① 글자 수를 줄이거나(2음절→1음절) ② **글자 없는 빈 노트 버전을 받아 한글은 나중에 합성**한다. 3회 실패 = 레버가 틀린 것.
- 진행 상태 표현(실선 완성 1 + 점선 가이드 1 + 연필 끝이 점선 시작점)은 원본이 이미 검증한 문법이라 그대로 상속한다.

**🔴 이번 수집이 알려준 것 3가지**

2. **C9(믹스드 콜라주)는 두 갈래로 갈라진다** — ① 이질 재료 병치(`child-tomato`·`ismail-friend`·`hole-garmann`) ② 질감판 겹치기(`teckentrup-samesky`·`gill-clevercrow`·`carlin-kingsky`). ①은 **AI가 가장 잘 뭉개는 유형**(사진을 사진풍 렌더로 바꿔 버린다)이라 실사 소스를 ref 로 줘야 하고, ②는 문구만으로도 어느 정도 선다. **신규 배정은 ②부터.**
3. **C2에도 감정을 쓸 방법이 있다** — `naylor-suitcase` 는 표정 대신 **인물 사이의 간격**으로 배척과 수용을 쓴다. §2.8이 "형태 언어는 감정을 못 쓴다"고 못 박았는데, **거리·간격은 표정 없이도 감정을 쓴다**는 예외 통로다(§2.8을 폐기하지는 말 것 — 여전히 「화가 나면」 같은 내면 상태는 못 쓴다).

**교차 관찰 3가지**
1. **C7이 15항목으로 가장 두껍다** — 범용성이 높다는 뜻이자 **가장 평범해지기 쉽다는 뜻**이다. C7 앵커에는 매체를 반드시 특정하라(유화 두껍게 / 목탄 그레인 / 잉크+수채 명암 — "회화풍"은 금지).
2. **프랑스 원작이 유독 C4에 몰려 있다**(Darme-Rizzo·Alméras·Virardi·Marais). 유럽풍 무대 라인에서 **프랑스 무대 권 = C4 우선**이라는 간단한 배정 규칙을 쓸 수 있다.
3. **2024 신설 Toddler 부문이 이 라인의 최적 사료다.** Fiction 은 중·고학년 실험작이 섞이는데 Toddler 는 전량 4세 이하 대중서라, **거기서 통한 것은 우리 4~6세에서 반드시 통한다**(위로 조금만 올리면 된다).

### 7.4 파일럿 앵커 ① — A-1 「화가 나면 털이 빨개져」

- **권 정보**(기획서 §5-A-1): 주제군 A 마음·감정 / 엔진 **오해와 반전**(§6 실측: 중앙값 500단어, **후렴 0/3 — 후렴 금지**) / 무대 **알프스 산마을** / 주인공 **여우**.
- **배정 판정**: **C6 단색조 + 악센트 1**. 🔴 이 권은 §2.9의 교과서다 — **빨강이 장식이 아니라 주인공의 상태 변수**이고, **안개**가 저정보 필드를 서사가 직접 제공한다. C1(나이브)은 전래동화와 4개 축이 겹쳐 위험, C4(형태)는 화·부끄러움을 못 그려 탈락.
- **분리 확인**: 종이 크림 ✕(차가운 회청 안개 필드) · 점눈 ✕(선으로 그린 눈+눈썹) · 색연필 낙서 ✕(석판 크레용의 눌러 칠한 결) → 점눈이·니들펠트 양쪽과 안 겹친다.
- 🔴 **파이프라인 순서**: 아래 STYLE ANCHOR 로 **먼저 캐릭터 시트를 굽는다** → 승인된 시트를 @image 로 붙여 12컷(§2.4). 시트 없이 장면부터 뽑으면 인물만 매끈한 CG로 나온다.

```
STYLE ANCHOR — changjak-A01 (fox / alpine / anger)

Style: a hand-printed picture-book page for 4-6 year olds, warm and quiet, not cute-glossy.

MEDIUM: lithographic crayon and oil pastel pressed onto slightly toothed paper.
  The grain of the paper breaks every stroke - colour sits in the tooth and skips on the ridges.
  Edges of shapes are made by the crayon running out, never by a clean vector line.
  Fog and air are laid in with the flat side of the crayon in long horizontal passes.
  Visible waxy build-up where colour is layered twice. No blending, no soft airbrush gradient.

PALETTE: a single cold grey-green fog dominates the whole page (roughly 80% of the surface),
  with warm paper-cream showing through the grain.
  EXACTLY ONE other colour exists on the page: a warm orange-red.
  The red appears ONLY on the fox's fur, and its AMOUNT is the story
```
