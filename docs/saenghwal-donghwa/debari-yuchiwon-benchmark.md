# 대발이 「유치원동화」 20편 전편 벤치마크

> 대발이TV(공룡 대발이) **「유치원동화」 20편 전편** 자막을 추출·분석(2026-07-15).
> 기존 [debari-benchmark](../../../memory 참조)는 **생활동화(배워요/만나요, 100+편)** 를 다뤘고,
> 이 문서는 **별개 완결 시리즈인 유치원동화 20편**(EP01~20)을 다룬다.
> ⚠️ ASR 자막이라 이름·표기 오타 많음 — **구조·톤·주제 분석용**(정확 인용 부적합).

## 시리즈 정체
- **대발이TV / 유치원동화 / EP01~20 완결 단편**(각 ~5~7분). 모음집이 5편 단위 4팩(01~05·06~10·11~15·16~20) + 전편 120분 모음 = 정확히 20편.
- **무대·가이드 고정**: **유치원 「별님반」 + 별님반 선생님**. 생활동화는 무대가 편마다 달랐지만, 유치원동화는 교실·선생님이 상수 → 시리즈감·안정감.
- **주제축 = 습관/안전이 아니라 '유치원 적응 + 사회정서'**: 분리불안·교사애착·질투·피해의식·정직·부끄러움·위생·안전.

## 전체 아크 — 01↔20 북엔드
- **01 오프너**: 대발이 혼자 남겨짐 → 친구들 다 유치원 감 → "나도 가고 싶다"
- **02~06 적응기**: 첫 등원(분리불안)·인사·배탈·교사애착·하루 일과 소개
- **07~19 별님반 일상**: 캐릭터 결점편 + 사회정서 13편
- **20 피날레**: 선생님 POV, "유치원 떠나기 싫어" → 01과 대칭(가고싶어↔떠나기싫어)

## 캐릭터 = 결점 1개 배역 (20편으로 확인)
- **대발이** 장난/미숙/허세 (주인공, 05·11·13·17·19)
- **뿔뿔이** 부끄러움/사회불안(03) + 걱정많음(08·12)
- **큰턱이** 먹보/깜빡/성급 (07·08)
- **말랑이** 산만/배탈 (04·08)
- **빠름이** 성급/허세/정직결핍 (11·16·19)
- **보들이·보송이** 우정/질투 (14)
- **파닥이** 위생/게으름 (18)
- **뾰족이** 피해의식 (15)
- **김목이** 모범생/화자 (06)
- **초록이** 관찰/탐정 (16)

## 생활동화 대비 진화점 (핵심 4)
1. **가이드 3층 구조** — 생활동화(엄마 or 또래)보다 발전: ①**선생님**(유치원 상시 가이드: 감정코칭·중재·우화·정상화·규칙) ②**엄마**(집) ③**할머니**(확장) + 또래. **선생님이 최대 신무기.**
2. **주제 = 습관/안전 → 유치원 적응 + 사회정서**. 집→기관 전환기의 감정·관계.
3. **관점 전환(인지 재구조화) 편 다수** — 15·17(피해의식→내 오해/잘못), 13·16(소외/미스터리의 진짜 이유). '마음 읽기'로 심화.
4. **북엔드 + 화자 전환**(01↔20, 걱정괴물·선생님 POV) → 시리즈감.
