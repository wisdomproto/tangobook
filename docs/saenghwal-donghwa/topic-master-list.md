# 호리네 생활동화 — 주제 마스터 리스트 (3사 분석 기반)

> 대발이(100화)·콩순이·페파 교차 분석 + 조회수 검증 + 탱고북 기존 18권 통합.
> 장치 = 분석에서 추출한 8대 스토리 장치 / 우선순위 P1(즉시·검증됨) > P2 > P3(확장).
> 캐스트 = 호리·엄마·아빠·호야(동생)·토토(토끼)·보리(곰)·콩이(다람쥐)·두부(강아지).

## 차용 장치 8종 (각 책의 뼈대)
- **리프레이밍**: 단점→장점, 싫은것→놀이 (대발이 나는나/목욕놀이)
- **인과**: 잘못된 습관→몸으로 결과 (대발이 배탈/충치/코피)
- **거울효과**: 내 행동·말이 그대로 돌아옴 (대발이 나눔/고운말)
- **점진수용**: "싫지 않았어요" 단계적 (대발이 동생)
- **상상역할극**: 무서운 걸 놀이로 (콩순이 병원=몸속 병사/의사놀이) ★우리 차별화
- **반복후렴**: 후렴송 + 가족 차례 반복구조 (대발이 수면)
- **명시교훈**: 마지막 한 줄 정리 (대발이 사과)
- **조력자 속정**: 무뚝뚝한 어른의 따뜻함 (대발이 할아버지)

## 출시 로드맵 제안
- **P1 (즉시 12권)**: 편식·양치·손씻기·배변·수면·병원·자기수용·사과·동생 + (정리·미아·화다스리기) → 검증된 인기 + 3사 공통 + 우리 보유분 우선.
- **P2 (확장 12권)**: 트랙별 2순위.
- **P3 (장기)**: 트랙7 일상 소재 무한 확장.

## 공통 작법 규칙 (모든 책 적용 — 3사 공식)
1. **작은 부정감정**으로 연다 (평화 묘사 금지).
2. **조력자 1명**이 ④비트에서 해결 (호리네 캐스트).
3. 편마다 **장치 1개**를 뼈대로.
4. **반복 후렴 1개** ("골고루 냠냠, 무지개 힘 쑥쑥!").
5. **의성어 매 페이지 + 제목=노래 오프닝**.
6. **결말 = 신체적 애정 + 교훈 1줄**, 항상 안전·따뜻하게.
7. **호리 시그니처 훅** 매 편 삽입(브랜드 정체성 — 페파 진흙탕 원리).
