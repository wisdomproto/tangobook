# 호리네 생활동화 P1 — 「주사 콕, 병균 뿅!」 (병원·주사)

> 커리큘럼 [curriculum-45.md](curriculum-45.md) 트랙C #15. 시그니처 장치 **상상역할극(몸속 병사)** 검증편.
> 포맷 = [cast-bible-and-pilot.md](cast-bible-and-pilot.md) §2 파일럿과 동일(10스프레드, 3인칭 해요체 + 대사).

- **주제**: 병원·주사 공포 극복
- **타겟 연령**: 3~5세
- **학습목표**: 주사를 무서워하던 아이가 "주사=병균 물리칠 약을 몸속 병사에게 배달"이라는 상상 프레임으로 용기를 내어 주사를 맞고, 병원이 나를 지켜주는 곳임을 안다
- **등장**: 호리(무서워하는 환자) · 엄마(조력자) · 코끼리 의사 선생님(상상 안내자) · (몸속 병사/병균 = 상상 캐릭터)
- **구조**: 5비트 — 일상→문제(공포)→증폭→전환(상상역할극)→도전·성공→자기수용+후렴
- **반복 후렴(전환·성공마다)**: *"주사 콕! 병균 뿅! 씩씩한 병사 나가신다!"*
- **분량**: 10 스프레드. 의성어 매 페이지 + 제목=오프닝.

## 집필 노트
- **장치 검증**: "몸속 병사" 상상역할극(콩순이식)을 P5~P8에 배치 — 공포 소재를 놀이로 뒤집는 우리 차별화 포인트. 병균은 **무섭지 않게(동글·바보스러운 얼굴)** 그려 유아 공포 최소화.
- **번호 규칙(안전편 필수, comic-editor 검수 반영)**: P7에 아이가 따라 할 3단계를 대사로 — "① 후~ 크게 숨, ② 팔 쭉, ③ 병사들을 생각해!"(호리가 실제 한 동작과 일치 → 주사 공포 극복 실전 도구).
- **은유 정확도 보정(comic-editor 검수 반영)**: 주사 = "병사에게 힘 주는 마법 물" → "병사를 도와줄 **약을 배달**"로 (백신/치료주사 뭉뚱그림 + P9 '약도 꿀꺽' 회복 인과 충돌 해소).
- **호리 시그니처 훅**: 무지개 부릉꼬리를 P8 승리 순간에 배치.
- **후렴**: "주사 콕! 병균 뿅! 씩씩한 병사 나가신다!" — P7·P10 반복. 리듬감(콕/뿅) 강조.
- **다음**: 이 대본으로 P1~P10 장면 이미지 생성(호리 캐스트 외형 키 고정) → TTS → 비공개 초안. cast-bible의 편식 파일럿과 세트로 P1 첫 2권.
