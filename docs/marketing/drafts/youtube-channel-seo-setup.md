## 6. Shorts 업로드 시 공통 설정 (참고)

- **카테고리**: 교육(Education)
- **아동용 여부(Made for Kids) = 아동용 아님(false) 확정** ✅ (2026-07-16 대표 확정)
  - 근거: 구매자·시청 결정자는 **부모**, 채널·CTA가 부모향 → 댓글·커뮤니티·개인화 노출 등 성장 기능 유지. 자동 업로드 스크립트 기본값도 false.
  - 채널 수준 설정(스튜디오 → 설정 → 채널 → 고급 설정 → "아동용으로 설정하지 않겠습니다")도 동일하게 맞춰 두면 편함.
- **재생목록**: `공룡 도감` / `자연관찰 동화` / `세계 명작동화` 3개를 만들어 두면 자동 분류 + 세션 시간↑.
- **해시태그**: 영상 설명 하단에 3~5개 핵심(#공룡 #유아교육 #그림책 #Shorts …) — 매핑표에 이미 들어 있음.
- **설명 링크 = 책별 딥링크**: 각 영상 설명은 홈이 아니라 **방금 본 그 책의 상세 페이지**(`www.tangobook.co.kr/library/{id}/about`, SSR 실존·200 확인)로 보냄 → "방금 본 그 공룡을 바로 그림책으로" 전환. 매핑표 `deeplink` 컬럼 + 자동 업로드 스크립트에 반영됨.
