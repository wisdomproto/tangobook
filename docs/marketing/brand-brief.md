## 1. ICP (타겟 페르소나)

키즈 앱 특유의 **듀얼 페르소나** — 결제자(부모)와 사용자(자녀)가 다르다. 둘 다 충족해야 한다.

- **자녀**: 만 **4~8세** (학습만화 확장 시 6~8세 신규 유입). 매일 켤 이유 = 콘텐츠 깊이(같은 동화 그림체 4종, 어휘 게임).
- **부모**: 교육열 높고 프리미엄/구독 수용도 높은 학부모. 매월 결제를 유지할 이유 = **측정 가능한 학습 진전**(주간 리포트: "○○이 어휘 12개↑, 동화 5권 완독").
  - 한국: 검색의 60%+가 네이버. 거점 = 맘카페(맘스홀릭·맘이베스트 등)·카톡 오픈채팅(양육/영어교육)·학부모 페북 그룹.
  - 동남아: 영어 사교육 갈증↑, 디지털 확산, 가격 민감도 높음.

**핵심 페인포인트**: ① 매일 동화 읽어주기 힘듦(시간/노력) ② "AI 양산 동화"의 함정·불안 ③ 학습이 실제로 되는지 측정 불가 ④ 광고 노출 스트레스.
**구매 동기**: 측정 가능한 학습 진전 = 결제 명분 · **광고 완전 제거** · 큐레이션된 콘텐츠 신뢰.

## 2. 핵심 포지셔닝 (2개 레이어 — 모순 아닌 단계)

> Phase 1에서 **부모를 모으고**(큐레이션 명작이 마중물), Phase 2에서 **작가를 영입**(오픈 마켓플레이스). 단기 메시지와 장기 비전을 레이어로 구분해서 쓴다.

- **단기 (제품/마케팅 메시지)**: *"AI 양산 동화가 넘치는 시대 — 탱고북은 **반대 방향**으로 간다."* 큐레이션된 명작 + 그림체 4종 + 어휘 게임 + 부모 학습 측정의 **깊이**.
- **장기 (투자/비전 메시지)**: *"넷플릭스처럼 보고, 웹툰처럼 누구나 만드는 글로벌 키즈 동화책 마켓플레이스."* 명작 콘텐츠는 부모를 모으는 **seed(마중물)**, 작가 개방은 그 다음 단계.

**메시지 기둥**
1. **큐레이션된 명작 깊이** (AI 양산이 못 가진 차별점)
2. **같은 동화, 그림체 4종** — 무한 그림체 자유도(AI 시대 표준)
3. **한/영 듀얼 언어** → 다국어 카탈로그
4. **측정 가능한 학습** (부모 리포트)
5. *(장기)* **작가 등단 채널** — 만화·웹소설처럼 동화책에도 비어있는 오픈 플랫폼 자리

## 3. 브랜드 보이스

> 출처: `docs/strategy-deck-rules.md`(명시 규칙) + deck/플레이북 어조. 🚩 표시는 **추론 초안 — 사용자 검수 필요**.

**해야 할 표현**
- 정직·가치 중심, 인과로 풀어쓰기(단언 X). 따뜻하고 일상적인 톤(자녀 "○○이" 화법).
- 자랑은 **시스템·구조·차별화·검증된 모델 적용**으로. 미검증 수치는 "~하도록 **설계**", "~ **목표**"로 프레이밍.
- 전문용어는 처음 나올 때 한 줄 풀이: 파닉스="글자와 소리를 연결해 스스로 읽는 법" · retention="30일 후 재방문율".
- AI는 **멀티모달 스택(Gemini·Grok·Whisper, 영역별 최적)**으로 표기 — 단일 모델 강조 금지.

**금지 표현**
- 과장·단정: "압도", "N배 우위", 경쟁사 직접 비교("Netflix보다").
- 작은 절대 숫자 자랑("233권", "9 카테고리").
- 강압적 바이럴("공유 안 하면 차단"), 또래 비교("상위 35%").

**채널별 톤 분리**
- 자체 블로그 = 깊이·정보(풀버전) / 네이버 블로그 = 친근·일상(발췌 + 자녀 후기 톤).

🚩 *위 "해야/금지"의 일상 톤·화법 부분은 deck 어조에서 추론한 초안입니다. 사장님 검수 후 확정해주세요.*

## 4. 글로벌 전략 (축 = 국가가 아니라 **언어**)

- 지원 언어 6종: **한글(ko) · 영어(en) · 베트남(vi) · 태국(th) · 중국어 간체(zh-CN) · 중국어 번체(zh-TW)**.
- **Phase 1**: 한글 + 영어 먼저 출시 → 한국 시장에서 테스트하며 콘텐츠 확장.
- **Phase 2**: vi · th · zh-CN · zh-TW를 **한꺼번에 글로벌 동시 출시**.
- 동화 콘텐츠는 다국어로 꾸준히 증가 (콘텐츠 출시 자체가 마케팅 이벤트 — §6).

## 5. 채널 믹스

- **오가닉 (모든 언어 기본 수행)**: 구글 SEO·자체 블로그 / 네이버 블로그(한국) / **YouTube 듀얼 채널(최우선)** / SNS·핀터레스트 / 커뮤니티 침투(맘카페·오픈채팅·페북 그룹).
- **유료광고 (선택적 레버 — "어느 시장에 돈 쓸지"만 결정)**: 메타 우선(학부모 친화) · 구글/네이버 검색 · 카톡 알림톡. 한국 베타 기준 가입 비중 ~15%, 후반(W4~W12)에만.
- 참고 비중(한국 베타): SEO 30% · 커뮤니티 22% · 인플루언서·PR 18% · 유료 15% · 바이럴/초대 15%.

## 6. 성장 루프

- **CORE LEVER**: 7일 무료체험 → **친구 초대 시 7일 연장** (베타에선 "1회 공유 = 1주일 무료").
- **초대 사다리**(베타 예시): 1명→+1개월 · 3명→정식 후 3개월 · 5명→6개월+굿즈 · 10명→1년+풀세트(명예 멤버). K-factor 목표 ≥ 1.5.
- **바이럴 자석 5종**(가입 가구가 발사대): ①학습 그래프 카톡 공유 ②좋아한 동화 인스타 카드 ③그림체 4종 비교 캐러셀 ④월말 성장 PDF 가족 공유 ⑤친구 초대. 인프라: `og-invite.png`, 레퍼럴 게이팅.
- **콘텐츠 루프**: 풀스펙 1개 출시 = 신규 획득 + 리텐션 트리거 + 자녀 챌린지 + 부모 리포트 → "1 풀스펙 ≈ 12개 마케팅 콘텐츠". 발행 캘린더 = 캠페인 캘린더.
- **⭐ 포인트**: 정식 런칭(M3+)에만 도입. **베타엔 절대 도입 X**(리텐션 동인이 콘텐츠인지 포인트인지 변수 통제 위해).

## 9. 시장별 노트 (진화의 자리)

- **ko (Phase 1)**: 네이버 중심(검색 60%+). 듀얼 블로그(자체=깊이/네이버=발췌·일상). 유료=메타 우선. 키워드 Naver 우선.
- **en (Phase 1)**: 구글·YouTube·핀터레스트. 명작 LOW 경쟁 키워드(wizard of oz 등)가 SEO 자석.
- **vi (Phase 2)**: *미정* — 동화 152권(vi) 번역 완료 자산 보유. 가격 민감도 높음.
- **th (Phase 2)**: *미정*.
- **zh-CN (Phase 2)**: *미정*.
- **zh-TW (Phase 2)**: *미정*.
