# 탱고북 마케팅 브리프 (Brand Brief)

> **2026-10-05 목표 시장 표현 최종 정정:** “동남아와 몽골” 대신 **아시아**로 통일한다. **아시아 미취학 아동을 위한 언어 학습 플랫폼**, 한국에서 시작해 아시아로 확장. 인도네시아·말레이시아·태국·몽골·베트남 등은 구체적인 국가 사례로 남긴다. 언어별 파닉스·다국어 동화의 확장 방향은 유지하며 국가별 진출 순서는 미정이다. 이전 기록의 지역 나열은 이 표현으로 갱신한다.


> **2026-10-05 도입부 시장·K-edu 방향:** 아시아 유아교육·보육 수요의 확장 → K-edu → 유료 플랫폼 학습 언어·가격 → 탱고북의 다국어 기회 순으로 설명한다. 사용자 정의 **K-edu = 한국식 교육 + 한국어**. 보육서비스의 아시아·태평양 민간 시장 전망과 OECD 취학률 자료는 큰 시장의 맥락이며, 언어 앱 TAM으로 옮기지 않는다. 한국어 수요는 세종학당 전 세계 수강생·거점 자료, 한국식 교육은 한국 교육기업의 실제 해외 서비스 사례로 보여준다. 미취학 수요·탱고북 성과를 입증한 것으로 쓰지 않는다.


> **2026-10-05 아시아 확장·경쟁 비교 갱신:** 첫 소개는 **“아시아 미취학 아동을 위한 언어 학습 플랫폼”**. 한국에서 시작해 동남아(인도네시아·말레이시아·태국 등)와 **몽골**까지 확장한다. 주요 동남아 자국어와 몽골어의 언어별 파닉스, 번역 동화로 자국어·영어·한국어·중국어 학습을 연결한다. 국가별 진출 순서·제작 일정은 미정이다. 첫 장에 ABCmouse Classic·Lingokids Plus·Reading Eggs·VMonkey의 공식 학습 언어·연령·유료 가격 비교를 넣는다. “아시아 자국어 전무”나 모두 미국 제품이라고 단정하지 않는다. VMonkey 공식 소개에서 한글 과정은 확인되지 않았다. **경쟁사의 노후화·업데이트 부족이나 콘텐츠로 이긴다는 주장은 하지 않는다.** 탱고북 콘텐츠 양·퀄리티는 실제 자산으로 보여주되 경쟁사보다 우수하다는 근거로 쓰지 않는다. 무료 전용 플랫폼 제외는 경쟁 비교 범위이며 무료 콘텐츠 오가닉 유입은 유지한다.


> **2026-10-05 목표·언어 범위 최종 정정:** **목표는 동남아, 시작은 한국**이다. 한국을 시험용 시장으로만 설명하거나 동남아를 막연한 글로벌 확장의 일부로 두지 않는다. 동남아 미취학 아동이 **자국어·영어는 기본, 한국어·중국어 등 추가 언어도 배우는 다국어 플랫폼**을 만든다. 파닉스는 한글·영어에 한정하지 않고 **주요 동남아 언어의 콘텐츠도 모두 제작**하는 방향이다. 동화책은 기존 이야기·그림에 번역과 언어별 음성·어휘를 연결해 확장한다. 안내 언어와 학습 언어를 구분한다. 국가별 진출 순서·주요 언어의 구체 목록·제작 일정은 아직 미정이며, 계획을 현재 구현 완료로 보고하지 않는다. 앞선 “글로벌, 특히 동남아”·“한국 점검 시장” 표현은 이 결정으로 구체화·정정한다.


**핵심 학습 가치 (2026-10-05 사용자 확정): 어휘력과 문해력.** 미취학 아동이 낱말의 뜻과 쓰임을 익히고, 글과 이야기를 이해하며 자기 생각을 표현하는 기초를 파닉스·동화·활동으로 함께 쌓는다.

> **2026-10-05 1차 타깃 확정:** 미취학 아동. 아이가 직접 사용하는 플랫폼이며 부모는 첫 체험·학습 가치 확인을 지원한다. 관심 소재와 언어별 학습 기록을 바탕으로 다음 책·놀이·복습을 제안하는 맞춤형 학습을 설계한다. [팀 공유 플랫폼 문서](branding-organic-strategy-2026-10-05.md)에서 콘텐츠·아날로그·다국어·AI 효율·양과 깊이의 지속 확장 구조를 설명한다. 추천·리포트의 구현 상태는 구분한다.

> **2026-10-05 리포팅 차별점 확정:** 아이의 어휘 노출·활동·파닉스 이력을 상세히 분석하는 학습 현황 리포팅을 핵심 제품 가치와 마케팅 포인트로 삼는다. 부모가 무엇을 만나고 어떻게 연습했으며 다음에 무엇을 하면 좋을지 이해하게 한다. 노출량을 습득으로 단정하지 않고 활동별 근거를 구분한다. 세부 기준과 구현은 후속 과제다.

> **2026-10-05 콘텐츠 설명 기준 갱신:** 목표는 아이의 첫 언어 떼기. 파닉스(학습)와 동화책(학습·재미)을 어휘와 독후활동으로 연결한다. 먼저 실제 한글·영어 파닉스와 책 구성을 충분히 설명하고 아날로그·글로벌 기획을 설명한다. 수익 설명은 뒤로 둔다. 사용자 정정에 따라 역방향은 **동화 → 독후활동 → 관련 파닉스**이며 읽기 중 직접 이동을 주 경로로 삼지 않는다. 역방향은 추가 설계 제안이다.

> **2026-10-05 참조 대화 반영:** ‘유입 중심축 제안’의 **브랜드는 넓게, 첫 유입 메시지는 선명하게**를 원문·HTML에 추가했다. 브랜드 후보는 ‘아이들이 이야기와 놀이를 통해 스스로 배우는 K-에듀 플랫폼’, 유입 후보는 ‘공부시키지 않아도, 아이가 먼저 찾는 놀이학습’. 한국 한글·파닉스 입구는 검증 가설이며 확정 카피·성과가 아니다. 현재 목표는 온라인 체험·체류·재방문, 수익화는 후속. 채널 우선순위·제작량은 미확정.

> **2026-10-05 현재 목표 정정:** 온라인 콘텐츠 유입·체류·재방문 우선, 수익화는 이후. 아날로그 구매 친숙함은 이후 수익화 가능성으로 설명하며 현재 CTA를 교구 구매로 정하지 않는다. 구체적 오가닉 실행 전략은 사용자와 논의 중이다.

> **2026-10-05 독후활동 표현 확정:** 동화·파닉스 원본 콘텐츠마다 블록 맞춰보기·써보기·색칠하기 등의 독후활동이 붙는다. 아이에게 재미를 주는 콘텐츠로 설명하고, 디지털·아날로그·디지털–아날로그 연계는 구현 방식으로 구분한다. 캠페인에는 원본·독후활동·제공 방식·현재 지원 상태를 함께 기록한다.

> **2026-10-05 글로벌 목표 확정:** 글로벌·동남아 목표와 **K-에듀**를 메시지에 반영한다. 한국 검증 → 다국어 구조 활용 → 현지 맥락의 오가닉 체험 → 해외 반응 확인 순서로 제안한다. “한국에서 먹히면 어느 나라든 먹힌다”는 전략 신념이며 모든 나라의 효과·매출 보장 문구로 쓰지 않는다. 우선 국가·언어·일정은 미확정, 한국은 첫 검증 시장이다.

> **2026-10-05 제품명 확정:** 플랫폼은 탱고북, 블록 제품군은 탱고 블록(탱고 한글 블록·탱고 영어 블록), 쓰기 놀이 제품은 탱고 노트. 현재 기획/카피에서 이 이름을 사용한다. 플레이노트는 과거 제품과 공식 출처 설명에만 남긴다. 연계 예정 상태는 유지한다.

> **2026-10-05 메시지 정정:** 재미의 핵심 가치는 **아이의 자기주도 학습**이다. “반복 이용의 이유”에서 멈추지 않고, 아이가 재미를 느껴 스스로 시작·선택·지속하는 배움으로 설명한다. 반복 이용은 관찰 지표로 구분한다. 사용자 직접 정정이며 HTML·전략 원문에 반영했다.

> **2026-10-05 실행 기준 갱신:** 현재 방향은 **부모에게 학습 가치, 아이에게 재미**를 주는 플랫폼이다. 파닉스·동화·색칠·블록·쓰기·아날로그 연계를 함께 설명하고 초기에는 오가닉에 집중한다. [새 브랜딩·오가닉 전략](branding-organic-strategy-2026-10-05.md)을 현재 실행 초안으로 사용한다. 아래 과거 그림체 4종·마켓플레이스·초대 보상·유료 비중·채널 수치는 역사적 기록이며 현재 캠페인의 확정 근거로 사용하지 않는다. 새 슬로건·발행량·무료 범위·가격은 제안 또는 미결이다.

## 1. ICP (타겟 페르소나)

키즈 앱 특유의 **듀얼 페르소나** — 결제자(부모)와 사용자(자녀)가 다르다. 둘 다 충족해야 한다.

- **자녀**: 1차 타깃은 **미취학 아동** (2026-10-05 확정). 좋아하는 이야기와 직접 하는 놀이를 스스로 고르고 이어가는 경험을 제공한다.
- **부모**: 교육열 높고 프리미엄/구독 수용도 높은 학부모. 매월 결제를 유지할 이유 = **측정 가능한 학습 진전**(주간 리포트: "○○이 어휘 12개↑, 동화 5권 완독").
  - 한국: 검색의 60%+가 네이버. 거점 = 맘카페(맘스홀릭·맘이베스트 등)·카톡 오픈채팅(양육/영어교육)·학부모 페북 그룹.
  - 동남아: 영어 사교육 갈증↑, 디지털 확산, 가격 민감도 높음.

**핵심 페인포인트**: ① 매일 동화 읽어주기 힘듦(시간/노력) ② "AI 양산 동화"의 함정·불안 ③ 학습이 실제로 되는지 측정 불가 ④ 광고 노출 스트레스.
**구매 동기**: 측정 가능한 학습 진전 = 결제 명분 · **광고 완전 제거** · 큐레이션된 콘텐츠 신뢰.

## 2. 핵심 포지셔닝 (2개 레이어 — 모순 아닌 단계)

> 🔴 **2026-09-04 폐기.** 아래 「웹툰처럼 누구나 만드는 마켓플레이스」 비전은 **사용자가 없던 일로 했다.**
> "우리가 끝까지 책임진다"와 정반대이기 때문이다. **이 절을 카피 근거로 쓰지 말 것.**
>
> 확정 정체성 = **「첫 글자부터 혼자 읽기까지. 자기 말로, 그리고 영어로.」**
> → [../STRATEGY.md](../STRATEGY.md) §1. 이 절은 다시 쓸 때까지 사문(死文)으로 남긴다.

> Phase 1에서 **부모를 모으고**(큐레이션 명작이 마중물), Phase 2에서 **작가를 영입**(오픈 마켓플레이스). 단기 메시지와 장기 비전을 레이어로 구분해서 쓴다.

- **단기 (제품/마케팅 메시지)**: *"AI 양산 동화가 넘치는 시대 — 탱고북은 **반대 방향**으로 간다."* 큐레이션된 명작 + 그림체 4종 + 어휘 게임 + 부모 학습 측정의 **깊이**.
- **장기 (투자/비전 메시지)**: *"넷플릭스처럼 보고, 웹툰처럼 누구나 만드는 글로벌 키즈 동화책 마켓플레이스."* 명작 콘텐츠는 부모를 모으는 **seed(마중물)**, 작가 개방은 그 다음 단계.

**메시지 기둥**
1. **큐레이션된 명작 깊이** (AI 양산이 못 가진 차별점)
2. **같은 동화, 그림체 4종** — 무한 그림체 자유도(AI 시대 표준)
3. **한/영 듀얼 언어** → 다국어 카탈로그
4. **측정 가능한 학습** (부모 리포트)
5. *(장기)* **작가 등단 채널** — 만화·웹소설처럼 동화책에도 비어있는 오픈 플랫폼 자리

## 3. 브랜드 보이스

> 출처: `docs/strategy-deck-rules.md`(명시 규칙) + deck/플레이북 어조. 🚩 표시는 **추론 초안 — 사용자 검수 필요**.

**해야 할 표현**
- 정직·가치 중심, 인과로 풀어쓰기(단언 X). 따뜻하고 일상적인 톤(자녀 "○○이" 화법).
- 자랑은 **시스템·구조·차별화·검증된 모델 적용**으로. 미검증 수치는 "~하도록 **설계**", "~ **목표**"로 프레이밍.
- 전문용어는 처음 나올 때 한 줄 풀이: 파닉스="글자와 소리를 연결해 스스로 읽는 법" · retention="30일 후 재방문율".
- AI는 **멀티모달 스택(Gemini·Grok·Whisper, 영역별 최적)**으로 표기 — 단일 모델 강조 금지.

**금지 표현**
- 과장·단정: "압도", "N배 우위", 경쟁사 직접 비교("Netflix보다").
- 작은 절대 숫자 자랑("233권", "9 카테고리").
- 강압적 바이럴("공유 안 하면 차단"), 또래 비교("상위 35%").

**채널별 톤 분리**
