## 3. 공통 패턴 (이 카테고리가 공유하는 것)

1. **히어로에 가격을 안 둔다 — 4곳 전부.** 첫 화면은 "무엇인가/왜 좋은가"이고 가격은 별도 페이지 또는 하단. CTA는 전부 `무료체험`/`상담`이지 `월 ○○원`이 아니다.
2. **신뢰장치를 페이지 중후반에 몰아 둔다.** 콘텐츠 설명으로 먼저 설득하고, 수상·후기·수치는 그 다음. 히어로엔 대표 신뢰 신호 1개만(핑크퐁 "교사 추천", 웅진 "AI 1등 각주").
3. **"이유 N가지"를 넘버링한다 (Point 01~05).** 핑크퐁·웅진 모두 동일. **정보를 번호로 매기는 것 자체가 "체계적"으로 보이게 하는 핵심 장치**다 — 각 포인트 = 헤드라인 + 한 줄 서브카피 + 전용 시각자료 하나, 리듬이 일정.
4. **수치에는 반드시 근거 각주.** 웅진 "AI 1등: 2024.11 특허 등록 건수 기준", 아이스크림 "78%(2026.5 기준)". 맨숫자보다 각주 붙은 숫자가 전문적으로 읽힌다.
5. **아이콘 시스템으로 특징을 묶는다.** 핑크퐁의 구독 특징 4개(광고차단/전체해제/기기호환/취소)는 아이콘+타이틀+한 줄. 흩어진 문장보다 신뢰감이 크다.
6. **콘텐츠 수치 = 라이브러리 모델의 대표 신뢰장치.** 후기가 약해도 "30+앱·3,000종·20,000편"이 규모를 증명한다. 우리에게 그대로 이식 가능한 유일한 축.
7. **"광고 없음"을 유료의 근거로 판다** (핑크퐁 "광고 완벽 차단"이 히어로 4가치 중 하나). 무료의 싸구려 신호를 피하고 유료를 정당화하는 카피.

## 4. 우리에게 적용할 것 (규칙 안 어기고)

> "이미 정해진 것"(무료 금지·마감일 금지·비교표 금지·불안금지·가르치는법설명 금지·오퍼는 한달체험+할인가·라이브가 최강주장)을 하나도 안 어기는 선에서.

### 4-1. 「왜 탱고북인가」를 넘버링 포인트로 (★ 전문성의 핵심)
현재 ②~⑤는 섹션이 흐르지만 **"이유 N가지"의 위계가 없다.** 경쟁사가 공통으로 쓰는 Point 01~05 구조가 페이지를 "체계적"으로 보이게 하는 최대 장치다. 우리 메시지 기둥을 넘버링 3~4개로 재배치:
- **01. 배우고, 그 글자로 바로 읽습니다** — 파닉스 71단원 + 동화책 266권이 한 앱에.
- **02. 한 낱말을 네 방식으로** — 그림·조립·따라그리기·쓰기 (이미 본문에 있는 문장을 포인트로 승격).
- **03. 읽은 게 글자 공부로 돌아옵니다** — 파닉스↔진도 연동 (현재 ⑤ 끝에 묻혀 있음 → 독립 포인트로).
- **04. 설치도 약정도 광고도 없습니다** — 아래 4-3.

각 포인트 = 짧은 헤드라인 + 한 줄 + 우리가 이미 가진 **라이브/사진** 하나. 지금 콘텐츠를 재배치만 해도 된다(신규 제작 불필요).

### 4-2. 수치에 근거 각주를 붙인다 (★ 후기 없이 전문성 만드는 법)
FACTS는 이미 실측이다. 그런데 화면엔 맨숫자로만 나온다. **작은 각주 한 줄**을 붙이면 웅진·아이스크림처럼 "근거 있는 숫자"로 읽힌다:
- "동화책 266권" → 아래 회색 각주 "2026-08 기준, 앱에 실제 공개된 권수". 현재 ⑥ 섹션 소개문("앱에 실제로 들어 있는 것만")을 **각 숫자 밑 각주로 내리면** 전문성이 산다.
- 이건 우리의 후기 대체재다. 후기가 "남이 좋다더라"라면, 근거 각주는 "직접 세어 검증 가능"이라 오히려 신뢰 축이 다르다.

### 4-3. 「없는 것」을 아이콘 세트로 묶는다
현재 "설치 없음·약정 없음·광고 없음"이 요금 섹션 문장에 흩어져 있다. 핑크퐁 구독특징 4개처럼 **아이콘+한 줄 카드 세트**로 묶으면(예: `📵 광고 없음` `🔓 전체 개방` `📺 TV·폰·태블릿` `🚫 약정·설치 없음`) 시각적 신뢰감이 커지고, "광고 없음"이 유료 근거로 자연스럽게 선다(핑크퐁이 검증한 카피 전략, 우리 브랜드 페인포인트 ④와도 정합).

### 4-4. 콘텐츠 수치 = 우리의 대표 신뢰장치임을 인정하고 밀어라
후기·수상이 없는 우리에게 **콘텐츠 수치가 라이브러리 모델의 정통 신뢰장치**다(핑크퐁 30+앱, 리틀팍스). 표지벽·카테고리칩·라이브 활동은 이미 그 역할을 한다. 여기에 4-1(넘버링)+4-2(각주)를 얹으면, 후기 없이도 핑크퐁급 신뢰 구조가 된다.

### 4-5. 히어로 신뢰 신호 1개 (선택)
경쟁사는 히어로에 대표 신뢰 신호 1개를 둔다(핑크퐁 "교사 추천", 웅진 "AI 1등"). 우리가 규칙상 쓸 수 있는 것 = **"실제 앱 화면이 이 페이지에서 돕니다"** 문구를 히어로 근처로 끌어올리기(현재 ④에만 있음). 이게 우리의 유일무이한 히어로 신뢰 신호다("스크린샷 아님").

| **수상/인증 배지** | ✕ | 받은 상이 없다. 가짜 배지 금지. |
| **누적 회원수(230만 류)** | ✕ | 베타라 자랑할 절대 숫자가 없다. **작은 숫자 자랑은 브랜드 보이스 금지**(brief §3). 콘텐츠 수치로만 규모를 말한다. |
| **재가입율·재선택율** | ✕ | 데이터 없음. |
| **경쟁사 이름·가격 비교표** | ✕ | **2026-08-05 의도적으로 제거**. 벤치마킹은 배우려는 것이지 남 상품 소개가 아니다(전사 규칙). |
| **상담 폼(전화 방문판매)** | ✕ | 우리는 셀프서브 구독. 전화 영업 모델 아님. |
| **불안 프레임**("성적 고민 끝"·"잊는다") | ✕ | 불안으로 팔지 않기(전사 규칙). 아이스크림/웅진의 "성적" 톤은 우리 4~7세 한글떼기와도 안 맞음. |
| **마감 날짜·긴급성 배너** | ✕ | 오퍼 접을 때 발목(전사 규칙). |
| **히어로에 가격 노출** | △ 유지 | 경쟁사는 전부 가격을 숨기지만(공통패턴 1), 우리는 히어로 가격을 **유지**한다 — "패드도 약정도 없다"는 우리 포지셔닝은 **가격 투명성 자체가 차별점**이라 숨기면 무기를 버리는 것. 단 요금 상세는 지금처럼 하단에. |

## 6. 한 줄 요약

경쟁사가 "전문적으로 보이는" 이유는 화려함이 아니라 **① 넘버링된 이유 구조 ② 근거 각주가 붙은 수치 ③ 아이콘으로 묶인 특징 ④ 중후반에 몰아둔 신뢰장치**다. 우리는 이 중 후기·수상만 못 쓰고 나머지는 다 쓸 수 있다. 우리가 못 쓰는 후기 자리는 **라이브 체험 + 콘텐츠 수치 + 근거 각주**가 이미 대신하고 있으니, 그것들을 넘버링·각주·아이콘으로 **구조화**하는 것이 이번 개선의 핵심이다. 신규 콘텐츠 없이 재배치만으로 가능하다.
