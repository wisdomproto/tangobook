# 네이버 블로그 세팅 — blog.naver.com/tangobooks

> 이미지는 `node packages/server/scripts/generate-naver-blog-assets.mjs` 로 재생성한다(멱등).
> 문구를 바꾸면 스크립트의 SVG 를 고치고 다시 굽는다 — 손으로 만든 PNG 를 덮어쓰지 말 것.

## 1. 이미지 (생성 완료)

| 파일 | 규격 | 쓰는 곳 |
|---|---|---|
| `cover-pc.png` | 966×**300** | 꾸미기 설정 → 타이틀 꾸미기 (PC 커버) — 영역 높이도 300 |
| `cover-mobile.png` | 1080×1300 | 기본 설정 → 블로그 정보 → **모바일앱 커버 이미지** |
| `profile-felt.png` | 286×286 | 기본 설정 → 블로그 정보 → 프로필 이미지 |
| `profile-3d.png` | 286×286 | 위 대신 (택1 — 아래 참고) |

🔴 **프로필은 둘 중 하나만 고른다.** 호리 렌더가 두 종류라 섞으면 같은 캐릭터가 달라 보인다.
- `profile-felt` = 니들펠트. **인스타그램 프로필과 같은 그림** → 채널 간 일치.
- `profile-3d` = 로고·커버와 같은 3D → 블로그 안에서의 일치.
채널을 넘나드는 사람보다 블로그 안에 머무는 사람이 많으므로 **`profile-3d` 를 권한다.**
(단 인스타를 주력으로 키울 생각이면 `felt` 로 통일하는 게 맞다.)

🔴 **모바일 커버에 글자를 넣지 않았다.** 네이버 앱이 그 위에 블로그명·프로필을 겹쳐 그려서,
글자를 넣으면 둘 다 안 읽힌다. 분위기(호리+배경)만 둔다.

## 2. 텍스트 — 관리 → 기본 설정 → 블로그 정보

글자 수 제한(화면 실측): 블로그명 **25자** · 별명 **10자** · 소개글 **200자**.

**블로그명** (검색 결과에 그대로 노출 + C-Rank 주제 판단에 쓰임) — 21자
```
탱고북 | 4~7세 동화책·한글 파닉스
```
주제어(`동화책`·`파닉스`)를 넣은 이유 = 개별 글은 작품명으로 유입되지만,
블로그 자체가 무슨 주제인지는 블로그명이 가장 큰 신호다.

**별명** (댓글·이웃 목록에 노출)
```
탱고북
```

**소개글**
```
아이와 함께 읽는 동화를 만듭니다.
세계명작·전래동화·자연관찰 동화를 그림과 함께 소개하고,
한글 파닉스와 어휘 학습까지 이어지도록 담았습니다.
평일 하루 한 편씩 올려요. → tangobook.co.kr
```

**내 블로그 주제** (필수) → **육아·결혼**

이 화면에서 가장 중요한 항목이다. C-Rank 가 블로그의 주제 전문성을 판단할 때 직접 쓴다.
`문학·책` 은 성인 도서 리뷰가 주류라 유아 그림책 글이 겉돈다. 우리 독자는 아이가 아니라
**부모**고, 실측 키워드(`분리불안`·`배변훈련`)도 육아 쪽이다. 나중에 변경 가능 —
7주차 유입 판정에서 자연관찰이 압도적이면 그때 재검토.

**연령그룹** 「연령 정보로 검색 및 추천 허용」 = 켜도 무방(타겟 부모층과 연령대가 겹친다).
⚠️ 검증한 게 아니라 추론이고, 영향도 크지 않을 것.

## 3. 카테고리

🔴 **처음부터 다 만들지 않는다.** 빈 카테고리는 방치된 블로그로 보인다.
첫 6주 측정 구간에 실제로 글이 들어가는 것만 만든다.

```
├ 자연관찰 동화      ← 주력(70%)
├ 전래동화           ← 측정(20%)
├ 세계명작 동화      ← 측정(10%)
└ 탱고북 이야기      ← 공지·서비스 소개
```

7주차 판정 뒤 주력이 바뀌면 그때 순서를 바꾸고,
호리 3라인(생활·유치원·세상탐험)은 발행을 시작할 때 추가한다.

## 4. 설정 체크리스트

**확실한 것**
- 관리 → **기본 설정** → 블로그 정보: 블로그명·별명·소개글·프로필 이미지
- 관리 → **꾸미기 설정** → 타이틀 꾸미기: `cover-pc.png`
- 관리 → **메뉴·글 관리** → 블로그: 카테고리 4개 생성
- 모바일 앱 → 내 블로그 → 홈편집: `cover-mobile.png`

**⚠️ 확인 필요 — 메뉴 이름을 검증하지 못했다**
(이 환경에서 `blog.naver.com` 접근이 정책상 차단돼 실물 화면을 못 봤다)
- **검색엔진 수집 허용**: 기본 설정 안에 외부 검색엔진(구글 등) 수집 허용 항목이 있다.
  꺼져 있으면 구글 유입이 통째로 막히므로 **반드시 켜져 있는지 확인**.
  네이버 자체 검색은 이 설정과 무관하게 수집된다.
- **RSS / 전체공개**: 글 공개 범위가 전체공개인지.

**나중에**
- 애드포스트(수익) — 글 50편쯤 쌓인 뒤
- 이웃 커넥트 위젯

## 5. 발행 전 확인

- 하루 **1~2편**. 152→251편을 몰아 올리면 신규 블로그는 저품질로 간다.
- 발행기 CLI 기본값 `--limit 1` (naver-blog-publisher 브랜치, Chunk 3 에서 배선)
- 7주차에 **관리 → 통계 → 유입분석 → 검색 유입 검색어**로 라인별 **편당 유입** 비교
  (총 유입으로 비교하면 편수 많은 자연관찰이 자동으로 이긴다)
