1한 페이지 요약 (TL;DR)

이번 분석에서 결정된 5가지

  • "파닉스" 단어 정공법은 피해라 — 검색량 8,120/월이지만 경쟁강도 "높음". 대신 한글떼기·영어발음·5세책추천 같은 보조 키워드가 진짜 골드.
  • 경쟁사 브랜드 검색량이 폭발적 — 리딩게이트 41,700/월, 윙크 19,850/월, 핑크퐁 17,010/월. "vs / 비교 / 단점 / 대안" 콘텐츠로 흡수하는 게 최단거리.
  • "영어발음" (7,590, 낮음) 같은 작은 단위 학습어가 골드 — 보조 키워드 클러스터로 트래픽 자산 빌딩.
  • 글로벌 진출 시 "alternative" 페이지가 최강 — ABCmouse 76,000/월 (CPC $1.36), Starfall 134,000/월, Reading Eggs 19,000/월. "abcmouse alternative"가 최저 비용 고전환.
  • AI 동화책 카테고리 신생 윈도우 — Google Gemini Storybook 런칭(2025-08) 이후 급성장 중. 난이도 낮음. 지금 들어가야 1년 후 #1.

🇰🇷 한국어 데이터 (실측)

네이버 검색광고 API /keywordstool 직접 호출 — 시드 79개 키워드 + 관련 키워드 발굴(includeHintKeywords=1)로 총 4,024개 고유 키워드의 PC/모바일 월간 검색량, 경쟁강도(낮음/중간/높음), 광고 평균 노출위치를 수집. 이후 우리 제품 관련 정규식 필터로 1,942개 추출 → 카테고리화 → 기회점수(검색량 × 경쟁 가중치) 산출.

🌐 글로벌(영문) 데이터

Similarweb 경쟁사 트래픽 인텔리전스 + Ahrefs 미러(ahrefstop.com) + WordStream 2025 Google Ads 벤치마크 + 시장보고서(AI 튜터링 시장). 경쟁사 브랜드 키워드는 verified 실데이터, 비브랜드 키워드 일부는 "no public data — 광고계정 키워드 플래너로 검증 필요"로 명시.

⚠️ 가짜 데이터 0개 정책 · 본 문서의 모든 검색량 수치는 출처가 명시된 실측값이다. 공개되지 않은 수치는 "데이터 없음" 또는 "추정"으로 표기. 보드/투자자 보고 시 그대로 활용 가능.
