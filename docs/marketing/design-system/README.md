# TangoBook 문서 디자인 시스템 · 1.0

사업계획서·제안서·팀 전략 문서의 공통 기준이다. 학습자 제품 화면의 [디자인 시스템](../../design-system.md)을 대체하지 않는다. 따뜻한 배경과 놀이의 색감을 공유하되, 사업 문서는 절제된 녹색과 넓은 여백으로 정보를 정리한다. 사용자 제공 플레이탱고 IR의 사진 중심 비교와 제품 설명 방식을 참고했다.

## 원본과 사용

- `deck-polish.css`: 2026.10.11 소개서 마감 스타일. 콘텐츠/순서를 바꾸지 않고 앱 중심 강조, 이미지 중심 콘텐츠 열, 제작 과정의 표면 위계, 수익 숫자 확대, 간지 배경을 조정한다. `full-view.css` 뒤에 적용하며 전체 보기 캔버스와 모바일 스크롤을 모두 검증한다.

- `tokens.json`: 색·글자 크기·간격·페이지 폭의 원본.
- `styles.css`: 문서 컴포넌트와 8가지 레이아웃. 장별 추가 색/그림자/임의 글자 크기를 넣기 전에 이 파일의 규칙을 확장한다.
- `system.cjs`: 토큰을 CSS 변수로 만들고 로컬 Pretendard Regular를 내장한다. 원본 폰트 라이선스는 public/fonts/Pretendard-LICENSE.txt. 굵은 글자는 브라우저 합성 굵기이며 별도 Bold 파일을 탑재했다고 주장하지 않는다.
- `build-guide.cjs`: 같은 토큰·CSS로 시각 가이드를 생성한다.
- `../drafts/build-investor-plan-20261010.cjs`: 실제 사업계획서 두 탭에 같은 시스템을 내장. HTML 하나로 전달 가능하며 외부 폰트 요청이 없다.

기존 dated editorial CSS는 이전 버전 참고로 보존하고 새 생성기에서 읽지 않는다. 기존 콘텐츠 모듈의 구조 스타일 위에 새 시스템을 적용한다. 단계적인 호환 구조이며 기존 스타일을 모두 제거한 상태는 아니다.

## 정보와 편집

한 장에는 주장 하나와 그것을 이해시키는 시각 근거 하나를 둔다. 제목은 주제를 짧은 명사구로 표시하고, 부제는 내용과 범위를 설명한다. 홍보성 문장·수사적인 결론을 제목에 쓰지 않는다. 본문은 3개 이하의 병렬 묶음을 우선한다. 긴 근거·예산 가정·검증 조건은 펼침 또는 부록으로 보존한다. 투자자용 본편은 현재 14장 속독, 팀용은 같은 시각 언어로 기존 상세 정보를 보존한다. 투자자 본편은 `../drafts/business-plan-topdown-20261010.cjs`에서 새로 작성한다. 시장→아날로그·디지털 비교→탱고북 개요→통합 학습 과정 순으로 설명한 뒤 보유 한글·영어 파닉스, 동화책, 독후활동을 세 장으로 소개하고, AI 저작도구는 별도 기술 장으로 보여준다. 상품·수익 모델을 먼저 설명한 뒤 언어·교구 확장과 콘텐츠·연령 확장을 두 장으로 구분하고, 마케팅 상세는 후속 확장 범위다.

## 토큰 규칙

아이보리 배경·흰 표면·진한 녹색 제목. 세이지는 과정, 코랄은 비교/중요 포인트에 사용한다. 무지개색 카드나 짙은 그림자는 쓰지 않는다. 8px 간격을 기본으로 16/24/32/48px을 사용한다. 제목 42px, 발표 36px, 모바일 30px, 본문 17px, 캡션 12px. 한국어는 단어 단위로 줄바꿈하며 왼쪽 정렬한다.

## 그래프와 이미지

시장 장표는 국내/세계 대표 규모와 각각의 근거 그래프를 배치한다. 국내는 같은 조사·같은 모수의 양육비 중 교육·보육비 비중을 도넛으로, 세계 시장 전망은 0 기준 금액 축으로 표시한다. 아시아는 별도 출처의 성장 배경으로 구분하며 세계 성장률을 아시아 수치로 옮기지 않는다. 두 시장을 같은 축에서 비교하지 않는다. 추정·전망·계산값과 조사 기간·범위를 숫자 곁에 표시한다. 읽기 확장 장표는 삽화만으로 읽기 기능을 대신하지 않고, 문장과 그림이 함께 보이는 실제 리더 화면을 우선한다. 같은 책·그림체의 독후활동을 나란히 보여 주며 캡처의 글자·진행 표시를 자르지 않는다.

막대는 0 기준, 동일 지표는 동일 축. 기간·모수·통화·등록/공개 정의를 숫자 곁에 표시한다. 서로 다른 시장 범위의 수치를 같은 판매 가능 시장으로 합산하지 않는다. 실제 화면은 자르면서 의미를 바꾸지 않고 contain으로 표시한다. 사진은 원본 비율을 유지하며 행동의 핵심이 보이게 크롭한다. 실제 화면 / 과거 제품 / 테스트 데이터 / AI 콘셉트를 캡션에서 구분한다. 현재 사양이나 효과로 오인되는 그림은 쓰지 않는다.

## 확인

문서 생성 후 전체 장표 제목·순서·탱고북 소개서/매출 시뮬레이션/판매·마케팅 전략 탭·이미지·가로 넘침을 확인한다. 대표 장의 사진/손/블록/글자/그래프를 육안으로 확인한다. 기본 스크롤 보기에서는 작은 화면을 세로로 읽는다. 사용자 요청으로 전체 보기에서는 1440×900px 고정 장표를 창 높이·폭에 맞춰 자동 축소하여 한 화면에 한 장 전체를 표시한다. 표지·간지는 화면 영역을 꽉 채우고, 상단에는 장 선택·이전/다음·스크롤 복귀만 포함한 도구막대를 둔다. PDF/인쇄를 검증하지 않았다면 그 결과까지 확인했다고 보고하지 않는다.

800px 이상 문서 폭에서는 통합 학습을 네 장면의 가로 흐름으로 유지한다. 비교·상품·투자 계획은 2열이며, 700–799px 통합 학습은 2열이다. 699px 이하에서는 세로 읽기로 전환한다. 상품 방향 사진은 블록과 쓰기 도구가 잘리지 않도록 반쪽 원본의 전체 비율을 표시한다. grid 열 지정은 display:grid와 함께 적용해 기존 flex 반응형 규칙과 충돌하지 않게 한다.

2026-10-11: 보유 동화책은 장르별 대표 표지 4열 + 창작동화 3열 갤러리로, 독후활동은 같은 책의 실제 화면 4개로 구성한다. 저작도구는 실제 삽화+예시 원고+제작/검수 기능을 문서용 HTML 화면으로 재구성하고 구성 예시임을 캡션에 표시한다. 모바일에서는 제작 화면을 세로로 재배치한다.

확장 교구 예시는 인식판 없이 블록 묶음만 보여준다. 숫자·연산 / 창의 도형 / 길·연결 퍼즐을 같은 크기·배경·조명의 제품 컷으로 나란히 배치하며, 개발 콘셉트를 현재 판매 사양으로 표시하지 않는다.

파닉스 소개는 한글4권·영어5권의 권별 구성 카드다. 시리즈명은 줄마다 한 번, 각 카드 상단에 권번호·학습 주제를 HTML 텍스트로 크게 표시한다. imagegen의 같은 종이 질감·색 체계 문자 이미지는 아래 보조로 배치한다. 실제 교재 표지나 앱 화면으로 부르지 않는다. 낱말 삽화/브랜드 반복/모호한 음절 조합을 피하고 제안서 크기에서 제목을 먼저 읽을 수 있게 한다. 소중한글은 공통 구성과 단계 설명의 참고이며 자산은 사용하지 않는다.

## 2026-10-11 훑어보기 기준

`scan-layouts.css`가 투자자 본편의 읽기 위계를 정의한다. 각 장은 명사형 제목 하나, 핵심 이미지·도표 구성 하나, 짧은 설명으로 읽는다. 같은 내용을 반복하는 상단 분류·소제목·하단 요약을 줄이고 출처·산식·개발 범위는 펼침으로 제공한다. 가격·목표/실적·미확정 기능 구분은 숨기지 않는다. 학습 과정은 동일 낱말 가구의 앱 화면·실물 블록·쓰기·게임 네 장면과 통합 기록 구성 예시로 표시한다. 보유 동화책은 4개 장르 대표 표지와 창작동화 3개 본문 예시로 구성한다. 기존 창작동화는 공개된 제안 구성을 전제로 하되 운영 공개 상태 변경은 하지 않는다. 장 선택 목차·스크롤 위치에 맞는 페이지 번호·높이 연동 상단바를 함께 검증한다.


## 2026-10-11 전체 보기

`full-view.css`는 생성 스타일 마지막에 적용한다. 전체 보기에서는 읽기용 CSS를 보존한 채 폭 미디어 쿼리를 1440px 캔버스 기준으로 해석한다. 모든 본문은 1440×900px(16:10) 고정 크기이며 동일한 축소율을 적용한다. 콘텐츠 길이에 따라 장표 크기를 바꾸지 않고 내부 이미지·여백을 조정한다. 창 크기·이미지 로드·폰트 완료 시 재계산한다. Escape 또는 스크롤 보기로 복귀하고 상세 탭 이동 시 읽기 스타일을 복원한다. 표지·간지는 별도 뷰포트 구성이다. `check-business-plan-full-view-20261011.cjs`로 장표 전체·목차·딥링크·상세 이동·인쇄 가시성을 확인한다. Part 3는 전체 구성→저작도구→보유 콘텐츠(파닉스·동화책)→디지털 활동→아날로그 교구→마케팅 도구 순서다.


2026-10-11 재독 보완: `business-plan-readability-20261011.cjs`의 플랫폼 도해는 핵심 제목을 HTML 텍스트로, 기존 사진·화면을 보조 이미지로 둔다. 복잡한 전체 이미지를 작게 축소해 넣지 않는다. 독후활동은 한 장당 실제 화면2개를 크게 표시한다. 교구 장은 작동 방식, 상품 장은 패키지 구성·이용기간·가격으로 역할을 구분한다. 블록 인식 기반 구현/탱고노트 출시계획/통합 연동 개발 상태를 본문에서 확인할 수 있게 유지한다.


2026-10-11 통일성 보완: 탱고북 개요는 밝은 본문 배경과 흰 콘텐츠 카드로 표시한다. 짙은 전체 배경은 간지에 사용하며 도구 UI 안의 브랜드 색과 구분한다. 표지 다음 차례는 4개 Part와 본문20장의 실제 제목/앵커로 생성한다. 플랫폼 전체도는 저작도구→공통 라이브러리에서 학습 제공/마케팅 도구로 분기하는 같은 카드 체계다. 판매 요약의 제품 공급·오가닉 마케팅은 왼쪽 탱고북 카드 안에 귀속시킨다.
