# 한글 나무 · 호리네 파닉스 동화 — 공통 집필 지침 (writer용)

이 라인의 전체 기획서 SSOT = `packages/client/public/hangeul-tree-plan.html`.
포맷·톤의 **정답 샘플** = `docs/phonics-hangeul-tree/kr-h1-u02.md` (반드시 정독하고 그 구조를 그대로 따를 것).

## 라인 개요
- 한글 파닉스 학습자용 **학습 장면형** 동화. 플롯 중심 X, 개연성 억지 X.
- 세계관: 호리네 마을의 **한글 나무** — 유닛마다 나뭇가지에 오늘의 글자 열매가 열림. 호리와 친구들이 열매를 따서 글자를 배우고, 관련 단어를 읽고, 도란도란 수다 떨고, 중간에 작은 웃음이 터진다.
- 대상 **4~5세**, 그림체 **니들펠트**(생활동화와 동일 — 지문에 스타일 문구 쓰지 말 것, 코어가 자동 부착).
- 호리는 **고정 주인공**. 유닛마다 지정된 친구가 로테이션. 한글 나무는 말하지 않는 배경 장치(열매만 반짝임).

## 8쪽 공통 beat (반드시 이 순서)
1. 나무 앞에 모이기 — "새 열매가 반짝!" 오늘의 글자 발견
2. 오늘의 글자 등장 — 열매를 따니 글자가 두둥, 소리 크게 함께 내기
3. 타겟 단어 ①② 짚으며 읽기 + **글자 소릿값 연결**("둘 다 '○' 소리로 시작하지?")
4. 타겟 단어 ③④ 읽기, 그림과 단어 짝짓기
5. 도란도란 수다 — 단어로 대화(친구 개성)
6. **작은 웃음 포인트** — 지정된 재미 훅
7. 다 같이 글자 소리내며 손으로 그려보기
8. 마무리 & 다음 예고 — 나무에 오늘 글자 열매가 톡 열림, 위에 익어가는 다음 열매 살짝

## 🔴 파닉스 학습 필수 규칙 (검수 통과 조건)
- **타겟 단어 4개는 각각 최소 2회씩** 이야기 속에 등장(발화·재활용). 한 번만 나오는 단어가 없게 할 것. (자연스러운 수다·훅에서 재노출)
- **오늘의 글자 소릿값을 소리 내어 읽는 장면 최소 3회**(기본: 쪽2 글자발성 + 쪽3 소릿값 연결 + 쪽7 따라그리기).
- 타겟 단어·글자는 **임의로 바꾸지 말 것**(게임·플래시카드 연동 데이터).
- 단어 정책 = **절충형**: 타겟 단어는 반복 노출, 나머지 대사·지문은 4~5세가 편한 쉬운 한국어. 억지 디코더블 문장 금지.
- 페이지당 본문 1~2문장. 한 쪽 = 한 장면. 의성어·의태어 적극 활용.
- 재미 훅은 타겟 단어/등장 친구와 자연스럽게 엮기. 개그를 위한 개그 금지.
- 안전·정확성: 위험행동 미화 금지, 순한 유머. 시간대는 아침→낮→오후로 자연스럽게 흐르게.

## SCENE 규격 (쪽마다)
5라벨 풀 콘티: `컷 / 장소·시간 / 인물(캐릭터별 포즈·표정) / 배경·소품 / 톤`.
- 캐릭터 인식 토큰 병기: Hori, Toto(bunny), Bori(bear), Kongi(squirrel), Dubu(puppy), Hoya(baby brother tiger), Mom(tiger), Dad(tiger).
- 각 쪽 끝에 **[등장]** 으로 그 컷 캐릭터 명시.
- 니들펠트 스타일 문구 **미기재**(코어 자동 부착).
- 오늘의 글자/타겟 단어의 시각 앵커 명시: 글자=나무 열매 표면, 단어=나뭇잎 글자판(옆에 작은 그림), 단어 속 오늘 글자는 빨강 강조.
- 🔴 **타겟 단어 4개 전부 `'단어' 잎 옆 작은 그림(…)` 형태로 시각 지시를 쓸 것** — 이 문구가 기획서 「타겟 단어 카드 프롬프트」의 소스라, 빠지면 본편 삽화와 단어 카드의 사물이 어긋난다.

## 단어 카드 → 앱 연동 (2026-07-26)

기획서에 붙여넣은 단어 카드는 **파닉스 유닛의 게임 자산**이 된다(그림 짝 찾기·낱말 그리기·블록·따라쓰기). 새 유닛 카드를 붙인 뒤 두 줄만 돌리면 끝:

```bash
node packages/server/scripts/link-hangeul-tree-word-cards.mjs --apply      # 카드 → flashcards[].imageUrl (w800 webp 로 구움)
node packages/server/scripts/extract-word-card-keypoints.mjs --preview     # 윤곽 → keypoints, 먼저 눈으로 확인
node packages/server/scripts/extract-word-card-keypoints.mjs --apply
```

둘 다 멱등. 한글↔로마자 매핑은 기획서 `UNITS` 배열이 SSOT라 유닛 목록을 따로 적지 않는다. 상세 → [features/phonics-learner/CLAUDE.md](../../packages/client/src/features/phonics-learner/CLAUDE.md)

## 특수 유닛 처리
- **모음 유닛(kr-h1-u01)**: 타겟 단어가 없음. 대신 **모음 10개(아·야·어·여·오·요·우·유·으·이)** 가 나무 열매로 주렁주렁. 쪽3~4에서 모음을 그룹으로 나눠 노래하듯 읽고(아야어여오요 / 우유으이), 쪽7에서 모음 하나를 손으로 그림. "오늘의 글자 3회" 대신 모음 소리를 여러 번 노래로 냄.
- **받침 유닛(kr-h2-*)**: "오늘의 글자" = 받침(예: 받침 ㅇ). 소릿값도 받침 소리로. 타겟 단어의 **받침 부분**을 짚어 강조. 나무 열매엔 받침 글자를 보여줌.
- **복잡한 모음 유닛(kr-h4-*)**: "오늘의 글자" = 지정된 모음 2~3개(예: ㅐ와 ㅔ). 둘 다 읽고, 타겟 단어와 짝지음.
