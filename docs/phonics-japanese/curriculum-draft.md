# 일본어(가나) 파닉스 커리큘럼 초안

> 2026-08-05 · feasibility.md 후속. **텍스트 커리큘럼만**(유닛 구조 + 유닛별 타겟 가나 + 타겟 단어).
> 음원·삽화는 범위 밖. 코드 미변경. **감이 아니라 웹 벤치마크 근거로 유닛을 나눔**(§벤치마크).

## 1. 물려야 할 커리큘럼 스키마 (한/영 실측)

한·영 커리큘럼은 `packages/shared/src/constants/index.ts` 의 `KOREAN_PHONICS_CURRICULUM`(L689)·
`ENGLISH_PHONICS_CURRICULUM`(L131)에 **같은 형태**로 들어 있다:

```ts
{ level, name, description, units: [
  { id, title, phonemes: string[], patterns: string[], sampleWords: string[], blending?: [][] }
]}
```

- **유닛 = 학습 한 묶음.** 한글1 자음 유닛은 `phonemes:['ㄱ']` 1개지만 `blending` 으로 음절 10개를 가르친다.
  영어 Book1 유닛은 `phonemes:['a','b','c']` 3~4 글자 + `sampleWords` ~9개(글자당 2~3).
- **plan 은 커리큘럼에서 파생**(`lib/korean-phonics-units.ts` `derivedPlans()`·`getAllKoreanUnits()`) —
  유닛 목록을 두 번 안 적는다. 복습 유닛은 `chunkForReview`(레벨 안 **4단원씩**, 꼬리≤2는 앞에 합침)로 자동 삽입.

**가나 매핑:** 가나는 blend 가 없다(글자=소리). 유닛 구조가 **영어 Book1 과 동형** — `phonemes` = 그 행의
가나 3~5자, `sampleWords` = 그 가나로 시작하는 유아 단어, `blending` 은 **빈 배열**. 한글의 자음+모음 조합
필드를 안 쓰는 게 정확하다.

```ts
// 제안 스키마 (JAPANESE_PHONICS_CURRICULUM, shared/constants)
{ id:'ja-l1-u02', title:'Unit 02: か행 (ka ki ku ke ko)',
  phonemes:['か','き','く','け','こ'], patterns:['gojuon-row'],
  sampleWords:['かに','きりん','くま','けむし','こま'], blending:[] }
```

## 2. 벤치마크 조사 (근거 출처)

| 출처 | 유형 | 확인한 것 |

| **Wikipedia Gojūon / Hiragana** | 구조 | 청음 46(+ん) · 탁음 20 · 반탁음 5 · 요음 33 · 촉음っ · 장음. 예시 차트어 あり·しか·たこ·はな 확인. |

**핵심 벤치마크 결론:** L2(Tofugu)와 JP-native(상위 노래) **양쪽 다 오십음(あいうえお) 순서, 행 단위, 모음 먼저**.
→ 우리도 **오십음 순 · 행 단위 · 모음 유닛 선두**로 간다. (⚠️ KUMON 계열의 "쓰기 쉬운 글자부터"(し·つ·く 등
획수순) 대안도 존재하나 웹 소스 확보 실패 — 아래 §5 결정 옵션에 남김. 확보한 근거는 전부 오십음순을 지지.)

## 3. 유닛 분할 초안 (히라가나 우선)

**입도 근거:** Tofugu "groups of 5, one column at a time" + 한글1이 학습 단위를 소릿결마다 쪼갠 것.
→ **한 행 = 한 유닛**(3~5자). 영어 Book1 유닛(3~4 글자)과 같은 밀도.

### Level 1 — 청음 46 + ん (10 유닛 + 복습 3)

| id | 유닛 | 타겟 가나 | 타겟 단어(그 가나로 시작) |
| --- | --- | --- | --- |
| ja-l1-u01 | あ행 (모음) | あ い う え お | あり(개미)・いぬ(개)・うさぎ(토끼)・えび(새우)・おに(도깨비) |
| ja-l1-u02 | か행 | か き く け こ | かに(게)・きりん(기린)・くま(곰)・けむし(애벌레)・こま(팽이) |
| ja-l1-u03 | さ행 | さ し す せ そ | さかな(물고기)・しか(사슴)・すいか(수박)・せみ(매미)・そら(하늘) |
| ja-l1-u04 | た행 | た ち つ て と | たこ(문어)・ちず(지도)・つき(달)・て(손)・とり(새) |
| — | **복습 1** (あ~た) | 20자 | (게임만 — 한글 복습 규칙) |
| ja-l1-u05 | な행 | な に ぬ ね の | なす(가지)・にじ(무지개)・ぬいぐるみ(인형)・ねこ(고양이)・のり(김) |
| ja-l1-u06 | は행 | は ひ ふ へ ほ | はな(꽃)・ひこうき(비행기)・ふね(배)・へび(뱀)・ほし(별) |
| ja-l1-u07 | ま행 | ま み む め も | まり(공)・みかん(귤)・むし(벌레)・めがね(안경)・もも(복숭아) |
| ja-l1-u08 | や행 | や ゆ よ | やま(산)・ゆき(눈)・よる(밤) |
| — | **복습 2** (な~や) | 18자 | (게임만) |
| ja-l1-u09 | ら행 | ら り る れ ろ | らくだ(낙타)・りんご(사과)・(る 재인)・れもん(레몬)・ろうそく(양초) |
| ja-l1-u10 | わ행 + ん | わ を ん | わに(악어)・(を 재인)・**ん**=ぱん(빵)・みかん(귤)・きりん(기린) 로 끝소리 익히기 |
| — | **복습 3** (ら~ん) | 8자 | (게임만) |

- **合 46자** = 5×7(あかさたなはま) + や3 + ら5 + わを2 + ん1. ✓
- 🔴 **재인(recognition-only) 가나** — `を`(조사 전용, 어두 단어 없음)·`る`/`ぬ`(어두 유아어 희소)는
  타겟 단어 대신 **읽기 재인**만. `ん`은 어두 불가라 **끝소리로 가르친다**(ぱん·みかん — 실제 교재 관습).
- **복습 위치:** 한글 `chunkForReview`(레벨 안 4단원)에 맞춰 u04·u08·u10 뒤. u08(や행 3자)·u10(3자)은
  작아서 4로 안 떨어지므로 3·3·4 로 묶거나 파생기 규칙에 맡긴다(자동).

### Level 2 — 탁음·반탁음 25 (5 유닛 + 복습 1)

근거: Tofugu·전 교재가 **청음 46 완료 후** "variation"(탁점) 도입. 유아엔 "같은 글자에 점 두 개" 개념.

| id | 유닛 | 타겟 가나 | 타겟 단어 |
| --- | --- | --- | --- |
| ja-l2-u01 | が행 | が ぎ ぐ げ ご | がま(두꺼비)・ぎんこう(은행)・ぐんて… → 유아어: がっこう? **재선정 필요**(탁음 어두어 적음) |
| ja-l2-u02 | ざ행 | ざ じ ず ぜ ぞ | ぞう(코끼리)・じてんしゃ(자전거)・ざる(소쿠리) 등 |
| ja-l2-u03 | だ행 | だ ぢ づ で ど | だるま(달마)・でんしゃ(전차)・どんぐり(도토리) (ぢ·づ 재인) |
| ja-l2-u04 | ば행 | ば び ぶ べ ぼ | ばなな(바나나)・びわ(비파)・ぶどう(포도)・ぼうし(모자) |
| ja-l2-u05 | ぱ행 (반탁음) | ぱ ぴ ぷ ぺ ぽ | ぱんだ(판다)・ぴあの(피아노)・ぷりん(푸딩)・ぽけっと(주머니) |
| — | **복습 4** | 25자 | (게임만) |

🔴 **탁음 단어 초안은 미완**(위 표에 물음표) — 탁음으로 **시작하는** 유아어가 청음보다 적다. 실제 교재는
탁음을 "청음 단어 안에서"(かぎ 열쇠·めがね 안경) 가르치기도 한다. **§5 결정 옵션**.

### Level 3 — 특수음 (요음·촉음·장음) — 🔴 보류 권장

근거: Wikipedia 가 요음(33)·촉음·장음을 확장/특수로 분류, 4~5세엔 "2글자 1소리"·"소리 없는 글자"가 어렵다.
한글이 복잡한 모음·받침을 뒤 레벨로 뺀 것과 같은 판단. **MVP 에선 청음+탁음까지, 특수음은 후속 레벨**.

- 요음 きゃきゅきょ… = 자음별 3~4 유닛으로 묶을 수 있음(base 자음 공유).
- 촉음 っ·장음 = 개념 유닛 각 1(낱말 안에서 "작게 멈춤"·"길게").

### 가타카나 = 별도 라인 (후속)

일본 유아는 히라가나 먼저·가타카나 나중(외래어). 같은 오십음 뼈대·같은 음원에 **글자 자산만 교체** —
Level 병렬 라인으로 뒤에 붙인다. 공수 2배 아님.

## 4. 타겟 단어 선정 관행 (벤치마크 반영)

- **"그 가나로 시작하는 대표 사물어"** — あいうえお表·상위 노래·Wikipedia 예시어 공통. 삽화 가능한 **구체
  명사**(동물·과일·탈것)로. 위 표는 그 관습을 따랐다(あり·いぬ·うさぎ…).
- 한 유닛 = 가나당 1단어(3~5개) — 영어 Book1(글자당 2~3) 밀도와 맞고, 단어 카드 파이프라인(유닛당 4장
  전후)에도 맞는다.
- 🔴 어두 단어가 희소한 가나(を·ん·る·ぬ·탁음 다수)는 **재인/끝소리**로 처리 — 억지 단어를 만들지 않는다.

## 5. 결론 — 지금 확정 가능한가

**대부분 지금 확정 가능하다.** 벤치마크가 일관돼서(오십음순·행 단위·모음 선두·글자당 사물어) 유닛 구조·
순서·복습 위치·타겟 단어(청음)는 **사람 손으로 바로 잠글 수 있는 초안**이 위 §3 표다.

**남는 사람 결정(옵션):**

| # | 미결정 | 옵션 | 기본 권장 |
| --- | --- | --- | --- |
| 1 | **타겟 학습자** (feasibility §3.2 #1과 동일) | A 일본 아이 native / B 한국 아이 L2 | 단어·뜻·안내 언어를 가름. 미결이면 단어 목록은 그대로 두고 gloss/안내만 나중 |
| 2 | **오십음순 vs 획수순** | 오십음순(근거 다수) / KUMON식 쓰기쉬운순 | **오십음순** — 확보 근거 전부 지지. 획수순은 소스 재확보 후 재검토 |
| 3 | **범위 깊이** | 청음만 / +탁음 / +요음·촉음·장음 | **청음+탁음**(Level 1~2), 특수음 후속 |
| 4 | **탁음 단어 vs 재인** | 탁음 어두어로 / 청음 단어 속에서 | 어두어 희소 → **일부 재인 + 낱말 속 노출** 혼합(§3 Level2 물음표 자리) |
| 5 | **재인 가나 처리** | を·ん·る·ぬ 를 타겟서 제외 / 끝소리·재인으로 포함 | **포함하되 재인/끝소리**(교재 관습, 위 표대로) |
| 6 | **작은 행 병합** | や행(3)·わ행(2)을 인접 행과 합칠지 | 그대로 두되 복습 묶음은 파생기에 맡김 |
| 7 | **가타카나 라인** | 안 함 / 히라가나 후 별도 레벨 | 후속 레벨 |

→ **#1(타겟)만 정해지면 청음 커리큘럼(Level 1)은 그대로 데이터화 가능**하고, 탁음(Level 2)은 단어 재선정
한 번(#4)이면 된다. 특수음·가타카나는 의도적으로 뒤로 민다.
