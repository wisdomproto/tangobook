# 일본어(가나) 파닉스 — 정식 커리큘럼 기획서

> 2026-08-06 · **상위 기획 문서**(확정판). 근거·조사 원본은 [feasibility.md](feasibility.md)·[curriculum-draft.md](curriculum-draft.md).
> 코드 미변경 — 기획만. 유닛 표는 사람이 검토·수정하기 쉬운 마크다운 표.

## 1. 개요 / 포지셔닝

**영어(ABC)·한글 파닉스와 나란한 3번째 언어 라인.** 사이드바 파닉스 랜딩에 한글·영어 옆 카드 하나 추가.

- **타겟 = 글로벌 아이(한국 아이 포함), 안내는 각자 UI 언어를 따라간다** — **기존 영어 파닉스와 완전히 같은
  포지션**(영어를 배우는 대상이 한국 아이만이 아니듯, 일본어도 UI 로케일이 안내를 결정). i18n 은 영어
  파닉스가 지금 하는 방식 그대로가 baseline(deferred i18n 상태 유지). **일본어 전용 하드코딩 없음.**
- **설계 전제: 가나 = 모라(mora) 음절 문자 → blend 없음.** 각 가나 = 하나의 온전한 소리(か=/ka/). 한글의
  자음+모음 조합도, 영어의 CVC 블렌딩도 **없다**. 학습 = 글자↔소리 짝 + 낱말 읽기.
  → **구조상 영어 Book 1(글자 단위, 통글자=소리)과 동형** — 그 활동 세트를 그대로 물린다.

## 3. 전체 레벨·유닛 구조 (확정)

**근거(벤치마크, 상세 [curriculum-draft.md §2]):** L2 가이드(Tofugu)·JP-native 상위 조회 노래(しまじろう/베네세
13.4M · MEWch 3.9M · KidsMusicTime 2.3M · BabyBus 1.3M) **전부 오십음(あいうえお)순·행 단위·모음 선두**.
→ **오십음순 · 1행=1유닛 · 모음 유닛 선두 · 청음→탁음→특수음 레벨링.**

복습 배치 = 한글 규칙(`chunkForReview`: 레벨 안 유닛 묶음마다, 꼬리≤2는 앞에 합침) 그대로 자동 파생.

### Level 1 — 청음 46 + ん  (10 유닛 + 복습 3)

활동 타입 = **glyph**(통글자, 영어 Book1 형).

| ja-l1-u02 | か き く け こ | かに(게)・きりん(기린)・くま(곰)・けむし(애벌레)・こま(팽이) | |

- **合 46자** = 5×7 + や3 + ら5 + わを2 + ん1. ✓
- 🔸 **재인(recognition-only) 가나** — `を`(조사 전용)·`る`/`ぬ`(어두 유아어 희소)는 타겟 단어 대신 **읽기
  재인**. `ん`은 어두 불가라 **끝소리**(ぱん·みかん)로 가르친다 — 실제 교재 관습, 억지 단어 금지.

### Level 3 — 특수음 (요음·촉음·장음)  🔴 후속(MVP 제외 권장)

근거: 요음(2글자=1소리)·촉음(소리 없는 작은っ)·장음(추상)이 4~5세엔 어렵다 — 한글이 복잡한 모음·받침을
뒤 레벨로 뺀 것과 같은 판단. **MVP = Level 1~2(청음+탁음). Level 3 은 그 뒤.**

- 요음 33 (きゃきゅきょ…) — base 자음별 3~4 유닛으로 묶음. 🔴 타일 단위 = 코드포인트로 き·ゃ 가 쪼개지므로
  요음까지 넣으면 그 한 곳만 결합 처리(태국어 grapheme 선례) 필요.
- 촉음っ · 장음ー = 개념 유닛 각 1(낱말 안에서 "작게 멈춤"·"길게").
- ※ ん(발음)은 어두 불가라 Level 1 u10 에서 **끝소리로 이미 도입** — 별도 유닛 불필요.

### 가타카나 라인 — 별도 레벨(후속)

히라가나 먼저·가타카나 나중(외래어). **같은 오십음 뼈대·같은 음원, 글자 자산만 교체.** 히라가나 라인 완성
후 병렬 레벨로 붙인다(공수 2배 아님). MVP 범위 밖.

## 4. 활동 매핑 (기존 phonics-learner 재사용)

가나 유닛 = **영어 Book1(glyph) 활동 세트와 동형**. 재사용/삭제:

| 활동(kind) | 가나에서 | 근거 |
| --- | --- | --- |
| `alphabet-letter-learn` (통글자 눌러 소리 듣기) | ✅ **재사용** — 가나 눌러 모라 소리 | Book1 「배우기」와 동일. BabyBus「どこのおと」(어느 소리?)와 동형 |
| `alphabet-letter-write` (통글자 따라쓰기) | ✅ **재사용** — 가나 획 쓰기 | `LetterFillCanvas`(영/한/일 통일). 폰트만 물리면 채점 동작 |
| `word-listen-choose` (듣고 고르기) | ✅ **재사용** — 낱말 소리→[그림+글자] 고르기 | BabyBus「なまえさがし」와 동형. 🔴 Book1처럼 보기에 낱말 철자 X(글자만) |
| `letter-hunt` (글자 사냥) | ✅ **재사용** — 오십음 사이 목표 가나 찾기 | 모양 변별. BabyBus 이름찾기 계열 |
| 게임 `game-connect-dots`(낱말 그리기)·`game-word-writing`(낱말 쓰기)·`game-line-matching`(그림 짝) | ✅ **재사용** | `splitUnits(word,'ja')`=코드포인트=가나 타일 정확 |
| `game-english-block`/`game-korean-block`(블록 게임) | ⚠️ **Book1처럼 뺄지 검토** — 가나 낱말은 짧고(2~3모라) 블록 조립 학습가가 약함 | Book1도 블록 게임 없음(2026-07-29). 넣으려면 kana 어댑터 분기 |
| **blend 계열 전부** — `consonant-tap`·`consonant-blend-listen`·`coda-blend-listen`·`vowel-blend-*`·`cvc-pattern-*`·`word-family-learn` | ❌ **삭제** — 가나엔 조합·라임·CVC 없음 | 설계 전제(모라=blend 없음) |
| `review-*` 6종 (사냥·뒤집기·듣고음절·그림짝·듣고낱말·낱말쓰기) | ✅ **재사용** — 복습 유닛 | 한글 복습 규칙 그대로("복습=게임만, 익히기 금지") |

**유닛 활동 흐름(초안, Book1 미러):** 배우기(가나 눌러 소리) → 듣고 고르기 → 따라쓰기 → 글자 사냥 →
[낱말 놀이: 낱말 그리기·낱말 쓰기·그림 짝]. 🔴 Book1 이 「듣고 낱말」을 「듣고 글자」와 중복이라 뺀 것처럼,
가나도 중복 활동은 뺀다.

## 6. 남은 결정 · 리스크

**빌드 착수 전 확정:**
- **탁음 어두 단어 재선정**(§3 Level2) — が·ざ·だ 어두 유아어가 청음보다 적다. 옵션: (a) 어두어로 채운다
  (b) 청음 낱말 속에서 노출(かぎ·めがね) (c) 일부 재인. → **혼합** 권장, 표 확정은 사람 검토.
- **블록 게임 포함 여부**(§4) — Book1 미포함 선례. 가나 기본 = 미포함, 원하면 어댑터 분기.

**빌드 중 실측:**
- 🔴 **낱 모라 발음 품질** — "き" 같은 1글자 발음. Gemini TTS 짧은 CJK 무응답 이력 → **104(또는 71) 클립을
  한 번 구워 라이브러리 직행**(Google Chirp3-HD ja 보이스 추가 또는 성우). 파일럿 1행(あ행 5클립)으로 확정.
- 🔴 **일본어 폰트 실기기 확인** — 미등록 시 조용히 폴백(에러 없음, 팔레트 램프 함정과 같은 부류).

**보류/후속:**
- **KUMON식 획수순(쓰기 쉬운 글자 먼저)** 대안 — 웹 근거 확보 실패. 확보한 근거 전부 오십음순 지지 →
  오십음순으로 가되, 소스 재확보되면 재검토.
- **요음 타일 결합**(§3 Level3) · **가타카나 라인** — Level 3 이후.
