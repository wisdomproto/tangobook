# 3. 알아보게 — 데이터·유료층 (2~6개월)

## 3-1. 창작동화 핵심단어 추출 — 작전

### 대상과 입력
- 창작동화 **850권**(15시리즈 × 50 + 미완 4 × 25) — 지금 `key_objects` **0개**
- 🔴 **우선순위 = 파닉스 낱말 중 아직 동화책에 없는 것**

| | 파닉스 낱말 | 동화책에 있음 | **미연결** |
|---|---:|---:|---:|
| 한글 | 126 | 72 | **54** |
| 영어 | 359 | 110 | **249** |

한글 54 중 **비명사·의성어는 뺀다**(꼬끼오·똑딱·쓱싹·쫑긋·풍덩·뽀뽀·나·너·모두·누구야·얘기·미소·예절·기도) —
카드가 안 되는 낱말이라 매칭 대상이 아니다. 실질 **약 39개**.

### 🔴 원칙 넷
1. **억지로 안 뽑는다** — 권당 4~6개 상한. 파닉스 낱말이 본문에 없으면 없는 것.
2. **뜻으로 잇는다** — `senses2.mjs` 의 동음이의어 분리를 쓴다.
   54개 중 조심할 것: **화가**(畫家 / 「화가 나다」) · **지도**(地圖 / 指導) · **가구**(家具 / 家口) · **미소**(微笑 / 된장) ·
   **기도**(祈禱 / 氣道) · **배**(船 / 腹 / 梨 — 붕이네가 「배」 천지) · **김**(海苔 / 蒸氣 — 코타 온천) · **이**(齒 / 虫).
3. **실물로 쓰였을 때만** — `lib-match.has()`(조사만 허용, 비유 「~처럼」 제외). 「달다!」가 달(月)로 잡히던 함정은 이미 막혀 있다.
4. **기계 점수로 상위 N 을 자르지 않는다** — 후보만 스크립트로 뽑고 **본문을 읽어 고른 뒤** 스크립트로 검증.

### 🔴 26-50 은 힌트가 공짜다
호리 세트 원고마다 `**그림 하나**` 가 있다 — 「그릇 위 세 가지 색(초록 잎·주황 새우·흰 국수)」 「이 사이에 낀 국수 가닥 · 바가지 물 한 컵」.
**그게 곧 그 권의 사물**이라 1순위 후보로 쓴다. 01-25 는 이 필드가 없어 본문 스캔만.

### 한글과 영어는 따로 — 순서가 다르다
| | 본문 | 언제 |
|---|---|---|
| **한글** | 850권 다 있음 | **지금** |
| **영어** | 창작동화 **영어 본문 없음** | 🔴 **번역 뒤** — 지금은 영어 본문 있는 191권(명작·자연·생활)에서 249개 먼저 찾는다 |

### 절차
1. 미연결 한글 39개 → 850권 본문에서 `has()` 로 **후보 스캔**(자동, 어느 권에 몇 번)
2. 후보 본문 읽고 **실물인지·그림에 있는지** 판정 → 고른다 (여기가 시간)
3. 26-50 은 `**그림 하나**` 에서 사물 추가
4. 시리즈별 `picks-{series}.mjs` 작성 → `build.mjs` → R2 적용 (`link-*` 계열 재사용)
5. 영어 191권에서 249개 스캔 → 별도 picks → 창작동화 영어 생기면 재실행

| | 지금 | 목표 |
|---|---:|---:|
| 한글 미연결 | 54 | **≤ 15** (남는 건 본문에 정말 없는 것) |

## 3-2. 연결 채우기
3-1 의 부산물이다 — 미연결 낱말이 채워지면 연결도 같이 채워진다.

## 3-4. 추천 엔진 — 커리큘럼 그래프
실사용자 4명이라 협업필터링은 못 하지만 **필요 없다** —

**배치**: 아이 홈 자동 추천부터(리텐션 직격) → 부모 리포트
