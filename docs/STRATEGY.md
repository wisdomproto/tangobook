## 1. 정체성

> # 첫 글자부터 혼자 읽기까지.
> ### 자기 말로, 그리고 영어로.

**정식 문장**: 글자를 모르는 아이를 혼자 읽는 아이로 만든다. 자기 말로, 그리고 영어로.

🔴 **문장 안에 시작점과 끝점이 둘 다 있는 게 핵심이다 — 그게 곧 책임 범위다.**
그리고 대기업은 이 문장을 못 쓴다. 교원은 「첫 글자」까지고 웅진북클럽은 「읽을 책」부터라
구간을 하나씩만 갖고 있어서 **「부터 ~까지」를 말할 수가 없다**(§2·§3).
「자기 말」이라 써서 나라를 늘려도 문장이 안 바뀐다.

**쓰임새별**

| 어디 | 문장 |
|---|---|
| 내부 기준 | 글자를 모르는 아이를 혼자 읽는 아이로 만든다. 자기 말로, 그리고 영어로. |
| 부모에게 | 우리 아이가 혼자 책을 읽게 됩니다. 한글로도, 영어로도. |
| 팀원·투자자 | 아이가 혼자 읽게 되는 전 과정을 직접 만든다. 조각을 사오지 않기 때문에 이어진다. |

### 🔴 「연결」은 정체성이 아니라 **수단**이다 (2026-09-04 사용자 정정)

한때 정체성을 「연결」로 잡았다가 내렸다. 사용자 말: *"연결은 원래 너무 당연한 건데,
기존 플랫폼이 한계가 있어서 못한 거야. 그니까 그건 그냥 수단인 거고."*

연결은 **전 과정을 직접 만들어서 따라오는 성질**이지 목표가 아니다.
정체성을 연결로 두면 일이 「이어붙이기」가 되고, 전 과정으로 두면 「빠진 칸 만들기」가 된다.

### 책임 범위 — 여기까지 한다

| | 지금 |
|---|---|
| 자기 말 글자 | 한글 파닉스 32단원 ✅ |
| 영어 글자 | 영어 파닉스 39단원 ✅ |
| 낱말 | 핵심단어 ✅ · **두 언어 매칭은 미완**(아래) |
| 문장·책 — 수준에 맞게 | 레벨 체계 ✅ · **분포가 L2 한 칸에 몰림**(§6) |
| 혼자 읽기 | 🔴 여기까지 데려간 적 없음 |
| 부모가 그 과정을 본다 | 리포트 ✅ |

### 🔴 여기부터 안 한다

- **말하기·듣기 회화** — 영어유치원·화상영어 자리. 말하기 게임도 dev-only로 꺼져 있다.
  🔴 **못 지킬 약속을 정체성에 넣지 않으려고 「언어」 대신 「읽기」를 골랐다.**
- **전과목·성적·학교 진도·선행**
- **수학 과목**(연산·도형·문제풀이)

### 🔴 경계 규칙 — 소재는 열려 있고, 과목은 닫혀 있다

| | |
|---|---|
| 수학 **과목** | ✗ |
| 수학이 **소재인 동화책**(수 세기·크기 비교) | ✅ 읽을거리다 |
| 「문해력이 좋아야 문장제를 푼다」 | 우리 **효용**이지 **범위**가 아니다 |

공개 책의 43%가 공룡·식물·우주인 것도 같은 원리다 — 과학을 가르치는 게 아니라
**아이가 읽고 싶어 하는 소재**를 쓰는 것.

🔴 **수학을 안 하는 이유는 정체성 때문만이 아니다.** 수학은 글자→낱말→책처럼 축적되는 구조가
아니라 **문제은행**에 가까워서 「직접 만들어 잇는다」는 우리 강점이 안 통한다. 대기업 여섯 곳이
월 15~20만원으로 이미 있는 자리다.

### 제안이 올 때 묻는 두 질문

1. 글자 모르는 아이를 혼자 읽는 데까지 데려가는 일인가?
2. 과목을 늘리는 건가, 소재를 늘리는 건가?

### 🔴 한글(자국어) ↔ 영어 — 범위 안 (2026-09-04 사용자 지적으로 추가)

독후활동에서 **두 언어 낱말을 맞춰보는 것**은 방해가 아니라 **학습 그 자체**다.
지금은 한글·영어 파닉스만 있고, **추후 중국어·베트남어·태국어·인도네시아어 파닉스**를 붙인다.

⚠️ **2026-07-13 「단일 언어 표시 정책」과 충돌한다** — 그때 병기를 여섯 곳에서 지웠는데,
지금 보면 **읽기와 배우기를 안 갈라서 한꺼번에 지운 것**이다.

| 지운 곳 | 성격 | 판단 |
|---|---|---|
| 뷰어 자막 | **읽기** | 지운 게 맞다(몰입) |
| 책끝 만난 단어 · 단어 상세 모달 · 어휘 미리보기 · 그림짝 라벨 · 말하기 뜻 | **독후활동** | 🔴 되살릴 대상 |

자산은 이미 있다 — 동화책 **149권 × 5언어**, 낱말 `nameTranslations`. 화면에서만 한쪽을 감추고 있다.
→ 실행 시점 미정(사용자: "한↔영은 나중에"). `memory/single-language-i18n-2026-07-13`

### 대상

- 지금: **4~7세** (콘텐츠 대부분이 여기)
- 확장: **8~9세 = 시리즈 학습만화** (타임 티코 샘플 있음, 삼국지·그리스로마신화 후보)
- 🔴 초등 저학년은 **무조건 시리즈물**이라는 게 사용자 판단(2026-09-02)

### 🔴 AI 가 전제를 바꿨다 (사용자, 2026-09-02)

예전: 동화책 한 권 = 글작가+그림작가+편집자, 3~4개월.
지금: **콘텐츠 생산 비용·속도가 0 으로 수렴**한다고 가정하고 BM 을 짠다.
한 사람이 검수까지 하며 **월 500권** 가능.

🔴 **"AI 양산 안 한다"의 정확한 뜻** = *다 맡기는* 양산을 안 한다는 것.
**편집자 역할은 사람이 계속 한다.** 기술자(글·그림 실무)만 AI 로 바꿨다.

## 2. 경쟁 지형 — 🔴 조사 완료, 재조사 금지 (2026-09-04)

### 대기업 플랫폼이 실제로 내세우는 말

| 브랜드 | 내세우는 말 | 파는 것 |
|---|---|---|
| 웅진 스마트올 | "습관 잡고 성적 올리는 AI 학습" · "공부의 맛" | 전과목 맞춤 |
| 대교 눈높이 | "눈높이 사랑, 눈높이 교육" → "딛고 더 높이" · "당신을 배웁니다" | 1:1 개인별 수준 |
| 메가 엘리하이 | "앞서가는 초등학생은 시작부터" | 선행·심화·진학 |
| 아이스크림 홈런 | "공부를 좋아하는 습관" | 전과목 + 현직교사 |
| 천재 밀크T | "모두의 1등 공부법" | 1등 |
| **웅진북클럽** | **"문해력 향상 맞춤 독서 프로그램"** | **전집 + 북큐레이션** ← 우리와 가장 가까움 |

**공통점 넷**

1. **전과목**이다 — 독서는 부속이거나 별도 브랜드로 분리.
2. **성적·등수를 판다** — 1등 · 앞서가는 · 성적 올리는 · 딛고 더 높이. 전부 "남보다".
3. **맞춤을 판다** — 여섯 곳이 다 같은 말을 해서 **차별점이 아니다**.
4. 말은 안 하지만 **본진이 초등 전과목 태블릿(월 15~20만원)**. 4~7세는 입구.

→ **우리가 쓸 수 있는 자리 = 그들이 안 쓰는 말**: 전과목 아님 · 성적 아님 · 고르지 않고 만듦.

### 소형 경쟁 (파닉스 축)

**소중한글 · 토도한글.** 파닉스만 놓고 비교하면 이쪽이 라이벌이다.
🔴 단 **글자→책 전체 사슬로 보면 양쪽 반을 다 가진 건 대기업뿐**이라, 비교 대상은 대기업이 맞다
(2026-09-04 사용자 지적으로 `memory/positioning-connection-2026-08-13` 의 "라이벌은 대기업 아님"을 이렇게 정정).

🔴 **경쟁사 콘텐츠는 앱 안에 갇혀 검색에 0줄**(토도 2,000·소중 700) → 유입 경로가 우리에게 열려 있다.
상세 → `memory/coloring-print-seo-2026-08-17`

## 3. 우리 이력 — 🔴 매번 다시 묻지 말 것

### 플레이탱고 (사용자 전 사업)

- 실물 한글 블록 + 인식판. **네이버 월간 검색량 8,000~10,000** 까지 갔던 브랜드.
- 코로나로 접음. **블록 인식판 원가가 너무 비쌌던 게 구조적 한계** → 이번엔 **카메라 인식** 버전.
- 🔴 **브랜딩은 「탱고북」으로 새로 간다** — 플레이탱고는 브랜드가 이미 망가져 재활용 안 함(2026-09-02 사용자).

### 교원 ODM — 🔴 우리 하드웨어가 대기업 커리큘럼에서 이미 검증됐다

2020년 **교원 REDPEN 유아 한글** = 자모음절식 학습법 + 스마트 튜터 또롱이 + **교원 탱고보드**.
보드에 자모 블록을 올리면 음성으로 읽어주고 앱이 뜻을 애니메이션으로 보여준다.
유치원·어린이집 교구로도 나갔다.

그 제품 카피: 자모가 결합해 어떤 소리를 내는지 *"원리만 깨치면 **처음 보는 글자를 쉽게 읽어내고**"*
→ **우리가 지금 랜딩에 쓰는 문구와 같은 말**이다.

🔴 **그런데 교원은 거기서 멈췄다 — 읽을 책이 없다.** 한글 떼면 빨간펜(전과목)으로 넘어간다.
이게 §1 의 빈 자리를 만든 사건이다.

### 이번 작전 (2026-09-02 사용자)

예전: 아날로그 먼저 → 디지털 연결 (실패)
이번: **디지털 먼저 출시 → 브랜딩 → 유저 → 연결된 아날로그 제품으로 큰 매출**

🔴 **유아 사업은 아날로그에서 돈이 난다.** 엄마들은 디지털에 큰돈을 안 쓴다.
디지털은 **유입·브랜딩·맞춤·게임화** 담당.

## 5. 아직 안 정한 것 (다음 세션이 여기서 시작)

### 🔴 다음 단계 = 「연결이 먹히는지 증명」 (2026-09-04 제안, **사용자 확인 대기**)

정체성은 정했는데 **그게 맞는지 아무도 확인하지 않았다.** 외부 실사용자 4명 · 학습 이벤트의
94.6%가 우리 · 그 4명도 전부 08-11·12 수정 이전 = **한 번도 제대로 측정한 적이 없다.**
지금 우리가 가진 건 가설이다 — 「글자와 책이 이어지면 부모가 돈을 낸다」.

```
1. 정체성 = 연결          ✅ 2026-09-04
2. 연결이 먹히는지 증명    ← 다음
3. 언제부터 돈 받나 (BM)
4. 아날로그
5. 8~9세 확장
```

🔴 **순서는 이미 정해져 있다** — 2026-09-02 사용자: 「일단 아날로그는 준비만 하고,
디지털 컨텐츠만 집중해서 할일 다 정해봐」. §4 참조. **이걸 다시 묻지 말 것**(2026-09-04 에 한 번 다시 물었다).

🔴 오늘 베타로 전부 연 것이 2번의 **전제 조건**이다 — 벽이 있으면 표본이 안 생겨 잴 수가 없다.

**2번에 필요한 셋**

| | 지금 | |
|---|---|---|
| 사람 | 4명 | 유입 0 |
| 연결이 실제로 작동 | 부분 | 게임 12% 책 · 레벨 0권 · 파닉스 낱말 64%만 책에 연결 |

(850권 창작동화가 어느 레벨인지부터 보면 된다).
