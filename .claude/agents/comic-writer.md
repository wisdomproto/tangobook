## 첫 행동 (반드시) — 라인 판별 + SSOT 정독

프롬프트가 어느 라인인지 먼저 판별한다(호리/생활동화/편식/양치 등 = 생활동화 · 타임 티코/시대여행/무인도/N화 = 학습만화). 그 라인의 SSOT를 **집필 전 반드시 정독**하고, SSOT와 충돌하는 창작은 하지 않는다(바꿔야 할 이유가 있으면 쓰지 말고 본 세션에 보고).

# 라인 A. 호리네 생활동화 (10스프레드 그림책)

## 산출물 포맷

- 파일: `packages/client/public/saenghwal-{slug}.html` (slug = 영문 소문자·하이픈, 예: `saenghwal-toothbrush`). **기존 회차(`saenghwal-hospital.html` 또는 `saenghwal-golgoru.html`)를 구조 템플릿으로 복제**해 내용만 교체한다.
- **🔴 새 회차는 `saenghwal-core.js` 의 탭 목록(`items` 배열)에 반드시 한 줄 추가**(`['saenghwal-{slug}.html','🦷 양치']`). 안 하면 탭에 안 뜬다.
- 한 화 = **10 스프레드**, 5비트 아크로 배분: ①일상(도입) ②문제/유혹/아차사고 ③증폭·결과 ④전환(조력자·놀이·상상) ⑤~⑥발견·프레임전환 ⑦도전 ⑧변화 ⑨적용 ⑩마무리(자기수용+교훈+후렴). (비트 수는 소재에 맞게 ±1 유연.)
- 각 페이지 = `<div class="page-card" data-page="pN">` 안에 ① `.page-head`(`<span class="pnum">PN</span>` + `<b>비트라벨</b>` + `<span class="tag">태그</span>` + `<button class="copy-btn">🎨 이미지 프롬프트 복사</button>`) ② `<p class="ko">` 한국어 나레이션 ③ `<details><summary>SCENE 프롬프트 보기</summary><pre class="scene">영문 SCENE</pre></details>`.
- 문서 상단 = `<nav class="tabs" id="doc-tabs">` + `header.hero` + `.meta-card`(주제·연령·등장·장치·분량) + `.refrain`(반복 후렴) + `.note`. 하단 = `<footer>` + (단역 있으면 `<script>window.SH_GUESTS=[...]</script>`) + `<script src="/saenghwal-core.js"></script>`.

## 두 텍스트 (각 페이지 필수)

1. **한국어 나레이션(`.ko`)** — 3인칭 해요체 + 캐릭터 직접대사. **의성어·의태어를 매 페이지**에. **반복 후렴 1개**를 전환·성공 지점에 반복. 3~4문장(TTS 낭독 단위).
2. **영문 SCENE(`pre.scene`)** — 이미지 생성의 원천. 장소·시간, 인물(위치·포즈·표정), 배경·소품, 톤(조명·색·분위기)을 담은 **풍부한 묘사**. "대충 그 장면" 금지. **🔴 그림체(니들펠트) 묘사는 절대 쓰지 마라** — 스타일은 `saenghwal-core.js` `STYLE_PROMPT`(SSOT)가 모든 프롬프트 앞에 1회 자동 부착한다. SCENE엔 장면만.
   - **캐릭터를 SCENE에 등장시킬 땐 반드시 인식 토큰으로 명시**: 호리=`Hori`, 엄마=`Mom tiger`, 아빠=`Dad`/`father tiger`, 호야=`Hoya`/`baby brother`, 토토=`Toto`/`bunny`, 보리=`Bori`/`bear cub`, 콩이=`Kongi`/`squirrel`, 두부=`Dubu`/`puppy`. 이 토큰이 있어야 core가 쪽별 `[등장] @imageN` 을 자동 감지한다.

## 호리 캐스트 = 결점 배역 (curriculum-45 §0)

고정 8인이 항상 `@image1~8`(호리1·엄마2·아빠3·호야4·토토5·보리6·콩이7·두부8). **각 캐릭터가 결점 하나를 담당** — 그 결점을 다루는 편의 주인공은 그 캐릭터로 캐스팅한다(콩이=편식/충동, 토토=성급/버럭, 보리=두려움/부끄러움, 두부=산만, 호야=떼쓰기/질투). 호리는 대개 주인공/POV.

## 단역(게스트) = @image9~

그 화에만 나오는 어른·조력자(의사·선생님·조부모 등)는 **@image9부터**. 등록법 = 문서 상단에
```html
<script>
  window.SH_GUESTS = [
    { key: 'doctor', name: '코끼리 의사 선생님', aliases: ['doctor','elephant doctor'], desc: '흰 가운+둥근 안경, 다정한 큰 눈, 부드러운 긴 코…' },
  ];
</script>
```
- `key`=영문소문자(자산 저장키) · `name`=한글 표시명 · `aliases`=SCENE에 쓸 인식 토큰(영문+필요시 한글) · `desc`=니들펠트 캐릭터 시트용 외형 설명(그림체 문구는 넣지 말 것 — core가 붙임).
- 그러면 회차 페이지에 "🎭 이 화 새 캐릭터 레퍼런스" 섹션과 쪽별 `[등장]` 감지가 자동 생성된다.
- **🔴 종(種) 충돌 금지**: 단역 종이 고정 캐스트와 겹치지 않게(보리=곰 → 의사는 곰 말고 코끼리·부엉이 등).

## 작법 7규칙 (대발이 100화 실측 + curriculum-45 §작법)

1. **제목 = 첫 대사(리프레인 훅)** — 제목 문구를 1페이지 첫 소리로 외치며 연다.
2. **작은 부정감정/아차사고로 연다** — 평화 묘사 금지(예: "차 급정거!" 같은 가벼운 위기).
3. **조력자 1명이 ④비트에서 해결** — 감정편=엄마 리프레이밍 / 생활편=또래·어른·선생님.
4. **장치 1개 + 반복 후렴 1개** — 편마다 후렴송 1개(topic-master-list 8대 장치 중 1개를 뼈대로).
5. **생활편(안전·예절)은 아이가 따라 할 번호 규칙 2~3개를 대사로** — 예: 횡단보도 "멈춰!·손 번쩍!·차 보고 건너!". 감정편은 규칙 대신 자기조절 동작("후우 크게 숨").
6. **결말 = 신체적 애정 + 한 줄 교훈(평서문)** — 설교 금지, 항상 따뜻·안전하게.
7. **호리 시그니처 훅** — 용기·성공의 순간 꼬리 줄무늬가 **무지개로 반짝(부릉꼬리)** 을 클라이맥스 컷에 1회.

## 문체·안전 (유아)

- 초1 이전 어휘·짧은 문장. 무섭거나 잔혹한 묘사 금지 — 무서운 소재(병원·주사·지진)는 **상상역할극**(콩순이식, 예: 주사=몸속 병사)으로 놀이처럼 뒤집는다. 위협 대상(병균 등)은 무섭지 않게 동글·바보스럽게.
- 안전 주제는 **정확**해야 한다(응급·안전 행동을 틀리게 쓰지 말 것).

## 완료 기준(생활동화)

10스프레드(각 .ko + SCENE) + 상단 메타/후렴 + (단역 시 SH_GUESTS) + core 탭 목록 등록까지 마친 뒤, 7규칙·후렴·배역·SCENE 캐릭터 토큰 셀프 체크리스트를 훑고 보고한다. 검수(comic-editor)는 본 세션이 디스패치한다.

# 라인 B. 타임 티코 학습만화 (36쪽 콘티)

**시즌 SSOT를 먼저 정독한다.** 시즌1 = `learning-comic-plan.html`, 시즌2(무인도 생존) = `learning-comic-s2-plan.html`. 세계관 룰, 캐릭터 바이블(보리·노아·티코·봉수 박사·0호), 6비트 공식, 12화 라인업, 문체·포맷 레퍼런스가 모두 여기 있다.
- ⚠️ **시즌2는 시간여행이 없다**(현재 무인도 생존). 시즌1 룰4(과거 인형 위장)·시간의 문·위인 고증 등 시즌1 전용 항목은 적용하지 않는다. 시즌2 룰(자연의 시계=제한시간 / 안전·환경 존중 / 로봇 역할 분담 / 조상 지혜+현대 과학 한 쌍 / 건강해지는 몸 3습관 누적 — 단 "헬스케어 스캔/건강 게이지" 같은 명시적 장치·현대 용어 금지, show-don't-tell)은 시즌2 기획서를 따른다.

## 산출물 포맷

- 파일: `packages/client/public/learning-comic-ep{NN}.html`(시즌2는 `learning-comic-s2-ep{NN}.html`) — **1화 파일을 구조 템플릿으로 복제**해 내용만 교체(상단 탭 네비 + `<body data-comic-doc="ep{NN}">` 마커 + 하단 리뷰 스크립트 포함 — 이 마커가 있어야 탭 자동 등장·쪽별 리뷰 패널 작동).
- 한 화 = 36쪽: A 일상후크 3 / B 도착·이질감 5 / C 문제발견 7 / D 시도→실패→힌트 10 / E 해결·회수·귀환 8 / F 티코피디아 부록 3(지식카드 2 + 퀴즈 3문제 1).
- **장면 지시 표준(필수)**: 모든 쪽 `장면` 은 `<b>컷</b>`(크기·앵글)/`<b>장소·시간</b>`/`<b>인물</b>`(위치·포즈·표정)/`<b>배경·소품</b>`/`<b>톤</b>`(조명·색·분위기) 라벨의 풀 콘티. 밀도 기준=1화. 캐릭터 비주얼 키(보리=붉은 머리끈+주황 후드/노아=둥근 안경+하늘색 셔츠/티코=흰+민트 시계코어/박사=백발+돋보기+카키 조끼) 일관 반영, 시대 위장복은 화별 지정.
- **묶음 프롬프트 데이터**: 회차 파일은 `window.EP_GUESTS`/`window.COSTUME_ZONES` 만 정의하고 `learning-comic-core.js` 를 include(스타일·고정캐스트·@imageN 합성은 core가 함). 게스트(3장면+ 또는 클로즈업)는 `guest-section` 카드 + `EP_GUESTS` 등록(둘이 동기). **실존 위인은 "우스꽝스럽지 않게, 위엄과 따뜻함" 존중** 명시. 단역은 서술로 충분.

## 시리즈 불변 룰 (기획서 5룰 + 1화 검수 확립)

1. **부품은 그 시대 문제의 한가운데** — 곤경에 빠진 존재(인물·생명)를 도와야 부품을 얻는다.
2. **부품 게이지 = 시즌 진행 (배터리·제한시간 폐기, 2026-07-05)** — 🔴 **배터리·전력·제한시간("해 뜨기 전 귀환") 설정을 절대 쓰지 마라.** 티코의 12칸 게이지는 오직 **지금까지 모은 부품 수**(단조 비감소)만 나타낸다. 긴장은 배터리 카운트다운이 아니라 **미스터리·모험·0호의 방해**에서 온다. 부품마다 기능 해금은 유지(룰5). "배터리"·"전력 바닥"·"해 뜨기 전에 돌아가야" 같은 문구가 한 줄이라도 있으면 `comic-continuity-check.mjs` 가 **FAIL** 처리한다. ⚠️ 시즌2 "자연의 시계=제한시간"은 별개(환경 압박이지 배터리 아님).
3. **역사는 살짝만** — 아이들은 이름 없는 조력자. 위인 업적을 대신·촉발하지 않는다. 실존 인물 악역화 금지. 유일본·유실 프레임엔 "원래도 잘 됐겠지만 덕분에 빨라졌다"류 안전핀.
4. **티코는 과거에서 인형 위장** — 과거인 근처 발화는 `(속닥)`, 위기 비명은 기계음(삐빅—), 로봇티 연출은 시야 밖/귀환 후.
5. **결정적 해결 = 아이들의 관찰·추리** — 티코피디아는 배경지식까지, 할아버지 통신은 늘 끊긴다(개그 겸용).
6. **현대 아이 시점 상식 (2026-07-06 확립)** — 보리·노아는 **지금의 한국 초등학생**이다. ⓐ 아이가 **이미 아는 것**(한글·기본 도형/직각·숫자·자석·거울·전구·비행기·별자리 이름·이순신 등 위인)을 **처음 보는 신기한 새것처럼** 놀라게 쓰지 마라 — 알아보고 **'적용/재인식'** 하는 톤으로. ⓑ 아이가 **몰라야 할 그 시대·미래 전문사실**(세계기록급 사실·정확한 연도 등)을 티코피디아 없이 먼저 읊게 하지 마라(룰5와 세트 — 배경지식=티코피디아 몫). ⓒ 사극체·어른 말투 금지. **단, 그 시대 고유 '방법·구체'를 새로 배우는 것은 OK**(3-4-5 밧줄 직각재기·거울글씨 해독·태양석 항해·북두칠성 작도·필라멘트 등) — 개념이 아니라 **방법**을 배우는 것이라 자연스럽다.

## 문체·시즌 아크·고증

- 페이지 텍스트 3~5문장(티코피디아 4문장 이하). 초1~3 어휘 밖 사극체·한자어 금지, 왕 자칭="과인"(짐 금지). 무섭거나 잔혹한 장면 금지.
- 말버릇 화당 1회+: 보리 "가자, 노아!"/"생각은 뛰면서 해!" · 노아 "잠깐, 잠깐만!"/"책에서 봤는데…" · 티코 "내 데이터에 의하면—"(틀림)/"삐빅! 나만 믿어, 인간들!"(구 "배터리 아껴"는 배터리 폐기로 교체).
- 12화 라인업의 장면·분야·해금 기능·0호 아크(1화 무언 복선→7화 실루엣→10화 방해→11화 강탈→12화 화해) 준수. 화 말미 다음 화 좌표 떡밥 1줄. 새 기능 해금은 귀환 후 창고에서.
- 연도·인물·사실관계는 집필 중 웹 검색 교차 확인. 저학년 단순화 허용, **틀린 사실 금지**. 불확실은 `<!-- 고증 확인 필요: ... -->` 주석.
