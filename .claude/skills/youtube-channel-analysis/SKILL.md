# 유튜브 채널 분석

## 🔴 절대 규칙 — n=1 결론 금지

**내 채널 데이터만으로 "이 장르/포맷은 유튜브에서 안 된다"고 결론내지 말 것.**

내 채널 숫자는 전부 *내 실행 결과*라, **시장이 안 되는 건지 우리가 못한 건지 구분할 수 없다.** 그 구분은 오직 **같은 장르 벤치마크 채널**과 비교해야 나온다.

### 실패 사례 (2026-07-24, 반드시 기억)

탱고북스 데이터만 보고 "명작 오디오북 롱폼은 유튜브에서 승산 없다 / 쇼츠에 집중하라 / 아동용은 구조적으로 성장이 느리다"고 단정했다. 사용자가 냠냠동화(@YumYumStory) 하나를 제시하자 **네 가지 주장이 전부 뒤집혔다**:

|           | 냠냠동화 (2.5개월) | 탱고북스 (4개월) |
| --------- | ------------------ | ---------------- |
| 총 조회   | 837,109            | 5,043            |
| 롱폼 평균 | **15,655**         | 44               |
| 쇼츠 평균 | 922                | 74               |

냠냠은 **롱폼이 쇼츠보다 17배** 잘 됐고, 댓글 0(아동용 설정)인데도 83만이었다.
→ 장르·포맷·아동용 문제가 아니라 **주제 선택과 제목**이 문제였다.

**교훈: 근거 대비 확신을 과하게 실었다. 벤치마크 없이 시장 판단을 말하지 말 것.**

## 분석 절차

### 1단계 — 벤치마크부터 (내 채널보다 먼저)

같은 장르에서 **잘 되는 채널 3~5개**를 먼저 뽑는다. 사용자에게 아는 채널을 물어보거나 검색한다.

### 2단계 — 같은 스크립트로 양쪽 덤프

```bash
# 내 채널
pnpm --filter @tangobook/server exec tsx scripts/analyze-youtube-channel.ts

# 경쟁 채널 (공개 데이터, 인증 불필요)
pnpm --filter @tangobook/server exec tsx scripts/analyze-youtube-channel.ts --handle=@ChannelHandle
```

출력: 영상별 조회수·길이·발행일 + 형식별/시리즈별/월별 집계.

### 3단계 — 비교 축 (추측 금지, 실측만)

- **형식별 평균** (롱폼 vs 쇼츠) — 어느 쪽이 본질인지
- **길이** — 유튜브는 시청시간을 보상한다
- **주제** — 상대 히트작 상위 10개의 *주제*를 나열해볼 것
- **제목 구조** — 키워드 밀도
- **발행량 대비 평균 조회수** 추이

### 4단계 — 같은 날 비교로 자기잠식 확인

하루에 여러 개 올렸다면 **같은 날 올린 것끼리** 비교한다(영상 나이 변수 제거).
탱고북 실측: 하루 2개 올리면 **유튜브가 사실상 1개만 민다**. 두 번째는 0~9회.
4개를 한 날에 올렸더니 `223 / 203 / 192 / 27` — 넷째가 죽었다.

## 검증된 사실 (탱고북 + 냠냠동화 실측)

### 제목 = 조회수의 1차 결정 요인

어떤 전략을 택하든 이건 항상 맞다.

```
게 · 고래 · 거미 · 개미            →  0~4회      (메타 폴백, 검색어 아님)
01. 골고루 먹으면 무지개 힘!        →  2회        (내부 번호 + 검색어 없음)
람포린쿠스를 아나요?               →  223회      (공룡 이름 = 검색어)
무찌르자 충치균 | 양치 습관 동화     →  78,068회   (육아 검색어 명시)
```

**성공 공식** (냠냠동화):
`[브랜드] 제목 | 시리즈명 | 주제 키워드 | 상황 키워드 | 어린이 동화책 읽어주기`

핵심은 **부모가 실제로 검색하는 말**을 넣는 것 — `편식`, `양치 습관`, `배변훈련`, `유아 성교육`.
귀여운 제목(`치카치카 쓱쓱!`)은 검색 진입로가 0이다.

### 주제 선택

유아 콘텐츠에서 가장 잘 팔리는 건 **부모의 실제 육아 고민**이다 — 배변실수·양치거부·짜증·성교육·안전.
세계명작(신데렐라·인어공주)은 검색 수요는 있으나 **수백 채널이 같은 걸 올려 차별화가 없다.**

### 아동용(Made for Kids)

성장을 막지 **않는다**(냠냠동화가 반례). 다만 댓글·알림·최종화면이 꺼지므로 유입 설계를 외부(설명란 링크·타 채널)로 돌려야 한다.

## 🔴 현재 데이터 한계 — 넘겨짚지 말 것

우리 OAuth 스코프는 `youtube.readonly` 라 **공개 통계(조회수·좋아요)만** 얻는다.

**없는 데이터**: 노출수, **CTR**, 평균 시청 지속률, 트래픽 소스, 이탈 그래프.

→ 따라서 다음은 **추측이며, 추측이라고 명시해야 한다**:

- "썸네일이 문제다" (CTR 없이는 모름)
- "영상이 지루해서 이탈했다" (지속률 없이는 모름)
- "검색에서 안 잡힌다" (트래픽 소스 없이는 모름)

확정하려면 `yt-analytics.readonly` 스코프 추가 + 채널 OAuth 재동의가 필요하다
(`packages/server/src/providers/youtube.provider.ts` 의 `SCOPES`).

## 보고 원칙

- 숫자는 실측만. 추측은 "추측"이라고 라벨을 붙인다.
- 전략 판단(어느 라인을 밀지)은 벤치마크 비교 후에만.
- 어느 가설이 맞든 동일하게 옳은 조치(제목 키워드 등)를 먼저 제안한다 — 사용자가 내 흔들리는 전략 판단에 베팅하지 않아도 되게.
