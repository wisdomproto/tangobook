# 이미지 생성 — GPT / krea2

## 어느 쪽으로 갈까

| | GPT | krea2 |
|---|---|---|
| 한 장 | ~90초 | ~40초 |
| 여러 칸에서 **같은 인물** | **유지된다** | 시트를 물려야만 유지 |
| 지정한 얼굴색(붉은 얼굴 등) | **먹는다** | 실측에서 계속 실패 |
| 투명 배경 | **진짜 알파** + 검증 | 체커보드를 «그려» 놓는다 |
| 군중·조연 얼굴 | 그려진다 | 유령·마네킹으로 샌다 |
| 비용 | ChatGPT 구독 한도 | 전기값 |

🔴 **기본은 GPT.** krea2 는 ①대량으로 싸게 돌릴 때 ②GPT 한도가 닳았을 때 ③로컬이어야 할 때.

## 돌리는 법 — 이 스크립트로만

```bash
node ~/.claude/skills/image-gen/scripts/gen.mjs gpt \
  --prompt "..." --out out/a.png [--ref sheet.png] [--transparent]

node ~/.claude/skills/image-gen/scripts/gen.mjs krea2 \
  --prompt "..." --out out/a.png [--ref sheet.png] [--size 1024x576] [--seed 1234]
```

🔴 **러너를 직접 부르지 마라.** 두 경로 다 산출물을 엉뚱한 데 떨군다 — GPT 는 샌드박스가 지정
경로 복사를 막아 `~/.codex/generated_images/<세션>/` 에 남고(그래서 «성공했는데 파일이 없다»가
된다), krea2 는 언제나 `ComfyUI/output/` 에 쓴다. 이 스크립트가 그걸 집어다 `--out` 으로 옮긴다.

## GPT 경로

- **ChatGPT Plus 이상 필요.** Free 는 이미지 생성이 제외돼 있고, 로그인·진단이 전부 초록이어도
  생성만 거절된다. 확인법 = Codex 에게 **자기 도구 목록을 말하게** 하면 `image_gen` 유무가 나온다.
- 로그인 = `codex login` (브라우저). `codex login status` 로 확인. 🔴 **API 키를 쓰지 마라** —
  그건 별도 과금되는 Images API 로 새고, gpt-image 스킬이 막아 두었다.
- 플랜을 올린 직후엔 토큰이 만료돼 401 이 날 수 있다 → `codex login` 다시.
- 이미지 턴은 **일반 턴보다 3~5배 빨리 한도를 먹는다.** 한도에 닿으면 재시도·폴백 없이 거절된다.

## krea2 경로

- **ComfyUI 가 떠 있어야 한다**(127.0.0.1:8188). 안 떠 있으면 스크립트가 띄우는 법을 알려 준다.
  모델 로딩까지 30~90초.
- 🔴 **`--prompt-file` 은 「한 줄에 한 프롬프트」다.** 여러 줄로 주면 **문단마다 따로 생성**된다
  (실제로 문단 8개가 조각 그림 8장이 됐다). 이 스크립트가 한 줄로 합쳐 준다.
- 🔴 **`--ref` 는 필수**이고 파일이 `ComfyUI/input/` 에 있어야 한다. 레퍼런스가 없으면 스크립트가
  중립 한 장을 만들어 자리를 채운다.
- 🔴 **`krea2_identity_edit_v1` LoRA 없으면 모자이크 블록 아티팩트.** 스크립트가 항상 얹는다.
- 🔴 **Krea2Edit 는 「소스 보존」 도구다.** 3칸 시트를 통째로 물리면 장면을 무시하고 시트를 그대로
  재현한다. **인물 하나만 잘라** 물리면 장면이 산다(그 조건에서 실제로 살았다).
- 커스텀 노드 `comfyui-krea2edit` 를 쓰지 마라 — 네이티브 `TextEncodeQwenImageEditPlus` 가 상위 호환.

## 🔴 여러 칸·여러 쪽에서 같은 인물을 그릴 때

**전신 시트를 먼저 굽고, 그걸 모든 칸에 `--ref` 로 물린다.** 이게 전부다.

한 지면 다섯 칸을 만들며 실측한 것:
- 시트를 물린 칸만 의도한 등신(2.5~3)이 나왔고, **안 물린 네 칸은 7~8등신으로 샜다.**
- 🔴 **클로즈업을 레퍼런스로 쓰지 마라.** 가슴 위만 있으면 비례 정보가 없어서, 그걸 물린 칸이
  어른 비례를 따라간다. 레퍼런스는 **발끝까지 보이는 전신**이어야 한다.
- 인물이 둘 이상인 칸은 각자 시트를 다 물린다(krea2 는 3장까지).

## 프롬프트에서 실제로 먹은 것 / 안 먹은 것

- ✅ **색은 사물에 빗대라** — 「genuinely RED, not flushed skin」은 계속 실패했고,
  「잘 익은 대추의 깊고 따뜻한 붉은색, 무대 분장의 붉은색」은 한 번에 먹었다.
- ✅ **등신은 재는 법까지 적어라** — 「정수리에서 턱까지가 키의 2/5, 턱 아래는 1.5 머리 높이」.
  🔴 **수염·머리카락을 머리로 세지 말라**고 못 박을 것(긴 수염이 있으면 몸이 늘어난다).
- ✅ **선 계약을 넣어라** — 「형태마다 가는 먹선, 굵기가 변한다, 색은 선 «안»에 들어간다,
  유화도 에어브러시도 아니다」. 안 넣으면 윤곽 없는 유화로 돌아온다.
- ❌ **「flat pale silhouettes」류로 군중을 지시하지 마라** — 흰 유령 덩어리가 된다.
  「작게, 단순하게, 그러나 다른 사람들처럼 온전히 칠해서」로 쓴다.
- ❌ **투명 배경을 krea2 에 시키지 마라** — 투명 표시용 체커보드를 «그려» 놓는다.
  GPT 의 `--transparent` 는 알파를 검증까지 한다.
- 🔴 Avoid 에 `panel borders, gutters, frame lines` 를 넣어라(만화 칸을 만들 때).
  테두리는 합성이 그린다 — 모델이 그리면 흔들리고 홈통 폭이 제각각이 된다.

## 만화 지면(여러 칸 + 말풍선)

**한 장으로 뽑지 않는다.** 칸을 따로 생성해서 지면에 앉힌다 — 1448px 를 다섯으로 쪼개면 칸당
픽셀이 무너지고, 모델은 칸 테두리를 구조로 안 그린다.

합성은 PIL 로 한다(puppeteer 불필요). 🔴 **칸 모양은 마스크가 정하므로 직사각형일 필요가 없다** —
재단 물림·비스듬한 분할·원형 인서트·테두리 넘는 풍선이 전부 생성 비용 0이다.
한글 말풍선 글자는 `C:/Windows/Fonts/malgun.ttf`.

작동하는 합성 예시 = 이 폴더의 `compose-page.py`.
